============================================================
CSS スニペット連動の必須要素（2026-05-21 〜）

Vault root リポジトリ `HIDEPON-UMG/obsidian-newsgrasp-vault` の

【Reading View カード化のための契約】

1. **frontmatter** に最低 `categoryId` / `accent` / `glyph` を含む
2. **h1**: `# {GLYPH} {CATEGORY_JP} — {CATEGORY_EN}` 形式 1 行
   （CSS で背景グラデーション + 白文字バンドに変換）
3. **summary callout**: `> [!summary]` ブロック
   （CSS でアクセント色のソフトボックス）
4. **hr 区切り**: 各記事カードの前後に `---`
5. **h3 見出し**: `### [{SCORE}] {TITLE}` 形式
   （CSS でニュースカードの上端 = `border-radius` 上 12px + 影）
6. **メタ段落**: h3 直後の段落で `📅 {YYYY-MM-DD} {HH:MM} · 📰 {SOURCE} · 🔗 [元記事]({URL})`
   （CSS でカード本体に取り込まれる）
7. **タグ段落**: メタ段落の直後にタグだけが並ぶ段落 (`#cat/... #co/... #score/{高|中|低}`)
   （CSS でカード本体に取り込まれる、pill 表示）
8. **サムネ画像**: タグ段落の直後で `![thumb]({URL})` 形式
   - **`alt` テキストは必ず `thumb`**（CSS の `img[alt="thumb"]` セレクタが識別子）
   - 取得失敗時も `null` プレースホルダ画像 URL を入れる（サムネ自体を省略しない）
9. **箇条書き**: サムネの直後に `-` で 3 件
   - 順に `【事実】：` / `【背景】：` / `【展望】：` で始める
   - `[[キーワード]]` と `**重要数値**` と `__重要文__` を含む
   - CSS でカードの下端 = `border-radius` 下 12px + 影を閉じる
10. **tip callout（任意）**: 関連波及があれば `> [!tip] 🔗 関連: {AXIS}`
    （CSS で軽量な border-left スタイル）
11. **前後号ナビ + フッター**: ファイル末尾

    - フッター `*🤖 Auto-generated by News-Grasp Runner ...*`
      （CSS で透明度を落として中央寄せ）

【CSS スコープ外（自由に追加可）】

- bullets 内の追加マーカー（`[[link]]` `__bold__` 以外）
