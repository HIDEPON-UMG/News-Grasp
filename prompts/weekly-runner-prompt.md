本リポジトリ内の prompts/weekly-research-system.md を Read で読み込み、その指示に厳密に従って、**いま（このプロセス内で）週次 DeepDive レポートを 1 本生成してください**。これは「構築途中の説明」でも「将来の予定」でもなく、**今この実行で完遂すべき実タスク**です。無人の自動実行なので、ユーザーに確認や質問を返さず（AskUserQuestion は使わない・使えない）、テーマ選定・リサーチ質問・採否はすべて自分で決めて最後まで進めてください。

具体的な手順: (1) JST で当日日付と issue（YYYYMMDD）を確定 → (2) `.venv\Scripts\python.exe tools\get_recent.py` で直近 7 日の記事を取得し、`data/articles.jsonl` の該当エントリの entities/topics を頻度集計して、速報性×奥行き×波及性で深掘りテーマを 1 つだけ選定 → 単一のリサーチ質問に言語化 → (3) **fan-out は使わない**（並列 Task 禁止・前回 415 万トークン失敗の真因）。この単一セッションで直列に WebSearch（英語＋日本語）→ WebFetch で一次ソースに到達する。**WebFetch は合計 6 件以内・1 ラウンド hard cap**（6 件で打ち止め、重複 fetch 禁止）。対向検証は別エージェントを立てずインラインで行い、裏が取れない数値・伝聞は「未確認」と明記するか落とす（推測で数字を埋めない）→ (4) `mkdir -p digest/DeepDive` のうえ `digest/DeepDive/{当日のJST日付}-DeepDive.md` を、スカラー frontmatter ＋ 3 節（## 背景 / ## 深掘り / ## 注目点 ＋ ## 要約 / ## 参考リンク）＋ 所定の fenced block（背景に timeline・players・**relations（関係図・必須）**、深掘りに **chart 最低 1（うち 1 つは時系列の数値変遷）と table（データ表・必須）**を source 必須で、注目点に decision を issue/options/deadline/decider の 4 キー必須）付きで生成 → (5) `git -c user.name="HIDEPON" -c user.email="hideki.kusunoki@gmail.com"` で digest/DeepDive/ と data/_status.md を add → commit まで実行（**push はしない**。bat が代行する）。

リポジトリに digest/DeepDive/ フォルダや週次 runner bat が未整備でも、それは想定どおりです（いま構築中のため）。必要なフォルダは mkdir -p で作成し、ためらわずに 1 本生成してください。直近 7 日が薄く深掘り価値のあるテーマが 1 つも立たない場合に限り、digest を作らず data/_status.md に休載行を 1 行追記して終了してください。予算（--max-budget-usd）や時間に達した場合は、md を 3 節そろえて生成済みなら commit して終了、未完成なら休載扱いにしてください。
