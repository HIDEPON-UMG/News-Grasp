# News-Grasp 文体ガイド

この文体ガイドは Reporter / Editor / Model Evaluation の共通正本である。

## 必須方針

- 翻訳調禁止。英語ニュースの語順を残さず、日本語ニュースとして自然な主語・述語に整える。
- 文末反復禁止。「〜した」「〜となった」「〜する見通し」が連続する場合は、因果・対比・次の焦点で文型を変える。
- 冗長な接続句を削減する。「一方で」「また」「さらに」は、本当に論点が切り替わる場合だけ使う。
- 数字は単独で置かず、比較軸・意味・変化点とセットで見せる。増減、前回比、対象期間、誰に効く数字かを明示する。
- `title_ja` は直訳ではなく自然なニュース見出しにする。固有名詞、動き、意味が一読で分かる短い見出しにする。
- News-Graspらしい「何が動き、なぜ重要で、次に何を見るか」を必ず出す。

## 編集観点

- 事実を盛らない。裏取りできない含意は落とすか「未確認」と明記する。
- 強調は 3 階層を使い分ける。主役は `[[...]]`、重要変化は `**...**`、読者が次に見る論点は `__...__`。
- 金融・政策・決算は、数字の意味を「価格」「期待」「需給」「規制」「採算」のどれに効くかで説明する。
- 文体調整は全件一律にしない。不自然さ、文末反復、冗長さ、`title_ja` の硬さが残る記事だけを Editor repair 対象にする。
