§01
¥ FOREIGN EXCHANGE / 為替

165円観測とCPIが同じ方向を向く

FACT 事実・概要

白井さゆり氏は、FRBが年内に利上げへ転じればドル円は163〜165円台へ進み得るとみており、円安の終点がまだ遠いとの警告を出した。

CONTEXT 背景・要点

市場では9月までの利上げ確率が75%前後まで高まり、投機筋の円ショートは15万枚超と2024年7月以来の高水準に積み上がっている。

OUTLOOK 影響・展望

同氏は日銀の次回利上げを10月か12月の0.25ポイントと予想したが、介入への疑念と財政不安が残る限り円の反転力は弱いと整理した。

→ §01 為替 詳細を読む
§02
◆ ARTIFICIAL INTELLIGENCE / AI

防御、常駐、悪用が同時に進む

FACT 事実・概要

Daybreakは脆弱性の検出だけでなく修復までを自動化する方向を打ち出し、AIセキュリティの主戦場をアラート生成からパッチ適用へ移した。

CONTEXT 背景・要点

更新版のCodex Securityは深いスキャン、検証、修正案生成を一体で回せるようになり、開発フローの中で防御を完結させる色合いを強めた。

OUTLOOK 影響・展望

GPT-5_5-CyberはCyberGym 85.6%などの指標を示して正式版へ進んだが、利用対象を信頼済み防御者に絞る設計で能力と統制を両立させている。

→ §02 AI 詳細を読む
§03
⌗ IT & CONSULTING / IT

AIを回す前提を整える

FACT 事実・概要

ファイブ・アイズはAIがサイバー攻撃力を数カ月単位で押し上げると共同声明を出し、企業に防御体制の前提見直しを迫った。

CONTEXT 背景・要点

声明は取締役会レベルでのリスク管理、不要な外部接続の削減、旧型ソフト更新、本人認証の厳格化を具体策として並べた。

OUTLOOK 影響・展望

防御側にもAIツール統合を促し、脆弱性検知と監視を自動化できる企業ほど被害と対応コストを抑えやすいという競争条件が鮮明になった。

→ §03 IT 詳細を読む
§04
◎ MOBILITY / モビリティ

走る車両より、通すルール

FACT 事実・概要

ロンドンは英国政府の受け付け開始で、米中ロボタクシー企業が国外で最初に競う市場になりつつある。

CONTEXT 背景・要点

本文では日本のGOにも触れつつ、ライドシェアすら制度化できていない日本との差が鮮明になった。

OUTLOOK 影響・展望

読者にとって重要なのは、ロボタクシーの勝敗が車両性能だけでなく規制と運行許認可の速さで決まる点だ。

→ §04 モビリティ 詳細を読む
§05
⬢ MANUFACTURING / 製造

量産の入口をどこに置くか

FACT 事実・概要

TOTOは半導体製造装置向け部材事業に今後5年で800億円規模を投じ、住設企業から高収益セラミック事業への軸足移動を鮮明にした。

CONTEXT 背景・要点

26年3月期はセラミック事業売上674億円に対しセグメント利益289億円で、連結営業利益537億円の過半を稼ぐ構造が見えた。

OUTLOOK 影響・展望

神奈川の研究拠点と福岡県豊前市の焼成棟増設を進めており、AI向けデータセンター増設が部材増産の判断を後押しした。

→ §05 製造 詳細を読む
§06
■ ECONOMY / 経済

マクロの温度と利益の持続性

FACT 事実・概要

月例経済報告は景気判断を据え置く公算が大きく、2020年6月起点の拡大局面が73カ月に達する可能性を示した。

CONTEXT 背景・要点

中東情勢に伴う値上がり懸念が残る中でも、ガソリン補助金と設備投資の底堅さが個人消費の失速をいったん防いでいる。

OUTLOOK 影響・展望

AI普及を追い風にした投資が支え役で、後退入りを示す決定打が乏しいぶん、実感なき長期拡大が続くかが次の焦点になる。

→ §06 経済 詳細を読む
§07
▶ GAMING / ゲーム

発売より、その後の回し方

FACT 事実・概要

Steam MachineはKOMODO経由で国内販売が始まり、512GBが18万9980円、2TBが24万9980円と価格帯まで明確になった。

CONTEXT 背景・要点

前号では海外発売が主題だったが、今回は日本でも順番待ちが発生したことで、Valveの据え置きPC需要が実需ベースで試され始めた。

OUTLOOK 影響・展望

Steam Controller同梱やSteamOS前提の設計まで含めると、Valveはデスクトップ級体験をリビングへ持ち込む販路を本格的に固めにきた。

→ §07 ゲーム 詳細を読む
