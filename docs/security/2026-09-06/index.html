TOP STORY 2026-11-09 · www.bleepingcomputer.com 95

N-able、N-centralのゼロデイ33件「Able2Shell」公開でホスト型環境を世界規模で停止

FACT
【事実・概要】
：独立研究者が11月8日、RMM基盤N-centralの未修正脆弱性33件と実証コードを「Able2Shell」として公開した。4つの攻撃チェーンのうち3つがリモートコード実行、1つがrootへの権限昇格に到達する。N-ableは9日に重大インシデントを宣言し、米州・欧州・アジア太平洋のホスト型環境を停止した。
CONTEXT
【背景・要点】
：検証対象はN-central Appliance 2026.4.0.31で、旧版にも影響が及ぶ可能性がある。ベンダーへの事前通知がない公開だったため、パッチではなく停止が先行する異例の対応となった。同社は9日15:15 UTC時点で悪用は未観測とし、ホットフィックスを開発中としている。
OUTLOOK
【影響・展望】
：MSP経由で多数の顧客ネットワークに届くRMMは、侵害時の波及範囲が桁違いに大きい。復旧時期は未定で、4時間ごとの状況更新が続く。利用企業は自社のMSPがN-centralを使っているかの確認が急務になる。

02 2026-11-09 · yourcyberbrief.com 85

CISA、悪用確認済みの脆弱性4件をKEVに追加 — GPUStack・FreeSWITCH・OpenSSH・IBMが対象

FACT
【事実・概要】
：米CISAは11月9日、悪用が確認された脆弱性を集めるKEVカタログに4件を追加した。対象はGPUStackの認証不備（CVE-2026-102895、9.8）、FreeSWITCHのコードインジェクション（CVE-2026-116779、9.8）、IBM Aspera Faspexの認可不備（CVE-2026-123218、9.8）、OpenSSHの不具合（CVE-2026-123158、8.1）で、連邦文民機関の是正期限は11月12日。
CONTEXT
【背景・要点】
：GPUStackではリバースプロキシ経由のアクセスでループバックアドレスを管理者として信頼してしまい、認証なしに管理者権限へ到達できる。「理論上の危険」ではなく悪用の実績があることがKEV入りの意味であり、OpenSSHの件はmusl libcかつPAMなしという特定構成でのみ成立する点も示された。
OUTLOOK
【影響・展望】
：KEVは全1,773件規模に達し、脆弱性管理の優先順位づけの基準になっている。実務では該当製品の利用有無の棚卸しと期限管理が焦点で、AI基盤（GPUStack）のような新しい資産が対象に入ってきた点も見逃せない。
