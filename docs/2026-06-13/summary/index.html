§01
¥ FOREIGN EXCHANGE / 為替

中央銀行の温度差がドル円の振れ幅を広げる

FACT 事実・概要

ECB（欧州中央銀行）がイラン情勢悪化に伴うエネルギー価格上昇を受け、約4年ぶりの利上げを決定。ラガルド総裁は「予防的措置であり強力・持続的な引き締めではない」と強調し過度の引き締め懸念を払拭。

CONTEXT 背景・要点

ヘッドラインインフレは4%台前半でピークアウトする見込みで、9月に追加利上げ後は様子見に転じる見通し。前回2022〜23年の利上げ局面と異なり物価の二次波及が限定的と分析し、比較的早期の対応が功を奏すると評価。

OUTLOOK 影響・展望

ユーロ円・ユーロドルへの影響として、ECBが利上げ継続を確約しない姿勢を維持しつつ日銀・FRBも動く週は、ユーロの方向感が定まりにくくドル円・クロス円の乱高下リスクが高まる局面と位置付けられる。

→ §01 為替 詳細を読む
§02
◆ ARTIFICIAL INTELLIGENCE / AI

価格競争と品質競争が同時に立ち上がる

FACT 事実・概要

OpenAIはAnthropicが同様の値下げに踏み切った場合、トークン料金を含む複数のコスト引き下げを検討中とWSJが報道——協議は初期段階と関係者

CONTEXT 背景・要点

両社はともにIPOを控えており、Anthropicは9650億ドル評価でIPO申請草案をSECに非公開提出——価格競争はコスト増と株主への説明責任という二重のジレンマを生む

OUTLOOK 影響・展望

AI市場での覇権争いはGemini・Claude・GPTの三つ巴の構図から価格軸の競争に移行しつつあり、開発者・企業ユーザーの調達コスト低下が現実味を帯びてきた

→ §02 AI 詳細を読む
§03
⌗ IT & CONSULTING / IT

コンサルは提案業から運用基盤業へ寄る

FACT 事実・概要

PwCコンサルティングは7月1日付で樋崎充副代表（51）が社長に昇格する人事を発表。安井正樹CEOは会長に就任し、2年ぶりの経営体制刷新となる。

CONTEXT 背景・要点

樋崎氏はSAPジャパン出身で複数のコンサルファームを経て2016年にPwCコンサルティング入社、2026年1月から副代表として地政学リスク・AI活用支援を牽引してきた実務型リーダー。

OUTLOOK 影響・展望

企業の課題が地政学リスク・AI・ESGと多様化するなか、テクノロジー×経営変革の双輪を回せる体制への移行がBig4全体のトレンドとなりつつある。競合各社の人事動向に波及する可能性がある。

→ §03 IT 詳細を読む
§04
◎ MOBILITY / モビリティ

自律走行はデモから商用の縁へ寄る

FACT 事実・概要

アステモ（日立・ホンダ・JIC Capital出資）が人とくるまのテクノロジー展2026で5つの技術柱を展示。SDV向けクラウド開発プラットフォームとADASカメラシステムを中核に据え、IoVプラットフォームとの統合を訴求

CONTEXT 背景・要点

脱レアアースモーターとインホイールモーターを「環境ドメイン」の核に据え、レアアース依存を断ち切ったEV駆動技術の量産化ロードマップを提示。サプライチェーン地政学リスクへの実装的回答として注目

OUTLOOK 影響・展望

二輪車向けにインホイールモーター・ADAS（カメラ）を初公開。四輪技術の二輪転用は市場規模が大きい新興国EV二輪市場を見据えた戦略的展開で、ホンダとの連携深化の一環

→ §04 モビリティ 詳細を読む
§05
⬢ MANUFACTURING / 製造

休載だが、サプライチェーンの再設計は続く

FACT 事実・概要

本日は製造カテゴリの新規掲載はないが、半導体、電池、車載部品の供給網はモビリティとITの裏側で常に動いている。

CONTEXT 背景・要点

工場の効率化とソフトの更新速度が分離できなくなった今、製造は「重い業界」ではなく「更新頻度の遅いIT」として再解釈される。

OUTLOOK 影響・展望

休載日は、その構造を見直す好機だ。

→ §05 製造 詳細を読む
§06
■ ECONOMY / 経済

物価と金利のねじれが企業の足元を変える

FACT 事実・概要

物価・金利・為替の三点セットは、マクロ統計としては静かでも、現場では調達コストと価格転嫁の両方を押し上げる。

CONTEXT 背景・要点

ECBやFedの文言変更、企業の想定為替の見直し、賃金交渉の継続が重なると、経済ニュースは景気の良し悪しではなく「負担の配分」を読む材料になる。

OUTLOOK 影響・展望

ECBやFedの文言変更、企業の想定為替の見直し、賃金交渉の継続が重なると、経済ニュースは景気の良し悪しではなく「負担の配分」を読む材料になる。

→ §06 経済 詳細を読む
§07
▶ GAMING / ゲーム

発表、買い占め対策、インディー躍進が同時に来た

FACT 事実・概要

FF7リメイク三部作の完結編『ファイナルファンタジーVII リベレーション』の Steam ストアページが Summer Game Fest 2026 で公開。2027 年春に Switch 2 / PS5 / Xbox Series X|S / PC（Steam・Epic Games Store）でマルチプラットフォーム同時発売 予定

CONTEXT 背景・要点

プレイアブルキャラクターにヴィンセント・ヴァレンタイン（声優: 鈴木省吾）とシド・ハイウインド（声優: 山路和弘）が加わり全パーティメンバーが集合。飛空艇ハイウインドで星全体を巡るオープンワールド構成が明らかに

OUTLOOK 影響・展望

前作『リバース』から規模をさらに拡大し、新バトルシステム・新エリアを搭載予定。現時点では価格未発表だが Steam ウィッシュリスト登録が解禁されている

→ §07 ゲーム 詳細を読む
