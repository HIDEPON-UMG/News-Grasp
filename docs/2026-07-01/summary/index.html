§01
¥ FOREIGN EXCHANGE / 為替

円安の先にある説明責任

FACT 事実・概要

円安 は 162 円台で重さが増し、政府の介入姿勢と日銀の警戒発言が同じ方向を向きました。

CONTEXT 背景・要点

【事実・概要】：USDJPYは162円台まで下落し、39年半ぶりの円安水準で日本経済新聞は政策不信と債券売りの共振リスクを報じた。

OUTLOOK 影響・展望

【背景・要点】：背景にはFedの高金利観測に加え、BOJの追加利上げが後手に回るのではないかという見方があり、為替だけでなく国債市場の信認も問われている。

§02
◆ ARTIFICIAL INTELLIGENCE / AI

配布網と認証が先に立つ

FACT 事実・概要

ソブリンクラウド で国産 AI が動き、生成 AI 利用クラウドの認定制度が始まり、OpenAI は Codex 向け入力デバイスを予告しました。

CONTEXT 背景・要点

【事実・概要】：ASPIC が 生成AI利用クラウドサービス向け情報開示認定制度 を新設し、申請受付 を6月30日に開始した。

OUTLOOK 影響・展望

【背景・要点】：18年分の認定運用実績と最新ガイドラインを踏まえ、AIガバナンス の可視化を進める狙いだ。2028年3月末まで手数料無料 として制度参加を促している。

→ §02 AI 詳細を読む
§03
⌗ IT & CONSULTING / IT

統制と理解が実装を決める

FACT 事実・概要

ガバメントクラウド の期限未達、AML 対応 SaaS、サイバー防衛 の経営課題化、BPS と SaaS 運用支援の一体化が並びました。

CONTEXT 背景・要点

【事実・概要】：ガバメントクラウド移行は全国1788自治体のうち1015団体が期限未達となり、地方システム標準化の主工程が今年3月末に収まり切らなかった実態が表面化した。

OUTLOOK 影響・展望

【背景・要点】：デジタル庁は事業者への発注集中とSE不足を主因に挙げ、自治体DXがクラウド選定より実装人材の供給制約に左右される段階へ入ったと示した。

→ §03 IT 詳細を読む
§04
◎ MOBILITY / モビリティ

安全条件と運行設計の再調整

FACT 事実・概要

自動運転 のペダル義務撤廃案と Waymo のリコール、Uber との提携終了は、技術の進歩 がそのまま商用拡張に直結しないことを示しました。

CONTEXT 背景・要点

【事実・概要】：NHTSAは、ブレーキペダルやハンドルを持たないADS専用車を対象に、足踏み式ブレーキ装置の義務を外す連邦基準改正案を示した。

OUTLOOK 影響・展望

【背景・要点】：現行制度ではメーカーが個別免除申請を出しても、年間最大2,500台の上限が量産の壁だった。TeslaやZooxのような無人前提車両は、ここが設計自由度のボトルネックだった。

→ §04 モビリティ 詳細を読む
§05
⬢ MANUFACTURING / 製造

拠点と工程を置き直す

FACT 事実・概要

日立建機 の中国 OEM 化、ニコン の ArF 露光装置、LIXIL の工場閉鎖、天津工場の拡張、トヨタ の電池セル特許が同居しました。

CONTEXT 背景・要点

【事実・概要】：日立建機は新ブランド「WIXIM」の第1弾製品で、東南アジア向け建機の製造を中国メーカーへ委託する方針を固めた。

OUTLOOK 影響・展望

【背景・要点】：油圧ショベル以外の需要が広がる一方で、中国勢がアジア市場でシェアを拡大しており、非主力機種を外部製造で補う戦略が必要になった。

→ §05 製造 詳細を読む
§06
■ ECONOMY / 経済

数字の改善と体感のずれ

FACT 事実・概要

景気判断 は維持されても、円安 と 米金利 の引き締め観測が家計と企業の受け止め方を揺らしました。

CONTEXT 背景・要点

【事実・概要】：円相場はロンドン市場で1ドル=161.96円割れまで下落し、政府は必要なら適切な措置を講じると表明した。

OUTLOOK 影響・展望

【背景・要点】：中東情勢と日米金利差が円売り圧力を強め、円安は輸入物価とエネルギー負担を通じて国内景気の採算を揺らしやすい。
