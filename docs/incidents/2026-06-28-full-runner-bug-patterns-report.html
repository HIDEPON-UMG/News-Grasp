02

問題の詳細と、なぜ起きたか

直接原因
復旧過程で SuccessProbeCommand を持たない wrapper lifecycle、repair handler scope、state reconciliation、current/historical URL liveness が連鎖して露出した。
なぜ起きたか
品質管理が単一 stop の復旧に寄り、runner / repair / state / report の横並び調査を同じ incident で強制できていなかった。
品質障害化
internal failure fallback overclaim が最も危険だった。外部障害ではない内部 Red を fallback success と混同すると、完全自走の仕様を破る。
非原因
最終的な build/publish-complete/2026-06-28.json は ok:true だったが、それは root cause を小さくしてよい根拠ではない。復旧事実、HTTP応答、local証跡をそれぞれ別の証拠として扱い、根本対策・publish完了・public proof の代替にしない。
証跡
scripts/ops/news-grasp-runner.ps1、tools/repair_coverage_matrix.py、tools/repair_registry.py、tools/historical_failure_scenarios.py、data/gate_attempts/2026-06-28.json、build/publish-complete/2026-06-28.json を根拠にする。
2次

reporting process も障害である。復旧レポートが E2E artifact collision と full runner bug pattern を同じ report に入れると、Class A-H の横並び調査が薄まり、次回の同型障害を検出できない。

05

恒久対応方針の網羅性と完璧性の担保

OK

完全自走を担保するには、単に当日 publish が Green になったことでは足りない。bug class、関連機能洗い出し、横並び調査、新規バグ候補、全体観点での対策を incident corpus と contract test に接続する必要がある。

Class A
E2E artifact collision / operational contamination

別 report で扱うが、full runner の入口前提として cross-check する。

Class B
wrapper completion vs child process termination

success probe と child lifecycle を contract 化する。

Class C
repair matrix / handler / artifact-scope mismatch

handler_unimplemented を Green にしない。allowed_artifacts と verify_gate を確認する。

Class D
state consistency / articles-digest reconciliation

data/articles、digest cards、distribution manifest を同じ date/HEAD で見る。

Class E
audio script quality / repeated closing drift

audio-script-length-patch と generation-quality を接続する。

Class F
internal failure fallback overclaim

content/artifact/local-tool は blocked_internal_quality_gate へ落とす。

Class G
current-day vs historical URL liveness responsibility

本日 DeepDive URL gate と履歴監査を分離する。

Class H
evidence observability / overbroad log handling failure

巨大 JSON 直読みではなく targeted evidence collector を使う。

STATE
Local Green / Publication Pending Approval / Public Verified

local validation と public publication を分離する。
