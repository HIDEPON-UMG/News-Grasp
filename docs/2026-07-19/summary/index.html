◆ ARTIFICIAL INTELLIGENCE / AI

利用枠がモデル選択を変える

FACT 事実・概要

Claude Fable 5の料金変更、Kimi K3、AI動画制作、岡山の6チーム25人の開発イベントが動いた。

CONTEXT 背景・要点

モデル性能の差だけでなく、計算費、信頼形成、課題設定、人とAIの役割分担が導入条件になる。

§03
⌗ IT & CONSULTING / IT

Consulting — AI基盤の拡大費用を測る

FACT 事実・概要

CONTEXT 背景・要点

AI評価の標準化も供給網移行も、技術の導入だけでなく監査、契約、データ、物流を変える。

OUTLOOK 影響・展望

§04
◎ MOBILITY / モビリティ

無人化の安全条件が増える

FACT 事実・概要

大阪メトロのEVバス190台・832件の不具合、Waymoの4都市展開、Zooxの105台更新、州法案が確認された。

CONTEXT 背景・要点

商用化は走行性能だけでなく、煙などの例外対応、更新管理、遠隔支援、ハード要件を含む。

OUTLOOK 影響・展望

Waymoの一般開放、Zooxの再発防止、NHTSA対応、州ごとのセンサー規制を追いたい。

→ §04 モビリティ 詳細を読む
§07
▶ GAMING / ゲーム

所有形態と継続運営の岐路

FACT 事実・概要

PlayStation新作のディスク生産終了方針と、A3!第五部の8月からの段階配信が発表された。

CONTEXT 背景・要点

流通はデジタルへ寄る一方、長期運営作品は新章や楽曲で継続利用の理由をつくる。

OUTLOOK 影響・展望

2028年までの互換性・ライセンス、中古市場、A3!の配信間隔とファン反応を確認したい。
