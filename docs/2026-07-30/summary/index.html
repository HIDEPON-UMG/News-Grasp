§04
◎ MOBILITY / モビリティ

充電網が復旧を支える

FACT 事実・概要

Tesla Japanが九州の急速充電設備を7月29日から8月4日まで無償開放した。

CONTEXT 背景・要点

充電網は移動手段だけでなく、災害時の地域インフラとして扱われる。

OUTLOOK 影響・展望

九州の復旧状況と、他社充電網が支援を広げるかを確認する。

→ §04 モビリティ 詳細を読む
§05
⬢ MANUFACTURING / 製造

停止後の再開条件を測る

FACT 事実・概要

トヨタ九州は南九州3工場を7月29日から31日まで停止すると発表した。

CONTEXT 背景・要点

余震と復旧状況を見ながら安全を優先し、完成車と部品の計画への波及を抑える。

OUTLOOK 影響・展望

工場の再開判断、部品物流、地域サプライヤーの復旧状況を確認する。

→ §05 製造 詳細を読む

■ ECONOMY / 経済

FACT 事実・概要

CONTEXT 背景・要点

OUTLOOK 影響・展望
