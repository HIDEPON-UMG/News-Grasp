「90日間ログ保持」はもう古い　VPNの脆弱性やActive Directoryを悪用するランサムウェアの実態と対策

FACT
【事実・概要】
：Mandiantの年次報告「M-Trends 2026」によると、初期侵入した攻撃者が実行グループへアクセスを引き渡す時間は2022年の8時間超から2025年には22秒へ短縮した。侵入経路の最多は脆弱性の悪用で32%、潜伏は約400日に及ぶ例もある。分業化した攻撃チェーンの速度が数字で示された。
CONTEXT
【背景・要点】
：攻撃者は誤設定のActive Directory証明書サービスを悪用して管理者権限を作り、バックアップや仮想化基盤を先に壊すことで復旧を妨げる。検知の目が届かないVPNやルーターなど境界機器が潜伏先になる。守る側の前提（90日のログ保持）が攻撃の滞在期間に届いていない点が核心だ。
OUTLOOK
【影響・展望】
：対策の焦点はログ保持の延長と境界機器の棚卸し、復旧基盤の分離に移る。攻撃の仕組みが分かるほど、平時の設計に割くべき投資の優先順位が明確になる。
