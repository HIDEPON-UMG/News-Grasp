§01
FOREIGN EXCHANGE / 為替

日銀が動いても、米金利が相場を引っ張る

FACT 事実・概要

日銀は物価上振れリスクを前面に出したが、ドル円は163円視野でなお強い。

CONTEXT 背景・要点

【事実】：日銀は政策金利を1%へ引き上げ、景気下振れより物価上振れリスクを前面に出した。円安がインフレ認識をどこまで押し上げるかが次の論点になる。

OUTLOOK 影響・展望

【背景】：内田眞一副総裁は原油高と企業間の価格転嫁を重視し、従来の様子見色が強い説明から一段とタカ派に寄った。

§02
ARTIFICIAL INTELLIGENCE / AI

家の中に入るAIは、使い方より入口設計が先

FACT 事実・概要

Google Homeの刷新で、Geminiは家庭の常設UIへ一歩進んだ。

CONTEXT 背景・要点

【事実】：Google Home スピーカーは6月25日発売、価格は16,800円。6年ぶりの専用機刷新で、Geminiを家庭内の常設入口に据える。

OUTLOOK 影響・展望

【背景】：Gemini Liveや自然言語での自動化設定、カメラ履歴の要約まで踏み込み、音声アシスタントを家電操作から継続対話へ押し広げた。

→ §02 AI 詳細を読む
§03
IT & CONSULTING / IT

物流の可視化と入口診断が、実装の値段を変える

FACT 事実・概要

Shippio Cargoの在庫可視化は、三菱自動車の物流を単なる進捗確認から外した。

CONTEXT 背景・要点

【事実】：三菱自動車はShippio-Cargoを採用し、KD部品の出荷から現地生産までのパイプライン在庫を一元管理する基盤づくりに踏み切った。

OUTLOOK 影響・展望

【背景】：導入の狙いは、洋上在庫の可視化と輸送実績の蓄積だ。到着予測精度は97.5%とされ、出港前28日からの早期追跡で遅延リスクを先回りして判断できる。

→ §03 IT 詳細を読む
§04
MOBILITY / モビリティ

IPOと実証で、乗客接点の取り合いが始まった

FACT 事実・概要

GOの上場、Momentaの香港IPO、mibotの実証、自動運転車検索の増加が重なり、移動の話は車両より接点と評価軸へ寄った。

CONTEXT 背景・要点

【事実】：GOが東証グロース上場で時価総額2050億円を確保し、調達資金を自動運転タクシー投資へ向ける構えを示した。

OUTLOOK 影響・展望

【背景】：訪日客の配車アプリ利用率は海外7〜9割に対し国内3割弱で、インバウンド回復が競争の主戦場になっている。

→ §04 モビリティ 詳細を読む
§05
MANUFACTURING / 製造

工程を握るか、材料を押さえるか

FACT 事実・概要

スバルはBEVとICEを同一ラインにまとめ、SandboxAQには米商務省が5億ドルを投じた。

CONTEXT 背景・要点

【事実】：スバルは矢島工場でBEVとICE、さらにトヨタ向け車種まで同一ラインで流す混流生産を公開。需要変動に合わせて利益を残す工場設計が主題だ。

OUTLOOK 影響・展望

【背景】：可動式基準や工程集約でタクトを落とさず、フォレスターも2026年8月に合流する。中京圏サプライヤー向け集約倉庫で輸送台数を半減した点も製造現場の示唆が大きい。

→ §05 製造 詳細を読む
§06
ECONOMY / 経済

供給再開の安心と、封鎖リスクの残像

FACT 事実・概要

カーグ島の積み出し再開は市場を少し落ち着かせたが、ボリビアの非常事態や重要鉱物の低水準は残る。

CONTEXT 背景・要点

【事実】：カーグ島では約6週間ぶりに原油積み出しが再開され、超大型タンカー3隻の接岸が供給再開の現実味を一気に高めた。

OUTLOOK 影響・展望

【背景】：注目点は、和平合意が単なる政治演出で終わらず実際の出荷再開に移ったことで、原油急騰を和らげる最初の実務シグナルになった点だ。

→ §06 経済 詳細を読む
§07
GAMING / ゲーム

IPは発売日より、回し方で差がつく

FACT 事実・概要

めっちゃカメレオンの配信バズ、4PGPのローカル対戦訴求、モノログインの短編ホラーは、ゲームが露出の設計で伸びることを示した。

CONTEXT 背景・要点

【事実】：めっちゃカメレオンは6月10日の配信開始から10日で500万DLに到達し、Steam発の小規模作でも世界同時ヒットを作れることを改めて示した。

OUTLOOK 影響・展望

【背景】：勝因は擬態かくれんぼという一文で伝わる企画に加え、にじさんじやホロライブ、海外配信者まで横断した実況拡散が重なった点にある。

→ §07 ゲーム 詳細を読む
