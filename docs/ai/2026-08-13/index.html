GeminiアプリのMAUが10億人を突破 Googleで14番目の大台到達製品に

FACT
【事実・概要】
GoogleのGeminiアプリが月間アクティブユーザー数（MAU）で10億人を突破した。スンダー・ピチャイCEOが8月11日（現地時間）に公表した。
CONTEXT
【背景・要点】
今回の数字は検索のAIモードなどを含まないアプリ単体だが、WorkspaceやYouTube、Androidとの接続が成長を後押しする。配布面の強さが競争力になっている。
OUTLOOK
【影響・展望】
音声利用や画像生成などの利用実態も示され、AIアシスタントはモデル性能だけでなく既存サービス統合で定着を競う。企業導入では利用頻度と業務接続を見極めたい。

毎日新聞が掲載した被災者の写真を生成ＡＩで加工か、偽画像がＳＮＳで拡散…「被災の実情が否定された気持ち」

FACT
【事実・概要】
熊本地震の被災者を写した毎日新聞掲載写真が生成AIで加工されたとみられ、偽画像がSNSで拡散した。被災者への中傷も確認されている。
CONTEXT
【背景・要点】
元写真は倒壊した自宅前の男性を写していたが、偽画像では笑顔でピースをする姿に変えられた。災害報道の文脈を反転させる加工が被害を広げた。
OUTLOOK
【影響・展望】
著作権・肖像権・名誉毀損のリスクに加え、報道機関には画像来歴と原本管理の強化が求められる。AI判定だけでなく、出典確認と投稿者追跡を組み合わせたい。

生成AI時代に注目される「FDE」 社会インフラ最適化の成果をグリッドが公開、四国電力は年間10億円以上の収益改善、出光の事例も紹介

FACT
【事実・概要】
グリッドがFDE（Forward Deployed Engineer）型開発の事例を公開した。四国電力で計画策定時間を半分以下にし、年間10億円以上の収益改善効果を示した。
CONTEXT
【背景・要点】

OUTLOOK
【影響・展望】
生成AIや最適化技術の導入では、モデル精度だけでなく業務定着とKPI改善まで担う人材配置が重要になる。ドメイン人材＋FDEの組み合わせを検討したい。
