¥ FOREIGN EXCHANGE / 為替

日銀発言と160円手前の介入警戒

FACT 事実・概要

日銀の追加利上げ観測、円売りポジションの再拡大、ドル円159円前後の推移、メキシコの政策金利据え置きが重なった。

CONTEXT 背景・要点

OUTLOOK 影響・展望

§02
◆ ARTIFICIAL INTELLIGENCE / AI

企業AIの利用範囲を線引き

FACT 事実・概要

法務省が企業法務支援の三条件を示し、NIIがLLM-jp-4 33Bを公開、透かし回避策とStarling Bankの展開も確認された。

CONTEXT 背景・要点

モデルの選択肢が広がるほど、非弁行為の回避、検出の証拠性、社内知見の再利用を一体で考える必要がある。

OUTLOOK 影響・展望

法務レビュー、必要な計算資源、利用者教育、検証手順が企業AIの導入範囲と定着を決める。

→ §02 AI 詳細を読む
§03
⌗ IT & CONSULTING / IT

Consulting — AI投資を成果へ配分

FACT 事実・概要

世界IT支出の増加見通し、防衛省のAI指揮統制、豪州のニュース対価法案、PQC検証、顧客行動分析が出そろった。

CONTEXT 背景・要点

AI投資はインフラ、機密データ、ニュース流通、暗号移行、店舗分析へ用途が分かれ、単純な一律削減では扱いにくい。

OUTLOOK 影響・展望

増えた費用を事業成果・機密性・権利処理・移行計画へ結びつける説明力が、IT予算の判断材料になる。

→ §03 IT 詳細を読む
§04
◎ MOBILITY / モビリティ

EV・自動運転の商用化が加速

FACT 事実・概要

国内EV販売が1〜7月で6万1090台に達し、UAE・東京・日本の軽市場・遠州で自動運転やEVの導入動きが続いた。

CONTEXT 背景・要点

補助金、新車投入、道路・認可、運行管理、地域交通の担い手不足が、同じ技術を異なる市場へ移す条件になる。

OUTLOOK 影響・展望

補助終了後の実需、ロボタクシーの認可と採算、充電設備、実証から定常運行への移行を確認したい。

→ §04 モビリティ 詳細を読む
§07
▶ GAMING / ゲーム

市場規模を課金へ変える

FACT 事実・概要

インドの約6億人市場で課金拡大が進み、任天堂の新作・セール、TGS2026、Steam無料体験、OP-17発売が続いた。

CONTEXT 背景・要点

市場規模や周年を、配信・試遊・値引き・カード商品へつなぐ複数の接点が、利用者の購入判断を支える。

OUTLOOK 影響・展望

地域別の課金モデル、無料体験後の購入率、周年商品の在庫と次回導線が継続利用を測る指標になる。

→ §07 ゲーム 詳細を読む
