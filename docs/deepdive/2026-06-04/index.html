OpenAI、コンサル市場へ直接参入の衝撃

OpenAIがDeployCoで実装受注に直接参入しFrontier Alliancesの提携先と競合に回る協調的競合は、グローバルコンサルと国内SIerの収益モデルと競争地図をどう塗り替えるか

❖関連レポート · RELATED

    生成AIエージェント、コンサルの人月モデルを侵食 2026.05.31

    前回はAIエージェントがコンサルの人月課金モデルを内側から侵食する力学を扱った。今回の変化点は、ツール供給元のOpenAIがDeployCoで実装受注に直接参入し、Frontier Alliancesの提携先でありながら競合に回る協調的競合の二重構造へ移行したこと。

BACKGROUND

背景

01 / 03

OpenAIによるコンサル市場への殴り込みは、本紙が前回（5/31）に扱った「生成AIエージェントがコンサルの人月課金モデルを内側から侵食する」構図の、明確な次の段階にあたる。前回はAIツールがコンサルの生産性を押し上げ、工数ベースの売上を目減りさせる力学を論じた。今回の変化点は、ツールの供給元であるOpenAI自身がDeployCo（OpenAI Deployment Company）で実装受注そのものに直接参入し、AccentureやMcKinseyの提携相手でありながら同時に競合へ回った——協調的競合（frenemy）への構造転換である。

OpenAIが2026年2月に結んだFrontier Alliancesは、当初は純粋な協力関係だった。BCG・McKinsey・Accenture・Capgeminiの4社がOpenAI技術の認定チームを編成し、OpenAIのForward Deployed Engineer（FDE）と組んで企業へAIエージェントを実装する——モデルは作るが手は動かさないOpenAIが、手を動かすコンサルを販路に変えるという、双方に利のある分業だった。

ところが2026年5月12日、OpenAIはDeployCoを立ち上げ、自ら$4Bを調達してTomoroを買収し約150名のFDEを即日投入した（CIO Dive）。リード投資家はTPGで、Advent・Bain Capital・Brookfieldが続く。これは分業の前提を壊す一手だ。CIO Diveが引くOmdia推計では、システムインテグレーター市場には年間1兆ドル超が流れ2031年まで年率6.5%で成長する。OpenAIが狙うのは、その実装売上そのものであり、競合相手として名指しされたのはAccenture・Deloitte・Cognizantだった。

国内も連動して動いた。NTTデータはOpenAIと組んで日本初のChatGPT Enterpriseリセラーとなり販路側に回って取り込む戦略を取り、富士通は専有環境向けのKozuchi Enterprise AI Factoryで国産・専有という差別化に賭ける。McKinseyはGoogle Cloudとも共同変革グループを組み、単一ベンダーに縛られない両建てで上流を確保しにいった。提携と競合が同じ顔ぶれの間で交錯する——この協調的競合の網こそ、今回の構図の核心である。

EXHIBIT C — 関係図 / RELATIONS
DEEP DIVE

深掘り

02 / 03

関係図が示す力学を、数値で裏づける。論点は単純だ——OpenAIの直接参入は既存コンサルのAI売上を奪う脅威なのか、それとも市場自体を膨らませる追い風なのか。鍵は「AI関連受注がどれだけの速さで伸びているか」と「実装を担う体制の規模差」の二つにある。

数値が語るのは、AI受注が既存コンサルの成長エンジンになっている事実だ。AccentureのGenAI新規受注は区分開示前の実質ゼロからFY24に約$3.0B、FY25に$5.9Bへほぼ倍増し（CIO Dive）、AI収益も$2.7Bへ3倍に伸びた。つまりOpenAIの参入は既存市場を奪い合うゼロサムではなく、実装需要そのものが急膨張する局面で起きている。Omdiaが示す年1兆ドル超・年率6.5%成長の市場で、勝負は「縮むパイの奪い合い」ではなく「膨らむパイの取り分」である。

EXHIBIT D — データ表 / TABLE

ただし体制規模の非対称は見過ごせない。AccentureはAI・データ人材を85,000人超抱え、NTTデータの600名、DeployCoの約150名とは二桁の開きがある。それでもOpenAIが脅威たり得るのは、人海戦術ではなくモデルとFDE方式で工数あたりの生産性を覆すからだ。ここで前回論じた人月モデルの矛盾が効いてくる——AIで一人当たりの生産性が跳ね上がるほど、時間課金で稼ぐ既存大手ほど自己破壊のジレンマに陥る。だからこそMcKinsey・BCG・Bainは成果報酬モデルへの移行を急ぎ、Accentureは提携でOpenAIを敵に回す前に取り込もうとしている。

そして国内勢の選択は割れている。NTTデータはOpenAIの販路に乗ることで実装規模を取りにいき、富士通は専有・国産環境という差別化で別の土俵を選んだ。Diamond Onlineによれば三菱商事・NTT連合がAccenture対抗を掲げる一方、富士通は3,000人規模を見直す——同じ「3,000人」が一方では新設、他方では削減という対照は、AI時代のSIerが人員構成そのものを問い直していることを象徴する。なおMcKinseyの分析ではGenAIプロジェクトの80%が業績改善に至らず90%がパイロットで停滞しており、実装の質が次の勝敗を分ける。

◇ 論点 — THE ISSUE

AI実装受注の主導権を誰が握るか — モデルベンダーの垂直統合(DeployCo)か、提携で取り込む既存コンサルか、国産SIerの独自圏か

01

OpenAI/Google等モデルベンダーが垂直統合で実装まで握る

02

Accenture/McKinsey等が提携＋成果報酬で防衛し主導権を維持

03

NTTデータ/富士通等が国産・専有環境を武器に独自圏を築く

期限 — DEADLINE

2026-06-18 Accenture Q3 FY26決算（AI受注の伸びと人月モデルの耐性を確認）

決定権者 — DECIDER
  • OpenAI経営陣（DeployCoの拡大ペース）
  • Accenture/McKinsey/BCG経営陣（提携と自社実装の線引き）
  • 発注企業のCIO・調達部門（誰に実装を任せるか）

三つの選択肢は排他ではなく綱引きだ。DeployCoが約150名から数千名規模へ拡大すれば、Palantirが埋め込み型エンジニアモデルから数十億ドル事業へ育った前例どおり実装の主導権はモデルベンダーへ傾く。逆にAccentureがFrontier提携でOpenAIを自社の納品網に組み込み、成果報酬で顧客の業績にコミットできれば、垂直統合の脅威は「最良の下請け」に転じる。最終的にボールを握るのは発注企業のCIO・調達部門であり、彼らが「モデル直結の速さ」を取るか「業界知見と説明責任」を取るかで地図が決まる。私の読み筋では、当面は既存大手が提携で時間を買いつつ成果報酬へ移行する defensiveな均衡が続き、DeployCoの規模が閾値を超える24〜36か月後に本格的な再編が来る。直近の試金石は6月18日のAccenture Q3決算で、AI受注の伸びが鈍れば脅威論が一気に現実味を帯びる。

❖ 要約 — IN ONE READ

OpenAIは5月、$4Bを投じたDeployCoでコンサル実装市場へ直接参入し、AccentureやMcKinseyの提携先でありながら競合に回った。Omdiaが年1兆ドル超・年率6.5%成長と見る市場で、AccentureのGenAI受注はFY25に$5.9Bへ倍増——参入はゼロサムでなく膨張するパイの取り分争いだ。既存大手は成果報酬へ移り、国内勢は販路取り込み（NTTデータ）と国産差別化（富士通）に割れる。主導権を決めるのは発注企業のCIOで、直近の試金石は6月18日のAccenture Q3決算である。
