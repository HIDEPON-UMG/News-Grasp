コンサル『人月』の崩落、AIが値付けを書き換える

生成AIがコンサル大手の人月（タイムチャージ）課金を掘り崩し、Google型『取り込み（$750Mファンド・JV）』とOpenAI型『代替（DeployCo）』の二経路で収益構造が成果報酬へ転換する流れは、各社の価格体系と序列をどう塗り替えるか

BACKGROUND

背景

01 / 03

値付けの足場が抜け始めた。 McKinsey の英国マネージングパートナー Michael Birshan によれば、同社のグローバル報酬の 約25%が既に成果報酬（outcome-based）型に移っている（AOL/Fortune、2026-05-26）。前回（6/4）の本欄は、OpenAI が DeployCo で実装受注に直接参入し競争地図を塗り替える構図を扱った。今回の変化点は、その先で コンサルの収益の土台である「人月（タイムチャージ）課金」そのものが崩れ始め、しかも崩しにかかる AI事業者 が 「取り込み」と「代替」の二経路に割れたことにある。

関係図が示すのは、同じコンサル大手を前にして AI事業者 が真逆の手を打っているという構造だ。OpenAI は DeployCo で Accenture や Deloitte の実装受注を正面から代替しに行き、McKinsey・Bain とは 出資で結ばれながら助言市場では競合するという 協調的競合（frenemy）に立つ。対する Google Cloud は、敵対ではなく $750Mのファンドでコンサルを束ね、McKinsey とは共同変革グループまで組んで 自陣の実装部隊として取り込む。代替（置換）か、取り込み（束ね）か——この二経路の分岐が、今回の力学の核心である。

その分岐が刺さる先は、いずれも コンサルの「人月」という値付けの根拠だ。OpenAI の FDE（Forward Deployed Engineer）が 人手の工数をAI工数へ置換すれば、稼働時間に比例した請求は痩せていく。Google の取り込みも、クラウド消費とエージェント本数で価値を測るモデルへ顧客を移し、「何人が何時間働いたか」から「成果が出たか」へ評価軸をずらす。供給側のどちらの経路を通っても、行き着くのは タイムチャージから成果報酬への移行という同じ出口である。

そして既存コンサルは、この圧力に 守りと攻めの二正面で応じている。Accenture は Q2 FY26で過去最高Q2の新規受注$22.11Bを積み上げ本丸を守りながら、人員最適化（severance）を並行させてAI前提の体制へ組み替える。McKinsey・Bain は DeployCoへ出資して敵を半身で味方に変え、BCG は AI関連売上を倍増させて工数収益の目減りを補う。誰も静観していないという事実が、価格体系の地殻変動が既に始まっていることを物語る。

EXHIBIT C — 関係図 / RELATIONS
DEEP DIVE

深掘り

02 / 03

数字が映すのは、需要は伸びているのに値付けの根拠が痩せていく逆説である。 Accenture の売上は 1年前の四半期$16.66Bから直近$18.04Bへ前年比+8%で増え（チャート①）、新規受注も $22.11Bと過去最高Q2を記録した。にもかかわらず同社は FY25Q4〜FY26Q1にかけ人員最適化（severance）を計上している。AIが需要を押し上げつつ、同じAIが人手＝請求の源泉を削る——この 増収と人員圧縮の同居こそ、人月モデルが内側から崩れている何よりの証拠だ。

崩落は既に 価格の数字として現れている。McKinsey は フィーの約25%を成果報酬型へ移し、社内AI Lilli は 月50万超のpromptで最大30%の知的労働を時短する。Bain は AI・技術起点の売上を約30%から将来50%へ、BCG は AI関連業務を2024年の20%から2026年に40%へ倍増させる見込みだ。稼働時間に比例した請求が縮み、成果に連動する請求が膨らむという置換が、複数社で同時に進んでいる。

EXHIBIT D — データ表 / TABLE

ここで背景の 二経路が論点に直結する（チャート②）。Google は $750Mを賭けてコンサルを束ね、$1のクラウド支出が$7.05のサービス売上を生む経済圏に取り込む。一方 OpenAI は DeployCoに$4Bを投じ、実装そのものを自ら受ける代替に賭ける。取り込まれる側は販路と需要を得るが値付けの主導権を渡し、代替される側は本丸の受注を失う。どちらの経路でも、コンサルが守ってきた「人月の値付け」は手放さざるを得ない——これが定量データから follow する中核の論点である。

注目点

EXHIBIT E — 意思決定フレーム / DECISION
◇ 論点 — THE ISSUE

AIが壊す人月課金モデルに対し、コンサル各社は値付けをどう作り直し、Google型『取り込み』とOpenAI型『代替』のどちらに賭けるか

01

成果報酬・価値ベース課金へ全面転換し人月から脱却する

02

AIベンダー(Google/OpenAI)のファンド・JVに乗り『取り込まれる側』で再販と実装を握る

03

独自AI・専有環境で垂直統合し実装を自社で抱え込む(防衛)

期限 — DEADLINE

2026-06-18 Accenture Q3 FY26決算(AI需要と価格圧力の実数)、および各社FY26通期ガイダンス更新

決定権者 — DECIDER
  • Accenture経営陣
  • McKinsey/Bain/BCGのマネージングパートナー
  • Google Cloud・OpenAIの事業責任者
  • 発注企業のCFO・調達部門

読み筋はこうだ。 三つの選択肢は排他ではなく、規模で本丸を守る Accenture、出資で敵を束ねる McKinsey・Bain、AI売上比率を上げる BCG と、各社が 既に別々の賭け方を始めている。共通するのは、人月という単一の物差しを手放す点だ。値付けの根拠が「投入工数」から「実現した成果」へ移るとき、勝つのは 成果を定義し計測する側——すなわち成果連動契約の設計力を握る陣営になる。

私見では、次の決定的シグナルは Accenture の6月18日Q3決算である。AI需要で受注が伸び続けるか、それとも 価格圧力で利益率が削れるかが初めて実数で出る。ここで 増収と margin の両立が崩れれば、市場は「取り込み・代替の二経路がコンサルの値付け権を奪い始めた」と読み、成果報酬への転換が一段加速する。人月の黄昏は、決算の一行に最初に現れる。

❖ 要約 — IN ONE READ

McKinsey は フィーの約25%を成果報酬型へ移し、BCG は AI関連売上を20%→40%へ倍増させる——コンサルの 人月（タイムチャージ）課金が定量データの上で崩れ始めた。崩しにかかる AI事業者 は二経路に割れ、Google は $750Mファンドで「取り込み」、OpenAI は DeployCoで「代替」を狙う。Accenture は Q2 FY26で過去最高Q2受注$22.11Bを守りつつ 人員最適化を並行させた。焦点は、値付けが「工数」から「成果」へ移る転換に各社がどう賭けるかに尽きる。次の実数は 6/18のAccenture Q3決算で出る。
