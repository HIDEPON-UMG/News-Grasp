中国BEV67%、軽EV日本上陸へ

中国のBEV量産・輸出圧力を背景に、BYD RACCOは日本の軽EV競争をどう変えるか

#deepdive#daily#news-grasp#issue-20260714#BYD#RACCO#日産サクラ#ヤナセ#中国NEV#軽EV
BACKGROUND

背景

01 / 03

中国NEV市場では2026年上期の販売が744.6万台に達し、その67%を純電気自動車が占めた。5月の新エネルギー乗用車輸出も42.4万台へ前年同月比112.6%増となり、国内の量産力が海外市場の開拓圧力へ変わる局面に入っている。

BYD Auto Japanは日本の軽規格専用BEV「RACCO」を2026年夏に投入する計画で、標準仕様を約20kWh・200km超、ロングレンジ仕様を約30kWh・300km超の目標に置いた。ヤナセEVスクエアとの正規ディーラー契約も結び、車両だけでなく販売・中古車・整備まで日本仕様にする構えだ。

迎え撃つ日産サクラは、2026年4月の月販が375台、5月が303台で、それぞれ前年同月を48.0%、64.7%下回った。軽自動車全体の需要とは別に、軽EVでは商品投入だけで購入不安を解消できないことが、参入前から数字に表れている。

この関係図の核は、BYDとヤナセの販売・整備での協力が、日産との軽BEV顧客争奪を可能にする点にある。中国側の量産力だけでは日本の購入者へ届かず、流通と残価への不安を吸収する国内パートナーが競争条件になる。

EXHIBIT C — 関係図 / RELATIONS
DEEP DIVE

深掘り

02 / 03

中国NEV産業の数字が示すのは、単なる国内BEV比率の上昇ではない。5月輸出は42.4万台へ倍増し、そのうち小型のA00・A0級がBEV輸出の53.8%を占めた。RACCOは日本だけの実験車ではなく、小型BEVを海外へ運ぶ量産構造の延長線上にある。

ただし、日産サクラの月販は2025年4月の721台から2026年4月の375台、5月の303台へ下がった。BYDが20kWh級と30kWh級を用意しても、航続距離の選択肢だけでは軽EV需要を再加速できないという先行市場の警告がある。

EXHIBIT D — データ表 / TABLE

そこで効くのが、関係図で示したBYDとヤナセEVスクエアの協力線だ。ヤナセは正規販売に加え、中古車・部品・アフターサービスまで事業範囲に置き、充電インフラと査定価格の低迷も課題として挙げた。中国の供給力を日本の保有体験へ翻訳できるかが勝負になる。

日産にとっても競争軸は値下げだけではない。既存の軽EV利用者と販売実績を持つ強みを、整備網・充電・下取りの安心へ結び直せるかが問われる。BYDの参入は、車両スペック競争を購入後の不確実性を減らす競争へ広げる。

BYD Auto Japanが20kWh級を前面に出せば日常利用への適合を示しやすいが、長距離不安は残る。30kWh級なら300km超の目標を訴求できるものの、価格は現時点で未確認だ。先に保有支援へ投資すれば立ち上がりは重くなるが、ヤナセとの協力を競合他社が模倣しにくい資産へ変えられる。

本稿の読み筋は、RACCOの勝敗を決めるのは最長航続距離ではなく、購入から整備・売却までの不安をどれだけ減らせるかだ。日産サクラの販売減速が示す需要の壁に対し、BYDとヤナセが保有コストと残価の見通しを発売時点で示せるかを次の節目として見る。

❖ 要約 — IN ONE READ

中国NEV市場では2026年上期販売の67%をBEVが占め、5月の新エネルギー乗用車輸出は42.4万台へ倍増した。その供給力を背にBYD RACCOが日本の軽EVへ入る一方、日産サクラの月販は303台まで減速している。焦点は航続距離の長短ではなく、ヤナセとの販売・中古車・整備連携で購入後の不確実性をどこまで下げられるかだ。
