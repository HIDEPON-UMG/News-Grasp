BACKGROUND

背景

01 / 03

前回はドル円が162円目前へ進み、介入の時機を中心に見た。今回は相場が163円台へ切り下がり、日銀の利上げ後も円安が止まっていない。変化点は、介入を打つか否かではなく、介入と追加利上げをどの順番で使うかへ論点が移ったことにある。

財務省が4〜5月に投じた11兆7,349億円は円買い介入として過去最大だったが、市場では約1か月で介入前の水準へ戻ったとの指摘が出た。介入は変動の速度を抑えても、金利差と輸入コストが作る円売りの流れまで単独で反転させにくい。

日本銀行は政策金利を1.0%へ引き上げたが、Fedの誘導目標は3.50〜3.75%にある。そこへ原油高が加わり、利上げは円を支える一方で企業収益と家計所得を圧迫しかねない。円防衛は為替だけを見て決められない二正面の政策問題になった。

EXHIBIT C — 関係図 / RELATIONS
DEEP DIVE

深掘り

02 / 03

日本銀行の物価見通しでは、CPIは実績の2.7〜2.8%から2026年度も2.8%へ高止まりする。原油高が一過性でも、円安が輸入価格への波及を長引かせれば低下は遅れる。介入には相場安定だけでなく、物価上振れを抑える時間を買う役割が生じる。

同時に、実質GDPは2025年度の1.0%から2026年度に0.5%へ減速する見通しだ。追加利上げは金利差を縮める反面、原油高ですでに傷んだ所得と投資へ重ねて効く。円安対策を金利だけへ寄せると、物価を抑えて成長を削る逆風が強まる。

EXHIBIT D — データ表 / TABLE

財務省の介入額は11兆7,349億円に達した一方、日米金利差は下限同士でも2.50ポイント残る。規模の大きい介入で流れが定着しなかった事実は、円売りの根が投機だけではないことを示す。介入は速度、金融政策は持続条件を受け持つという順序設計が欠かせない。

関係図では、財務省と日本銀行が介入と金利を分担し、日本銀行とFedは政策対話を続けながら金利差では逆方向に働く。為替市場はこのずれを試すため、単一機関の強い発言だけでは均衡しにくい。次に見るべきは水準そのものより、原油・物価・金利差が同じ方向へ動くかである。

◇ 論点 — THE ISSUE

ドル円が163円台で推移し原油高が物価を押し上げる中、日本当局は円買い介入と追加利上げをどの順番で組み合わせるべきか

01

急変時の円買い介入を先行し、日銀は成長と物価のデータを待つ

02

日銀が追加利上げを前倒しし、介入は相場急変時の補助に限定する

03

介入・利上げ条件・日米対話を一体で示し、速度と持続性を分担する

期限 — DEADLINE

ドル円の163円台定着前、遅くとも次回の日本銀行金融政策決定会合まで

決定権者 — DECIDER
  • 財務省・政府
  • 日本銀行政策委員会

介入先行は財務省が相場の急変を止めやすい半面、金利差が残れば再び円売りを招く。利上げ先行は持続条件を変えられるが、GDP減速と原油高の中で負担が重い。選択肢は二者択一ではなく、介入で時間を買い、その間に利上げ条件を明示する組み合わせが現実的だ。

私の読み筋は、日本当局が急変には介入、基調的な物価上振れには金融政策と役割を分ける第3案である。Fedが利下げへ動けば国内の追加引き締めは小さくできるため、日銀会合までに円相場・原油・基調物価の三つを同じ判断表で示せるかが次の焦点になる。

❖ 要約 — IN ONE READ

ドル円は4〜5月に11兆7,349億円の円買い介入を受けた後も163円台へ下落した。日銀は政策金利を1.0%へ上げたが、Fedとの金利差と原油高が円売り・物価高を支える。介入で急変を抑え、物価の基調を見ながら追加利上げの条件を示す二正面の政策設計が問われている。成長を削り過ぎないためにも、次回会合までに両政策の役割分担を明確にする必要がある。
