Warsh初FOMC、利下げ期待を消す

Warsh新議長の初FOMCで、据え置き決定と年内利上げ示唆、短文化された声明、SEP上方修正がドル金利と円相場の読み筋をどう変えるか

    前回は日銀1%利上げ後の説明力を扱った。今回の変化点は、Warsh新議長の初FOMCが実際に据え置きを決め、米側の利下げ期待を年内利上げリスクへ反転させたことだ

BACKGROUND

背景

01 / 03

Fedは2026年6月17日のFOMCで、政策金利を3.50〜3.75%に据え置いた。前回は日銀の1%利上げが円を守れるかを見たが、今回の変化点は米側だ。Kevin Warsh新議長の初会合は、利下げ待ちの市場に対し、米金利が下がらない時間が延びるという読み筋を突きつけた。

関係図で見ると、Warsh初FOMCの主役は金利の据え置きだけではない。声明を短くし、ドットプロットから自分は外れ、5つの作業部会で運営を見直すという動きが、FOMC参加者、市場、米政権を同時に揺らした。議長が先行き案内を薄くするほど、市場は委員の分布と実データを直接読むしかなくなる。

USD/JPYに効くのは、この「説明を減らすFed」が日銀の説明責任とぶつかる点だ。日銀が1%へ上げても、米側が利下げではなく利上げ方向へ傾けば、金利差縮小の物語は弱くなる。円相場の焦点は、日銀の追加利上げより先に、米金利がいつまで下がらないかへ戻る。

DEEP DIVE

深掘り

02 / 03

1つ目の図は、Fedが金利を動かしていないのに市場の意味が変わったことを示す。3月時点では12人が年内利下げを見込んでいたが、6月には9人が利上げ、8人が据え置き、1人が利下げという分布へ変わった。同じ据え置きでも、次の一手が利下げか利上げかでドル金利の意味は逆になる。

2つ目の図と表で見るべきは、Warsh自身がドットプロットを出していない点だ。9対8対1という分布は、委員会が明確な利上げ多数へ固まったというより、議長の手元を空白にしたまま市場へ投げ返した形に近い。先行き案内の削減は透明性の低下ではなく、データ反応型へ市場を戻す試みだが、短期的には価格変動を増やす。

EXHIBIT D — データ表 / TABLE

物価面では、PCE見通しが2.7%から3.6%へ、コアPCEが2.7%から3.3%へ上がった。中東要因の原油高だけなら一過性と片づけられるが、コア見通しも上がるなら、Fedは「エネルギーだけ」とは言い切れない。円にとってのリスクは、日銀の利上げ不足より、米国の物価粘着がドル金利を高止まりさせることにある。

Warshが選びそうなのは、すぐに利上げ宣言へ飛ぶ道ではなく、先行き案内を削ったままデータを待つ道だ。これはFedの裁量を広げる一方で、USD/JPYには高ボラティリティを残す。市場は議長の言葉ではなく、CPI、PCE、雇用、原油の順にドル金利を再計算する。

日銀側から見ると、Fedの変化は厄介だ。日本が追加利上げを示しても、米側の利下げ観測が消えれば、円高方向の余地は限定される。次に見るべきは日銀単独のタカ派度ではなく、米物価統計が「年内利上げ9人」という分布を多数派へ変えるかどうかである。
