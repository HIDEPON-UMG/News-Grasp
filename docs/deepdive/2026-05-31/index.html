生成AIエージェント、コンサルの人月モデルを侵食

生成AIエージェントの普及が大手コンサルと日系SIerの人月課金モデルをどう侵食し、各社はどう再編で応じているか

#deepdive#weekly#news-grasp#issue-20260531#Accenture#Anthropic#OpenAI#AIエージェント#コンサル業界
BACKGROUND

背景

01 / 03

直近半年で、エンタープライズ向け生成AIの主戦場は「モデル性能」から 実装と運用 へと急速に移った。Anthropic は2月にエージェントプラグインを投入し、5月には Blackstone らと総額15億ドルの合弁会社を設立した。モデルを売る側が顧客の現場に自ら降りてくるという構図が、わずか3か月で前面に出てきている。

同じ5月4日、OpenAI も「The Development Company」を立ち上げ、40億ドルを調達した。両社に共通するのは、Palantir が広めた現場常駐エンジニア(FDE)型を採り、要件定義から実装まで一気通貫で請け負う点だ。従来は SIer とコンサルが握っていた「実装の中間層」を、モデルベンダーが直接取りにきたと読める。

一方で両社は4大コンサルと Frontier Alliances や Partner Network を結び、彼らを販売・実装のチャネルとして取り込んでもいる。敵に回すと同時に味方に取り込む二面戦略であり、コンサル側は「分配を得る代わりに自社の付加価値を薄める」ジレンマに立たされている。日系では 富士通 と NTTデータ が専有型エージェント基盤で追走するが、顧客の人員を削る道具を売るほど自社の人月も細る構造的矛盾を抱える。

DEEP DIVE

深掘り

02 / 03

業界最大手 Accenture の数字が、この地殻変動を最も鮮明に映す。GenAI 新規受注は FY2024 の 30億ドルから FY2025 の 59億ドルへ約2倍、収益は 9億ドルから 27億ドルへ約3倍に伸びた。だが通期売上 約649億ドルに対し GenAI 収益はなお4%程度で、その裏で約1.1万人を削減し、8.65億ドルの構造改革費を計上しつつ全55万人を再教育している。AI実装の受注増（上振れ）と人月単価の圧縮（下押し）が、同じ一社に同時に効いている——これがこのテーマの核心だ。

前段の関係図が示した提携でありつつ競合という二面性は、ここで具体的な力学になる。Anthropic は Partner Network（1億ドル、Deloitte・Accenture らを巻き込む）で大手コンサルを販売・実装チャネルに取り込みながら、Blackstone らとの 15億ドルJVで現場常駐(FDE)型の直販に降りてくる。OpenAI も Frontier Alliances で4大コンサルと組みつつ「The Development Company」で直販する。コンサルにとって、アライアンスの分配を得るほど自社の中核（実装の中間層）をベンダーに明け渡す——提携が深まるほど競合で削られる、という非対称なジレンマが構造化されている。

EXHIBIT D — データ表 / TABLE

では関係図の底辺、発注企業の人月予算はどちらに流れるのか。MIT の Project NANDA は、生成AI本番導入の95%が損益貢献を示せず、内製の成功率33%に対しベンダー調達は67%と約2倍開くと報告する。「誰が責任を持って実装し運用するか」という需要は消えず、複雑化でむしろ SIer 依存は残る。一方で課金の物差しは動いており、McKinsey は報酬の約25%を成果連動に移し、成果・従量型のハイブリッド採用は1年で 27%→41%へ急伸した。実装需要（パイ）は増えるが、値付けの単位が「人月」から「成果」へ置き換わる——これが奪い合いの本質だ。

二面性は各陣営の内側にも矛盾として現れる。Accenture は顧客の人月を削るAIを売る加害者であり最大の受益者でもあるが、削った1.1万人ぶんの単価を成果課金で取り戻せるかは未証明だ。富士通・NTTデータ は調達担当を1,500→375人に削るような「人月を削る道具」を売るほど、自社の人月ビジネスも細る——加害と被害が同一事業の内側で衝突する。対して McKinsey は内製 Lilli を自社で実証してから商品化するフライホイールで、frenemy の中では提携依存度が最も低い。勝者は、ベンダーとの提携で「分配」を取る者ではなく、自社のAI実装能力で「成果課金の値付け力」を握る者になる。

その値付けの底を抜きにかかるのが、Distyl や月250ドルで戦略レポートを生む Rocket のような「人月ゼロ」競合だ。人月を成果課金に置き換えても、成果の単価そのものがAIで下がれば、コンサルの取り分は二重に圧縮される。問いは「AIで上がった生産性を、値下げではなく成果課金で自社に取り込めるか」に収斂する。

EXHIBIT E — 意思決定フレーム / DECISION
◇ 論点 — THE ISSUE

コンサル/SIerは人月（工数）課金から成果・従量課金へ移行すべきか。移行する場合、自社のAI実装能力で先行者利益を取り切れるか

01

AI実装を成果報酬型で請け負い、人月減を単価と量で補う（Accenture型の二刀流）

02

モデルベンダーと組み販売・実装チャネルに徹する（Partner Network型）

03

従来の人月モデルを死守し、AIは社内効率化に留める（守りの選択）

期限 — DEADLINE

2026-06-18 Accenture Q3 FY2026 決算 ／ 2026年下半期の大型契約更改シーズン

決定権者 — DECIDER
  • Accenture CEO Julie Sweet ら大手コンサル経営陣
  • Anthropic / OpenAI の JV 経営陣
  • 発注側の大企業 CFO・調達部門

3案のトレードオフは明快だ。二刀流は受注規模を維持できるが単価下落と人員整理の痛みを伴い、チャネル特化は安全だが付加価値をモデルベンダーに明け渡す。守りは短期の利益を守るが、Distyl や月250ドルで戦略レポートを生む Rocket のような「人月ゼロ」競合に価格の底を抜かれるリスクが高い。本命は二刀流だが、成立条件は「AIで生産性が上がった分を、値下げではなく成果課金で自社に取り込めるか」に尽きる。次の試金石は 6月18日の Accenture 決算で、AI収益の人月外比率と価格モデルへの言及が、業界全体の方向を決めるだろう。

❖ 要約 — IN ONE READ

エンタープライズAIの主戦場は「モデル性能」から 実装と運用 へ移り、Anthropic・OpenAI が5月に各々合弁会社を設立して現場常駐型でコンサルを中抜きし始めた。最大手 Accenture は GenAI 受注を 2倍・収益を 3倍に伸ばす一方、約1.1万人を削減——AI実装の追い風と人月単価の逆風が同じ一社に同時に効く局面だ。ただし生成AI本番導入の95%が損益貢献を示せず、実装責任の担い手としてのSIer需要は当面消えない。焦点は 6月18日の Accenture 決算と、人月から成果課金への移行速度に移る。
