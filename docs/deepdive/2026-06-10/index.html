日本半導体の再編、垂直統合と日の丸連合の攻防

BACKGROUND

背景

01 / 03

日本の半導体は「誰の傘の下で作るか」という主導権争いの局面に入った。 前回（6月9日）は、AI供給網 への投資が政策イベント前の日本株を支えられるかという市場側の問いだった。今回の変化点は、その供給網そのものが、デンソー のローム買収撤回、ローム・東芝・三菱電機の統合協議、そして熊本ファブの微細化前倒しという形で 供給側の構造再編 に動き出したことである。市場が下支えを期待する対象が、いま内部で陣取りを始めた という点が、本日のテーマの核心になる。

関係図が示すのは、日本の半導体が二つの異なる結合様式で同時に再編されている という構図だ。左側では、TSMC を頂点に トヨタ・デンソー・ソニーが出資でぶら下がる 垂直の系列型クラスター（JASM）が、補助金を受けて先端ノードへ駆け上がる。右側では、ローム・東芝・三菱電機 が対等合併に近い 水平の連合を組み、首位インフィニオンへ対抗しようとする。結合の論理が縦と横で正反対なのが、今回の再編の特徴である。

その二つの構図を 橋渡しするのがデンソーとロームの「協調的競合」 だ。デンソー は車載 SiC パワー半導体の調達網を系列内に取り込もうと約 1.3兆円の買収を提案したが、2026年4月に撤回した。ロームは「巨大なトヨタグループに飲み込まれること」を嫌って拒否し、代わりに東芝・三菱電機との水平連合を選んだ。それでも両社は SiC・アナログ半導体の協業は継続 する。買収という強制統合は崩れ、提携という緩い結合だけが残った。

最下段の 日本政府は、両陣営の双方を補助金で支える後見役である。JASM 第2工場には最大 46.2億ドルの補助が付き、パワー半導体連合にも量産投資計画の認定が下りた。国は勝者を一つに絞らず、垂直と水平の両賭けで国内製造力を底上げしようとしている ように見える。経済安全保障の旗の下で、競合する二つの再編が同時に公費の支えを受けている。

EXHIBIT C — 関係図 / RELATIONS
DEEP DIVE

深掘り

02 / 03

データが映すのは、二つの再編がいずれも「規模が足りない」という同じ弱点への処方箋だという点だ。 JASM第2工場は当初の 6nm から 4nm（2025年12月）、さらに3nm相当（2026年2月） へ微細化を前倒しした。これは TSMC が熊本を後工程や成熟ノードの拠点ではなく、車載・AI向けの先端ノードを国内で回す拠点 へ格上げしようとしていることを意味する。ノードの世代を一段飛ばすほど、車載勢の調達を熊本へ引き寄せる磁力は強まる。

一方、パワー半導体の連合は「先端」ではなく「束ねる」ことで規模を作ろうとしている。 ローム の SiC、東芝の Si MOSFET、三菱電機 の IGBT は、強い製品分野が重ならず 補完的に積み上がる。だからこそ統合すれば首位インフィニオンに次ぐ 世界2位連合になり得るが、各社のシェアは依然 1桁台にとどまる。単独では中国勢の価格攻勢に削られるという危機感 が、競合だった3社を一つのテーブルに着かせた。規模の壁が、ライバル同士を連合へ押し込んでいる。

EXHIBIT D — データ表 / TABLE

背景の関係図に戻ると、ここで効いてくるのがデンソーの「敗北」である。 デンソーが ローム を買収できていれば、車載SiCは トヨタ系の垂直統合に取り込まれ、日の丸連合は核を失っていた。買収撤回によってロームは独立を保ち、水平連合の主役として残った。つまり 垂直統合の失敗が、結果的に水平連合の成立を後押しした という逆説が起きている。次に問われるのは、緩い提携のまま残ったデンソー＝ローム間の協業が、競合する連合の内側でどこまで続くかである。

EXHIBIT E — 意思決定フレーム / DECISION
◇ 論点 — THE ISSUE

日本の車載・パワー半導体クラスターは、垂直統合（トヨタ系の系列囲い込み）と水平統合（日の丸連合の独立規模化）のどちらで世界競争力を確保すべきか

01

デンソー主導の垂直統合（車載SiCを系列内に取り込む）

02

ローム・東芝・三菱の水平統合（独立連合で規模を作る）

03

JASM型の外資ファウンドリ依存（TSMC熊本に先端を委ねる）

期限 — DEADLINE

2026年内のローム・東芝・三菱の統合枠組み確定、JASM第2工場の2027年末稼働、各社の次期決算

決定権者 — DECIDER
  • デンソー・トヨタ経営陣
  • ローム・東芝・三菱電機 経営陣
  • 日本政府（経産省）

三つの選択肢は排他ではなく、すでに同時進行している。 デンソーの垂直統合は買収撤回で後退したが、SiC協業という形では生き残っている。ローム 主導の水平連合は「想定より時間が必要」とされ、合弁の枠組みはまだ流動的だ。そして JASM への先端委託は、国内に4nm・3nm相当を呼び込む現実解として走り続ける。問題は、補助金で三つを並走させ続けられるほど日本の半導体投資余力が厚いのか という点である。

私見では、勝負を分けるのは「規模」より「誰が車載の調達を握るか」だ。 車載SiCの需要が読める トヨタ グループが調達の主導権を持てば、ロームの独立連合は最大の顧客を系列に押さえられかねない。逆に日の丸連合が外販で規模を確立すれば、垂直統合の磁力は弱まる。2026年内に見るべきは、合弁の出資比率と統治構造、そしてデンソー＝ローム協業が連合の内側で「提携」のまま残るか「競合」へ振れるかである。 ここが、垂直と水平のどちらが勝つかの分水嶺になる。

❖ 要約 — IN ONE READ

6月10日の焦点は、日本の車載・パワー半導体クラスターが二つの正反対の様式で同時に再編されている ことだ。TSMC 熊本の JASM 第2工場は 6nm から3nm相当へ微細化を前倒しし、トヨタ・デンソー の出資する 垂直の系列型クラスターを先端化する。一方、ローム・東芝・三菱電機 は 水平の日の丸連合で世界2位を狙う。両者を橋渡しするのが、デンソーの 1.3兆円ローム買収撤回と継続する SiC協業という 協調的競合 である。垂直統合の失敗が水平連合を後押しした いま、勝敗を分けるのは規模よりも車載調達の主導権だ。次の節目は連合の枠組み確定とJASMの2027年末稼働である。
