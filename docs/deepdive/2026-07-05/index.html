ロボタクシー、違反通知の時代へ

カリフォルニアのAV違反通知制度は、ロボタクシー拡大の競争軸をどう変えるか

#deepdive#weekly#news-grasp#issue-20260705#Waymo#California-DMV#CPUC#robotaxi#AV-regulation
BACKGROUND

背景

01 / 03

カリフォルニアのロボタクシー規制は、2026年7月1日を境に実証許可の管理から道路上の違反行動の是正へ重心を移した。これまで無人車両は、違反が起きても人間の運転免許に切符を結び付けにくかったが、AB 1777は警察がメーカー向けの notice of AV noncompliance を出し、DMVが調査と是正を判断する経路を作った。空席の運転席ではなく、運行システムを責任主体にする制度変更である。

この動きが重要なのは、Waymoのような先行事業者が走行距離と安全データの厚みを競争優位として示す一方、現場の警察・消防はサイレン、停車、迂回、事故時対応を即時に扱わなければならないからだ。DMVは2025年次の試験走行が900万マイルを超えたと公表し、CPUCは旅客サービスの四半期報告に走行距離、乗車、停止イベントを含める。規制の焦点は「走れるか」から「都市の例外状態にどう従うか」へ進んでいる。

EXHIBIT C — 関係図 / RELATIONS
DEEP DIVE

深掘り

02 / 03

Waymoの安全ハブは、2026年3月までにrider-only 2.206億マイルを示し、Phoenix、San Francisco Bay Area、Los Angelesの3地域だけで大半を占める。これは単なる規模自慢ではない。違反通知制度が始まると、メーカーは事故率だけでなく、警察の停止指示、緊急車両、通行止め、工事帯といった例外処理の失敗履歴を継続的に説明する必要が出る。走行距離の多さは、同時に説明責任の母数も増やす。

制度面では、California DMVがAV試験の年次報告と違反通知を扱い、CPUCが旅客サービスの四半期報告を持つ。さらにBerkeley TIMSは、NHTSA SGOを含む事故データを研究者や政策担当者向けに可視化する。つまり、ロボタクシーの拡大はメーカー発表、州規制、旅客監督、事故データ基盤の4層で見られる。ITコンサルタントにとっての論点は、単一KPIではなく、監督データを横断した運行ガバナンス設計である。

EXHIBIT D — データ表 / TABLE

反対に、数字には限界もある。DMV自身が、disengagement report は企業間比較のために設計されたものではなく、deployment permit 下の運行は報告対象が異なると説明している。Waymoの安全データも、同社が公開する rider-only miles と比較手法に依存する。だからこそ、違反通知は安全率の広報と現場の是正要求を接続する新しい観測点になる。次の競争軸は「事故が少ない」だけでなく、「指摘された挙動をどれだけ速く直せるか」に移る。

◇ 論点 — THE ISSUE

ロボタクシー事業者は、違反通知を単発の法務対応に留めるのか、運行改善と自治体説明の中核KPIに組み込むのか。

01

通知ごとに個別是正し、既存の安全レポートへ最小限反映する

02

違反通知・停止イベント・事故データを統合した運行ガバナンス指標を公開する

03

都市ごとの運行拡大を抑え、警察・消防との事前計画を優先する

期限 — DEADLINE

2026-08-01のCPUC 2026年Q2報告期限、および7月以降のDMV違反通知運用の初回蓄積

決定権者 — DECIDER
  • California DMV
  • CPUC
  • WaymoなどAVメーカー
  • 市・郡の警察と初動対応部門

California DMVとCPUCが握る次の焦点は、違反通知を罰則の入口で止めるか、運行改善の公開指標へ押し上げるかである。メーカー側は、都市別に拡大するほどデータ開示の粒度と初動対応の手順を揃えなければならない。ここを先に標準化できる企業ほど、次の都市展開で自治体の心理的ハードルを下げやすい。

読み筋としては、Waymoのような先行勢が有利だが、優位は自動では続かない。走行距離が多い企業ほど、違反通知や停止イベントの絶対件数も増えやすく、説明が遅れれば安全実績の見え方を損なう。AVメーカーは安全率、違反通知、初動対応、都市別運行制限を同じダッシュボードで扱う必要がある。ロボタクシーの事業拡大は、車両AIの性能競争から、都市OSに接続する運用設計競争へ変わる。

❖ 要約 — IN ONE READ

カリフォルニアでは2026年7月1日から、無人AVの交通違反をメーカー責任として扱う notice of AV noncompliance が動き始めた。Waymoは2.206億マイルの走行実績を示すが、今後は安全率だけでなく、違反通知・停止イベント・事故データを結び、都市ごとの運行ガバナンスを説明できるかが競争軸になる。
