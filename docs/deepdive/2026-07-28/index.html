AI半導体、設計と製造の一体契約へ

LISTEN DeepDive 解説対談 2026-07-28

SamsungとBroadcomの5年MOUは、AI半導体の供給責任をどう変えるか

#deepdive#weekly#news-grasp#issue-20260728#Samsung-Electronics#Broadcom#HBM4#2nm#advanced-packaging
BACKGROUND

背景

01 / 03

Samsung ElectronicsとBroadcomは7月24日、2030年までの5年間に2000億ドル超と見積もる戦略協力MOUを結んだ。対象はHBM、2nm以下のファウンドリ、2.3D／2.5D先端パッケージである。ただし金額は確定発注額ではなく、設計から実装までを一つの交渉枠へ束ねたことが今回の変化だ。

Samsungは2月にHBM4の量産出荷を始め、3月にはAMDとHBM4の主要供給を含むMOUを締結した。7月のBroadcom協業では、メモリー供給に加えて通信半導体の2nm製造と先端実装まで明記している。部品単位の受注から顧客別の一体最適化へ進む流れが、4カ月で輪郭を増した。

この関係図の要点は、BroadcomとAMDがAIアクセラレーターで競う一方、両社がSamsungのHBM4供給へ接続している点にある。Samsungは顧客を奪い合うのではなく、競合する設計陣営を同じ製造スタックで支える。競争のボトルネックが設計性能だけでなく、統合供給の再現性へ移る構図だ。

DEEP DIVE

深掘り

02 / 03

Samsungの公開発表を同じ尺度で数えると、外部協業で明示する対象は2月のメモリー1領域から、3月のメモリーとファウンドリ協議、7月のメモリー・製造・実装の3領域へ広がった。これは売上や受注量ではなく発表範囲の集計だが、顧客が切り分けていた工程を一つの責任線へ寄せる変化を示す。

HBM4の定常ピン速度は11.7Gbpsで、HBM3Eの最大9.6Gbpsを22%上回り、上限は13Gbpsに達する。単一スタックの最大帯域も3.3TB/sとされる。性能向上は設計上の主張として確認できるが、顧客製品での量産歩留まりと電力効率が同じ比率で改善するとは限らない。

EXHIBIT D — データ表 / TABLE

Broadcomにとって一体契約の利点は、HBM、ロジック、実装の相互依存を同じ相手と詰められることだ。設計変更がメモリー帯域やパッケージ熱設計へ波及しても、工程間の調整をSamsung内で閉じやすい。その代わり、一つの工程で歩留まりが崩れると全体日程へ伝播するため、統合は調整コストを減らす一方で集中リスクを太くする。

2000億ドル超というMOUの見出しは大きいが、確定注文、個別数量、量産歩留まりは公表されていない。しかもSamsungの数値は同社発表であり、独立した顧客認定結果ではない。したがって評価の軸は契約総額ではなく、設計凍結から量産までの節目を外部から検証できるかに置くべきだ。

EXHIBIT E — 意思決定フレーム / DECISION
◇ 論点 — THE ISSUE

BroadcomはSamsungのメモリー・2nm製造・先端実装を一体で採用し、供給責任を集約するか

01

一体採用で共同最適化と開発速度を優先する

02

HBM・ファウンドリ・実装を分離調達して集中リスクを抑える

03

限定製品で段階認定し、歩留まり確認後に対象を広げる

期限 — DEADLINE

2026-12-31（HBM4量産拡大と初期案件の進捗確認）

決定権者 — DECIDER
  • Broadcom経営陣・製品部門
  • Samsung Electronics DS部門

Broadcomが選ぶべきなのは、2000億ドルという枠を一度に実行へ移すことではない。限定製品で段階認定し、歩留まり、電力効率、納期の三つを同じゲートで確認してから範囲を広げる案が現実的だ。統合の便益を残しながら、未確認の量産リスクを契約全体へ広げないためである。

次に見る数字は、SamsungのHBM売上目標だけではなく、Broadcom向けの個別認定完了、2nm製品の量産開始、2.3D／2.5D実装の生産能力である。これらが開示されないまま協力総額だけが膨らむなら、発表と実装の距離は縮まらない。設計から製造までの責任線が実測値で閉じるかが勝敗を分ける。

❖ 要約 — IN ONE READ

Samsung ElectronicsとBroadcomは、2030年までの5年間に2000億ドル超と見積もるMOUで、HBM、2nm以下の製造、先端実装を束ねた。競争軸は単品性能から設計・量産の一体最適化へ移る。ただし確定数量と歩留まりは未公表で、段階認定と量産指標の開示が実効性を測る条件となる。
