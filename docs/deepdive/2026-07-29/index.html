国産DUV、量産より適格性が分岐点

中国の国産DUV製造開始報道は、ASML依存と輸出規制に支えられた露光装置供給網をどこまで変え得るか

#deepdive#daily#news-grasp#issue-20260729#ASML#Aishengna#SMIC#DUV#半導体製造装置#輸出規制
BACKGROUND

背景

01 / 03

Aishengnaが液浸DUV装置の製造を始め、年内に中国の半導体3社へ納入すると報じられた。ただし、同社は事業内容を公表しておらず、関係各社も報道への回答を示していない。現時点で確認できるのは製造開始という報道であり、量産ラインで使える装置になったとの一次確認ではない。

オランダ政府は2023年に先端装置の許可制を始め、2024年9月には対象となるDUV装置を拡大した。米商務省BISも装置24種類、関連ソフト3種類、140の企業・組織を対象に規制を積み増した。一律禁輸ではないものの、調達と保守の予見性を下げる制度が、中国側に国産代替を急がせる需要を生んだ。

報道された装置は追加試験が必要で、ASMLの競合機と同等の性能にはなお距離がある。露光装置は搬入時点ではなく、重ね合わせ精度、歩留まり、稼働率と保守が量産工程で揃って初めて価値を持つ。したがって焦点は国産機の存在ではなく、中国の半導体メーカーがどの工程まで実用適格性を認められるかにある。

EXHIBIT C — 関係図 / RELATIONS
DEEP DIVE

深掘り

02 / 03

ASMLのDUV販売台数は3年間で396台から279台へ減少したが、2025年の中国向けDUV事業は会社想定より強かった。販売台数の減少を中国による代替の進展と直結させる材料はなく、むしろ既存装置の保守と工程ノウハウまで含めた供給関係が残る。装置の台数と供給網の支配力は同じ指標ではない。

同じ期間にASMLの研究開発費は40億ユーロから47億ユーロへ増えた。国産DUVが成熟工程や非クリティカル層から採用されても、精度改善を続ける装置本体、計測・検査、ソフトと保守の複合差はすぐには消えない。中国側の最初の勝負は最先端性能ではなく、止めずに使える工程範囲を広げることになる。

EXHIBIT D — データ表 / TABLE

関係図が示すように、オランダ政府と米商務省BISが外部調達を絞り、Aishengnaが代替供給を試み、中国の半導体3社が歩留まりを背負って採否を決める。この三者関係から導かれる次の動きは全面置換ではなく、既存ASML装置を維持しながら国産機を限定工程で認定する二重運用だ。規制が強いほど、調達責任は装置選定から工程分割へ移る。

EXHIBIT E — 意思決定フレーム / DECISION
◇ 論点 — THE ISSUE

中国の半導体メーカーは国産DUVをどの工程から量産認定し、ASML装置と保守への依存をどの速度で下げるか

01

成熟工程・非クリティカル層から国産機を限定導入する

02

ASML装置を主軸に据え、国産機は評価ラインにとどめる

03

工程を二重化し、規制リスクと歩留まりリスクを分散する

期限 — DEADLINE

2026年内の初号機納入と、2027年に向けた量産ライン適格性評価

決定権者 — DECIDER
  • SMIC・Hua Hong・CXMTの製造責任者
  • Aishengnaの装置・保守責任者
  • オランダ政府と米商務省BIS

SMIC・Hua Hong・CXMTにとって、限定導入は国産化の学習を進める一方で、低い稼働率が工程全体を止める恐れがある。ASML主軸は歩留まりを守れるが、許可や保守が細れば調達継続性が弱い。二重化は保険になる反面、工程設計と人材を二重に持つ費用が増すため、どの層を国産機へ切り出すかが実務上の決定点になる。

現時点の読み筋は、Aishengnaの報道値を量産能力と見なさず、初号機の稼働率、重ね合わせ精度、保守時間を工程別に測ることだ。2027年の台数目標より先に、顧客工場での適格性評価が公開または第三者確認されるかを追いたい。国産DUVが供給網を変えたと言えるのは、納入ではなく再現可能な量産実績が出た時点だ。

❖ 要約 — IN ONE READ

中国で国産液浸DUVの製造開始が報じられたが、関係各社は未確認で、装置には追加試験が必要だ。ASMLはDUV販売台数を減らす一方、研究開発費を3年連続で増やした。輸出規制が代替需要を生む構図は確かでも、勝負を決めるのは納入台数ではない。歩留まり・稼働率・保守を量産ラインで再現できるかが供給網転換の分岐点になる。
