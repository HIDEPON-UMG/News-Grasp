軽EV199万円、価格競争が始まる

LISTEN DeepDive 解説対談 2026-08-01

BYDの軽EV参入は、日本勢の価格・販売網・調達戦略をどう変えるか

#deepdive#daily#news-grasp#issue-20260801#BYD-RACCO#軽EV#日本市場#価格競争
BACKGROUND

背景

01 / 03

日産サクラが2022年6月に軽EV市場を切り開いてから4年、BYD Auto Japanは日本専用の「RACCO」を2026年7月28日に発売した。200グレードは補助適用後の実質負担を199.5万円からと打ち出し、従来の輸入EVより広い軽自動車需要へ踏み込んだ。 競争軸が輸入EV同士から軽自動車の日常利用へ移った ことが、今回の新しい材料である。

BYDの国内乗用車登録は2025年に3,742台となり、前年から68%増えた。ただし、増加率の高さは市場支配を意味しない。RACCOは親会社の車両・電池供給と日本法人の販売・保守を束ね、国内勢が持つ顧客接点へ挑む構図だ。 製品価格より販売後の信頼をどこまで短期間で補えるか が、数量拡大の制約になる。

国内軽EV勢は、既存の店舗網、整備、残価形成という見えにくい資産を持つ。対するRACCOは210kmと320kmの航続距離を用途別に分け、価格と電池容量の選択肢を明確にした。 競争は単純な安売りではなく、必要十分な航続距離をどの総費用で提供するか に移る。

EXHIBIT C — 関係図 / RELATIONS
DEEP DIVE

深掘り

02 / 03

BYDの登録は2025年1月の42台から同年12月の322台へ増え、2026年1月は156台だった。月ごとの振れが大きいため、単月をそのまま成長率に読み替えるべきではない。それでも2025年通年の3,742台は前年の2,223台を上回り、RACCO投入前から顧客基盤が広がったことを示す。 軽規格への参入は、この基盤を量販市場で試す段階に入った と読める。

RACCO 200は22.4kWhで210km、300系は35.8kWhで320kmを確保する。単に大容量を標準化せず、日常利用と遠出を分けた設計は、車両価格と電池原価の両方を抑える選択だ。 利用頻度に合わない航続距離へ過剰投資しない という提案が、価格に敏感な軽自動車市場と噛み合う。

EXHIBIT D — データ表 / TABLE

国内軽EV勢にとって重要なのは、車両価格だけを追随することではない。店舗網、修理日数、充電器との適合、保険、下取りまで含めた総保有費用を数値で示せなければ、RACCOの分かりやすい価格・航続距離の二層設計に比較軸を握られる。 調達側は補助後価格と運用リスクを同じ表で評価する必要がある。

EXHIBIT E — 意思決定フレーム / DECISION
◇ 論点 — THE ISSUE

日本の軽EV市場で、価格優位と販売後の信頼をどの組み合わせで標準提案にするか

01

補助後価格を最優先し、RACCO 200を日常利用の標準にする

02

航続距離を優先し、RACCO 300系と国内軽EVを総保有費用で比較する

03

国内勢の店舗網・残価・保守を優先し、価格差をサービス価値で吸収する

期限 — DEADLINE

2026年末（RACCOの販売実績と国内各社の次期軽EV施策を比較できる節目）

決定権者 — DECIDER
  • BYD Auto Japan経営陣
  • 国内自動車各社の商品・価格部門
  • 法人フリート・個人購入者

BYD Auto Japanが取るべき第一の選択は、200を量販グレードとして広げるか、300系で航続距離への不安を先に消すかである。国内勢には、値下げ、装備再編、保守価値の可視化という三つの応答がある。 年末までに見るべき数字は受注の大きさだけでなく、納車、修理、充電、下取りまで含む実績 だ。

法人フリートと個人購入者は、補助後価格に加えて、走行距離、急速充電の頻度、保守拠点までの距離を同じ調達表へ置くべきだ。筆者は、RACCO 200が送迎・買い物中心の需要を取り込み、国内勢が値下げよりサービス保証の定量化で対抗するとみる。 価格競争の勝者は最安車ではなく、不安を最小の総費用で消した車になる。

❖ 要約 — IN ONE READ

BYD Auto Japanは軽EV「RACCO」を投入し、200グレードの補助後実質価格を199.5万円からとした。2025年の国内登録は3,742台で前年比68%増。RACCOは210kmと320kmの航続距離を用途別に分け、日本勢の軽EVに価格と仕様の再説明を迫る。 次の焦点は受注数だけでなく、販売網、修理、充電、残価を含む総保有費用で信頼を証明できるか にある。
