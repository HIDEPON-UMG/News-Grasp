ロボタクシー、都市先行で量産局面へ

なぜロボタクシーは都市展開を加速できる一方、自家用の完全自動運転は2040年以降へずれ込むのか

#deepdive#daily#news-grasp#issue-20260711#Waymo#NHTSA#robotaxi#autonomous-driving
BACKGROUND

背景

01 / 03

Waymoは7月8日、デンバー、ラスベガス、サンディエゴ、タンパの4都市で、まず従業員を対象に無人運行へ移る方針を示した。既存の一般向けネットワークは10都市超に広がっており、今回の追加は一台の自家用車を全国で走らせる順序ではなく、都市ごとに運行条件を閉じて横展開する順序を鮮明にする。

この構図では、WaymoとHyundaiが車両と運転システムを分業し、NHTSAが人間向け操作部を前提にした規制を無人車向けに組み替える。事業者は走行地域、車両、遠隔支援、整備を一体で管理できるため、難しい条件を限定しながら学習量と稼働率を増やせる。

対して自家用車メーカーは、購入者がどこへ行くかを選べないうえ、運転者の関与、保険、整備、再販価格まで商品として成立させなければならない。ロボタクシーが先に伸びるのは技術の完成度だけでなく、都市フリートが運行条件と費用回収を管理できる事業形態だからであり、普及の時間差は所有モデルの差から生まれる。

EXHIBIT C — 関係図 / RELATIONS
DEEP DIVE

深掘り

02 / 03

Waymoの公表値では、2025年12月までの無人走行は1億7,070万マイルに達し、重傷以上の事故率は100万マイル当たり0.02件だった。比較対象となる人間運転の0.22件を下回るが、これは現在の運行都市と道路条件に基づく実績である。都市を増やしても同じ差を保てるかが、規模拡大の品質指標になる。

走行距離はPhoenixが全体の約40%、San Francisco Bay Areaが約31%を占める。大量の実走データを限られた都市で積み上げ、検証後に次の都市へ移す順序なら、未知条件を一度に抱えずに済む。NHTSAが操作部の形ではなく停止距離などの性能を残す方向へ動くことも、専用フリートが安全結果で説明する余地を広げる。

EXHIBIT D — データ表 / TABLE

採算面でもフリートが先行しやすい。McKinseyはロボタクシーの1マイル当たり費用が2025年から2030年以降に半分以下へ下がり得ると試算し、現在のAV運行費用も1マイル8ドル超から1ドル強へ低下する余地を示す。高価なセンサーや遠隔支援を高稼働で薄められる一方、自家用車では利用時間が短く、同じ装備費を一台の所有者が負担する。

したがって、ロボタクシーの都市拡大と自家用完全自動運転の後ずれは矛盾しない。前者は地域限定、集中整備、高稼働、遠隔支援を組み合わせた運行サービスであり、後者は購入者が選ぶ広い走行範囲で常時成立する製品である。技術の成熟度ではなく、失敗条件を誰が管理し、費用を何回の走行で回収するかが両者を分ける。

Waymoにとって最速の一般開放は走行データと売上を同時に増やすが、4都市を一度に広げれば地域差の原因切り分けが難しくなる。安全検証を長く取る案はNHTSAへの説明力を高める反面、量産能力と先行投資を遊ばせる。都市ごとに公開条件を固定し、同じ安全指標で順番に解除するのが現実的だ。

見るべき数字は乗車回数だけではない。新規4都市での100万マイル当たり負傷事故率、遠隔支援率、空車走行率が既存都市に近づくかを追う必要がある。これらが収束すればフリートの横展開モデルが証明され、収束しなければ自家用完全自動運転の遅れと同じく、地域ごとの例外処理費用が壁になる。2026年は無人化の可否より、都市をまたいで再現できるかを測る年になる。

❖ 要約 — IN ONE READ

Waymoは新たな4都市で無人運行へ進み、NHTSAも人間向け操作部を前提にした規制を見直し始めた。都市フリートは走行地域、整備、遠隔支援を一体管理し、高稼働で費用を薄められる。対して自家用車は広い走行条件と所有コストを同時に満たす必要がある。ロボタクシー先行の核心は、失敗条件と採算を事業者が閉じて管理できることにある。
