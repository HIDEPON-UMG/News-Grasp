欧州EV、関税防衛から現地生産競争へ

欧州EV販売の伸びと中国勢の現地生産化は、EUの関税防衛を域内生産・提携競争へどう変えるか

#deepdive#daily#news-grasp#issue-20260724#EU#Geely#Ford#BEV#Valencia
BACKGROUND

背景

01 / 03

欧州EV市場では、2026年上期の新車登録が 前年同期比5.7%増 となり、BEVの構成比は 15.6%から20.7% へ上がった。HEVは 37.3% と最大の動力源区分を保ち、ガソリンとディーゼルの合計は37.8%から29.7%へ縮んだ。需要の重心が内燃機関から移るなか、関税だけでは競争条件を固定できない局面に入っている。

Geely AutoとFord Europeは7月23日、Valencia工場に共同出資会社を置き、Ford 66%・Geely 34% の持分で 2028年から5車種を生産すると発表した。約50万台の潜在年産能力と開発費を分け合う構想は、輸出側と既存メーカーが同じ工場で協力しつつ販売では競う構図をつくる。欧州参入の主戦場が港から工場へ移ることを示す案件だ。

欧州委員会は中国製BEVに 7.8〜35.3% の相殺関税を設定し、Geelyには 18.8% を適用した。同時に2026年1月の指針では、最低輸入価格だけでなく販売経路、相互補填、将来のEU投資も価格約束案の審査対象にした。防衛措置を投資誘導へ接続できるかが、次の制度設計を左右する。

EXHIBIT C — 関係図 / RELATIONS
DEEP DIVE

深掘り

02 / 03

BEVのEUシェア20.7%は、2025年上期から 5.1ポイント上昇した。HEVとPHEVを合わせると、電動系3方式は市場の 67.8% を占める。これは一車種のヒットではなくパワートレイン構成の変化であり、域内の工場・部品・販売網を誰が押さえるかが競争の中心になる。

Geely―Ford JVは、関係図にある協調的競合を数字で裏付ける。Fordは 66%の支配持分 と約50万台の工場能力を持ち込み、Geelyは 上期海外販売47万4,228台 の伸びとEV商品を持ち込む。両社は固定費を分けながら別ブランドで顧客を奪い合うため、提携の成否は生産台数より開発費と稼働率の改善で測るべきだ。

EXHIBIT D — データ表 / TABLE

欧州委員会にとって難しいのは、輸入関税の対象企業がEU域内の既存工場へ入ると、通商政策と産業政策の境界が重なる点だ。価格約束指針は 最低価格・販売経路・将来投資 を審査対象に含めるが、現地組立だけで補助金問題が解消するとは限らない。雇用と能力移転を検証可能な条件へ落とせるかが、関税防衛を投資競争へ変える鍵になる。

EXHIBIT E — 意思決定フレーム / DECISION
◇ 論点 — THE ISSUE

EUは中国系メーカーと欧州既存メーカーの現地生産JVを、関税・価格約束・競争審査のどの組み合わせで扱うべきか

01

現行関税を維持し、JVは通常の競争・投資審査で承認する

02

最低価格と域内投資・雇用条件を束ねた価格約束を企業別に認める

03

中国由来の補助金と技術・調達依存までJV審査を広げ、承認を厳格化する

期限 — DEADLINE

2027年上期のJV運営開始予定まで。最初の5車種の生産開始は2028年

決定権者 — DECIDER
  • European Commissionの通商当局
  • EU・加盟国の競争／投資審査当局
  • FordとGeelyの取締役会

EU当局が現行関税だけを維持すれば制度は単純だが、企業は 域内生産へ移る誘因を強め、輸入統計だけでは実態を追えなくなる。反対にJV審査を広げすぎれば、遊休工場の再稼働とEV供給の拡大が遅れる。通商防衛と産業再生を別々に採点する設計が必要だ。

本稿の読み筋は、価格約束と域内投資条件を企業別に結び、最低価格、現地付加価値、雇用、能力移転を定期開示させる案が中心になるというものだ。Geely―Fordの 2027年上期の運営開始までに評価基準を定められれば、関税を一律に緩めず投資の質を比較できる。2028年の量産前に検証可能な条件を置けるかを見たい。

❖ 要約 — IN ONE READ

欧州EV市場では、2026年上期のBEV比率が 20.7% へ上昇し、GeelyとFordはValenciaで 5車種を生産するJV を発表した。中国製BEVへの関税は残るが、競争軸は輸入台数から域内工場、開発費、雇用へ移る。政策の成否は、工場の稼働率と域内付加価値の開示で測られる。EUが価格約束と現地投資を検証可能な条件で結べるかが次の焦点だ。
