Anthropic 先行上場、AI IPOバブルの号砲

Anthropicが約9,650億ドル評価でOpenAIに先んじてSECへ極秘IPO申請したことは、AIラボ間の資本市場レースと『AI IPOバブル』論をどう塗り替えるか

BACKGROUND

背景

01 / 03

わずか数日で構図が一段跳ねた。 Anthropic は 2026年6月1日、米 SEC に新規株式公開へ向けた Form S-1 を非公開（confidential）で提出し、ライバル OpenAI に先んじて上場準備フェーズへ入った。前回（6月2日）の本欄は AI ラボ同士の 私募ラウンドでの評価額レース——Anthropic が 1兆ドルの大台を視界に捉えた局面——を扱った。今回の変化点は、その評価額が Series H で 約9,650億ドルへ到達した直後に、舞台が 私募から公開資本市場へと移ったことにある。

時系列が示すのは、評価額が階段ではなく崖を登る速度で跳ねたという事実だ。Anthropic は 2025年9月の Series F で1,830億ドル、2026年2月の Series G で3,800億ドルと半年で倍増させ、さらに 5月の Series H で約9,650億ドルへ到達した。この間に OpenAI の 約8,520億ドル（2026年3月）を 初めて評価額で追い抜いたのが決定的な転換点である（Crunchbase は2月の8,400億ドルとも報じ、媒体間で数値に差があるため幅は要確認）。

力学の核は 後ろ盾の二重性にある。Anthropic を支えるのは Amazon（Series H で50億ドル）と Google（同100億ドル）であり、OpenAI の背後には Microsoft が立つ。ここで効くのが「協調的競合」だ——Google は出資者でありながら Gemini で前線競合し、Microsoft も Copilot で同種の二面性を抱える。戦略株主が同時に将来の競合という構造が、上場後の 主導権と囲い込みの綱引きを予感させる。

そして両社の頭上には、規制当局という共通の関門が立つ。SEC は 非公開 S-1 を審査し、開示水準と上場の可否を握る。私募では説明で済んだ損益が、公開審査では実額の提示を迫られる——この一点が、評価額一辺倒だった物語に 「実体は伴うのか」という重力を初めて加える。

DEEP DIVE

深掘り

02 / 03

数字が映すのは、実体の急拡大と評価のさらなる先行である。 Anthropic の年換算売上は 2025年1月の約10億ドルから2026年5月の約470億ドルへと 1年強でおよそ40倍に膨らんだ（チャート①）。一方で評価額は Series F の 1,830億ドルから Series H の 約9,650億ドルへと 売上の伸びをさらに上回る勾配で跳ねた。この売上曲線と評価額曲線の乖離こそ、ドットコム比較が持ち出される核心だ。

背景の関係図がそのまま論点になる。Anthropic を Amazon と Google が、OpenAI を Microsoft が支えるという布陣は、上場が「ラボ単体の勝負」ではなく「クラウド連合の代理戦争」であることを示す。Google が出資しながら Gemini で競合する二面性は、上場後に 優先供給・データ・チップ確保を巡る綱引きへ直結し、SpaceX（xAI 統合で約1.25兆ドル）を含む 兆ドル級の上場ラッシュが続けば、テック株の指数集中というマクロ波及まで広がる（チャート②）。

EXHIBIT D — データ表 / TABLE

では次に何が問われるか。 Anthropic が 先行上場で得るのは流動性と人材・顧客への信認だが、The Register が指摘するように S-1 が初めて損益の実額を開示すれば、「営業黒字に近い」という私募期の説明が市場の検証に晒される（黒字化は 未確認）。最初に実額を晒す者が最も厳しく値踏みされる——Anthropic の先行は 先行者利益と先行者リスクの両刃である。

読み筋はこうだ。 Anthropic の 先行上場は、Dan Ives が言う 『IPO市場の水門開放』の号砲になり得る一方、最初に実額を晒す者が最も厳しく値踏みされる構造にある。選択肢は突き詰めれば、「良い会社か」ではなく「約9,650億ドルという価格が実需に見合うか」への賭け方の違いに収斂する。ドットコム期に Amazon が生き残ったように、勝ち残る側を選別できるかが分水嶺だ。

私見では、OpenAI の申請動向が次の決定的シグナルになる。Anthropic が先行で 価格の物差しを市場に置けば、OpenAI・SpaceX の評価はその物差しで測られ、1社の S-1 開示が連合全体の値踏みを連鎖させる。6月のロードショー入りと損益開示こそ、バブル論が一段沈むか加速するかの最初の関門となる。

❖ 要約 — IN ONE READ

Anthropic は 2026年6月1日、OpenAI に先んじて SEC へ S-1 を非公開提出した。Series H で評価額は 約9,650億ドル、年換算売上は 約470億ドルに達したが、評価額の伸びは売上を上回り、ドットコムとの比較が再燃している。Amazon・Google と Microsoft が両陣営を支える 「協調的競合」の構造下で、兆ドル級 IPO ラッシュの号砲が鳴った。焦点は、価格が実需に見合うか否かに尽きる。
