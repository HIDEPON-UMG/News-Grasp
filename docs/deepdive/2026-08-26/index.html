OpenAI推論チップ、GPU依存を分解

    前回はTeslaが自動運転向け推論半導体の内製と複数調達を進める構図を扱った。今回の変化点は、OpenAIが生成AI向け独自チップの実測値を示し、推論基盤の置換可能性を数値で問える段階へ進んだことだ。

BACKGROUND

背景

01 / 03

前回はTeslaが推論半導体を内製しつつ製造先を分散する動きを追った。今回はOpenAIが独自チップの初ベンチマークを公表し、内製の狙いが供給確保から電力・遅延の同時最適化へ進んだ。生成AIでもモデルと半導体を一体設計する競争が実測段階に入ったことが変化点になる。

OpenAIはアクセラレーターの論理設計を握り、Broadcomがシリコン実装とネットワーク、Celesticaがボードとラックを担う。9カ月でテープアウトした点は垂直統合ではなく、設計権を内側へ寄せながら量産機能を外部専門企業へ配分した成果だ。競争単位は単体チップではなく、モデルからラックまでの分業設計へ広がっている。

対するNVIDIAはFY2026のデータセンター売上高を1,937億ドルまで伸ばし、GPU、接続、ソフトウェアを束ねた規模を持つ。Jalapeñoの開示範囲は推論専用で、学習基盤の置換を証明していない。OpenAIの交渉力はNVIDIAを排除することより、推論負荷を移せる選択肢を持つことで強まる。

DEEP DIVE

深掘り

02 / 03

NVIDIAのデータセンター売上高はFY2024の475億ドルからFY2026の1,937億ドルへ約4.1倍になった。この規模は需要の強さだけでなく、顧客がGPU、ネットワーク、開発環境をまとめて調達している現実を映す。性能差だけでは移行せず、既存ソフトウェアと運用の切替費用が調達判断を支配する。

その壁に対し、Jalapeñoはワット当たり処理量をNVIDIA比1.5〜1.9倍、応答速度を1.7〜3.6倍とOpenAIが主張する。3種類の公開モデルで方向性を示した点は前進だが、同社が設計し公表した測定であり、価格、歩留まり、稼働率は未開示である。優位性は独立環境で再現されるまで確定値ではない。

EXHIBIT D — データ表 / TABLE

関係図が示すように、OpenAIはチップを自作する一方、BroadcomとCelesticaの量産・統合能力を使う。つまりNVIDIAへの依存をBroadcom系の供給網へ単純に付け替えるのではなく、推論設計権を自社へ移して複数の専門企業を束ねる構造だ。調達リスクは消えず、支配するレイヤーがGPU選定から設計仕様へ上がる。

企業利用者に効くのは、OpenAIの原価がそのまま価格低下へ転じるかだ。初期展開が2026年末に始まっても、割当量、モデル別の対応範囲、API価格への反映は未確認である。短期の選定では公表ベンチマークを価格前提にせず、遅延・可用性・単価を契約上のSLAで比較する必要がある。

OpenAIが段階移行を選べば再現性を測りやすいが、コスト改善の速度は落ちる。電力制約拠点へ集中すれば効果は大きい一方、障害時の切替設計が難しくなる。第二系統として残す案は供給交渉に効くものの、二重運用費がかかる。最も妥当なのはモデルと拠点を限定した段階移行で、独立測定を通過した負荷だけを広げることだ。

読者側はJalapeñoの最大性能より、本番稼働率・実効単価・API価格の3点を追うべきだ。ここが未開示のままなら、ベンチマークは設計可能性の証拠にとどまる。2026年末の初期展開で、性能主張が調達条件と顧客価値へ変換されたかが本当の判定線になる。

❖ 要約 — IN ONE READ

OpenAIの独自推論チップJalapeñoは、NVIDIA比で電力効率1.5〜1.9倍、応答速度1.7〜3.6倍と同社が主張する。BroadcomとCelesticaを使う分業型内製で、NVIDIAを直ちに排除する構想ではない。2026年末の初期展開で本番稼働率・実効単価・API価格への反映を確認できるかが、GPU依存低下の判定線になる。
