公開ルールと供給線、競争の先回り

AI推論、半導体後工程、自動運転規則、政策投資、ゲーム配信まで、公開ルールと供給線が収益化の順番を決め始めた

BACKGROUND

背景

01 / 03

今日はOpenAIの推論チップ、ASEの後工程増強、WP29の自動運転包括規則、高市政権の370兆円投資工程表、PSN課金とSteam配信面が同じ朝に並んだ。共通点は、商品そのものより先に、それを回すルールと供給線が競争を決めることだ。

AIではJalapeñoが示したものが大きい。OpenAIはモデル提供者であるだけでなく、推論を走らせるシリコンとデータセンター供給の内側へ入ろうとしている。これはモデル精度の競争が、推論単価と供給安定の競争に下りてきたということだ。

製造ではASEの15工場計画と中国のタングステン禁輸が対になった。後工程の能力を増やしても、材料と特殊ガスが詰まれば量産は伸びない。投資計画、後工程、材料制約を別々に見ないことが今日の読み筋になる。

モビリティでは国連の包括規則とWaymoの安全実績が同時に出た。自動運転は「走れるか」から「事故時に検証できるか」へ移っている。公開ルールが安全説明の標準を決め、実績データがその標準に応える構図だ。

DEEP DIVE

深掘り

02 / 03

数字はそのまま比較できない。GW、百万マイル、万円、兆円、工場数は単位が違うからだ。ただし、並べる価値はある。すべてが市場に出る前の前提条件を表している。AIなら推論基盤、自動運転なら監査可能性、製造なら後工程と材料、ゲームなら配信面と課金回路だ。

特に製造とAIはつながっている。OpenAIが推論チップを持っても、パッケージング、検査、材料が詰まれば展開速度は落ちる。逆に、政府投資やASEの能力増強が進めば、AIモデル企業の供給線は太くなる。「どの会社が勝つか」より「どの供給線が先に詰まるか」を見る方が早い。

EXHIBIT D — データ表 / TABLE

ゲームも例外ではない。PS5本体販売が鈍ってもPSN課金が利益を支えるなら、勝敗は端末台数だけでは読めない。SteamのAI開示やレビュー速度も同じで、配信面のルールが作品の到達速度を左右する。ここでも公開ルールが収益化の先に立っている。
