02 / 03

§01 AI導入 — 国産LLMの比較記事から確認範囲を考える

国産LLMにはどんなものがある？主要モデルの比較と企業の選び方【2026年版】という記事は、モデルの選択肢と企業での選び方を扱う。 モデルを選べることは、入力データの扱い、出力の正しさ、契約条件、更新方法が確定したことを意味しない。モデルの提供元、評価データ、実行環境、ログの保全、停止方法を別々に確認する必要がある。 利用者が増えるほど、比較表の情報と業務利用の判断境界が重要になる。記事が示すのは選択肢と判断材料であり、導入後の安全性や効果の実証ではない。

EXHIBIT D — データ表 / TABLE

§02 市場情報 — 円急伸を予測ではなく観測項目へ戻す

円急伸、一時158円台前半 介入・日銀利上げ加速に警戒感という見出しは、為替の方向と政策要因へ読者の注意を向ける。 円相場の急変は判断材料の一つだが、実際の相場、政策発表、金利差、介入観測は別の時点で動く。記事の見出しを将来の価格や政策結果へ直結させず、更新主体と発表時刻を記録する方が再確認しやすい。 数字を扱うときは、観測値、解説、予測を同じ列へ置かない。何が本文で確認でき、何が今後の観測なのかを明示する。

§03 物流実装 — 自動運転トラック輸送を成果と混同しない

三井倉庫ロジ／Ｔ２ 日立産機の製品を自動運転トラックで輸送という記事は、自動運転トラック輸送を物流の実装条件へ接続する。 自動運転トラック輸送の実施は、特定区間で輸送が行われることを示す。一方で、運行の安全性、提供地域、通信、異常時の責任、継続条件が確定したことを意味しない。 輸送実績、運行計画、現場の安全記録は、証拠の種類が異なる。公開情報を次の判断へ移すには、いつ、誰が、どの資料で条件を確定するかを残す必要がある。

§04 製造投資 — 量産工場計画を成果の証明に読み替えない

愛知県内で量産工場 プロドローン、29年までに 年５万８千機を計画という記事は、量産工場の計画を設備投資と生産条件へ接続する。 量産工場の計画は、設備投資と生産能力の構想を示すが、実際の稼働、生産性、投資効果、供給網の強さを直接示す指標ではない。着工時期、設備規模、対象製品、販売先、量産開始条件を分けて記録する。 工場計画の価値を判断するなら、計画発表だけでなく、更新された説明、運用上の制約、次に確認する担当を同じ台帳へ置く。

§05 共通の因果 — 見出しから判断までに段差を置く

4件は、AI導入、市場の観測、物流実装、製造投資という異なる接続先を持つ。共通する因果は、公開情報が確認作業を始めるきっかけになり、本文と一次情報の照合が影響範囲を絞り、現場条件と責任者の確認が次の行動を決めるという順序だ。 この順序を飛ばすと、記事の期待が実績のように扱われる。反対に、未確認の点を明示し、停止や代替の条件まで残せば、続報で判断を更新できる。

§06 反証と意思決定 — 根拠が足りないものを広げない

当日4件だけでは、国産LLMの安全性、為替の方向、自動運転トラックの継続実績、量産工場の経済効果を断定できない。 編集担当は9月3日までに各URL、公開日、更新主体、本文根拠を一覧へ記録し、業務担当者は影響を受ける利用者、地域、設備、契約条件を分けて確認する。 情報システム担当はモデル実行や外部接続のログと停止操作を点検し、業務・物流担当は運行・量産の実施条件を確定する。 根拠が不足する場合は、記事の見出しを実績と呼ばず、対象範囲を拡大しない。
