BACKGROUND

背景

01 / 03

日銀は6月15日から金融政策決定会合に入り、31年ぶりとなる政策金利1%への利上げを最終判断する局面に入った。前日までの論点は「1%へ上げるか」だったが、当日になると焦点は上げたあとに何を言うかへ移った。植田和男総裁が欠席するなかで、会見の一語一句がUSD/JPYと日本国債の値動きを左右する。

この関係図で重要なのは、日銀の利上げ判断が単独で完結していないことだ。Fedが据え置き方向ならドル金利は高止まりし、米イラン和平で原油高の緊急度が下がれば、日銀がタカ派化する理由は一部薄れる。1%利上げは円防衛の入口であって、出口ではない。

一方で、日本側の期待インフレは無視できない。日経は、日米の予想インフレ率の逆転が迫り、「日銀の歯止めが効かない」懸念が増していると報じた。つまり日銀は、海外要因が和らいだから慎重でよい、とは言い切れない。国内の物価観が変わるなら、利上げ後の経路を曖昧にするほど市場は円安再燃を疑う。

EXHIBIT C — 関係図 / RELATIONS
DEEP DIVE

深掘り

02 / 03

会合当日の市場は、政策変更を二段階で読む。第一段階は1%利上げの有無で、ここはかなり織り込まれている。第二段階は、声明と会見が次回以降の利上げをどれだけ残すかだ。Bloomberg が「次のヒント」を焦点に置いたのはこのためである。1%は節目だが、円相場にとっては「そこが天井か、通過点か」の方が大きい。

Fedの据え置き観測は、日銀の効果を薄める。米金利が下がらないなら、日米金利差は圧縮されても消えない。日銀が1%へ動いても、会見が「しばらく様子見」と読まれれば、為替市場は利上げ材料の出尽くしとして反応しうる。逆に、追加経路を条件付きで残せば、円安再燃を抑える時間を買える。

EXHIBIT D — データ表 / TABLE

米イラン和平の観測は、日銀にとって両刃だ。原油・ホルムズ不安が後退すれば、輸入物価の緊急度は下がる。しかしそれは同時に、「急いで引き締める理由」を弱める。地政学リスク後退は市場には好材料だが、日銀の説明材料としてはタカ派色を薄める。ここで期待インフレの上振れをどう扱うかが、今回の会見の質を決める。

最も筋が通る読みは、日銀が1%利上げを実施しつつ、追加利上げはデータ次第として明確に残す形だ。原油リスクが和らいだからといって慎重姿勢に寄りすぎれば、期待インフレと米金利据え置きの前で円安圧力が残る。逆に強すぎるタカ派姿勢は、JGBと株式を揺らす。

したがって、今回の分岐点は政策金利そのものではなく、会見が1%を終点に見せないことだ。市場が「利上げはここまで」と読めば、円安は戻る。市場が「次も条件次第である」と読めば、日銀は少なくとも時間を買える。説明なき利上げは、円を守る政策ではなく、単なるイベント消化で終わる。

❖ 要約 — IN ONE READ

日銀は6月15日から金融政策決定会合に入り、31年ぶりの1%利上げを最終判断する。だが当日の焦点は、利上げの有無より利上げ後の説明へ移った。Fedは据え置き観測が強く、米イラン和平で原油リスクが後退する一方、国内の期待インフレ懸念は残る。1%は円防衛の必要条件だが、追加経路を示せなければ市場は出尽くしと読み、円安再燃を許す。
