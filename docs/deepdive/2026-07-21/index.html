MOIA試乗開始、運行統合が勝敗を分ける

MOIAのハンブルク試乗開始は、Apollo Goの規模先行に対し、公共交通と運行基盤を束ねる拡大モデルを成立させるか

#deepdive#daily#news-grasp#issue-20260721#MOIA#Apollo-Go#Hamburg#robotaxi#ridepooling
BACKGROUND

背景

01 / 03

MOIAは2026年7月15日、ハンブルクで乗客を乗せる自動運転ライドプーリングの試験を始めた。既存サービスでは280台を270平方キロで運行し、毎月数十万人を支える。自動運転車だけでなく、配車・遠隔支援・公共交通との接続まで一体で持つことが、同社の拡大戦略である。

Apollo Goは2026年第1四半期だけで完全無人の運行乗車320万回を記録し、週次ピークは35万回を超えた。対するMOIAは選定利用者の試乗段階だが、既存の有人運行で都市交通の現場を持つ。規模の差は大きい一方、量産後の運行を誰が引き受けるかという競争はまだ決着していない。

Uber・Lyftとの提携はApollo Goに需要導線を与え、MOIAとハンブルクの連携は都市制度と公共交通の接続点を与える。前者は市場横断の展開速度、後者は都市ごとの実装密度を強みにする。ロボタクシーの主戦場は自動運転精度だけでなく、運行責任を束ねる事業設計へ移った。

DEEP DIVE

深掘り

02 / 03

Apollo Goの累計乗車は2025年1月の900万回超から2026年4月の2200万回超へ伸び、展開都市も16から27へ約69%増えた。この規模は学習データ、遠隔支援、配車需要を循環させる。単一都市の実証だけでは追いつきにくいデータ優位が形成されている。

それでもMOIAには、既存の280台運行、270平方キロのサービス圏、毎月数十万人という都市交通の実務基盤がある。自動運転台数は未確認だが、2030年最大1万台という目標は車両調達だけでは達成できない。配車、清掃、充電、遠隔支援、事故対応を公共交通の中で回す能力が成否を分ける。

EXHIBIT D — データ表 / TABLE

関係図が示すように、Apollo GoはUber・Lyftを通じて需要導線を広げ、MOIAはハンブルクとの連携で制度と運行を先に結び付ける。両者の差は「技術対技術」ではなく「広域プラットフォーム対都市別ターンキー」にある。都市側は走行性能より先に、責任分界と運行KPIを比較可能にする必要がある。

◇ 論点 — THE ISSUE

都市はロボタクシー導入で、配車規模を先に取るか、公共交通統合と運行管理を一体調達するか

01

MOIA型として車両・配車・遠隔支援・公共交通統合を一体導入する

02

Apollo Go型として既存配車プラットフォームを通じて車両規模を先に広げる

03

限定区域で両方式を併走させ、安全・稼働率・補完効果の共通KPIで段階選定する

期限 — DEADLINE

2026年末までのMOIA試乗拡大とApollo Go欧州試験・国際配車提携の進捗確認

決定権者 — DECIDER
  • 欧州の都市・公共交通当局
  • MOIAとハンブルクの運行責任者
  • Baidu・Uber・Lyftの国際展開責任者

都市・公共交通当局が一体導入を選べば責任分界は明確になるが、事業者の切替余地は狭まる。配車規模を先に取れば需要獲得は速い一方、事故対応や公共交通補完を後付けするコストが残る。限定区域で共通KPIを揃える第三案が、規模と統治を同じ物差しで比べる現実的な入口になる。

2026年末までに見るべき数字は、試乗者数そのものではなく、無人走行率、1台当たり有償乗車、遠隔介入、運休、公共交通からの移行である。Apollo Goの規模優位は明確だが、MOIAが運行KPIを開示して都市統合の効果を示せれば、競争軸を台数から運用品質へ引き戻せる。

❖ 要約 — IN ONE READ

MOIAはハンブルクで乗客を乗せる自動運転試験を始め、既存の280台・270平方キロの運行基盤を自動化へつなぐ。累計2200万回超、27都市へ広がるApollo Goには規模で大差があるが、都市導入では配車だけでなく遠隔支援や公共交通統合も要る。次の勝敗は車両台数ではなく、責任分界と運行KPIを束ねられるかで決まる。
