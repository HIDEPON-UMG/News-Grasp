AIラボ評価額レース、Anthropic逆転で1兆ドル目前

Anthropicが評価額でOpenAIを逆転し両社がIPO準備に入ったAIラボの資本レースは、ARR・出資構造・公開市場の実態に照らしバブルか構造転換か

#deepdive#weekly#news-grasp#issue-20260602#Anthropic#OpenAI#Microsoft#AI投資#IPO
BACKGROUND

背景

01 / 03

2026 年の AI ラボ競争は、製品性能の比べ合いから資本市場の覇権争いへと軸足を移した。直近 7 日の収集記事でも Anthropic（32 件）と OpenAI（24 件）が突出し、events には「資金調達」「出資発表」「M&A」が並ぶ。その中心が、Anthropic が2026 年 5 月 28 日にシリーズ H で650 億ドルを調達し、ポストマネー評価額を 9,650 億ドル に乗せて、未上場 AI 企業として初めて OpenAI を評価額で逆転した一件である。値付けの主役が顧客から大型機関投資家へ移ったことが、この一手の本質だ。

逆転劇の構図はシンプルではない。Anthropic のシリーズ H は Altimeter・Dragoneer・Greenoaks・Sequoia が主導し、150 億ドルの既コミット分（Amazon の50 億ドルを含む）を内包する。一方の OpenAI は2026 年 5 月 22 日に SEC へS-1 を機密提出し、第 4 四半期（9 月説）の上場を視野に入れた。主幹事は Goldman Sachs と Morgan Stanley、狙う評価額は 8,520 億ドル から1 兆ドル超に及ぶ。私募で値を積む陣営と、公開市場へ出る陣営という対照が、ここで鮮明になった。

ただし「どこを起点に逆転したか」は出典で揺れる。OpenAI の直近の私募評価額は Axios が7,300 億ドル、日本の ITmedia が8,520 億ドルと報道が割れており、本稿は両値を併記して扱う。さらに注目すべきは、両陣営を支えるのが互いの競合でもあるクラウド大手という入れ子構造だ。Google は Anthropic に出資しつつGemini で正面から競い、Microsoft は OpenAI をAzure で支えながら自社Copilot を推す。NVIDIA は両陣営に等しく GPU を供給する唯一の供給者で、この軍拡の最大受益者に座る。誰が誰を支え、同時に誰と競うかという関係構造こそ、次の局面を読む鍵になる。

EXHIBIT C — 関係図 / RELATIONS
DEEP DIVE

深掘り

02 / 03

数字の傾きが、この逆転の震源を語る。Anthropic の年換算売上（run-rate ARR）は2024 年末の 10 億ドルから2026 年 5 月の 470 億ドルへと、約 1 年半で 47 倍に膨らんだ。SaaStr によれば中間点は 14 億ドル（2026-02）・19 億ドル（2026-03）・30 億ドル（2026-04）と毎月のように切り上がり、消費者課金に依存しない法人 API・開発者契約が約 8 割を占める。年換算 100 万ドル超を払う企業が500 社を超える厚みが、評価額の急騰を裏打ちした。

もっとも、評価額の逆転は売上の逆転とは別物である。実額の四半期売上では OpenAI（約 57 億ドル）が Anthropic（約 48 億ドル）を依然上回ると報じられ、300 億ドル級 ARR の計上方法（Anthropic は Google Cloud や AWS 経由の売上を含める）は両社で係争中だ。OpenAI の最高収益責任者は「約 80 億ドル過大」と反論し、純計算では約 220 億ドル相当だと主張する。つまり「評価額 9,650 億ドル」は実需の追い越しというより、出資構造を握るクラウド大手と機関投資家が先回りで値付けした期待値である――背景で見た協調的競合の構造が、ここで価格に直結している。

EXHIBIT D — データ表 / TABLE

マルチプルを並べると論点が際立つ。Anthropic は評価額を run-rate 売上で割ると約 20 倍だが、OpenAI はFY2025 実売上（131 億ドル）比で 65〜76 倍に達し、IPO 目標の1 兆ドルは「従来の収益利回りでは正当化しにくい」と Investing.com も警告する。加えて OpenAI は2026 年に約 270 億ドルのキャッシュバーン、黒字化は2029〜30 年見込みで、先行投資で赤字を掘り続ける段階にある。Anthropic の収益性は非開示＝未確認であり、ここは推計で埋めない。

だから次に試されるのは、私募で積み上げた期待値を公開市場が引き受けるかである。背景の関係図でいえば、Microsoft が支える OpenAI の先行上場が、Google・Amazon が支える Anthropic を含むAI ラボ全体の値付けの基準点になる。初値と需給が崩れれば Anthropic の 9,650 億ドル にも再評価圧がかかり、堅調なら私募の連鎖調達が正当化される。市場最高値（Micron の時価総額 1 兆ドル乗せや NVIDIA の設備投資依存）が示すとおり、この一本の上場が「バブルか構造転換か」の最初の審判台になる。

EXHIBIT E — 意思決定フレーム / DECISION
◇ 論点 — THE ISSUE

AIラボの評価額・IPOレースは公開市場が引き受け可能な構造転換か、それともバブルの臨界点か。投資家と各社は次の資金・上場局面でどう動くべきか

01

OpenAIの先行上場の初値・需給で実需を見極めてから動く

02

Anthropic型に私募で評価額を積み増し上場を急がない

03

売上マルチプルの正常化に賭けてAI配分を絞る

期限 — DEADLINE

2026年第4四半期（OpenAI上場目標・9月説）／各社の次四半期ARR開示

決定権者 — DECIDER
  • OpenAI・Anthropic経営陣（上場時期と価格設定）
  • 主幹事Goldman Sachs・Morgan Stanleyと機関投資家（需給形成）
  • 公開市場のIPO投資家（最終的な値付け）

三つの選択肢はトレードオフが明確だ。OpenAI の上場を待つ道は最も情報量が多いが、初値が出るまで判断が遅れる。Anthropic 型に私募で積み増す道は上場リスクを先送りできる反面、出口の遅延が評価額の正当性を問われ続ける。マルチプル正常化に賭けて配分を絞る道は、強気相場の取り残しを覚悟する必要がある。私の読み筋は、最初にボールを握るのが OpenAI 経営陣と主幹事 Goldman Sachs・Morgan Stanley である以上、2026 年第 4 四半期の上場需給が全 AI ラボの値付けを規定する、というものだ。逆転の主役 Anthropic ですら、他社の初値という外生イベントに評価額の正当性を握られている点に、このレースの危うさが集約される。

❖ 要約 — IN ONE READ

Anthropic は2026 年 5 月 28 日、シリーズ H 650 億ドルで評価額 9,650 億ドル に達し、OpenAI（直近 7,300〜8,520 億ドルで報道は割れる）を評価額で初めて逆転した。年換算売上は470 億ドル run-rate で法人 API 主導だが、実額売上では OpenAI がなお拮抗し、300 億ドル級 ARR の計上は係争中だ。OpenAI は S-1 を機密提出し第 4 四半期上場へ動くが、目標 1 兆ドルはFY2025 売上比 65〜76 倍でバーン約 270 億ドルを抱える。この先行上場が「バブルか構造転換か」の最初の審判台になる。
