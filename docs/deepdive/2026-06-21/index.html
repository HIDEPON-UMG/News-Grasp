アクセンチュア急落、AI変革の時間差

    前回は生成AIがコンサルの人月課金を掘り崩す構造を扱った。今回の変化点は、Accentureの予約減と株価急落で、その懸念が決算指標として表に出たことだ。

BACKGROUND

背景

01 / 03

Accentureをめぐる今回の焦点は、単なる決算ミスではない。前回は生成AIが人月課金を崩す構造を見たが、今回はFY2026 Q3で新規予約が前年を下回り、株価も急落したことで、AI変革の追い風と既存サービスの逆風をどう分けて評価するかが投資家の論点になった。

AccentureはFY2026 Q3で売上18.72Bドル、EPS3.80ドル、フリーキャッシュフロー3.6Bドルを出しており、表面上は崩れていない。重いのは、新規予約が19.32Bドルと前年の19.70Bドルを下回った点で、未来売上の入口が細る兆しとして読まれたことだ。

CEOのJulie Sweetは、企業がAIを本番展開へ進めるには時間がかかると説明した。これは正しいが、投資家から見ると「AI導入支援は伸びるが、従来型の作業量は削られる」という二面性が残るため、増える案件と減る人月が同じ決算に混ざるところが評価を難しくしている。

今回の関係図で見るべきは、AIネイティブ企業がAccentureの敵だけではない点だ。顧客のAI実装では提携相手になり、同時に業務自動化では作業代替の競争相手になるため、協調的競合の線を管理できるかがITサービス大手の次の勝敗を分ける。

EXHIBIT C — 関係図 / RELATIONS
DEEP DIVE

深掘り

02 / 03

データの核心は、Accentureの売上が16.47Bドルから18.72Bドルへ伸びる一方で、新規予約は21.1Bドルから19.32Bドルへ縮んだことだ。売上は過去案件の実行で増えるが、予約は将来案件の入口なので、投資家は現在の利益より次の成長率を見て売ったと読む方が自然だ。

さらに、FY2026 Q3の内訳ではConsulting予約が10.26Bドルに戻る一方、Managed Services予約は9.06Bドルに落ちた。AI導入の上流設計は伸びても、運用・保守・BPO型の継続業務が圧迫されるなら、「AIでコンサルが儲かる」という一枚絵では説明できない。

EXHIBIT D — データ表 / TABLE

ここで重要なのは、Julie Sweetの説明と市場の反応が矛盾していない点だ。企業がAIを全社展開するにはデータ整備、業務設計、統制、セキュリティが必要で、Accentureの仕事は残る。ただし、その仕事は従来の人員投入ではなく、短く高密度な再設計案件へ寄るため、売上認識と稼働率のモデルが変わる。

波及先はインドIT株や日本のSI・コンサル株にも広がる。Accentureが「AI支援の勝ち組」でも予約減を避けられないなら、同じ説明を掲げる各社は、AI案件の受注額だけでなく既存保守の置き換え率を開示しない限り、同じ疑念を受けやすい。

次の分岐は、AccentureがAIを「売上のテーマ」ではなく予約の回復として見せられるかにある。Consulting予約が伸びてもManaged Servicesが細れば、一時的な再設計案件で継続収益を置き換えられるのかという問いは残る。

読者が見るべき指標は、FY2026 Q4の新規予約、Managed Servicesのbook-to-bill、そしてAI関連案件の本番移行率だ。AIの需要はあるが、既存の人月を守る需要ではないため、次の決算で「AIが増えた」ではなく「予約が戻った」と言えるかが決定的になる。

❖ 要約 — IN ONE READ

AccentureのFY2026 Q3は、売上18.72Bドルと利益成長だけを見れば堅いが、新規予約19.32Bドルの減少がAI時代のITサービス評価を揺らした。AI導入支援は追い風でも、Managed Servicesの予約低下が示すように、増える再設計案件と減る人月を切り分ける開示が次の焦点になる。
