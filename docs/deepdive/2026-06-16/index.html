Rapidus包囲網、2nm量産は設計連携で決まる

Rapidusが英・伊の半導体設計連携を広げる中で、日本の2nm国産化は製造設備だけでなく、顧客設計とTSMC対抗の供給力をどこまで同時に作れるか

BACKGROUND

背景

01 / 03

Rapidusは2nm量産を2027年に掲げるだけでは足りなくなった。前回はTSMC熊本を軸に、日本の半導体再編を供給網の問題として見た。今回の変化点は、英半導体センターやイタリア設計法人との基本合意が収集記事に並び、製造ラインの完成より先に設計顧客を囲う競争が前面に出たことだ。

関係図で見ると、Rapidusの相手は単純にTSMCだけではない。日本政府の資本、IBMの技術移転、海外設計機関の入口、そしてAI・ロボティクス顧客が一列につながらない限り、2nm量産は工場完成で止まる。勝負は露光装置の搬入ではなく、設計データが量産ラインへ流れる速度に移っている。

DEEP DIVE

深掘り

02 / 03

数字はRapidusの課題をはっきり示す。2676億円の調達は国策スタートアップとして大きいが、報道ベースの量産必要額は約4兆円に達する。TSMCは一方で、2026年のCapExを520億〜560億ドルへ寄せ、HPC売上比率も2024年Q1の46%から2026年Q1の61%へ上げている。Rapidusが同じ土俵で設備量を競うのは、最初から分が悪い。

だからこそ、Rapidusの英・伊連携は単なる国際交流ではない。PDK、試作設計、パッケージ設計を早く顧客の手元へ届け、製造ラインに流す候補を増やす意味を持つ。TSMCが大口AI/HPCの供給量で押すなら、Rapidusは小ロットでも高性能な専用チップを短いサイクルで回す市場を先に押さえなければならない。

EXHIBIT D — データ表 / TABLE

ただし、その読み筋には弱点もある。単枚処理は精度とデータ収集に強い一方、Rapidus自身の説明でもバッチ処理より効率とコストに不利な面を持つ。AI顧客が短TATに高い対価を払うなら武器になるが、価格だけで比較されればTSMCの量産経済に飲まれる。設計連携の数ではなく、実際のテープアウトと歩留まり改善が次の証拠になる。

決定権者 — DECIDER

次に見るべきは、Rapidusが提携発表をどれだけ増やすかではなく、提携先から設計案件が出てくるかだ。選択肢は三つある。顧客候補を広く集める道、用途を絞って短TATの実績を作る道、政府支援を厚くしてTSMC型の容量競争へ寄せる道である。最も現実的なのは、用途を絞って成功例を先に作るルートだ。

その場合、TSMCとの比較軸も変わる。売上規模やCapExではなく、設計変更から試作、評価、再設計までの時間をどれだけ縮められるかが勝負になる。日本政府にとっても、追加支援の説得材料は「国産2nm」という看板だけでは足りない。初期顧客がRapidusを選ぶ具体的な理由を、2026年内に数字で示せるかが分岐点になる。

❖ 要約 — IN ONE READ

Rapidusの2nm戦略は、工場建設から設計顧客の囲い込みへ焦点が移った。英・伊連携は、TSMC型の設備量競争を避け、短TATでAI・ロボ向け専用チップを回すための入口である。だが資金規模ではTSMCに大きく劣るため、2026年内に試作案件と歩留まり改善を数字で示せるかが勝負になる。
