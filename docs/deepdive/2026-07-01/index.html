Joby・Toyota、空飛ぶ量産の入口へ

LISTEN DeepDive 解説対談 2026-07-01

JobyとToyotaのeVTOL製造JVは、空飛ぶタクシー競争を認証から量産へ移せるか

#deepdive#daily#news-grasp#issue-20260701#Joby#Toyota#eVTOL#FAA#JTAMPC
BACKGROUND

背景

01 / 03

JobyとToyotaの発表は、空飛ぶタクシーを「試験飛行の話」から製造会社の設計へ進めた点が新しい。SEC提出書類では、ToyotaがJTAMPCの51%、Jobyが49%を持つとされ、主導権は機体開発側だけでなく量産側にも移った。

Toyotaは2024年時点でJobyへの追加投資を発表し、累計投資額は8.94億ドルに達した。今回はそこに生産性・品質・コストを改善するJVが重なり、資金支援から製造責任へ踏み込む局面になった。

規制側も止まっていない。FAAは2026年3月にeVTOL Integration Pilot Programを導入し、Jobyは同月、FAA適合機の飛行試験開始を発表した。つまり今日の焦点は、認証が取れるかだけでなく、認証後に何機を安定して出せるかへ移っている。

EXHIBIT C — 関係図 / RELATIONS
DEEP DIVE

深掘り

02 / 03

数字を見ると、Toyotaの資本参加はすでに9億ドル弱まで積み上がっているが、JTAMPCの初期拠出は合計200万ドルにすぎない。ここで重要なのは金額の大きさではなく、製造権限と取締役構成を先に固めたことだ。

Joby側の課題は、現金残高よりも生産の段差にある。2025年Q2時点で9.91億ドルの現金・短期投資を持つ一方、年間資金使用は5.00億〜5.40億ドルと示されており、認証待ちの企業が量産体制を先に抱える重さが見える。

EXHIBIT D — データ表 / TABLE

生産能力も同じ構図だ。Marina拡張後の計画は年24機、2027年計画は月4機、Daytonの長期能力は年500機とされる。JTAMPCの役割は、この大きな段差をToyota Production Systemで埋め、少量の適合機から運航網に供給できる量へ橋を架けることにある。

ただし、量産だけでは商用化にならない。FAAのeIPPは安全なAAM運用の枠組み作りを目的に掲げ、JobyはFAA適合機のTIA向け試験を始めた段階だ。したがって、量産能力と規制データが同じ速度で進まなければ、機体は作れても路線が増えないという逆転が起きる。

◇ 論点 — THE ISSUE

JobyとToyotaは、認証完了前に製造JVをどこまで固定し、どの時点で商用供給能力として市場に示すべきか

02

03

期限 — DEADLINE

決定権者 — DECIDER

当面の読み筋は、Jobyが認証の進捗を、Toyotaが製造の再現性を、それぞれ市場に示せるかに集まる。製造標準を先に固定すれば量産の学習は早まるが、FAA評価で仕様が動けば手戻りが出る。認証待ちと量産準備を並走させる緊張が、今回のJVの核心だ。

逆に、認証を待ちすぎるとToyotaが持つ生産改善の時間を失う。都市・運航パートナーを先に固める選択肢もあるが、機体供給が伴わなければ路線計画は広告で終わる。次に見るべきは、FAAの試験進捗、Dayton立ち上げ、JTAMPCの追加契約が同じ四半期内でそろうかだ。

❖ 要約 — IN ONE READ

JobyとToyotaは、eVTOLを試験飛行の段階から量産準備の段階へ移すJVを立ち上げた。Toyotaは51%を持ち、Jobyは認証・運航構想を握る。焦点は、FAAのTIAとeIPPで安全データを取りながら、年24機から年500機級へ伸ばす量産の橋を架けられるかにある。
