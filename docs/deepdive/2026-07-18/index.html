万博EVバス、調達設計の撤退基準へ

LISTEN DeepDive 解説対談 2026-07-18

大阪メトロのEVバス活用断念は、公共交通の新技術調達を段階導入・検収・保守責任中心へどう変えるか

#deepdive#daily#news-grasp#issue-20260718#Osaka-Metro#EV-Motors-Japan#EVバス#公共調達#リスク管理
BACKGROUND

背景

01 / 03

Osaka Metroは万博輸送で、EVモーターズ・ジャパン製の大型115台、小型35台、超小型40台を使った。全ルートのEV化を万博後の社会実装につなげる構想だったが、事故と立入検査を受けて全車を停止し、2026年3月に使用断念へ転じた。実証と本番を同時に大規模化したことが、撤退時の損失を広げた。

7月17日の調査結果で、Osaka Metroは段階的な試験導入、外部有識者の活用、撤退基準の明確化を再発防止の基本方針に置いた。これは車両不具合だけの反省ではない。現場の安全上の懸念が経営判断へ届かず、客観的な計画審査や内部監査も弱かったという、新技術調達の統治不全への回答である。

供給者のEVモーターズ・ジャパンは、契約解除を認めず、運行停止はOsaka Metroの判断だと主張している。発注者側は安全性への疑念と充電不具合の頻発を挙げ、96億円を請求したと報じられた。責任分界が争われるほど、調達時に検収条件、保守部品、ログ提出、停止・撤退時の費用負担を固定する契約の観測可能性が重要になる。

EXHIBIT C — 関係図 / RELATIONS
DEEP DIVE

深掘り

02 / 03

第一の論点は、190台を一つの調達単位として扱ったことだ。用途は会場外、会場内、オンデマンドの3系統に分かれていたのに、事故と立入検査の後は全車停止となり、継続利用台数はゼロへ落ちた。用途別の小規模導入と合格判定を積み上げていれば、障害の影響範囲を限定できた可能性がある。

第二の論点は、約67億円の損失が車両価格だけで説明できないことだ。公表額には補助金返還引当金なども含まれ、供給者への請求は96億円と報じられた。万博輸送ではEVバス自体は使われ、輸送実績報告もゼロエミッション施策として評価したが、会期後の転用価値が消えた。イベント納期と長期運用価値を同じ合格判定にしない設計が要る。

EXHIBIT D — データ表 / TABLE

第三の論点は、Osaka MetroとEVモーターズ・ジャパンの責任分界である。発注者は不具合と安全懸念を理由に契約解除へ進み、供給者は停止判断の主体を争っている。契約書に性能値だけを置いても、誰がログを保管し、誰が故障原因を立証し、どの閾値で停止するかが曖昧なら紛争は長引く。検収を証拠設計として組み立てることが調達の核心になる。

したがって公共交通の新技術調達では、実証車群、本番車群、転用車群を分離し、各段階に安全KPI、保守KPI、撤退KPIを置くべきだ。大阪メトロの再発防止策はその方向を示したが、実効性は次回案件で外部審査と現場の拒否権を契約・稟議へ落とせるかで決まる。技術導入の速さより、止め方を先に設計する必要がある。

EXHIBIT E — 意思決定フレーム / DECISION
◇ 論点 — THE ISSUE

公共交通事業者は新技術車両を一括調達せず、どの段階・証拠・撤退条件で本番台数を増やすべきか

01

少数実証から安全・稼働率・保守部品の合格後に段階増車する

02

納期を優先して一括導入し、保証・損害賠償条項で下流リスクを移転する

03

車両保有を抑え、性能連動のリースや運行サービス契約へ切り替える

期限 — DEADLINE

Osaka Metroが再発防止策を次の新技術導入案件の稟議・調達仕様へ反映する時点

決定権者 — DECIDER
  • Osaka Metro取締役会・調達審査部門
  • 大阪市など公共株主・補助主体
  • 国土交通省など安全規制当局

Osaka Metroが選ぶべきは、少数実証から段階増車へ進む案を基本に、供給者の保守能力が読めない部分だけ性能連動契約で補う組み合わせだ。一括導入は納期を守りやすいが、今回のように全車停止が起きると損失が同時化する。調達数量をリスク予算として扱うのが現実的である。

次に見るべきは、取締役会が掲げた撤退基準を数値化できるか、現場の安全懸念に稟議停止権を持たせるか、供給者に故障ログと部品在庫を提出させるかである。再発防止策が研修や会議体の追加にとどまれば、納期圧力の前で再び弱くなる。経営責任を契約とデータの境界へ移すことが次の節目だ。

❖ 要約 — IN ONE READ

Osaka MetroはEVMJ製EVバス190台の使用を断念し、約67億円の特別損失を計上した。7月17日の調査結果は、段階的な試験導入、外部知見、撤退基準を再発防止の柱に据える。焦点はEVの是非ではなく、実証・本番・転用を分け、検収ログ、保守責任、停止条件を契約へ埋め込むことだ。新技術調達は導入速度より止め方を先に設計する局面へ入った。
