Anthropic急拡大、メモリ供給戦へ

Anthropicの急拡大は、MicronのHBM/DRAM/SSD供給をどこまで戦略資産化するか

#deepdive#daily#news-grasp#issue-20260624#Anthropic#Micron#HBM#Claude#AI-infrastructure#memory

    前回は価格競争とIPO準備を扱った。今回の変化点は、Anthropicが資金調達後にMicronとのメモリ供給・共同設計まで踏み込み、競争軸がモデル価格から計算資源の確保へ広がったことだ

BACKGROUND

背景

01 / 03

前回はAnthropicのIPO準備と価格競争を見たが、今回はモデルを安く出す前提になる供給網が主役に変わった。Micronは6月22日にAnthropicとの戦略契約を公表し、HBM、DRAM、SSDの設計協力、供給、Claude導入、Series H投資を一体化した。価格競争の裏側で、メモリが調達品から交渉力へ変わる局面だ。

Micronの発表で重要なのは、単なる「部品売り」ではなく、Anthropicのワークロードに合わせてメモリとストレージを分析・最適化すると書いた点だ。HBMやSSDの需給を押さえるだけなら購買契約で足りるが、共同設計まで入ると、モデルのトークン経済性そのものに供給元が入り込む。

Anthropic側も、5月28日のSeries Hで650億ドル調達、ポストマネー評価額9650億ドル、ランレート売上470億ドル超を示した。これだけの拡張をIPO前に掲げるなら、次の制約はモデル能力だけでなく、クラウド容量、HBM、ストレージを複数年で確保できるかに移る。

EXHIBIT C — 関係図 / RELATIONS
DEEP DIVE

深掘り

02 / 03

数字の読み筋は単純だ。Micronの売上はFY2025 Q3の93.01億ドルからFY2026 Q2の238.60億ドルまで伸び、Cloud MemoryとCore Data Centerも同じ方向に動いた。ここにAnthropicの470億ドル超のランレート売上が重なると、AIモデルの成長はGPUだけでなくメモリの予約競争として表に出る。

もう一つの論点は、Anthropicが三大クラウドを使いながら、Micron、Samsung、SK hynixを戦略インフラパートナーに並べたことだ。クラウド容量が上限ならAWSやGoogleが主役になるが、メモリ帯域とSSD効率が上限ならMicronの共同設計が効く。供給元がモデル企業のコスト構造に入るほど、価格競争の勝敗は調達力に近づく。

EXHIBIT D — データ表 / TABLE

ただし、公開情報だけではMicronのAnthropic向け供給量、投資額、契約期間は未確認だ。したがって、今回の結論は「AnthropicがMicronを大口サプライヤーとして固定した」ではなく、「Anthropicの拡張が、メモリ供給元を共同設計・資本参加まで巻き込む段階に入った」というものになる。未公表の数量を埋めず、公開済みの構造変化だけを見るのが安全だ。

◇ 論点 — THE ISSUE

AnthropicはIPO審査と需要拡大の間に、メモリ・ストレージ供給を複数年で固定できるか

01

Micronとの共同設計をClaudeの主要ワークロードへ深く組み込む

02

Samsung / SK hynixを含む複数調達で供給リスクを分散する

03

クラウド側の容量契約を優先し、メモリ供給はクラウド経由に寄せる

期限 — DEADLINE

SECのS-1審査完了と市場条件が整うIPO判断前、次の確認点はMicronのFY2026 Q3決算発表

決定権者 — DECIDER
  • Anthropic経営陣・Compute責任者
  • Micron経営陣・データセンター部門
  • 主要クラウドパートナー
  • SECと資本市場

次に見るべきは、MicronがFY2026 Q3以降でCloud MemoryとCore Data Centerの伸びをどこまで維持するかだ。Anthropic契約は象徴性が強いが、実際に効くのは部門売上、粗利、設備投資、HBM供給見通しに反映されたときである。契約発表よりも、供給制約が数字に出るタイミングを追う必要がある。

Anthropicにとっての選択肢は、Micronに深く寄せて最適化を取るか、複数調達で供給の独立性を守るかだ。前者はトークン効率と性能改善を狙いやすいが、供給元依存が強まる。後者は調達リスクを下げる一方、共同設計の学習効果は薄くなる。IPO前の投資家は、売上成長よりも「成長を支える部品を確保できるか」を見るはずだ。

❖ 要約 — IN ONE READ

AnthropicはSeries H後、Micronとの戦略契約でHBM/DRAM/SSDの共同設計・供給・資本参加まで踏み込んだ。MicronのAI関連部門はFY2026 Q2に大きく伸びており、Claude拡大の焦点はモデル価格からメモリ供給網へ広がっている。
