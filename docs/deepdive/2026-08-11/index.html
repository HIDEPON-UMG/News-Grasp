TSMC最高売上、AI半導体は工場運用戦へ

TSMCの売上加速とSamsungの一体供給契約は、AI半導体の競争軸をどう変えるか

#deepdive#daily#news-grasp#issue-20260811#TSMC#Samsung-Electronics#Broadcom#NVIDIA#AI半導体#2nm
BACKGROUND

背景

01 / 03

TSMCの2026年7月売上高は4,675億8,000万台湾ドルとなり、1月以降の最高額を更新した。1〜7月累計も2兆8,720億6,400万台湾ドル、前年同期比37.0%増に達する。AI半導体の需要が、期待ではなく工場の売上として現れたことが今回の変化点だ。

競争の構図は、設計ルールの優劣だけでは捉えきれない。Samsung ElectronicsとBroadcomは、HBM・2nmロジック・先端パッケージを束ね、2030年までの5年間で2,000億ドル超の協業を見込む。一方、TSMCはNVIDIAの計算基盤を工場へ取り込み、顧客契約と量産運用を一体で磨く競争へ踏み込んでいる。

TSMCとSamsungは2nm量産で競うが、それぞれが設計企業と結ぶ線は異なる。TSMCはNVIDIAのAIを露光・工程制御・欠陥検査へ組み込み、SamsungはBroadcomとメモリーから実装までを契約単位にする。競争力の単位が、単一プロセスから量産エコシステムへ広がったと読める。

DEEP DIVE

深掘り

02 / 03

TSMCの売上高は2月に3,176億5,700万台湾ドルへ下がった後、7月には4,675億8,000万台湾ドルまで上昇した。前年比も4月の17.5%増から6月の67.9%増へ振れ、単純な右肩上がりではない。需要の強さと量産の立ち上がり時期を分けて読む必要がある。

ここで関係図の線が効く。NVIDIAはTSMCの顧客であるだけでなく、cuLithoで20〜50%、cuESTで平均50倍という工程改善を支える。SamsungもBroadcomとHBM・2nm・先端実装を一体化した。設計企業を工場改善へ巻き込めるかが、供給能力の差へ変わる。

EXHIBIT D — データ表 / TABLE

ただし、SamsungとBroadcomの2,000億ドル超は5年間の協業見込みであり、TSMCの月次売上という実績値と同列には置けない。契約規模は供給意欲を示すが、歩留まり・量産時期・実出荷は別の評価軸だ。大きな発表を実際の供給能力と読み替えないことが、調達判断の前提になる。

決定権者 — DECIDER
  • 半導体設計企業のCTO・調達責任者
  • クラウド事業者のAI基盤責任者

調達責任者にとって、単一陣営への集約は量産学習を深く共有できる半面、供給制約と価格交渉力を抱える。分散は停止リスクを抑えるが、設計移植、検証、パッケージの再設計が増える。契約価格だけでなく切替可能性の費用まで比較する必要がある。

読み筋は、全面的な二重化より製品世代別の分散が現実的だ。主力世代は実績のある量産線へ置き、次世代品ではSamsungの一体供給を検証する。そのうえで歩留まり、納期、工程変更時間を同じ尺度で測る。供給先の数ではなく、実際に切り替えられる設計を持つことが分散の価値を決める。

❖ 要約 — IN ONE READ

TSMCの2026年7月売上高は4,675億8,000万台湾ドルと年初来最高を更新した。SamsungはBroadcomと2,000億ドル超の協業を掲げ、HBM・2nm・先端実装を束ねる。NVIDIAがTSMCの工場改善まで担うなか、AI半導体の競争軸はプロセス性能から、設計企業を巻き込んだ量産エコシステムへ移っている。
