韓国利上げ、AI成長の代償を測る

LISTEN DeepDive 解説対談 2026-07-17

韓国中銀の3年半ぶり利上げは、AI輸出主導の成長と家計債務・インフレの板挟みをどう変えるか

#deepdive#daily#news-grasp#issue-20260717#韓国銀行#Samsung-Electronics#SK-hynix#AI半導体#金融政策
BACKGROUND

背景

01 / 03

韓国銀行は7月16日、政策金利を2.50%から2.75%へ引き上げた。利上げは3年半ぶりで、7人の金融通貨委員が全員賛成した。輸出と投資を押し上げるAI半導体景気を歓迎しながら、同じ成長が物価と住宅信用を刺激するため、好況を冷やさず過熱だけを抑える局面へ入った。

Samsung ElectronicsとSK hynixは、AI向けメモリで競争しながら世界需要を支える。韓国銀行は、半導体価格の上昇が企業利益、投資、賃金、税収を通じて内需へ波及するとみる。つまり輸出好調は外需だけで完結せず、国内の購買力を押し上げる経路を持ち、成長の恩恵が需要インフレへ転じる境目が政策判断を難しくする。

金融面では、首都圏家計・住宅市場のローンが月8〜9兆ウォンの高いペースで増加し、ソウルと京畿道の住宅価格上昇も加速した。政策金利の引き上げは信用需要を抑える一方、既存債務の返済負担も高める。韓国銀行は景気刺激の解除ではなく、AI景気が住宅と物価へ漏れ出す速度を抑える調整を選んだ。

DEEP DIVE

深掘り

02 / 03

韓国の総合CPIは1〜2月の2.0%から6月の3.2%へ上昇し、物価目標との差は1.2ポイントに開いた。コアCPIも2.5%で、エネルギーだけでは説明し切れない。半導体景気による所得改善が内需へ回れば、輸入コスト型から需要型へ物価圧力が広がる可能性がある。

ただし、AI半導体株は好況一色ではない。7月2日にSamsungが9%超、SK hynixが約15%下落し、7月7日にもそれぞれ7%、6%下げた。韓国銀行はHBMを中心とする供給制約からスーパーサイクル継続を見込むが、市場は投資採算と供給増のリスクを織り込む。金利政策が依存する成長エンジン自体も高変動である。

EXHIBIT D — データ表 / TABLE

関係図で示したように、Samsung ElectronicsとSK hynixの供給競争は世界のAI投資を受け止め、その利益が国内所得と住宅信用へ流れる。韓国銀行の利上げはこの還流を遮断するのではなく、物価と家計債務への流量を絞る操作だ。利上げが速すぎれば半導体投資と家計消費を同時に抑え、遅すぎれば住宅価格とインフレ期待の固定化を招く。

焦点は2.75%という金利水準そのものより、追加利上げを決める順序にある。韓国銀行は成長、物価、金融安定の三条件を並べ、今後も引き締め方向を維持するとした。次の判断では、CPIの鈍化だけでなく、家計ローンの月次増加が8〜9兆ウォンから落ちるか、半導体利益が賃金と内需へどこまで波及するかが、停止か続行かを分ける実務的な信号になる。

◇ 論点 — THE ISSUE

AI半導体主導の成長を損なわず、物価と首都圏の家計債務を抑えるため、追加利上げと住宅向け信用規制をどう組み合わせるか

追加利上げを早め、物価期待と住宅信用を同時に抑える

02

2.75%で一度停止し、CPI・家計ローン・半導体投資の反応を確認する

03

政策金利は維持し、住宅ローン規制などマクロプルーデンス措置を強める

期限 — DEADLINE

決定権者 — DECIDER
  • 韓国銀行金融通貨委員会
  • 韓国の金融当局

韓国銀行金融通貨委員会が早期の追加利上げを選べば、物価期待と信用膨張を先に抑えられる半面、AI投資の変調時に景気を二重に冷やす。いったん停止すればデータを待てるが、住宅価格の加速を許すおそれがある。政策金利と住宅信用規制を分業させる案は、成長と金融安定の衝突を和らげる。

現時点の読み筋は、2.75%を短期間維持しつつ、家計ローンと首都圏住宅への措置を先行させる組み合わせだ。総合CPIが3%台に残り、家計ローンの増加ペースも落ちなければ追加利上げへ移る。半導体株の変動が示すように成長側の不確実性も高く、単一指標ではなく三条件の同時確認が必要になる。

❖ 要約 — IN ONE READ

韓国銀行はAI半導体が輸出・投資・所得を押し上げる一方、6月CPIが3.2%、家計ローンが月8〜9兆ウォン増となったため、政策金利を2.75%へ上げた。次の焦点は追加利上げの有無だけではない。AI成長を傷めず住宅信用を抑える政策分業を設計できるかが問われる。
