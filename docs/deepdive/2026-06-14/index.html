BOJ 1%前夜、植田不在の円防衛

BACKGROUND

背景

01 / 03

日銀は6月15〜16日会合で政策金利を1%へ引き上げる観測を背負ったまま、会合直前を迎えた。前回はUSD/JPYの160円攻防を、日米金利差と為替介入の問題として見た。今回の変化点は、植田和男総裁の入院で氷見野良三副総裁が会合を議長代行し、内田眞一副総裁が会見を担う見通しになったことだ。政策そのものより、政策をどう説明するかが市場の焦点になった。

この関係図の核は、日銀が国内の物価だけでなく、Fed・ECB・ホルムズ海峡の三方向から同時に押されている点にある。ECBは6月11日、イラン戦争に伴うエネルギー高を理由に預金金利を2.00%から2.25%へ上げた。欧州が先に「見過ごさない」を選んだことで、日銀の据え置き説明は一段難しくなった。

一方、植田総裁の不在は、利上げの是非そのものより会見のニュアンスを難しくする。FTは、利上げがかなり織り込まれた状況では、次回以降の経路をどれだけタカ派に示すかが円と債券を動かすと整理している。内田副総裁が慎重に話せば、1%利上げでも円安が残る。逆に追加利上げの含みを強く出せば、JGB利回りと株式バリュエーションへ圧力がかかる。

EXHIBIT C — 関係図 / RELATIONS
DEEP DIVE

深掘り

02 / 03

データが示すのは、日銀がインフレ対応と景気配慮を同時に迫られる狭い通路に入ったことだ。原油は戦前の70ドル前後から危機時に113ドルまで跳ね、6月12日は一時85ドル割れまで下げたが、その後89ドル超へ戻した。物価圧力はピークアウトしても、輸入国の日本が安心できる水準には戻っていない。

だからECBの利上げは、日銀にとって単なる海外ニュースではない。ユーロ圏はCPI 3.2%と成長鈍化を抱えながら、預金金利を2.25%へ上げた。日銀が1%へ動くなら、「円安対応」だけでなく「エネルギー高の二次波及を先に抑える」政策として説明する必要がある。説明が弱ければ、為替市場は利上げを一度きりと見て、円売りを再開する。

EXHIBIT D — データ表 / TABLE

もう一つの論点は、利上げ後の天井が見えないことだ。FTが紹介した見方では、植田体制下の政策金利は2027年末に2%へ届く可能性がある。一方で、1〜3月GDPは年率1.8%へ下方修正され、設備投資も弱い。利上げを急げば景気を冷やし、遅れれば円安と輸入物価が家計を削る。この二律背反こそ、1%という節目の重さである。

関係図に戻ると、財務省の介入は市場の速度を落とすブレーキであり、日銀の利上げは金利差の燃料を細らせるエンジン調整だ。4月末の円買い介入は11.7兆円規模と報じられたが、それでも円安圧力は戻った。160円防衛は、介入だけでは完結せず、日銀が追加経路を示して初めて持続する。

EXHIBIT E — 意思決定フレーム / DECISION
◇ 論点 — THE ISSUE

日銀は1%利上げ後に、円安・輸入物価・景気減速を同時に抑える経路をどう示すか

01

1%利上げに加え、追加利上げの含みを明確にして円安を抑える

02

1%利上げにとどめ、景気減速と債券市場を優先して慎重な会見にする

03

利上げを見送り、財務省の介入警戒と海外要因の沈静化に賭ける

期限 — DEADLINE

2026-06-15〜16 日銀金融政策決定会合、同週の内田副総裁会見、翌週のFed会合

決定権者 — DECIDER

  • 氷見野良三副総裁
  • 内田眞一副総裁

最も筋が通るのは、日銀が1%利上げを実行しつつ、追加経路は条件付きで残す選択だ。植田総裁不在の会見で過度にタカ派化すれば、JGBと株式が揺れる。だが慎重すぎれば、USD/JPYは1%を織り込み済みとして160円圏へ戻る。利上げは実弾、会見は照準であり、今回は照準の精度がいつも以上に問われる。

見落としてはいけないのは、市場が日銀だけを見ていないことだ。Fedが高金利を維持し、ECBがエネルギー高で利上げに動き、原油が90ドル近辺で不安定に残るなら、日本だけが景気配慮で慎重に構える余地は狭い。私の読み筋は、1%利上げそのものより、内田会見が「次もあり得る」と市場に読ませられるかが円防衛の分岐点だ。そこに失敗すれば、財務省の介入警戒が再び前面に出る。

❖ 要約 — IN ONE READ

日銀は6月15〜16日会合で政策金利を1%へ引き上げる観測が強いが、植田総裁の入院で会合後の説明は副総裁体制になる。前回のUSD/JPY 160円攻防から、今回は利上げ後の経路説明が焦点へ移った。ECBはエネルギー高を受け2.25%へ利上げし、Brent原油は危機高値113ドルから下げても90ドル前後に残る。1%利上げは円防衛の必要条件だが、追加利上げの含みを示せなければ円安圧力は残る。
