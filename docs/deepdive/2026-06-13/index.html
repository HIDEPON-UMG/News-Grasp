AI価格競争へ、OpenAI値下げとAnthropic上場の攻防

OpenAIのトークン値下げ検討とAnthropicのIPO準備中トラフィック急増が同時に表面化する中で、フロンティアAIモデルの競争軸は能力から価格へ移り、両社のビジネスモデルの違いはどこで決着するか

#deepdive#weekly#news-grasp#issue-20260613#OpenAI#Anthropic#Google#Claude#ChatGPT#AI価格競争#ai
BACKGROUND

背景

01 / 03

OpenAIがトークン課金の引き下げを社内で検討し始めた、とBloombergが6月12日に報じた。協議は初期段階で何も決まっていないが、報道は値下げ検討を「競合する米Anthropicが同様の料金引き下げに踏み切る可能性を見据えたもの」と位置づける。能力で殴り合っていた2社が、はじめて価格で身構え始めたという転換点である。前提として、この市場の値付けは5月に動いている——GoogleがAI Ultraの上位層を月250ドルから200ドルへ20%引き下げ、入門層に月100ドルを新設したとき、OpenAIとAnthropicは価格を維持して静観していた。その静観が、わずか3週間で崩れかけている。

この構図の核は、「価格を下げる側」と「下げられて身構える側」が交錯している点にある。先に動いたのはGoogleで、自社のTPUとデータセンターという垂直統合の原価優位を背景に、5月22日にAI Ultraを20%値下げして2強を価格競争へ引きずり込んだ。その効果は数字に出ている——同社調べでGeminiのウェブ訪問シェアは前年の6.00%から25.46%へ3倍超に伸び、対するChatGPTは77.43%から56.72%へ落ちた。価格は確かにシェアを動かす武器になっている。

一方、上場を急ぐAnthropicは価格より能力と勢いで殴り返す側にいる。6月9日に公開したClaude Fable 5は「複雑な長時間タスクのコアベンチで初めて90%を達成」とされ、6月22日までPro/Max/Enterprise各プランに無料同梱して需要を測りつつ段階的に有料化へ移す戦略を取った。その結果が6月13日報道のトラフィックで、5月にClaudeの世界訪問は月次16%増・9.52億回超・前年同期比855.6%増に達し、AIチャットボットの訪問シェアで約9%・市場3位へ浮上した。OpenAIの値下げ検討は、この追い上げに価格面でも蓋をしておく予防的な一手と読める。

EXHIBIT C — 関係図 / RELATIONS
DEEP DIVE

深掘り

02 / 03

データが示すのは、シェア・能力・価格の3つが連動して動き始めたという事実だ。まず市場シェアの変遷を見ると、ChatGPTの web チャットボット訪問シェアは1年で76.4%から52.7%へほぼ4分の3に縮み、空いた分をGeminiとClaudeが奪っている。首位の絶対安全圏が消えたことが、OpenAIを価格の守りへ向かわせる直接の力学である。

このデータから立つ論点は2つある。第1に、両社のビジネスモデルは「収益の出方」で対照的だ。Anthropicは直近実績で約47億ドルの収益ながらARR走行率は7月末に500億ドル超（前年40億ドルから12.5倍）と急角度で、法人API需要を取り込む B2B 寄りの伸びが評価額9650億ドルを支える物語になっている。対してOpenAIはChatGPTという消費者サブスクの巨大な裾野を持つが、そのシェアが削られている分、価格で守らざるを得ない。値下げ検討が先に出たのがシェアを失っている側だ、という非対称は偶然ではない。

EXHIBIT D — データ表 / TABLE

第2に、価格競争はマージンを直撃する。AnthropicがFable 5を6月22日まで無料同梱し、その後クレジット課金へ移すのは、値下げではなく「需要を先に作って後から課金する」育成型の価格設計である。一方OpenAIのトークン値下げは即時に単価を削るため、同じ「安くする」でも収益への効き方が逆になる。フラッグシップの出力単価が百万トークンあたり50ドル（AnthropicのFable 5、Opus 4.8の2倍）という高単価帯がまだ生きているうちに、汎用層で価格を削り合えば、収益の実体と評価額の乖離が上場審査で問われる。実際、6月2日のバブル論では3社とも「稼ぐより多く損失を出している」と指摘されており、価格競争はその傷を深くする方向に働く。

EXHIBIT E — 意思決定フレーム / DECISION
◇ 論点 — THE ISSUE

OpenAIは価格競争にどう応じ、両社は上場前にマージンと評価額の整合をどう示すか

01

汎用トークンを即時値下げしGoogleの価格攻勢に正面から追随する

02

フラッグシップ高単価を維持し下位モデルのみ選択的に値下げする

03

Anthropic型の無料同梱→クレジット課金で需要育成に振り、即時値下げは回避する

期限 — DEADLINE

2026年秋のOpenAI・Anthropic IPO（S-1での収益・利益率開示）／6月22日Fable 5無料同梱終了後の課金移行

決定権者 — DECIDER
  • OpenAI経営陣(値下げ可否)
  • Anthropic経営陣(無料同梱後の課金設計)
  • Goldman Sachs/JPMorgan/Morgan Stanley等の引受幹事
  • Fujitsu/Microsoft等の大口需要側(マルチLLMで価格圧力)

次に見るべきは、OpenAIが値下げに実際に踏み切るか、踏み切るなら何を削るかだ。汎用モデルのトークン単価を下げてGoogleの価格攻勢に追随するのか、フラッグシップの高単価を維持したまま下位モデルだけ削るのか、それともAnthropic同様に無料同梱で需要を作る育成型へ寄せるのか。この選択が、秋に予定される両社のIPOで「成長の質」をどう語るかを規定する。

選択肢を分けて読むと、即時値下げ（A）は短期シェア防衛に効くがマージンを削り、上場の収益ストーリーを傷つける。下位限定値下げ（B）はOpenAIの現実解だが、Googleの20%攻勢に火力で見劣りする。無料同梱型（C）はAnthropicがすでに走らせており、需要を先取りしてから課金へ移す分だけ「成長の質」を演出しやすいが、無料期間明けに利用が剥落するリスクを抱える。私の読み筋は、OpenAIは全面値下げを避け、下位モデルの選択的値下げ＋ChatGPTの付加価値（スーパーアプリ化・エージェント統合）で単価防衛に動く公算が大きい。決め手は需要側だ——FujitsuやMicrosoftがマルチLLMで価格を横並び比較する以上、価格を下げない側はベンチマーク優位（Fable 5の90%）で正当化し続けるしかなく、その綱引きが秋のIPOまで続く。

❖ 要約 — IN ONE READ

OpenAIのトークン値下げ検討（6/12 Bloomberg）と、IPO準備中のAnthropicのトラフィック急増（5月に月次16%増・前年同期比855.6%増・市場3位）が同時に表面化し、AIモデル競争の軸が能力から価格へ移り始めた。火種はGoogleのAI Ultra 20%値下げで、ChatGPTのシェアは1年で76.4%→52.7%に縮んだ。両社のビジネスモデルは対照的で、Anthropicは無料同梱で需要を育てる型、OpenAIは即時値下げを迫られる型。価格競争はマージンを直撃するため、秋のIPOで収益の実体と評価額の整合が最大の論点になる。
