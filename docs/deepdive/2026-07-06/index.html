AI半導体、量産投資の主戦場へ

LISTEN DeepDive 解説対談 2026-07-06

AIインフラ需要はメモリーと電源半導体の量産投資をどう前倒しするか

#deepdive#weekly#news-grasp#issue-20260706#Micron#Infineon#WSTS#AI半導体#HBM#パワー半導体
❖関連レポート · RELATED

    AI半導体、供給網再配線へ 2026.07.03

    前回はAI需要がメモリ、装置、電力半導体、光通信へ広がる供給網の詰まりを扱った。今回の変化点は、Micron広島の起工とInfineon Dresdenの開場で、供給制約が量産設備と公的支援の実行局面へ移ったことだ。

BACKGROUND

背景

01 / 03

前回はAI半導体の供給網を、メモリから装置・電力・光接続まで広がる詰まりの連鎖として見た。今回はMicron広島の新クリーンルーム起工とInfineon Dresden Smart Power Fabの開場が重なり、不足を読む段階から、誰が量産投資を先に固定するかを見る段階へ移った。

Micron広島の案件で重要なのは、単なる新工場ではなく開発と生産を同じ拠点に置く点だ。EE Times Japanは、広島工場がHBM、DDR5、LPDDRなどのDRAM製品を多く生産し、新棟への製造装置搬入が2028年後半になる見込みだと報じているため、今日の起工は数年先のAIサーバー供給力を先に予約する動きと読める。

一方のInfineonは、DresdenのSmart Power Fabを欧州の電源半導体拠点として開く。メモリーがデータを抱えるなら、パワー半導体はデータセンター、電動化、再エネ設備の電力制御を支えるため、AI投資はGPUだけでなく、電気を扱う基礎部品まで同時に増やさないと詰まる。

EXHIBIT C — 関係図 / RELATIONS
DEEP DIVE

深掘り

02 / 03

SIAが示した4月の世界半導体売上は1105億ドルで、前年同月から93.9%増えた。単月の伸びだけで投資を正当化するのは危ういが、WSTSが2026年市場を1.51兆ドル、メモリーを8000億ドル超と見るなら、AI向け需要は短期の在庫循環より大きい投資サイクルとして扱われ始めた。

ここでMicronとInfineonの投資は、同じAI半導体でも役割が違う。Micronはデータを近く速く持つメモリーを押さえ、Infineonは電力を安定して変換するパワー半導体を押さえるため、AI基盤の制約は計算チップだけではなく、メモリー帯域と電源効率の二重制約になる。

EXHIBIT D — データ表 / TABLE

公的支援の比率を見ると、Micron広島は報道ベースで投資額の約35.7%に相当する支援が付き、Infineon Dresdenは約20%に相当する支援を受ける。これは補助金競争というより、政府が供給網のどこを国内・域内に残すかを選んでいる数字であり、需要企業は価格だけでなく、補助付き設備の立ち上がり時期を調達計画に織り込む必要がある。

EXHIBIT E — 意思決定フレーム / DECISION
◇ 論点 — THE ISSUE

AI半導体投資で、メモリー増産と電源半導体増産をどの順番で供給契約・政策支援に結び付けるべきか

01

Micron型のHBM/DRAM供給を先に長期契約で押さえる

02

Infineon型のパワー半導体と電源効率を先に固定する

03

メモリー、電源、光接続を同時に束ね、補助金付き拠点の立ち上がりに合わせて調達ポートフォリオを組む

期限 — DEADLINE

2026年後半のInfineon生産開始と2028年後半のMicron広島装置搬入まで

決定権者 — DECIDER
  • Micron / Infineon経営陣
  • 経済産業省・EU・ドイツ・ザクセン州
  • AIデータセンター運営企業の調達責任者

AIデータセンター側の短期判断は、HBMだけを追いかけると電源・熱・効率の制約を見落としやすい。メモリー供給を先に押さえる選択肢は性能面で強いが、Infineon型の電源半導体が遅れれば、設備全体の稼働効率で差が出る。

政策側の読み筋は、METIとEU・ドイツがどちらも単独企業の支援ではなく、供給網の節点を国内・域内に残す支援へ寄せている点にある。したがって最も現実的なのは、メモリー、電源、光接続を別々の銘柄テーマにせず、補助付き拠点の稼働時期を束ねて見ることだ。

❖ 要約 — IN ONE READ

Micron広島の1.5兆円投資とInfineon Dresdenの50億ユーロ超投資は、AI半導体の争点がGPU単体から量産設備と公的支援の実行力へ移ったことを示す。WSTSは2026年市場を1.51兆ドル、メモリーを8000億ドル超と見ており、次の焦点は需要の大きさではなく、メモリー・電源・政策支援を同じ時間軸で立ち上げられるかにある。
