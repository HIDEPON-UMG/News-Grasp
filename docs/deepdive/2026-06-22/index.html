BACKGROUND

背景

01 / 03

前回は日銀が1%へ動けるかを見たが、今回は実際に1.0%へ引き上げた後の効き方が焦点になった。日銀は6月16日に7対1で利上げし、基礎的な物価リスクにも言及した。それでも円安圧力が一気に消えないのは、相手側にFedの高金利が残っているからだ。

Warsh議長の初FOMCは、政策金利を3.5〜3.75%に据え置き、声明からフォワードガイダンスを薄めた。市場にとってこれは「次の利下げ時期を読みやすくする材料」ではなく、米金利が下がるまでの時間を長く見る材料になる。日銀1%は大きいが、日米差を一気に閉じるには足りない。

ここで財務省の役割は、金利差を直すことではなく、急な円売りに介入警戒を残すことに限られる。財務省の月次データは介入実績を追えるが、介入は相場の速度を落とす手段であり、金利差の燃料を消す手段ではない。したがって、次の焦点は「追加利上げ」「介入」「Fed待ち」の順番になる。

DEEP DIVE

深掘り

02 / 03

1枚目のチャートで見ると、日銀は3月・4月の0.75%据え置きから6月に1.0%へ一段上げた。これは円安対応としては明確な一歩だが、市場が見るのは水準そのものより次の利上げ余地である。1%で止まるなら、円買いの材料は短命になりやすい。

2枚目のFed側データは、円相場にもっと重い。Warsh議長はFF金利中央値を2026年末3.8%、2027年末3.6%と説明し、PCEインフレも2026年3.6%と2%目標を上回る見通しを示した。つまり米金利低下に賭ける円高シナリオは、まだ時間を必要とする。

EXHIBIT D — データ表 / TABLE

関係図を踏まえると、日銀と財務省は円防衛で同じ方向を向くが、手段の副作用は違う。日銀の追加利上げは金利差に直接効く一方、景気と国債市場への負担が残る。財務省の介入は急変動を止めるが、Fed高金利という相手側の燃料を消せない。この違いが、今日の円安論点の核だ。

決定権者 — DECIDER

  • 財務省
  • Federal Reserve

最も筋が通るのは、日銀が追加利上げの可能性を残しながら、財務省が介入警戒で速度を抑える組み合わせだ。日銀だけで円安を止めようとすれば景気負担が増え、介入だけなら金利差という根因が残る。したがって、政策の実務は利上げの示唆で期待を作り、介入警戒で投機を抑える形になりやすい。

ただし読み筋の前提は、Fedが夏にかけて利下げ期待をさらに遠ざけないことだ。Warsh体制がガイダンスを薄めるほど市場は米金利を高めに見積もり、円安の燃料は残りやすい。次に見るべきは、7月の日銀会合で追加利上げの地ならしがあるか、同時に米物価とFed通信が円売りを再燃させるかである。

❖ 要約 — IN ONE READ

日銀は6月16日に1.0%へ利上げしたが、Fedが3.5〜3.75%を維持し、Warsh体制でガイダンスを薄めたため、円安圧力は一気に消えない。焦点は、日銀の追加利上げ、財務省の介入警戒、Fedの物価鈍化待ちのどれが先に効くかへ移った。
