中国EVの価格逆転、現地生産が次の主戦場

LISTEN DeepDive 解説対談 2026-08-08

中国発の低価格EVは、新興国で日本メーカーの価格・現地生産・商品戦略をどう変えるか

#deepdive#daily#news-grasp#issue-20260808#中国EV#新興国#現地生産#価格競争
BACKGROUND

背景

01 / 03

中国EVメーカーは、国内の販売減を輸出の急増で補い始めた。IEAによると、2026年上期の中国の自動車販売は前年同期比で20％超減った一方、輸出は65％増え、EV輸出は120％超伸びた。競争の主戦場は中国国内から新興国の価格と生産拠点へ移っている。

新興国政府は、安い輸入車を呼び込む政策と国内生産を義務付ける政策を組み合わせている。タイは補助対象の輸入台数に応じて国内生産を求め、インドネシアも税優遇に国産化率40％以上などの条件を置く。輸入価格の勝負は、工場・電池・雇用を含む立地競争へ連続している。

日本メーカーにとって相手は中国車だけではない。中国勢と組む現地供給網、産業政策を握る政府、既存のHV顧客基盤が同時に動く。車両価格だけを下げても、現地調達と充電網を押さえられなければ競争力は持続しない。

EXHIBIT C — 関係図 / RELATIONS
DEEP DIVE

深掘り

02 / 03

中国市場では、内燃機関車より安いBEVの販売比率が2018年の10％から2021年の50％、2024年の約3分の2へ上がった。電池価格の低下だけでなく、垂直統合と激しい車種競争が価格を押し下げた。輸出されているのは完成車だけでなく、低コストを作る事業構造そのものだ。

ブラジル・タイ・インドネシア・メキシコでは、中国からの輸入比率が約3分の2から85％へ達し、BEVと内燃機関車の価格差が急縮小した。IEAの2026年上期更新でも、中国のEV輸出は前年同期比120％超増えた。国内販売の弱さが輸出圧力を強めるため、価格競争は一過性とみなしにくい。

EXHIBIT D — データ表 / TABLE

ただし、タイとインドネシアの政策は輸入の安さだけを恒久優位にしない。減税・免税と国内生産義務を結び付け、メーカーへ工場投資を促している。日本勢の既存拠点は強みだが、EV部品の現地調達率と商品価格へ変換できなければ埋没する。

決定権者 — DECIDER
  • 日本メーカーの地域事業責任者
  • 商品・調達責任者
  • 投資審査を担う経営会議

低価格BEVへ正面から追随すれば数量は守りやすいが、値下げと工場投資が同時に必要になる。HVへ寄せれば既存資産を生かせる半面、政府のEV誘導が強い市場では成長枠を失う。現地協業は投資を抑えられる一方、ソフトウェア・電池・顧客データの主導権を分ける必要がある。選択肢ごとの損益だけでなく、支配するレイヤーを決めるべきだ。

本稿の読み筋は、市場ごとの三分法である。都市部・充電網整備済み市場は現地調達BEV、地方や電力制約の強い市場はHVと保守網、規制で現地化期限が迫る市場は協業を優先する。世界共通車の横展開ではなく、政策期限と供給網を単位に商品を組み替える企業が先行する。

❖ 要約 — IN ONE READ

中国EVメーカーは、2026年上期にEV輸出を前年同期比120％超増やし、新興国の価格差を縮めている。各国政府は免税と現地生産義務を組み合わせ、競争を工場・電池・雇用へ広げた。日本勢は一律の値下げではなく、低価格BEV・HV・現地協業を市場別に配分し、どの供給網と顧客接点を自ら握るかを決める必要がある。
