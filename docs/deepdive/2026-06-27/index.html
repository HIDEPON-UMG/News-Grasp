BACKGROUND

背景

01 / 03

前回はWaymoの運用規模とTeslaの量産約束が主戦場だったが、今回の変化点は国際基準と運行インフラが同時に動いたことだ。国土交通省は6月26日、WP.29でレベル3・4を含む自動運転システムの国際基準が合意されたと発表した。競争軸は「走れる車」から「検証できる運行網」へ寄り始めている。

WP.29の基準は、車両の安全性だけでなく、メーカーの組織体制、投入後のモニタリング、不具合改善まで見ている。ここが重い。ロボタクシーは事故時に誰が原因を特定し、誰が改善を回すかを示せなければ、都市と規制当局をまたいで増やせない事業になる。

Uber陣営のHouston計画は、その規制の読み替えに近い。Uberは50,000平方フィートの拠点を押さえ、Nuroは安全オペレーター付きの公道試験を続け、Lucidは量産検証車を出す。配車、車両、運転AI、整備拠点を分担する設計が、自動運転をソフト単体ではなく運行システムとして見せる。

DEEP DIVE

深掘り

02 / 03

Waymoの数字は、レベル4競争が「いつ量産するか」だけでは足りないことを示す。2025年の15百万回超から2026年末の週100万回へ進むなら、単なる試験走行ではなく、乗車、空港、幹線道路、事故率、都市対応をまとめて説明する段階に入る。安全性は研究成果ではなく、運用データの継続提出で測られる。

Uber・Nuro・Lucidの計画は、逆に「Waymo型の垂直統合を持たない陣営」の答えだ。Uberは配車需要と拠点、Nuroはレベル4運転AI、Lucidは車両と工場統合を持ち寄る。最低35,000台、数十市場という数字は大きいが、価値は台数そのものより、認証、整備、充電、清掃、異常時対応を市場ごとに複製できるかにある。

EXHIBIT D — データ表 / TABLE

国際基準は、その複製性を審査する物差しになる。国土交通省が示した要件には、交通ルール順守や衝突回避だけでなく、不具合時の安全停止、作動状態の記録、モニタリングと改善が並ぶ。つまり、事故をゼロと言い張る競争ではなく、事故や異常を説明し続ける競争になる。ここで勝つ会社は、AIモデルだけでなく運行の監査証跡を持つ会社だ。

決定権者 — DECIDER

  • Waymoと競合OEMの自動運転事業責任者
  • 都市交通当局と保険・リスク管理部門

次の焦点はHoustonである。Bay Areaだけなら技術実証に見えるが、Houstonを第2市場に選び、拠点・充電・整備まで先に置くなら、都市ごとの運行パッケージを複製できるかが問われる。2027年の発効時期と商用投入時期が重なるため、制度対応は後工程ではなく事業設計そのものになる。

読み筋は、Waymoが「実績データで先に信頼を取る会社」、Uber・Nuro・Lucidが「分業で展開速度を取りに行く会社」へ分かれるというものだ。短期ではWaymoの乗車規模が強いが、中期ではUberが運行網と都市拠点をどれだけ標準化できるかが効く。レベル4の勝者は、最良の車ではなく、監査可能な運行を最速で増やす陣営になりやすい。

❖ 要約 — IN ONE READ

WP.29でレベル3・4を含む国際基準が合意され、ロボタクシー競争は車両性能の発表合戦から、安全証明と運行網の実装競争へ移る。Waymoは乗車実績で先行し、Uber・Nuro・LucidはHoustonを第2市場に据えて分業型の拡張を狙う。2027年は、基準発効と商用展開が重なる最初の審判年になる。
