BACKGROUND

背景

01 / 03

前回は日銀が1.0%へ利上げしても円安圧力が残る構図を扱った。今回の変化点は、USDJPYが161円90銭台まで進み、片山財務相とベッセント米財務長官の協議で介入が市場の中心論点に戻ったことだ。

財務省は5月末公表分で1兆1734.9億円の介入実績を示しており、介入余地を単なる口先ではなく実弾の履歴として市場に見せている。ただし、介入は相場の速度を落とす道具であって、Fed高金利が生むドル買いの根を抜く道具ではない。

日銀は6月16日に政策金利を1.0%へ上げ、物価上振れリスクと中東情勢を理由に追加調整の余地を残した。それでも円売りが止まらないのは、Fed側の金利低下期待が戻らず、日米の政策差がまだ市場の主役であり続けているからだ。

DEEP DIVE

深掘り

02 / 03

1枚目のチャートは、財務省が1兆1734.9億円の介入実績を示した後でも、6月下旬にUSDJPYが161円80銭台から161円90銭台へ進んだ流れを並べた。単位が違うため同じ尺度の価格比較ではなく、介入実績と円安再燃が同じ時間軸に並んだことを示す図として読むべきだ。

2枚目は、政策手段の性格を分けた。為替介入は即効性が高いが、米金利が高止まりすれば持続性は落ちる。日銀の追加利上げは金利差に直接効く一方、景気と国債市場への副作用を管理しなければならない。米金利低下待ちは副作用が小さいが、当局が主導できない。

EXHIBIT D — データ表 / TABLE

関係図と表を重ねると、今日の論点は「介入するか」だけでは足りない。財務省と米財務省の協議は市場心理に効くが、Fedがドル金利を残す限り、円防衛は介入・追加利上げ・米金利待ちの三択を同時に抱える。だから、次の一手は単発の円買いではなく、政策順序の設計になる。

短期で最も効くのは、財務省が介入警戒を明確に残し、日米協議の事実を市場に意識させる組み合わせだ。USDJPYが39年ぶり水準に近づいた局面では、投機筋に「次の一手」を読ませないこと自体が防衛線になる。

ただし、読み筋の本丸は日銀の追加利上げ余地である。介入だけなら1兆円規模の実績があっても、金利差が残れば再び円売りが戻る。したがって、7月会合へ向けて日銀が物価・為替・国債市場をどう結び直すかが、円安局面を短期の介入相場で終わらせるか、政策持久戦へ入るかを分ける。

❖ 要約 — IN ONE READ

USDJPYが161円90銭台へ進み、財務省と米財務省の協議で介入論点が戻った。5月の1兆1734.9億円介入実績は市場への牽制になるが、Fed高金利と日米金利差は残る。次の焦点は、財務省の実弾、日銀の追加利上げ示唆、日米協調期待の順序設計である。
