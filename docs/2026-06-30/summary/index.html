§01 ¥ 為替

FX — 161円台後半、政策と指標待ち

ドル円 は 161円90銭台後半 まで円安が進み、米雇用統計と9月利上げ観測 が次の揺れを作ります。ECBシントラ の利上げ観測もユーロを支え、今日は水準より、介入警戒と政策メッセージの組み合わせが焦点でした。

FACT
【事実・概要】
USDJPYは一時161円90銭台後半まで下げ、1986年以来の39年半ぶり円安水準に達した。
CONTEXT
【背景・要点】
背景にはFedの高金利が長引くとの見方とBOJとの金利差があり、円売り・ドル買いが続いている。
OUTLOOK
【影響・展望】
162円台が視野に入るほど為替介入への警戒は強まり、輸入価格と家計負担が次の政策論点になりやすい。
→ §01 為替 詳細を読む
§02 ◆ AI

AI — 配布網と安全審査が競争軸

OpenAI の Partner Network は30万人の認定コンサル育成を掲げ、Anthropic は Mythos 5 を再開しつつ Fable 5 を止めたままです。Bedrock 再販や Gemini の学習ノート追加も含め、モデル選びから導入・運用設計へ 重心が移りました。

FACT
【事実・概要】
OpenAI が 1億5,000万ドル を投じる OpenAI Partner Network を発表し、2026年末までに認定コンサルタント30万人育成を掲げた。AI導入の実装支援を担う世界規模の提供網を整える。
CONTEXT
【背景・要点】
企業のAI導入は、モデル単体より 業務設計 や既存システム統合、チェンジマネジメントが成否を分け始めた。Select/Advanced/Elite の段階制と専門資格で、案件化から運用定着までの品質を揃えにきた。
OUTLOOK
【影響・展望】
ITコンサルやSIにとっては AI導入 の主戦場がPoCから全社変革へ移る合図だ。Codexやエージェント分野の認定 が広がれば、提案体制と人材育成の再編 が加速する。
→ §02 AI 詳細を読む
§03 ⌗ IT

IT — 文脈を業務に埋め込む

Chronos-2 の需要予測 PoC、NEC の PMM 育成、Lupe のコンテキスト機能、SmartHR と ラクス の論争が並びました。何を作るかより 前提と例外をどこで持つか が価値を分け、AI を使う側の設計力が表に出ています。

FACT
【事実・概要】
キヤノンITソリューションズとAWSはChronos-2を使ったホテル朝食ビュッフェの需要予測PoCを公開し、個別学習なしのゼロショット推論でフードロス削減を狙う構成を示した。
CONTEXT
【背景・要点】
フードロス削減は日本全体で464万トン、外食産業で66万トンという課題を抱え、欠品を避けたい現場文化と需要変動の大きさが予測精度の壁になっていた。
OUTLOOK
【影響・展望】
需要予測AIはSageMaker上でPoCから運用設計まで繋げられるため、ITコンサルはモデル選定より業務データ整備と現場定着の設計を問われる局面に入る。
→ §03 IT 詳細を読む
§04 ◎ モビリティ

Mobility — ルール先行で商用化を押す

WP29 のレベル4基準、NHTSA のブレーキ見直し、Tesla の小規模ロボタクシー、ロート製薬 の490キロ実証が同じ線上にあります。車両性能だけでは足りず、規則・運行密度・荷主採算 を先に揃えた側が次の段階へ進みます。

FACT
【事実・概要】
米NHTSAは、ハンドルやブレーキペダルを持たないADS車を想定したブレーキ基準見直し案を公表し、足踏みペダル前提の要件を一部外す方針を示した。
CONTEXT
【背景・要点】
今回の案は商用運行の全面解禁ではないが、安全停止性能は残したまま車内レイアウト自由度を広げる内容で、規制が従来車中心からソフト主導車両へ寄り始めた。
OUTLOOK
【影響・展望】
読者が次に見るべきはパブリックコメント後の確定条文で、米国向けロボタクシーや配送車の設計投資が前倒しされるかが量産タイミングを左右する論点になる。
→ §04 モビリティ 詳細を読む
§05 ⬢ 製造

Manufacturing — 資本投下と拠点再編

サムスン と SK の84兆円投資、韓国の新クラスター、独 VW の工場・雇用調整、SMFL の太陽光PPA が並びました。投資額の大きさより 電力、雇用、部材をどこで組み替えるか が問われ、供給網の再設計が競争力になります。

FACT
【事実・概要】
SamsungとSKハイニックスは約84兆円の投資計画を公表し、今後5年でDRAM製造能力を2倍へ引き上げる方針を示した。
CONTEXT
【背景・要点】
AI需要の急拡大でHBMを含むメモリー供給が逼迫する中、首都圏集中の電力・用水制約を避けるため地方分散型の増設を急いでいる。
OUTLOOK
【影響・展望】
量産前倒しが進めば韓国メモリー供給網の主導権は一段と強まり、装置・材料の増設連鎖と台湾・米国との補助金競争が次の焦点になる。
→ §05 製造 詳細を読む
§06 ■ 経済

Economy — 成長率と家計負担をどう両立するか

骨太原案 は名目 3%超の成長定着を掲げ、ガソリン補助金 は算定方法を改定しました。ラガルド は欧州の耐性向上を強調し、東電 総会では原発か再エネかが問われています。積極財政と負担抑制 の両立が、今日の政策軸です。

FACT
【事実・概要】
政府は骨太方針原案で、名目3%超・実質1%超の成長定着を目標に据え、経済財政運営を抜本転換する方針を30日の諮問会議へ示す。
CONTEXT
【背景・要点】
原案は2027〜2040年度を対象にした「責任ある積極財政」型の中長期計画を掲げ、従来の単年度発想ではなく成長投資を前倒しする設計へ軸足を移す。
OUTLOOK
【影響・展望】
27年度以降の予算編成では成長投資と財政規律の両立が焦点となり、AI・半導体など戦略分野への資金配分をどう具体化するかが金利・国債市場との対話を左右する。
→ §06 経済 詳細を読む
§07 ▶ ゲーム

Game — IP支援と販路の伸ばし方

任天堂 の Splatoon Raiders Direct、IP360 の大型採択、スイカゲーム の Steam 版、FUJI の採択、Steam Machine のケース問題が並びました。新作発表だけでなく 配布先と資金の通し方 を押さえた作品が、次の伸びしろを作っています。

FACT
【事実・概要】
任天堂は6月30日23時からスプラトゥーン-レイダース-Directを約15分配信し、Nintendo Switch 2向け新作の詳報をまとめて出す段取りを示した。
CONTEXT
【背景・要点】
公式商品ページではスプラトゥーン-レイダースの発売日を7月23日、価格をダウンロード版6480円と案内済みで、発売3週間前に情報開示を厚くする販促局面へ入った。
OUTLOOK
【影響・展望】
単独Directを切ったことで、Switch 2初期ラインアップの牽引役としての期待値がさらに高まる。30日夜の新要素開示量が予約の伸びとSNS熱量を左右しそうだ。
→ §07 ゲーム 詳細を読む

明日へ — 節目を持つかを見る
