§01 総論

総論 — インフレとAIが同時に臨界点を超えた水曜日

米4月CPI+3.8%とPPI+6.0%が同週に確認され、利下げシナリオは崩壊した。翌日には新FRB議長が就任する。一方でAI陣営はモデルリリース・企業向けJV・金融エージェント・中小企業向けパッケージを一気呵成に展開した。「インフレという規律と、AIという解放力」が同時に加速する構造的転換点が今日の本質だ。2つの力がぶつかる局面で、どちらが資産価格を支配するかが2026年後半の最大の問いとなる。

§02 為替

米4月CPI+3.8%確報 — ドル円157.8円急騰、年内利下げシナリオ崩壊

米4月CPIが前年比+3.8%（3年ぶり高水準）を記録しドル円は157.8円へ急伸。PPIも前年比+6.0%とダブルインフレショックが鮮明になった。明日就任のウォーシュ新FRB議長の金融政策方針を巡り、市場は12月利上げシナリオを30%まで織り込み始めている。

  • 米労働省発表の4月CPIは前年同月比+3.8%（2023年5月以来の高水準）、前月比+0.6%。ガソリン・食品の値上がりが全体を押し上げ、コアCPIも前月比+0.4%と連邦準備制度の目標2%の2倍超が継続している。
  • 発表直後にドル円は157.8円へ急伸。CME FedWatchでは12月利上げ確率が30%まで上昇し、2026年内の利下げシナリオは急速に後退した。S&P500は反落（-0.37%）、Nasdaq も-0.65%と軒並み下落。
  • 翌日のウォーシュ新議長就任と重なり「インフレ退治優先」への政策転換期待が強まっており、ドル高・円安の構造が当面維持される公算が高い。

§03 AI

Claude Opus 4.7 正式公開 + Claude Platform AWS GA — ソフトエンジニアリング+14%、18地域ネイティブ展開

AnthropicがClaude Opus 4.7を正式公開し同週にClaude Platform AWSを一般提供開始。OpenAIも$40億のAIコンサル子会社DeployCoを設立し、AnthropicはBlackstone・Goldman Sachs支援の企業向けAIサービス会社を立ち上げた。AIが「研究所の技術」から「産業インフラ」へと転換する水曜日となった。

  • Claude Opus 4.7がGA（一般提供開始）。前モデルOpus 4.6比でソフトウェアエンジニアリング+14%、複雑なマルチステップワークフローではツールエラーを1/3に削減。長時間稼働タスクと視覚理解でも向上。
  • Claude Platform on AWSが18地域で同時一般提供開始。既存AWSアカウントでネイティブ認証・請求統合が可能になり、Bedrock経由の別契約が不要となる大きな転換点。
  • Messages API・Files API・Managed Agents・Agent Skillsが全て利用可能。日本（東京）を含む全18リージョン対応で、グローバル企業が本番採用しやすい環境が一気に整った。

§04 IT

Google Cloud $7.5億パートナーファンド — アクセンチュア450+エージェント構築、NTTデータが5,000名投入

Google Cloudが$7.5億のAIエージェントパートナーファンドを設立し、アクセンチュアが英Faculty買収完了・Databricks社との合弁を相次いで発動。NTTデータも5,000名をエージェントAI開発に投入する成長戦略を発表。コンサル業界はAIエージェントの「産業展開競争」に突入した。

  • Google CloudがCloud Next '26（Las Vegas）でハイパースケーラー史上最大の$7.5億パートナーファンドを発表。Accenture・BCG・Deloitte・McKinsey・KPMG・PwC・Capgeminiなど120,000社のパートナーエコシステムに投資。
  • アクセンチュアはGoogle Cloud上に450超のエージェントを構築済みで全業界verticalに展開中。NTTデータは5,000名をエージェントAI開発に専任投入すると表明。パートナー1ドルの投資に対し$7.05のサービス収益が発生する乗数効果がGoogleの主な訴求点。
  • FDE（Forward-Deployed Engineers）をコンサル各社に常駐配置する「embedded FDE」モデルを採用。AIエージェント展開の主戦場がコンサル経由に移ったことを象徴する動きだ。

§05 経済

米4月CPI+3.8%（3年ぶり高水準）— 年内利下げ遠のき、12月利上げ確率30%へ

米4月CPI+3.8%（3年ぶり高水準）・PPI前年比+6.0%（2022年以来最大）のダブルインフレが確認され、S&P500・Nasdaq が反落。12月利上げ確率は30%まで上昇し「年内利下げ」シナリオは崩壊した。明日就任のウォーシュ新FRB議長が最初のスピーチで何を語るかが、2026年後半のマーケット方向を決める。

  • 米労働省発表の4月CPI（消費者物価指数）は前年比+3.8%、前月比+0.6%。2023年5月以来3年ぶりの高水準で、ガソリン・食品の値上がりが押し上げた。コアCPIは前月比+0.4%・前年比+2.8%とFederal Reserveの2%目標を大幅に上回る状態が継続。
  • CPI発表直後にS&P500は-0.37%、Nasdaq -0.65%、Dow -0.21%と反落。CME FedWatchで12月利上げ確率が30%まで上昇し、年内の利下げシナリオは「消滅」に近い状況となった。
  • 翌13日には米4月PPI（生産者物価指数）も前年比+6.0%（前月比+1.4%）と2022年以来の大幅上昇を記録。インフレの「川上」から「川下」に至る全面的な物価圧力が確認され、「第二波インフレ」を市場が正式に宣告した日となった。

明日へ — ウォーシュの一言とOpus 4.7の採用速度

最大の注目点は5/15ウォーシュ新FRB議長の就任スピーチ。タカ派宣言ならドル高・株安、フロントローディング利下げ示唆なら株高・ドル安という両睨みの状態が続く。AI側ではClaude Opus 4.7の金融・エンタープライズでの採用状況が週後半の指標として浮上する見込みだ。CPI・PPI後の株式市場調整とAI産業化の加速が「同じ週に起きている」この構造を、長期投資家はむしろ「AIへの腰を据えた参入機会」として捉えているかもしれない。
