§01
FOREIGN EXCHANGE / 為替

利上げ後の説明が相場を動かす

FACT 事実・概要

日銀が政策金利を1%へ引き上げても、円相場は素直に反転しなかった。

CONTEXT 背景・要点

【事実】：日銀は政策金利を31年ぶりの1%へ引き上げ、異例の低金利体制をさらに後退させた。為替よりも物価と政策信認の修復を優先した格好だ。

OUTLOOK 影響・展望

【背景】：内田副総裁が示したのは、今回で打ち止めではないというメッセージだ。市場は年内の追加正常化を織り込み始め、短期金利の見方も切り上がりやすい。

→ §01 為替 詳細を読む
§02
ARTIFICIAL INTELLIGENCE / AI

安全と収益化を同じ線上で競う

FACT 事実・概要

ソフトバンクGとOpenAIは重要インフラ向けの脆弱性診断を打ち出し、Anthropicは修正猶予の短縮や当日撤回で守りを磨いた。

CONTEXT 背景・要点

【事実】：ソフトバンクグループはOpenAIと組み、日本の重要インフラ向けにAIで脆弱性を洗い出し修正提案までつなぐ新サービスを前面に出した。

OUTLOOK 影響・展望

【背景】：焦点は便利な生成AIの導入ではなく、AIそのものが攻撃面を拡張する時代に防御側の運用をどう先回りするかへ移ったことだ。

→ §02 AI 詳細を読む
§03
IT & CONSULTING / IT

導入後の運用責任が主戦場になる

FACT 事実・概要

Doppel、複数サイト対応WAF、API連携基盤、そしてAnthropic輸出規制への反発が並び、IT案件は「入れたか」よりどう運用するかへ重心が移った。

CONTEXT 背景・要点

【事実】：OpenAIとソフトバンクグループが組んだ新サービスは、生成AIを業務効率化だけでなく防御運用へ前線投入する流れを日本市場で明確にした。

OUTLOOK 影響・展望

【背景】：読者にとって重要なのは、AI導入の論点がPoCから本番監視へ移った点だ。セキュリティ運用を誰が持ち、どこまで自動化するかが次の調達論点になる。

→ §03 IT 詳細を読む
§04
MOBILITY / モビリティ

EV普及は運行と残価で伸びる

FACT 事実・概要

ノルウェーのEV比率99%は、補助の有無より需要が自走段階に入ったことを示す。

CONTEXT 背景・要点

【事実】：ノルウェーでは新車販売のEV比率が99%に達し、補助頼みの普及局面をほぼ抜けた。

OUTLOOK 影響・展望

【背景】：優遇縮小後も販売が崩れず、価格・燃料費・充電網を含めた総保有コストで内燃車を上回り始めている。

→ §04 モビリティ 詳細を読む
§05
MANUFACTURING / 製造

量産前の周辺能力が競争力になる

FACT 事実・概要

ラピダスの海外連携、ニコンの後工程材料、オーブレーのダイヤモンド基板、富士フイルムの欧州強化、日精樹脂のインド新工場が並んだ。

CONTEXT 背景・要点

【事実】：ラピダスが英国・イタリア機関との連携を打ち出し、政府支援を背景に量産前の設計・研究網を外から厚くする構図が見えた。

OUTLOOK 影響・展望

【背景】：焦点は工場建設そのものより、2ナノ量産に要る周辺能力をどこまで先回りで集められるかで、国際連携の幅が競争力になる。

→ §05 製造 詳細を読む
§06
ECONOMY / 経済

物価と供給不安を同時に見る

FACT 事実・概要

日銀の物価上振れリスク、追加利上げが政権運営に与える負荷、日ブラジル会談のEPA交渉入り、米イラン合意案の原油輸出再開、ZEW改善が同時に動いた。

CONTEXT 背景・要点

【事実】：日銀は物価が2%を上回って推移するリスクを改めて示し、今回の利上げを終点ではなく通過点として位置付けた。市場は次の一手を織り込み始めている。

OUTLOOK 影響・展望

【背景】：焦点は金利水準そのものより、賃金とサービス価格が上振れを続けるかだ。景気を冷やし過ぎずインフレを抑える難しい運営が続く。

→ §06 経済 詳細を読む
§07
GAMING / ゲーム

発見導線を握る側が売上を取る

FACT 事実・概要

Steam Nextフェスの体験版ラッシュ、ゼンレスゾーンゼロのSteam展開、サンリオのゲーム参入、Mistfall Hunterの反応測定、ポケモンカードAIエージェント競技化が並んだ。

CONTEXT 背景・要点

【事実】：Steam-Next-フェス が始まり、数千本規模の体験版が一斉公開 されたことで、夏商戦前の発見競争 が一気に前倒しになった。

OUTLOOK 影響・展望

【背景】：開発側にとっては ウィッシュリスト と配信露出を積み増す好機で、イベント期間中の反応が発売初速を左右 しやすい。

→ §07 ゲーム 詳細を読む
