「政策イベント前の市場緊張と、AI・半導体・ゲームの実装競争が同時に進んだ火曜日。」
日本 Q1 GDP の下方修正は景気の鈍さを示したが、同じ紙面には BOJ 利上げ観測、USD/JPY 160 円接近、日経平均のリスクオフ、Fujitsu / NTT DATA の企業 AI、Denso / ROHM / Toyota / TSMC の半導体供給網、Tesla / Waymo のロボタクシー運用台数差、Nintendo Direct の Switch 2 供給計画が並んだ。つまり今日の論点は、単なる「景気が弱い日」でも「AI 発表が多い日」でもない。短期では政策イベントが市場を縛り、中期では AI と半導体の実装力が日本市場の支えになるかを試されている日だ。為替は GDP と BOJ の板挟み、株式は AI 期待とリスクオフの綱引き、企業 AI は PoC から業務基盤へ、製造は買収より供給網設計へ、ゲームは一度の発表より継続ラインアップへ移っている。これらを束ねると、今日の焦点は「発表されたか」ではなく、継続して実装・供給・運用できるか だ。以下、各カテゴリを横断して読み解く。

§01 総論

総論 — 発表から実装力の競争へ

今日のニュースは、AI モデル、企業導入、ロボタクシー、半導体、ゲームイベントがばらばらに動いたように見える。しかし共通するのは、発表そのものより 継続運用 の力が問われている点だ。モデル、車両、半導体、ゲームはいずれも供給と運用の厚みで評価され始めた。市場はストーリーだけでなく実装能力を見ている。

§02 為替

為替 — GDP と BOJ が円相場の緊張を作る

日本 GDP の下方修正と BOJ 利上げ観測が同時に残るため、USD/JPY は単純な景気悪化トレードにならない。政策イベント前の市場は、成長鈍化でも円安・物価対応を優先するかを見ている。為替は日本の政策信認を測る入口になった。来週の会合前に、円相場はすでに答えを迫っている。

  • 日本Q1 2026 GDP確報値は年率+1.8%（速報+2.1%から下方修正）、設備投資が速報+0.3%→−0.7%へ大幅修正されたことが主因。
  • 個人消費は+0.3%を維持し堅調、春闘+3.82%を背景とした実質賃金プラスが家計の下支えに機能している。
  • ING Groepは「GDP下方修正にかかわらず、BOJ金融政策決定会合（6月16日）での0.75%→1.0%利上げ確率を66%以上と維持」と分析。

§03 AI

AI — 資本市場と安全保障がモデル競争に重なる

Anthropic の S-1 と Claude Opus 4.8、OpenAI の Rosalind は、AI が資金調達・安全保障・モデル性能の3軸で競争していることを示す。研究所の優劣はベンチマークだけでなく、資本市場と社会実装への説明力で決まる。AI 企業は技術企業であると同時にインフラ企業になった。競争の舞台は研究室から制度へ広がっている。

  • OpenAI は GPT-Rosalind の利用範囲を拡大し、バイオ防衛・パンデミック備えの政府/研究機関連携を前に進めた。
  • 今日の新材料は、モデル性能そのものではなく、安全保障用途のアクセス制御と配布先が具体化した点にある。
  • AI は一般消費者向けチャットから、政府・研究機関が使う危機対応インフラへ組み込まれ始めている。
→ §03 AI 詳細を読む
§04 IT

IT — 企業導入は大規模運用の段階へ進んだ

Fujitsu と Anthropic、NTT DATA と NVIDIA の動きは、企業 AI が PoC から標準業務基盤へ移る流れを示す。10万人規模展開や AI factory は、導入の量だけでなく運用責任を伴う。ここからはモデル選定より、セキュリティ、データ境界、業務再設計が差を作る。AI 導入は IT 部門の実装力を問う。

  • NTT DATA は Google Cloud との連携拡大を発表し、Gemini Enterprise を使った agentic AI を実証から本番展開へ移す方針を示した。
  • 専任の Gemini Enterprise practice を立ち上げ、5,000人の認定エキスパート育成と最大500件の業界別AIエージェント共創を掲げる。
  • 企業AIの焦点はモデル選定から、ガバナンス・業務導入・マネージドサービスを含む実装運用体制へ移っている。
→ §04 IT 詳細を読む
§05 モビリティ

モビリティ — ロボタクシーは台数と地域実装で測られる

Tesla の Austin 拡張と Waymo 577台との差は、自動運転が「できる」から「運べる」へ評価軸を移したことを示す。BYD の海外販売も含め、車両台数、都市運用、規制対応、供給力が競争の中心になる。ソフトウェア発表だけではロボタクシー市場は取れない。運用網そのものが競争優位になっている。

  • Teslaが無人ロボタクシーサービスをオースティン市全域（人口235万人のメトロエリア）に拡張（6月8日）、Cybercabが市内各地でスポッティング。
  • 稼働台数42台（テキサス州6月公開記録）—Waymoの577台に対し1/14の規模、「量から質」の差別化戦略が鮮明。
  • FSD v14.2アップデートが都市環境での自律走行精度を大幅改善、NHTSA監査記録なしで自律走行安全を訴求。
→ §05 モビリティ 詳細を読む
§06 製造

製造 — パワー半導体は買収より連携で再編される

Denso / ROHM、東芝、三菱電機、Toyota / TSMC / Denso の熊本投資は、日本の半導体戦略が単独買収から共同投資と供給網設計へ移ることを示す。EV、AI、車載制御では、半導体の安定供給が製品計画を左右する。製造競争は工場単体ではなく、資本・技術・需要家を束ねる設計になった。供給網が戦略そのものになっている。

  • Denso は ROHM 買収案から撤退する一方、SiC パワー半導体の協業は維持する構え。
  • 完全買収ではなく、供給・技術連携で車載半導体の安定調達を確保する方向へ寄せている。
  • 日本の自動車サプライチェーンでは、資本再編よりも実装速度と供給リスク管理が焦点になる。

§07 経済

経済 — AI 期待とマクロ不安が同じ市場に入る

日本株には AI プレミアム の中期期待が残る一方、GDP 下方修正、地政学、金利イベントが短期リスクを増やしている。市場は強気テーマを維持しながら、政策イベント前にはポジション調整を優先する。AI プレミアムは上昇材料であると同時に、失望時の調整幅を広げる材料でもある。今日は期待と警戒が同居した。

  • 日本の Q1 GDP は設備投資の弱さを背景に下方修正され、景気の足取りが想定より鈍いことを示した。
  • 中東リスクによる資源価格・企業心理への圧力も重なり、政策当局は成長と物価のバランスを見極める必要がある。
  • BOJ 利上げ観測が残る中で、GDP 下方修正は円相場・株式市場の両方に不確実性を加える。
→ §07 経済 詳細を読む
§08 ゲーム

ゲーム — Direct は Switch 2 の継続供給力を測る

Nintendo Direct は、Switch 2 発売後の熱をどれだけソフト計画へ接続できるかを測る場になった。Zelda、Mario、サードパーティへの期待は大きいが、期待値が高いほど発表後の評価も厳しくなる。任天堂に必要なのは一度のサプライズではなく、数カ月先まで続く供給計画だ。ゲーム市場でも継続実装力が問われている。

  • Nintendo Direct の配信時刻・想定尺・発表候補が整理され、Switch 2 初期展開の期待が高まっている。
  • ユーザー関心は本体発売後の継続ソフト、既存 IP の新作、サードパーティ対応に集中する。
  • 6月9日の配信は、Switch 2 のローンチ熱を継続できるかを見る初期テストになる。
