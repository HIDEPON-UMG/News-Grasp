§01
¥ FOREIGN EXCHANGE / 為替

158円台の膠着、FOMC待ちで方向感なく週明けへ

FACT 事実・概要

USD/JPY は158円台後半で様子見が続く。Warsh新Fed議長の「利下げ封印」スタンスが米金利を高止まりさせ、均衡なき円安が継続する構図に。

CONTEXT 背景・要点

介入ライン160円が再び意識され始め、財務省・日銀の牽制発言も増加。4月末・5月頭の円買い介入（推定5兆円規模）の効果が薄れつつある段階。

OUTLOOK 影響・展望

市場の次の焦点は5/28 FOMC議事録。タカ派・ハト派の温度差が確認されれば、ドル円の方向感が一時的に定まる可能性。

§02
◆ ARTIFICIAL INTELLIGENCE / AI

Mythos・Spark・DeployCoで「AIが人間の領域に踏み込む」週

FACT 事実・概要

Claude Mythos がProject Glasswingのパートナー企業（AWS・Apple・Cisco・Google・Microsoft・NVIDIA等）に公開されて以来、1万件超の重大・高重要度脆弱性をクリティカルソフトウェアから自律検出した。

CONTEXT 背景・要点

特筆すべきは27年前のFreeBSD RCE脆弱性（NFS経由でroot取得可能）を完全自律で発見・エクスプロイト作成した事例。wolfSSL（数十億台搭載）では偽証明書生成の手口を実証済み。脆弱性発見の容易さと修正の難しさが新たなボトルネックと指摘。

OUTLOOK 影響・展望

Anthropicは一般公開の前提として「現時点でどの企業も構築できていないセーフガード」の実現を挙げており、リスクと能力の非対称問題に正面から向き合う姿勢を示した。

→ §02 AI 詳細を読む
§03
⌗ IT & CONSULTING / IT

OpenAI DeployCoがコンサル聖域に参入

FACT 事実・概要

OpenAI が5月11日、エンタープライズAI実装専業子会社「OpenAI Deployment Company (DeployCo)」を正式立ち上げ。初期投資は$40億超、TPG・Goldman Sachs・Bain Capital・マッキンゼーら19社が出資参画。

CONTEXT 背景・要点

FDE（Forward Deployed Engineers）150名が顧客企業に直接常駐し、AIワークフローを既存システムに組み込む——これはアクセンチュア・マッキンゼーが数十年間独占してきたビジネスモデルそのもの。コンサル業界が自ら育てた競合が牙を剥く構図。

OUTLOOK 影響・展望

Tomoro社の買収でFDE人材を即時補強。企業の「実験的AI → 本番運用」移行を年単位から月単位に短縮する狙いで、$3750億のエンタープライズIT市場を直接狙う。

→ §03 IT 詳細を読む
§06
■ ECONOMY / 経済

Micron 1兆ドル・日経65,408円・5/28 FOMC議事録が今週を決める

FACT 事実・概要

Micron Technology が+19%急騰でついに時価総額1兆ドルを突破。UBSがAI楽観論を背景に目標株価を大幅引き上げたことが契機。S&P500は7,519・NASDAQは26,656と揃って史上最高値を更新。

CONTEXT 背景・要点

AI半導体・データセンター需要の強さが米企業業績を牽引。S&P500全体のQ1 EPSは+27%（4年ぶり好決算）の恩恵が今も市場心理を強気に保つ。半導体がバロメーターとなる相場構造が定着。

OUTLOOK 影響・展望

ただしダウ工業株は-118ドルと逆行。テック集中vs.景気敏感の二極化が一段と鮮明で、割高懸念も燻る。5/28 FOMC議事録が過熱を冷ます材料になり得る。
