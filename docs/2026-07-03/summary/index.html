§ 00 EDITORIAL SYNTHESIS / 総論

総論

今日の総論

今日は、米雇用減速でドルが揺れ、7月利上げ観測は後退しました。それでも AI と IT は計算資源と契約導線の外販を進め、Manufacturing は半導体の前工程と後工程を同時に積み増し、Mobility は自動運転を制度と燃料の両面から実装へ押し出しています。景気の鈍り が見えても供給側の投資は止まらず、Economy でも原油安と資源協力が並び、論点は需要の強さより「誰が供給責任を握るか」へ移りました。

§01
¥ FOREIGN EXCHANGE / 為替

雇用失速で円買いが走る

FACT 事実・概要

USDJPY は弱い米雇用統計で160円台後半へ急落し、同時に BOJ の追加利上げ前倒し観測も強まった。

CONTEXT 背景・要点

米金利は下がったが、円安水準と 短観 の堅さが残るため、日本側の正常化期待はむしろ消えていない。

OUTLOOK 影響・展望

次は CPI と当局発言を受け、160円台前半を守るのか、日銀前倒し織り込みがさらに進むのかを見たい。

→ §01 為替 詳細を読む
§02
◆ ARTIFICIAL INTELLIGENCE / AI

株式とチップで囲い込む

FACT 事実・概要

OpenAI は政府との資本設計を探り、Anthropic はチップ供給、Microsoft と Google は企業導入と低コスト化を前へ進めた。

CONTEXT 背景・要点

モデルそのものの差より、誰が計算資源、配布経路、既存契約、日常業務の接点をまとめて握れるかが競争条件になっている。

OUTLOOK 影響・展望

企業導入は、性能比較よりも契約継承、推論単価、業務導線への接続のしやすさで勝負が決まりやすくなる。

→ §02 AI 詳細を読む
§03
⌗ IT & CONSULTING / IT

AI基盤を外販収益へ変える

FACT 事実・概要

AI計算資源、通信コア、GPU監視、基幹SaaSの権限分離がそろい、基盤そのものを外販する案件が増えた。

CONTEXT 背景・要点

企業は新機能だけでは買わず、監視、権限設計、運用ノウハウ、人材育成まで含めた長期運用の形を求めている。

OUTLOOK 影響・展望

今後は、AI基盤を持つ会社ほど運用込みの提案力が問われ、外販モデルがクラウド案件の収益源として太りやすい。

→ §03 IT 詳細を読む
§04
◎ MOBILITY / モビリティ

自動運転を制度と燃料で回す

FACT 事実・概要

販売回復、自動運転規制、低炭素燃料実証、経路生成AIバスが重なり、モビリティの論点が制度運用へ寄った。

CONTEXT 背景・要点

自動運転や商用EVは、技術成熟だけでなく、応答義務、給油運用、保守体制、閉鎖空間での採算がそろって初めて広がる。

OUTLOOK 影響・展望

次は、制度対応と燃料運用を先に整えた事業者が、物流や地域交通で先行利益を取れるかどうかが勝負になる。

→ §04 モビリティ 詳細を読む
§05
⬢ MANUFACTURING / 製造

半導体増産が後工程まで広がる

FACT 事実・概要

メモリー新工場、装置販売上方修正、300mm工場稼働、基板JV、光通信用材料増産が同日に進んだ。

CONTEXT 背景・要点

AI需要の拡大で、増産競争は前工程だけでは足りず、パッケージ、基板、光配線材まで一体で整える必要が出ている。

OUTLOOK 影響・展望

装置と材料の供給余力を持つ企業ほどAIインフラ投資の波を取り込みやすく、後工程の立ち上げ速度が差を広げる。

→ §05 製造 詳細を読む
§06
■ ECONOMY / 経済

金利後退でも資源戦略は前へ

FACT 事実・概要

雇用減速でFRBの7月利上げ観測は低下した一方、原油安、韓国輸出、日印資源協力が実体経済の焦点として浮上した。

CONTEXT 背景・要点

金利の先読みが少し和らいでも、エネルギーと鉱物資源、輸出の裾野、インフレ粘着性はなお各国の政策判断を縛っている。

OUTLOOK 影響・展望

次は、資源協力や輸出の強さが日本とアジアの投資判断へどこまで波及し、再び金利観測を揺らすかを見たい。

→ §06 経済 詳細を読む
