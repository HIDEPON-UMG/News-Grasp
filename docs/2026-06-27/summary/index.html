「先行配布と基準線」
今日は、OpenAI の限定提供、Google の学校向けチューター、BIPROGY の AML SaaS、自動運転レベル4 の国際基準、ペルソナ3 リロード の長期販売が同じ朝に並び、どこまで先に配るか と どこを基準線に置くか が競争の分岐になりました。AI もモビリティも、派手な新機能より、認可・標準・運用の線を引けるかどうかが先に問われています。為替も 161.96 円という節目が見えることで、値動きの読み方が一段はっきりしました。

§02 FX

FX — 介入警戒と雇用統計待ち

USDJPY は 161 円台後半 を保ち、PCE 通過後も介入警戒が上値を重くしています。米雇用統計 が強ければ 162 円台定着を試せますが、弱ければ上値追いは鈍りやすい。金利差と 161.96 円の節目 を同時に見ると、来週の読み筋が立ちます。

§03 AI

AI — 限定提供と定着先の競争

GPT-5.6 の 20 社限定提供と Jalapeno チップは、モデル競争が配布条件と推論基盤の争いへ移ったことを示しました。中国の Claude API プロキシと LearnLM の学校展開も並び、使わせ方と守り方 が同じくらい重い。今日は性能より 定着先の設計 が主題です。

  • GPT-5.6 は 当初の提供先を約20社に限定 され、一般提供までの利用に米政府承認 が必要になった。
  • モデル性能そのものより、OpenAI が 国家安全保障を踏まえて配布を制御 し始めた点が大きい。最先端AIの公開は製品判断だけで完結しなくなる。
  • 読者が次に見るべきは、承認待ちで誰が先に使えるか と、限定提供が企業導入の商談速度をどこまで変えるかだ。

§04 IT

IT — 標準化して回す段階へ

BIPROGY の AML SaaS、清水建設 の Snowflake 移行、山下PMC の現場横断 UI、NTT東日本 の AWS 認定 37 名が並び、IT は 「ソフトを入れる」から「業務を標準化して回す」段階 に入りました。提案力 だけでなく 現場で続く運用設計 が採用理由になっています。

  • BIPROGYは外国送金の商流情報をAIで判定するAML SaaS「Trabotic」を12月に始め、人手依存だった一次チェックを標準化しにきた。
  • 国内初のSaaS型を掲げ、商流管理と送金データを突き合わせて異常兆候を可視化するため、金融機関ごとの差が大きい審査実務を横断基盤へ寄せる狙いがある。
  • 今後はSwiftの異常検知APIやAmazon Bedrockも組み合わせる計画で、AML対応を個別開発から継続更新型サービスへ移す流れが銀行IT投資の新しい軸になりうる。

§05 Mobility

Mobility — 認証と補助と採用の順番

自動運転レベル4 の国際基準、Uber と Lucid・Nuro のロボタクシー、東京都 の ZEV 補助、Tesla の日本採用が同じ日に出て、モビリティは性能競争より 認証・補助・採用 の順番を詰める局面です。先に走れるかより、先に通るか が勝負になっています。

§06 Game

ペルソナ3 リロード の 300 万本、Steam Machine の 60FPS 表記修正、めっちゃカメレオン の 1000 万本、BanG Dream! Our Notes の事前登録、JAMMM の始動が並び、ゲームは発売点より 運営と収益の持久力 が問われました。販売線を伸ばす設計 が、きょうの主語です。
