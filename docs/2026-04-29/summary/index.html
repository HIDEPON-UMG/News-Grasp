§01 総論

総論 — GAFAM決算が「AIの賞味期限」を問う

アルファベット・メタ・マイクロソフトが本日引け後に決算を発表する。共通点は巨額のAI設備投資と「いつ儲かるのか」という市場の問い。2024年から続く「投資先行・利益後追い」の構図が、今日の決算で検証の俎上に載る。Microsoft は Copilot の課金転換率、Google は Cloud AI の収益化加速、Meta は Llama 4 以降のマネタイズ戦略をそれぞれ問われている。決算が予想を下回れば、日経6万円と連動する形で急落リスクも生じうる。逆に通過すれば「AI収益化元年」の確信が世界市場を席巻する。

§02 為替・経済

為替・経済 — FOMC据え置き＋GW休場前の円安圧力

FOMCは本日政策金利の据え置きを発表する公算が大きく、焦点は記者会見でのパウエル議長のトーン変化に絞られた。GW連休（4月30日〜5月6日）の東京市場閉鎖は流動性の空白を生み出す。過去3年のパターンでは、GW中にドル円が1〜2円乱高下したケースが多く、今年は160円防衛ラインをめぐる政府介入への警戒が加わっている。植田総裁の「夏利上げ示唆」が確信に変わる6月会合まで、為替は構造的な円安圧力下に置かれ続ける。

§03 AI・技術

AI・技術 — MythosとGPT-5.5の「セキュリティAI競争」

Claude Mythos Previewは「世界で最初のサイバー兵器級AI」として一般公開を控えながら、Project Glasswingという防衛的フレームワークの中で先行運用されている。GPT-5.5との性能差はベンチマーク別では互角に近いまで縮まり、もはや「どちらが強いか」より「どの用途に何を選ぶか」が問いになった。この棲み分けはコンサル・エンタープライズの導入選定に直接影響する。自民党のサイバー対策会合でMythosが議題となったことは、AIが「技術ニュース」から「政策課題」へと昇格したことを示している。

§04 産業・業界

産業・業界 — NTT AIWONとコンサル業界の「実装戦争」

NTT AIOWNは単なるデータセンター拡張宣言ではなく、「日本国内でAIを処理する」という主権宣言でもある。一方、OpenAIのFrontier AllianceとGoogle Cloud $7.5億ドル基金はコンサル大手を自軍の「実装アーム」として囲い込む競争を激化させた。この構図は、AIを「作る側」と「使わせる側」の分業を確立させつつある。McKinsey・BCGが新卒採用を「AI協働人材」にシフトさせているのも同じベクトルであり、コンサル業界自体が最大のAI導入実験場となっている。

§05 明日へ

明日へ — 日経6万円の維持条件

日経平均が4月27日に終値で初めて6万円を超えた。この水準を維持するための3条件がある。①GAFAM決算の通過（本日）、②FOMC でのタカ派サプライズ回避（本日夜）、③GW中の為替変動が160円を突破しないこと。3条件が揃えば5月第2週にかけて「クリア後の買い戻し」が起きる可能性が高い。逆に1条件でも崩れれば、乖離が拡大していたTOPIXとの修正過程で日経は57,000〜58,000円への調整も視野に入る。今夜の決算発表と明日のFOMC結果が、5月相場のシナリオを決定づける。
