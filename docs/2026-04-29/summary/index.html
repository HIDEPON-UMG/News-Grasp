§01 総論

総論 — GAFAM決算が「AIの賞味期限」を問う

アルファベット・メタ・マイクロソフトが本日引け後に決算を発表する。共通点は巨額のAI設備投資と「いつ儲かるのか」という市場の問い。2024年から続く「投資先行・利益後追い」の構図が、今日の決算で検証の俎上に載る。Microsoft は Copilot の課金転換率、Google は Cloud AI の収益化加速、Meta は Llama 4 以降のマネタイズ戦略をそれぞれ問われている。決算が予想を下回れば、日経6万円と連動する形で急落リスクも生じうる。逆に通過すれば「AI収益化元年」の確信が世界市場を席巻する。

§02 為替

FOMC 本日結果発表 豪CPI・カナダ金融政策と重なる"超多難な火曜日"

FOMC本日結果発表・GW連休前の160円攻防・植田総裁利上げ「夏か」──ドル円の行方を決める3大イベントが火曜日に集結した。

  • FOMCは本日午後（JST 30日3時）に声明を発表。FFレート 3.50〜3.75%の据え置きが確実視され、焦点はパウエル議長会見での次回利下げ示唆の有無に絞られている。
  • 豪CPIとカナダ中銀決定も本日。コモディティ通貨の動向がドル円へ二次波及するため、クロス円全般に注意が必要。
  • GW連休入りで東京市場が4月30日から閉鎖。流動性低下局面でのヘッジ外しが短期的な円安圧力となりうる。

§03 AI

Claude Mythos Preview「危険すぎて公開できない」―Project Glasswingで防衛側が先制

Claude Mythosが「危険すぎて公開できない」AIとして防衛側先制のProject Glasswingを加速させる一方、GPT-5.5との性能拮抗・Gemini 3.1コスト革命が並走する目が離せない1日。

  • Anthropicが4月22日、Project Glasswingの参加企業を拡充。AWS・Apple・Google・Microsoft等50社以上が未公開のClaude Mythos Previewでゼロデイ脆弱性の先行修正作業を開始。
  • Mythosは全OSを横断してすでに数千件のゼロデイ脆弱性を発見。27年間未発見だったOpenBSDの脆弱性を自律的に特定した事例が報告されている。
  • 4月20日には自民党サイバーセキュリティ対策本部でMythosが正式議題となり、Anthropic・OpenAI代表が出席。国家レベルのAIサイバーリスク議論が日本でも始動。

§04 IT

NTTグループ「AIOWN」発表 2033年にデータセンター容量3倍超・国内AIインフラ主権を宣言

NTTグループが「AIOWN」でインフラ主権を宣言し、OpenAI×コンサル3社の「Frontier Alliance」・Google Cloud $7.5億ドル基金が実装戦争を激化させる。AIコンサル業界は「作る側」から「実装する側」へと構造転換中。

  • NTT・NTTデータグループ・NTTドコモが4月27日、AIネイティブインフラ「AIOWN」を発表。国内DCのIT電力容量を現状約300MWから2033年度に約1GWへ3倍超拡張する。
  • 東京都心部・栃木・印西白井の3エリアに液冷標準のAI対応型DCを新設。GPU密度対応の冷却設備が標準仕様となり、推論・学習ワークロードを国内で完結させる体制を構築。
  • 国内IT市場5兆6,540億円（2030年予測）の制覇を視野に、NTTグループが「インフラ主権」を軸にAI事業化を加速させる構造転換。

§05 経済

GAFAM4社 本日引け後に決算 AI設備投資の「利益圧迫」論が試練の場を迎える

本日はFOMC結果・GAFAM3社の決算発表・日経平均6万円維持の3大イベントが重なる「2026年最大の経済的試練」。AI設備投資が収益に転化するかを問う一週間が始まった。

  • アルファベット・メタ・マイクロソフトが本日引け後、アマゾン・アップルが明日とGAFAM5社が本格決算シーズン。AI設備投資の増額が利益を圧迫するか否かが市場の最大焦点。
  • 市場コンセンサスはMSFT売上高+16.2%・EPS $4.06、GOOGL EPS $2.35。クリアした上でガイダンスが前向きなら買い継続、下振れなら短期的な急落リスク。
  • S&P500が本日時点で7,173.91と2営業日連続の最高値。FOMCとGAFAM決算の2大イベント通過が安心買いにつながるかが鍵。

ニンテンドーeショップ「GWセール」開幕 Switch2タイトルが最大50%引き
