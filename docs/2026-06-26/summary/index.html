§01 総論

総論 — 実装と回収の入口を見る

AI と IT は機能追加の話から業務をどこまで動かすかへ移り、Mobility と Manufacturing は設備の転用や増設でどの拠点から回収するかが前に出ました。FX と Economy は、金利差と景気の底堅さが値動きの説明軸を支えています。今日は、見栄えよりも実装の入口と回収の出口をそろえる朝でした。

§02 為替

為替 — 161円台後半、介入警戒と金利差

ドル円は161円台後半で粘り、PCE後の米利上げ観測後退で上値が少し重くなりました。とはいえ、日銀の段階利上げ観測と介入警戒が消えたわけではなく、金利差が縮むかどうかが短期の焦点です。ユーロドルも戻り待ちに入り、材料は次の指標へ移っています。原油安でECBの追加利上げ観測もやや後退していて、米欧の政策差が為替の次の向きを決める形です。

  • ドル円は一時161.95円まで上げた後も161円台後半を維持し、161.96円突破なら1986年以来の円安水準という緊張が残った。
  • 5月PCEは前年比4.1%と予想通りだった一方、前月比は予想をやや下回り、ドル買い一辺倒の流れを鈍らせた。
  • FRBの7月利上げ確率は約30%へ低下したが、日米政策差はなお大きいため、介入警戒だけが上値抑制役として残った。

§03 AI

AI — エージェントは本番と防御へ

Gemini 3.5 Flash の Computer Use 統合と OpenAI Codex の社内定着で、AIエージェントは研究段階から業務実装へ進みました。いっぽうで Anthropic の蒸留攻撃告発や NEC の秘匿計算実証、公取委のPR素材問題が示すのは、性能よりガバナンスと審査ログが導入条件になることです。NEC の cotomi が秘匿計算でも実用圏に近づいたことで、国産LLMも「作る」から「安全に回す」段階へ一段進みました。

  • Gemini 3.5 Flash に Computer Use を標準統合したことで、操作専用モデルを分けずにエージェントを組める 構成へ変わった。
  • Web・モバイル・デスクトップをまたぐ実行経路が一つのモデルに寄ったため、長手順の自動化を設計しやすく、Gemini API の実装負荷も下がる。
  • 不正な指示の注入を検知して停止する保護策まで同時に出した点は、企業導入の壁が性能ではなくガバナンスへ移ったことを示し、AIエージェントの本番投入を早める。

§04 IT

IT — SaaSは業務実行基盤に寄る

freee は会計SaaSを業務を代行する基盤へ組み替え、KPMG は顧客理解AIエージェントを支援側に乗せました。Fortinet のSOC統合も含め、システム名より往復を何回減らすかが評価軸になっています。Amazon の大型投資も、その接続先を広げる動きです。国内実務をAIから呼び出す接点が増えるほど、導入の勝負は画面の見た目より運用の回数削減に移ります。

  • freeeは会計・人事労務SaaSをAIエージェント実行型へ移す方針を示し、人が触るソフトから業務を代行する基盤へ軸足を移した。
  • Amazon-Bedrock上で複数エージェントを本番稼働させ、MCPサーバーと382本のAPIを公開済みと説明したことで、外部AIから国内実務を呼び出す接続面まで見えた。
  • 介護現場の経費精算を月30分から2分へ縮めた事例や、SLMの精度10ポイント超改善・推論5倍超を示し、AI導入がPoCではなく運用KPIの段階に入ったことを示した。

§05 モビリティ

モビリティ — EVの勝負は認証と回路

ホンダ はEV見直し損失を抱え、ハイブリッド軸へ再配分しました。May Mobility の欧州ロボタクシー、米政権のブレーキペダル義務見直し、V2G 商用化、中国の充電網拡大まで並ぶと、車両性能より制度と充電回路が市場を決める空気が強まります。車の売り方ではなく、走らせるための回路が先に整うかどうかが、事業の速度を左右します。

  • ホンダは定時株主総会を迎え、北米向け3EV中止と最大2.5兆円規模の損失見通しを抱えたまま説明責任を問われる局面に入った。
  • 3月の会社発表では米EV需要鈍化と中国勢との競争激化を理由に、0 SUV・0 Saloon・Acura RSXの計画中止とハイブリッド再強化を打ち出している。
  • 読者が次に見るべきは電動化戦略の後退そのものより、日米中で商品配分と投資回収をどう組み直すかだ。

§06 製造

製造 — 工場、材料、電力の再配置

アンドゥリル の追浜工場取得協議は、自動車工場をドローン量産拠点へ変える発想を示しました。IBM のサブ1nm、TSMC の値上げ、トーヤク の新工場、日機装 の太陽光稼働も重なり、工場は作る場所から組み替える場所へ移っています。IBM は 0.7nm で 3D 積層の性能5割向上を狙い、TSMC は 3nm から 7nm まで 5〜10% 値上げを通知しました。材料、電力、用途のどれか一つでも詰まると回収計画がずれるので、配置の妙が効いてきます。

  • アンドゥリルは日産追浜工場の取得協議を進め、自動車工場を軍事用ドローンの量産拠点へ転用する構想を示した。
  • 関係者によれば従業員の多くを再雇用する意向もあり、工場閉鎖後の雇用と技能を防衛生産へ移す絵が見え始めた。
  • 重要なのは日本製部品だけを使うドローン構想と結びつく点で、自動車の遊休設備が防衛産業基盤へ流れ込む可能性が国内製造の再配置を加速させる。

§07 経済

経済 — 米景気は強く、債務は物差しを固定

IMF は米景気の堅調さを認め、Fed 据え置きを支持しました。GDP上方修正とNY株続伸も重なり、利下げ期待後退でも株が崩れにくい状態です。日本では高市首相が総債務対GDP比低下を財政目標の中核に据え、市場の信認をどう測るかを先に決めました。米国では企業投資の強さと個人消費の鈍さが同居しており、今日はそのねじれも読みどころでした。

  • 労働生産性と国内投資の強さを根拠に、米国だけが高成長と高インフレの鈍化を同時に保てるかが次の焦点になった。
  • 同日に出たGDP確報値の上方修正も追い風で、Fedの判断は景気失速懸念より物価管理を優先する流れを補強した。
