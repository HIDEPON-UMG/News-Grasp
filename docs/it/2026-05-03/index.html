Accenture Q2 FY2026 beats forecasts — $18.0B収益・$22.1B過去最高受注を達成

FACT
【事実・概要】
AccentureのQ2 FY2026収益は180億ドル、予想比0.95%上振れでUSDベース8%成長。四半期受注は221億ドルと過去最高を記録し、うち1億ドル以上の受注クライアントが41社と過去最多。上半期累計受注は430億ドルに達した。
CONTEXT
【背景・要点】
生成AI関連の累計受注はFY2025下半期比で倍増ペースで推移。AIエージェント・ERPモダナイゼーション・クラウド移行が牽引し、マネージドサービスが前年比+10%と高成長。Accenture全体の従業員数は78.6万人で世界最大のAI実装チームを擁する。
OUTLOOK
【影響・展望】
株価は発表後一時下落。通期ガイダンス（現地通貨ベース3〜5%成長）の据え置きとFederal事業縮小（約1%影響）への懸念が重荷。ただしAI受注増は構造的であり中長期のトレンドは変わらずとの見方が大勢。

BCGのAI収益が全売上の25%（$3.6B）に — 「コンサル業界史上最大の転換」

FACT
【事実・概要】
BCGの2025年総収益は144億ドル、うち36億ドル（25%）がAI関連コンサル。Bloomberg 4/23報道で「コンサル業界史上最大のシフト」と評価された。AI戦略策定・実装支援・AIエージェント導入の3本柱が収益を牽引。
CONTEXT
【背景・要点】
BCG Gammaプラットフォーム（AI開発・展開基盤）が受注増の主要因で、「AIを語る」から「AIで実装する」フェーズへの業界全体の移行が鮮明になった。McKinseyのAI関連プロジェクト比率は約40%に到達。
OUTLOOK
【影響・展望】
大手3社（Accenture・McKinsey・BCG）のAI関連売上合計は年間100億ドル超と推定。コンサル業界は「人員削減と収益成長が同時進行する」構造的転換期に入った。

2026年のコンサルAI競争 — McKinsey「Agents-at-Scale」・PwC「Agent OS」・KPMGが激突

FACT

大手コンサルのAI活用完全比較 — McKinsey/Accenture/Deloitte/EYの戦略を解剖

FACT
【事実・概要】

AI Consulting市場 2025-2032 — Accenture/IBM/Deloitte/PwC/EYが60%以上を独占

FACT
【事実・概要】
AI consulting市場は2025年500億ドルから2032年に向け年率18.5%成長を予測。Accenture・IBM・Deloitte・PwC・EYが上位5社で市場の60%以上を独占する構造が続く見通し。
CONTEXT
【背景・要点】
成長ドライバーは製造業・金融・ヘルスケアへの生成AI導入支援。特に日本市場はDX推進政策と労働力不足によりAI投資が世界平均を上回るペースで拡大中で、NTTデータ・富士通・NECとのコラボレーションが活発化。
OUTLOOK
【影響・展望】
