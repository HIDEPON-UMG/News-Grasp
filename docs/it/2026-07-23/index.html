OpenAI、2030年までの計算資源予算を122兆円に引き上げ

FACT
【事実・概要】
OpenAIが2030年までの計算能力への支出見通しを7500億ドル（約122兆円）前後へ引き上げた。年初の約6000億ドルから増額する。
CONTEXT
【背景・要点】
複数のクラウドコンピューティング企業との新契約を反映し、モデルの開発・運用に必要な計算資源を先回りで押さえる。AIの競争軸がモデル性能から計算基盤へ広がっている。
OUTLOOK
【影響・展望】
巨額投資はAIインフラ需要を押し上げる一方、資本効率と電力・データセンター供給が問われる。IPO前の資金計画と契約の実行度が次の焦点になる。
