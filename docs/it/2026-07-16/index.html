トビラシステムズ、プロディライトと資本業務提携　クラウドPBXを拡販

FACT
【事実・概要】
トビラシステムズが、INNOVERAを展開するプロディライトと資本業務提携を締結した。10万株を取得予定で、クラウドPBXの販売拡大を狙う。
CONTEXT
【背景・要点】
両社は顧客基盤、販売チャネル、導入支援ノウハウを持つ。法人電話のクラウド化が進むなか、機能だけでなく移行・運用支援の厚みが競争軸になる。
OUTLOOK
【影響・展望】
サービス連携や共同開発、販売網の相互活用を進める。電話DX市場でシェア拡大を実現できるか、株式取得後の協業を見極めたい。
