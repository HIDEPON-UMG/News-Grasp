AWSのCloudFront障害、PayPayやnoteなどに波及

FACT
【事実・概要】
AWS CloudFrontで世界規模の障害が発生し、PayPayやnote、ニコニコ生放送などが利用しにくくなった。
CONTEXT
【背景・要点】
原因はCloudFrontの「VPC Origins」機能の問題とされ、同機能を使わない回避策が示された。基盤障害が複数サービスへ連鎖した。
OUTLOOK
【影響・展望】
AWSは午後9時20分ごろ復旧を発表した。依存機能の切り分けと代替経路をどこまで設計できるかが次の焦点になる。
