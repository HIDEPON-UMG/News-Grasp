ガートナー、IT予算を一律削減から戦略配分へ転換

FACT
【事実・概要】
ガートナーは、AI時代のIT支出増を前提に、予算を一律削減ではなく戦略的に配分する考え方を示した。世界IT支出は6兆3690億ドル、前年比14.2%増の予測。
CONTEXT
【背景・要点】
データセンターシステムは前年比62.5%増、IaaSは29.3%増と伸びが偏る。削減・性能改善・事業成果への投資を分けて管理することが判断材料になる。
OUTLOOK
【影響・展望】
AIインフラは一時投資から継続運用費へ重心が移る。CIOは増えた支出ではなく、事業成果に結びつく裁量を説明できるかが問われる。

FACT

サイバーセキュリティクラウド、PQC対応の技術検証を開始

FACT
【事実・概要】
サイバーセキュリティクラウドが耐量子計算機暗号（PQC）の技術検証を始めた。まずクラウド型WAF「攻撃遮断くん」での対応実現を目指す。
CONTEXT
【背景・要点】
検証対象にはIETFのRFC 10024で定義されたハイブリッド鍵合意方式が含まれ、Web環境との互換性や通信性能を確認する。現段階は技術検証の開始で製品化ではない。
OUTLOOK
【影響・展望】
量子計算機の実用化を見据え、企業は暗号利用箇所の棚卸しと移行準備を迫られる。今後は検証結果と正式な提供時期が判断材料になる。

FACT
