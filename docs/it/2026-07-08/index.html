請求起点で損益可視化、マネーフォワードがERP連携強化

FACT
【事実・概要】
マネーフォワードは クラウド請求書Plusに「プロジェクトマスタ」を追加し、請求書や売上明細と案件単位の情報を結び付ける ことで、ERPの一気通貫性 を高めた。

【背景・要点】

OUTLOOK
