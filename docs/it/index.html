Qantas HQ to outsource 850 jobs to Accenture カンタス航空本社、850職をアクセンチュアへ移管

FACT
【事実・概要】
：カンタス航空は10日、Accentureと複数年の戦略提携を結び、本社の財務・調達・人事・マーケティングなど約850職に影響する再編を発表した。業務はインド拠点が中心となり、一部は豪州に残る。AI投資と業務移管を一体で進める判断だ。
CONTEXT
【背景・要点】
：同社は1,000超のレガシーアプリが連携前提で設計されていない課題を抱え、基幹の刷新と自動化・AIによる変革を移管の先に置く。影響は全従業員約28,000人の約3%に及ぶ。人を減らす話ではなく基盤を作り替える話として提示された。
OUTLOOK
【影響・展望】
：移行は2027年半ばから段階的に始まり、労組との協議が先行する。大規模アウトソーシングの成否は、移管後の品質とコストの実績で測られることになる。
