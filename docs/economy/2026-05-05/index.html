S&P500が7,209で最高値更新 — 好決算・イラン和平進展・原油安が三重奏

  • 4月30日のS&P500は7,209.01（+1.02%）で終値ベースの史上最高値を更新。イランの和平提案・Appleの好決算（市場予想を83%の企業が超過）・原油価格下落が同時に株高を後押しした。
  • ただし決算発表が終盤に差し掛かり、S&P500が最高値水準にある中では「好材料出尽くし」のリスクが意識されており、5月の相場展開は売り方が主導権を握り始める可能性がある。
  • 「Sell in May」格言通りの展開を警戒するアナリストも増えている。金利上昇局面でのバリュエーション修正は避けられず、ナスダック指数の高PERが特に懸念される。

米3月CPI +3.3%、2024年5月以来の最高水準 — イラン戦争でガソリン+18.9%

  • 米3月CPIは前年同月比+3.3%と2024年5月以来の最高水準に上昇。エネルギー価格が+12.5%（ガソリン+18.9%・燃料油+44.2%）に急騰し、イラン戦争による供給不安を反映した。
  • コアCPI（食品・エネルギー除く）は+2.6%にとどまり、サービス価格の粘着性は依然あるが制御可能な水準。4月CPI は5月12日発表予定 で、和平進展による原油安効果が注目される。
  • ジェローム・パウエルFRB議長は利下げを急ぐ必要なしとの姿勢を維持。年2回の利下げ予想は変わらないが、地政学リスクと金融政策が直結 する異例の環境が続く。
05 2026-04-28 16:00 · 日本経済新聞 78

日銀4月会合 政策金利0.75%据え置き — CPI見通し+2.8%へ大幅上方修正

  • 日銀は4月27〜28日の政策決定会合で、無担保コール翌日物金利の誘導目標を0.75%に据え置くことを6対3で決定。植田和男総裁は6月会合での利上げを示唆する発言を避けた。
  • 同時に発表した展望レポートで、2026年度CPI（生鮮食品除く）見通しを1月の+1.9%から+2.8%へ大幅引き上げ。エネルギー高騰と円安進行を反映し、利上げ再開の地合いは整いつつある。
  • 会見後に円相場が159円台に戻すなど、市場は植田発言を「想定内のハト派」と解釈。次回7月会合での0.25%利上げが有力視されており、USD/JPYは介入水準157〜160の攻防が続く。
