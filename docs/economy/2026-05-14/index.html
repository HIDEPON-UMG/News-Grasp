米4月CPI+3.8%（3年ぶり高水準）— 年内利下げ遠のき、12月利上げ確率30%へ

  • 米労働省発表の4月CPI（消費者物価指数）は前年比+3.8%、前月比+0.6%。2023年5月以来3年ぶりの高水準で、ガソリン・食品の値上がりが押し上げた。コアCPIは前月比+0.4%・前年比+2.8%とFederal Reserveの2%目標を大幅に上回る状態が継続。
  • CPI発表直後にS&P500は-0.37%、Nasdaq -0.65%、Dow -0.21%と反落。CME FedWatchで12月利上げ確率が30%まで上昇し、年内の利下げシナリオは「消滅」に近い状況となった。
  • 翌13日には米4月PPI（生産者物価指数）も前年比+6.0%（前月比+1.4%）と2022年以来の大幅上昇を記録。インフレの「川上」から「川下」に至る全面的な物価圧力が確認され、「第二波インフレ」を市場が正式に宣告した日となった。

米PPI前年比+6.0%（2022年以来最大）— S&P500続落、インフレ第二波が株式リスクプレミアムを押し上げ

  • 米4月PPI（生産者物価指数）は前年比+6.0%・前月比+1.4%と予想（+0.5%）を大幅超過。前週比での原油・食料コストの急伸が主因で、消費者向けインフレへの波及は今後2〜3ヶ月内に顕在化する見通し。
  • S&P500はCPI翌日も続落。投資家はリスクプレミアムの再評価を迫られており、「Sell in May」の現実味が高まった。半導体株（NVDAなど）も利益確定売りの対象となっており、AI投資への過熱修正が起きている。
  • CPI+PPIのダブルショックは「イラン情勢→原油高→物価波及」というサプライチェーンインフレの典型パターン。地政学リスクがマクロ経済に本格的に組み込まれたことを市場が認識しつつある。

ウォーシュ新FRB議長 明日就任 — 「フロントローディング利下げ」か「タカ派転換」か

  • ケビン・ウォーシュ氏が5月15日にFRB議長として正式就任。パウエル氏の4期目任期満了を受けトランプ大統領が指名し上院委員会が承認。「タカ派」評価と近年の「利下げ支持」発言が市場の混乱を招いてきた人物。
  • TradingKey分析によれば、ウォーシュ就任によって「漸進的利下げ→急速前倒し（フロントローディング）への転換」または「インフレ再燃受けのタカ派化」の二分岐が生じる。就任後最初のスピーチがドル高・株式市場の方向を決める。
  • NVIDIA・Qualcomm・Teslaなどグロース株は政策転換感応度が高い。インフレが確認された今、ウォーシュ氏が利下げを支持すれば「サプライズ利下げ」として株高のカタリストになりうる逆説的シナリオも浮上している。
