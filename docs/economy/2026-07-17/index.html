TSMC、4～6月期純利益77.4%増　AI半導体で過去最高

FACT
【事実・概要】
TSMCの2026年4～6月期純利益は前年同期比77.4%増の7065億台湾ドル、売上高は36.0%増の1兆2703億台湾ドルとなり、そろって四半期最高を更新した。
CONTEXT
【背景・要点】
AI半導体向けの先端品需要が業績を押し上げた。魏哲家会長兼CEOはAI需要を「極めて力強い」と説明し、7～9月期も好調が続くとの見通しを示した。
OUTLOOK
【影響・展望】
AI向け需要がファウンドリーの増収をどこまで支えるかが焦点になる。次は7～9月期の受注と、供給能力を増やす投資の持続性を見極めたい。

孫正義氏、2040年の「ASI Economy」を提示　GDPの2割をAIに

FACT
【事実・概要】
孫正義氏は2040年の「ASI Economy」について、世界GDPの約20%（約7000兆円）がAIに置き換わるとの見通しを示した。
CONTEXT
【背景・要点】
講演では、100兆個のAIエージェント、10億台のヒューマノイド、3TWのAIデータセンター、年5兆ドルの投資という規模感を提示した。
OUTLOOK

AIの競争力はモデル性能だけでなく電力・計算資源・防衛体制で決まる。企業は「Return on AI」を軸に投資効果と脆弱性対策を同時に検証する必要がある。

米大手5行の決算好調、株価の持続力にリスク

FACT
【事実・概要】
米大手5行が4～6月期決算を発表し、利益と売上高はいずれも予想を上回った。ゴールドマン・サックスの株価は9%上昇した一方、シティグループは約5%下落した。
CONTEXT
【背景・要点】
投資銀行手数料とトレーディング収入が伸び、各行の費用効率も改善した。信用損失は抑制されたが、好調な市場環境が収益を押し上げた面もある。
OUTLOOK
【影響・展望】
銀行の好決算が実体経済の強さを示すのか、市場変動と大型案件の特需なのかを、融資需要と信用損失の推移で見極める局面だ。
