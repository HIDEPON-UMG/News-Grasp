東京23区の物価上昇率、8月は1.8%に鈍化

FACT
【事実・概要】
東京都区部CPIの8月中旬速報値は、生鮮食品を除く総合が前年同月比1.8%上昇。電気・ガス代補助とコメ価格下落が伸びを抑え、7カ月連続で2%を下回った。
CONTEXT
【背景・要点】
市場予測の中央値は1.7%上昇だった。日銀の物価安定目標である 2% を下回る一方、生鮮食品とエネルギーを除く総合は2.0%上昇しており、基調の見極めが要る。
OUTLOOK
【影響・展望】
日銀の政策判断では、補助や食品価格の一時要因と基調的な物価を分けて見る必要がある。次は 補助終了後の物価上昇率 と賃金の連動が焦点になる。
