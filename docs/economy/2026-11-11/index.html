東京マーケットダイジェスト・10日　ユーロ底堅い・株大幅高

FACT
【事実・概要】
：10日の日経平均は1,684円高の60,459.58円で終え、終値で6万円台を回復した。TOPIXは1.98%高の3,893.71で、前夜の米国で半導体株が急伸した流れを引き継いだ。値がさ株主導の戻りが鮮明だった。
CONTEXT
【背景・要点】

OUTLOOK
【影響・展望】
：夜の米CPIが予想を上回ったことで、焦点は米金利の反応と6万円台の定着に移る。引け後のソフトバンクG決算を受けた先物の動きも朝の材料になる。

ソフトバンクG、上期7680億円の赤字　投資利益1.7兆円も費用膨らむ

FACT
【事実・概要】
：ソフトバンクグループは10日、2026年4〜9月期の純損益が7,680億円の赤字になったと発表した。投資利益は1.7兆円を確保したが、前年同期の2.9兆円黒字からは大きく後退した。AI投資のコストが利益を食う構図が数字に出た。
CONTEXT
【背景・要点】
：赤字の主因は米国のAIデータセンター向け発電設備の調達見直しに伴う約5,972億円の損失と、財務費用の7,907億円への急増だ。当日の株価は決算前に13.88%高で終える一方、PTSでは下落した。期待と実績の温度差が株価に表れた。
OUTLOOK
【影響・展望】
：焦点はNAVと借入比率の管理と、OpenAIなど投資先の評価の行方だ。AI関連株全体の投資負担への見方を試す決算として残る。

FACT
