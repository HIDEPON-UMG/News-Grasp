日経平均 史上初の65000円台 5月25日に65158円 AIと半導体関連が牽引 全員参加の相場

【事実】

日経平均5月29日66329円で終値66000円台初達成 原油安・米イラン停戦期待が追い風

【事実】
5月29日の東京株式市場で日経平均は前日比1,636円高の66,329円で引け、終値ベースで初の66,000円台に到達。上げ幅1,400円超という異例の強さで最高値を4日ぶりに更新した。
【背景】
「トランプ大統領の米イラン停戦合意示唆」が起爆剤。ホルムズ海峡の正常化→原油価格落ち着き→コスト圧力緩和→企業収益改善という好循環を市場が先取りした。
【展望】
S&P500も最高値を更新し「同時高」の構図。ただしFRBのタカ派転換リスクと日銀の利上げ観測が上値を抑える要因として残り、二つのCBイベント（6/17 FOMC、6月日銀会合）が目下最大の下方リスク。
03 2026-06-02 07:00 · TradingKey 82

ウォーシュ新FRB議長就任 6月17日初FOMC タカ派シフト懸念でCPI3.8%受け利上げ観測

【事実】
ウォーシュ議長が第17代FRB議長として5月22日に正式就任。6月17日が初FOMCとなり、CPI3.8%（4月）とNFP115,000人増という強めの経済指標を前に、タカ派スタンスへの転換が意識されている。
【背景】
CME FedWatchでは6月据え置き確率が99%。ただし「利下げ打ち止め→利上げ再開」シナリオへの警戒は高まり、10年債利回りが4.5%台に上昇。株式市場へのバリュエーション圧力となる。
【展望】
日本への影響は複層的。ドル円は160円台維持→輸出企業の収益増、一方で輸入インフレ再燃→消費者物価の押し上げ→日銀の早期利上げ圧力増大という連鎖が「悪い円安」のリスクとして浮上。
04 2026-06-02 09:00 · LIMO 78

日銀保有国債含み損が45兆円で過去最大 植田総裁「原油高は広範かつ持続的」とコメント

【事実】
日銀が保有する長期国債の含み損が45兆円に達し、過去最大を更新。長期金利の上昇（10年債利回り1.7%台）と大量の低クーポン債保有が相まって、評価損が膨らんだ。
【背景】
植田和男総裁は原油高について「広範囲かつ持続的」と発言。これはインフレ圧力への認識の高まりを示すが、含み損拡大という「バランスシートの弱点」が利上げ決断を心理的に縛るという逆説がある。
【展望】
市場では「日銀は利上げしたくとも含み損が壁となり躊躇する」という見方が広がる。しかし国際基準では含み損は問題にならない——認識論的な混乱が日銀コミュニケーションをより難しくしている。
