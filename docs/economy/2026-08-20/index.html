秋田のAIデータセンター構想、UAEが視察

FACT
【事実・概要】
秋田県でAIデータセンター構想が進み、UAE大使が19日に予定地などを視察。大型インフラ投資が地域経済を押し上げる可能性を探る。視察は投資決定ではない。
CONTEXT
【背景・要点】

OUTLOOK

GDPはプラスでも、物価高が家計と景気を圧迫

FACT
【事実・概要】
2026年4〜6月期の実質GDPは前期比0.3%増、3四半期連続のプラスとなった。GDPは伸びたが、個人消費と設備投資は弱い。
CONTEXT
【背景・要点】
物価高で家計が節約志向を強め、宿泊・飲食への支出も低調。企業物価指数は前年比7.2%上昇し、コスト転嫁が続く。内需の弱さが重要だ。
OUTLOOK
【影響・展望】
秋以降は原油関連の値上げが表面化し、成長率が鈍るとの見方がある。実質賃金の伸びと個人消費の回復、日銀の政策判断を追う。

AI未上場株の評価益が映す、ビッグテック決算の実力とリスク

FACT
