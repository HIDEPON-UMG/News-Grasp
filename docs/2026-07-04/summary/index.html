§01
¥ FOREIGN EXCHANGE / 為替

価格の入口をどこに置くか

FACT 事実・概要

日銀の需給ギャップは17四半期連続の需要超となり、国内長期金利は30年ぶり高水準の2.81%まで上がった。

CONTEXT 背景・要点

弱い米雇用で早期利上げ観測は和らいでも、日本側では円安の副作用と政策後手懸念が残り、相場の下値と上値の両方を押し広げている。

OUTLOOK 影響・展望

FOMC議事要旨と当局発言を経て、160円台前半で止まるのか、金利上昇と円安が同居する不安定な価格帯が続くのかが次の焦点になる。

→ §01 為替 詳細を読む
§02
◆ ARTIFICIAL INTELLIGENCE / AI

政策と端末で入口を押さえる

FACT 事実・概要

資本政策、独自チップ、教育指針、端末常駐、自治体窓口実証が同時に進み、AIの接点が複数の現場へ広がった。

CONTEXT 背景・要点

モデル性能だけでなく、規制対応、半導体供給、学校現場の安全基準、日常端末への常駐がそろって初めて利用が定着する段階に入っている。

OUTLOOK 影響・展望

政府や自治体、教育機関が最初の採用窓口になるなら、AI企業の競争はAPI単価以上に、制度順守と導入支援の厚みで差がつきやすくなる。

→ §02 AI 詳細を読む
§03
⌗ IT & CONSULTING / IT

外販基盤に統制を載せる

FACT 事実・概要

GPU外販、脆弱性開示、追加学習不要の予測モデル、会計自動化、ソブリンAI基盤と、ITの主役は基盤運用に寄った。

CONTEXT 背景・要点

企業や政府は新機能だけで契約せず、脆弱性対応、データ主権、既存業務への接続まで面倒を見られる提供者を選び始めている。

OUTLOOK 影響・展望

今後は演算資源を持つ会社ほど有利という単純な話ではなく、統制を伴う導入責任まで束ねられるかが大型案件の勝敗を分ける。

→ §03 IT 詳細を読む
§04
◎ MOBILITY / モビリティ

普及の鍵が補助から運行へ移る

FACT 事実・概要

税優遇の終了、販売回復、自動運転トラック体制整備、欧州進出、燃料逼迫起点のEV需要増が同じ日に現れた。

CONTEXT 背景・要点

モビリティの普及は価格だけでは決まらず、保有税、運行設計、燃料事情、許認可交渉の組み合わせで地域ごとに勝ち筋が変わる。

OUTLOOK 影響・展望

次は、税支援が薄れる市場でも走るモデルと、制度交渉を先に終えた自動運転事業者がどこまで先行利益を取れるかを見たい。

→ §04 モビリティ 詳細を読む
§07
▶ GAMING / ゲーム

既存母集団を新作へ送る

FACT 事実・概要

フェス、無料試遊、リアルイベント、無料キャンペーン、世界同時配信が並び、既存ユーザーを次のタイトルへ送る施策が目立った。

CONTEXT 背景・要点

広告だけで新作を立ち上げるより、既存IP、会員基盤、イベント接点、無料枠を束ねたほうが送客効率と継続率を読みやすい。

OUTLOOK 影響・展望

今後は初週売上よりも、フェス参加者の転換率、無料試遊からの継続購入、リアルイベント後の再接触が重要な判断材料になる。

→ §07 ゲーム 詳細を読む
