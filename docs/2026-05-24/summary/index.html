§01
¥ FOREIGN EXCHANGE / 為替

貿易黒字の復活と「介入警戒×PCE待ち」の二重拘束

FACT 事実・概要

来週（5/25週）の重要スケジュールは5/28 FOMC議事録・5/29 米GDP改定値・5/30 PCEコア価格指数の三連弾。5/25はメモリアルデーで米国全休のため、相場は火曜以降に本番を迎える。

CONTEXT 背景・要点

PCEが市場予想3.5%を上回ればFRB利下げ後退観測が高まりドル買い優勢。逆に5/30同日発表の東京CPIが前月比加速（想定：+2.1%超）なら日銀利上げ期待が再燃し円買いが波状的に広がるシナリオが待つ。

OUTLOOK 影響・展望

外為どっとコムの週次予測では、ドル円のコアレンジを158〜161円と想定。160円手前の介入警戒ラインは依然有効で、MOFの口頭介入で158円割れを目指す動きが週中に起きれば好機と見るトレーダーも多い。

§02
◆ ARTIFICIAL INTELLIGENCE / AI

モデル戦争から「制御プレーン」争奪へ

FACT 事実・概要

GPT-5.5 InstantがChatGPTのデフォルトモデルに昇格。OpenAIが強調するのは「規制分野（医療・法律・金融）における幻覚率の大幅低減」で、従来のGPT-5系と比較してコンプライアンス文書処理での精度が向上したと主張する。

CONTEXT 背景・要点

Instantという命名が示す通り、レイテンシとコストの最適化が主眼。アーキテクチャの改良により同等タスクを30〜40%低いコストで処理できると発表。企業API利用者にとって直接のコスト削減につながる設計で、AnthropicのClaude APIとの価格競争が激化する。

OUTLOOK 影響・展望

背景にはOpenAI Frontierプラットフォームへの企業移行を加速する戦略がある。McKinsey・BCG・AccentureがOpenAI Frontier Alliancesに参画し、GPT-5.5系を成果連動型フィーで展開するエコシステムが完成形に近づきつつある。

→ §02 AI 詳細を読む
§03
⌗ IT & CONSULTING / IT

「採用増とリストラ」が同時進行する業界の二極化

FACT 事実・概要

Bloombergの報道によると、McKinsey・PwC・EYの3社が幹部秘書（Executive Assistant）職を相次ぎ削減。PwCは米国で約600名、McKinseyは200名超の技術・支援スタッフを削減済み。KPMGも同様の動きで、Big4のうち3社が支援職を整理という同時進行が確認された。

CONTEXT 背景・要点

削減対象は「スケジュール管理・調査・報告・文書作成」といった定型業務群で、生成AIが数分で完結させるタスクをこれまで数週間かけて処理してきた。内部AIツール（Microsoft Copilot/専用AI）への移行が人件費圧縮の直接要因となっている。

OUTLOOK 影響・展望

特徴的なのは、この削減が外部クライアントに見える形の「ダウンサイジング」でなく、バックオフィス（ミドルレイヤー）の静かな収縮として進んでいる点。コンサル産業の「人×時間=フィー」モデルが内部から溶解していくサインとして受け止められている。

→ §03 IT 詳細を読む

■ ECONOMY / 経済

本日は経済ジャンル休載（土曜日は対象外）

FACT 事実・概要

経済カテゴリは月〜金の平日のみ掲載。

CONTEXT 背景・要点

ただし関連指標として、日本の4月貿易収支黒字転換（§02 為替セクション）とSwitch 2のメモリ高騰要因（§06 ゲームセクション）は経済的なシグナルとして参照されたい。

OUTLOOK 影響・展望

来週5/30のPCEコア価格指数と東京CPIが、日米双方のインフレ動向を巡る最重要データポイントとなる予定。

§07
▶ GAMING / ゲーム

「AI半導体の直撃」と「IPの強さ」が同日に現れた土曜日

FACT 事実・概要

5月24日（日本時間）、Switch 2翌日の値上げ（¥49,980→¥59,980）を前に全国の量販店で在庫争奪が起きた。Bic Cameraは「Bic Cameraブランドのクレジットカード保有者限定」という販売制限を導入し、転売目的の大量購入を阻止しようとした。

CONTEXT 背景・要点

価格改定の公式理由はAI半導体需要急増によるメモリチップ高騰と米国関税・円安の三重苦。任天堂は5月8日の発表から17日間の「駆け込み期間」が予期せぬ特需を生み出したと後から評価することになった。

OUTLOOK 影響・展望

Switch 2発売（6月5日）から約1年が経過しようとする中、価格帯が任天堂史上最高値¥59,980となるSwitch 2は来期の出荷目標16.5M台（前期比▲3M台修正）の重石になる可能性がある一方、品薄プレミアム効果で需要の長期持続を示す逆説的な兆候でもある。

→ §07 ゲーム 詳細を読む
