§01 ¥ 為替

FX — 政策、フロー、税務で見る

日銀の正常化論が一段進み、植田体制の利上げペースは27年夏までの物価対応と結びつきました。USDJPY は 162 円台をうかがい、月末・四半期末フロー と米雇用統計が次の揺れを作ります。韓国ウォン の介入観測と外貨差益課税も重なり、為替は水準だけでは読めません。政策、資金、税務の三点で見ると、円相場の見え方が少し変わります。

FACT
【事実・概要】
日銀は政策金利を1.0%へ引き上げ、植田体制の金融正常化が次の判断局面に入った。
CONTEXT
【背景・要点】
争点は物価上振れと円安が続くなかで、27年夏までに利上げペースをどう整えるかへ移っている。
OUTLOOK
【影響・展望】
原油高や供給制約が残ればBOJは追加対応を迫られ、政策姿勢そのものがドル円の方向感を左右しやすい。
→ §01 為替 詳細を読む
§02 ◆ AI

AI — 計算資源と防衛が主戦場

Google は Meta 向け Gemini 利用を絞り、Anthropic の蒸留告発はモデル防衛を前面に押し上げました。Codex の 189 倍利用が示すのは、AI が答える道具から業務を預かる道具へ移ったことです。富士通 の PHOTON や Study Notebooks も、性能と教育接点の両方を広げています。計算資源、守り、定着先が同時に問われる朝でした。

FACT
【事実・概要】
Anthropic の最上位モデル Claude Fable 5 について、トランプ政権が 7月上旬にも制限解除 を認める可能性が出た。6月12日の全面停止後、提供再開の協議が最終承認段階に入った。
CONTEXT
【背景・要点】
前号では Mythos 5 の一部再開を扱ったが、今回は 一般向けFable 5の復帰時期 まで議論が進んだ。輸出管理と脱獄懸念が、モデル公開の条件 を左右している。
OUTLOOK
【影響・展望】
焦点は AI規制 が企業向けモデル供給をどこまで遅らせるかだ。Anthropicの安全対策 が認められれば、OpenAIやGoogleにも 公開前審査の前例 が広がる。
→ §02 AI 詳細を読む
§03 ⌗ IT

IT — 人手不足を切り出して埋める

アストン は障害者雇用をIT運用BPOへつなぎ、法定雇用率の引き上げを商機に変えようとしています。メディアフュージョン は DX 実務向けの情報基盤を公開し、何を読ませ、何を標準化するか を前面に出しました。IT 支援は、機能追加より業務の切り出しと情報整理の設計で差がつきます。現場のしんどさを、運用と導線でほどく発想が見えました。

FACT
【事実・概要】
Snowflakeは好決算を受けて株価が50％急騰し、AIエージェントがSaaSの席巻で既存課金を壊すという悲観論に反証を与えた。
CONTEXT
【背景・要点】
SaaS課金モデルを巡っては2850億ドル規模の論争が続いていたが、記事は利用席数ではなく成果連動の設計へ進化すれば伸び余地があると示した。
OUTLOOK
【影響・展望】
ITコンサルはライセンス再販前提の提案から、AIエージェント時代の価格設計・定着KPI・利益配分をどう再設計するかまで踏み込む必要がある。
→ §03 IT 詳細を読む
§04 ◎ モビリティ

Mobility — 地図と制度を先に整える

交通空白 を 2029 年までに解消する政策が前に出て、newmo の走行データ収集、May Mobility と CaoCao の提携、スズキ のマレーシア EV 初投入が並びました。車両性能より地図・制度・販売網 が先に整うかどうかが焦点で、商用拡張の前提づくり が競争力を決めます。実証の派手さより、地味な準備が効く朝です。

FACT
【事実・概要】
政府は交通空白の解消期限を2029年へ切り、自動運転・ドローン・配車DXを組み合わせる地域交通再編を次の成長戦略に据えた。
CONTEXT
【背景・要点】
これまで『減少』止まりだった政策目標を、地方自治体やNPOへの補助金支援まで含む達成型へ改めた点が大きく、技術実証より実装件数を問う局面に入る。
OUTLOOK
【影響・展望】
読者が次に見るべきは自動運転バスやライドシェア連携が補助制度と一体で事業化されるかで、地方交通政策がモビリティ需要を直接つくる相場になりやすい。
→ §04 モビリティ 詳細を読む
§05 ⬢ 製造

Manufacturing — 部材、施工、人材、安全を積む

京セラ の 6500 億円投資、鹿島 の技能者 7500 人超、日揮HD の材料転換、IBM の 0.7nm 試作、フジキン の安全弁量産が同居しました。AI・半導体需要を支える部品、施工、人材、安全部材 がそろわないと前に進めず、投資額より実行の厚み が重くなっています。表に出る機能より、裏で支える工程の差が出ました。

FACT
【事実・概要】
京セラは2031年3月期までに6500億円を部品事業へ投じ、AI半導体とデータセンター向けを中心に能力増強を進める方針を示した。
CONTEXT
【背景・要点】
投資先は半導体製造装置向けセラミック部品や光通信用セラミックパッケージで、25年3月期までの6年間比で2割増という配分が成長領域への集中を映す。
OUTLOOK
【影響・展望】
製造業目線ではAIインフラ需要の取り込みを前提にした増産で、装置・材料サプライヤーの受注連鎖と国内部品供給網の再編が次の焦点になる。
→ §05 製造 詳細を読む
§06 ■ 経済

Economy — 体感と適応力で読む

高市内閣 の支持率上昇と食品消費税案への賛否、人権デューデリジェンス の遅れ、今週の小売決算、トリドール のインバウンド需要が並びました。家計支援の期待 と 供給網の管理 が同時に進み、景気は指数より実感と適応力で読まれる朝です。小売も外食も、値段だけでなく、どこまで需要を受け止められるかが問われています。

FACT
【事実・概要】
政府の骨太方針原案では、実質1%超・名目3%超の成長定着を掲げ、従来の延長線上ではない経済財政運営への転換を打ち出した。
CONTEXT
【背景・要点】
AI・半導体など17戦略分野を軸に、2040年度まで370兆円超の官民投資を想定し、補正予算依存からの脱却と財政規律の再設計を進める。
OUTLOOK
【影響・展望】
日銀法4条と共同声明を踏まえた金融政策連携が明記され、成長投資と物価安定の同時達成をどう説明するかが27年度予算編成と市場対話の焦点になる。
→ §06 経済 詳細を読む
