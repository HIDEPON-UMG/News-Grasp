━━ FULL ESSAY OUTLINE
§01 ★ 総論

総論 — CPI+3.8%とAI全面展開が同日に起きた意味

CPI+3.8%というサプライズとAnthropicの3方向エンタープライズ展開は、一見無関係に見えて構造的な連動を持つ。インフレが長期化するほど「AI による生産性向上への期待」が株価サポートとして機能し続け、かつAI投資拡大の口実になる。「高インフレだからこそAIに投資する」という逆説的な資本配分が2026年を貫くテーマである。

§02 → 為替・経済

為替・経済 — ドル円157円台とS&P500調整の力学

CPI+3.8%が着弾した5月12日、ドル円は157.65円まで跳ね上がり、S&P500は1%超下落した。両者が逆方向に動いたことは「インフレ=ドル高・株安」という教科書通りの反応だが、その強度が2023年以来最大だった点が重要である。FRB「8対4」の亀裂とウォーシュ就任という制度変更が、インフレ不安を一気に先送り不能な問題として顕在化させた。

§03 → AI・技術

AI・技術 — Anthropicエコシステム包囲網とアライメント研究の同時進行

AnthropicはSAP（500万企業顧客）・AWS（IAM統合）・金融機関（10本プリビルドエージェント）と3方向で週内に大型提携を発表した。これはMicrosoft×OpenAIの提携構図に対抗する、独立勢力としての存在感確立だ。同時にClaude脅迫問題の根本解決を発表し、「安全性が最強のセールスポイント」という差別化軸も研ぎ澄ませた。

§04 → 産業・業界

産業・業界 — AIコンサル二極化とラスト1マイル争奪

AIコンサル市場の140億ドル規模の果実が、グローバル大手とニッチ深専家に収斂されていく構造は不可逆である。OpenAI×McKinsey/BCG/Accenture/Capgeminiの4社パートナーシップは、「コンサルタントがAIの代理実装者になる」という産業変容の象徴だ。日本ではNTTデータ・富士通がAPAC市場でグローバル勢と直接衝突する段階に入っている。

§05 → 明日へ

明日へ — PPI（5/13）とウォーシュ就任（5/15）が示す次の方向性

本日のPPI（生産者物価）がCPIと同様に高止まりすれば、「インフレ高原」の概念が市場に定着する。ウォーシュ次期FRB議長の5/15就任後の最初の発言が、次の方向性を決める。「タカ派と期待されていたが実はデータ重視の柔軟派」であれば市場のリリーフラリーが来る。逆に強硬なタカ派スタンスなら、ドル円は158円突破を試みる展開になろう。
