§01
¥ FOREIGN EXCHANGE / 為替

介入の実弾が相場を試す

FACT 事実・概要

日米両政府が円買い協調介入を確認し、ドル円は一時155円台まで円高に振れた。

CONTEXT 背景・要点

金利差と財政不安が残るため、介入額だけでなく追加対応への警戒と日銀の利上げ観測が相場を左右する。

OUTLOOK 影響・展望

155円台が定着するか、追加介入と日銀の政策運営がどこまで円安の流れを変えるかを確認する。

§02
◆ ARTIFICIAL INTELLIGENCE / AI

実環境接続の被害半径

FACT 事実・概要

Anthropicの評価事故、Astraの機械検証、25ドルでの脆弱性発見、Lloydsと住友化学の大規模導入が確認された。

CONTEXT 背景・要点

AIの性能向上と普及が進むほど、モデルの能力だけでなく外部接続、教育、権限管理の設計が重要になる。

OUTLOOK 影響・展望

評価環境の分離、パッチ適用、AI導入の職種再設計が、利用拡大を安全な成果へ変えられるかを左右する。

→ §02 AI 詳細を読む
§03
⌗ IT & CONSULTING / IT

Consulting — 成長と本人確認の両立

FACT 事実・概要

Amazonの時価総額3兆ドル、クラウド市場の43%成長、Visaの買収、偽装就労への警告、SCSKの拠点拡大が報じられた。

CONTEXT 背景・要点

クラウドとAIの拡大は、投資回収だけでなく外部人材、認証、不正検知の管理範囲も押し広げる。

OUTLOOK 影響・展望

クラウドの成長率とアクセス権限・本人確認の棚卸しを同じ経営課題として追う必要がある。

→ §03 IT 詳細を読む
§04
◎ MOBILITY / モビリティ

走行性能から納車網へ焦点移動

FACT 事実・概要

BYDの軽EV、モメンタのL4試験、スズキの欧州輸出、自動運転トラック実証、三菱自の決算が示された。

CONTEXT 背景・要点

車両性能だけでなく、規制適合、販売・整備網、物流ルートが普及と採算を決める段階に入った。

OUTLOOK 影響・展望

受注の納車転換、欧州での仕様と価格、一般道実証の安全管理を次の観測点とする。

→ §04 モビリティ 詳細を読む
§05
⬢ MANUFACTURING / 製造

AI半導体の熱と供給網を再設計

FACT 事実・概要

AI半導体の高発熱検証、TSMC熊本の復旧、ルネサス高崎工場の閉鎖、大同メタルのメキシコ新工場が報じられた。

CONTEXT 背景・要点

材料・保守・耐震補強・在庫・立地の組み合わせが、製造拠点の継続性と復旧速度を左右する。

OUTLOOK 影響・展望

量産に近い熱検証、部材供給、物流の平常化、海外拠点の投資回収を順に確認する。

→ §05 製造 詳細を読む
§06
■ ECONOMY / 経済

利益と現金のずれ

FACT 事実・概要

5大銀行と三菱商事は増益となった一方、三菱商事株は下落し、金利・災害・中東情勢の影響も決算に表れた。

CONTEXT 背景・要点

利ざや、資源価格、期待先行、家計負担、操業停止が企業ごとの利益の質と分配を分けている。

OUTLOOK 影響・展望

次の決算では利益の大きさだけでなく、営業CF・投資CF・フリーCFと一時要因の持続性を見る。

→ §06 経済 詳細を読む
§07
▶ GAMING / ゲーム

発表を継続利用へ

FACT 事実・概要

任天堂のDirect、KLabの新作開始、Unity CLI、ゲームフリーク新作、Steamフェスが予定・開始された。

CONTEXT 背景・要点

ゲームの価値提供が、作品単体だけでなく公式発表、複数販路、開発自動化、テーマ型販促へ広がっている。

OUTLOOK 影響・展望

発売初日の評価、事前登録からの継続率、CLIの正式化、体験版から購入への転換を追う。

→ §07 ゲーム 詳細を読む
