§01 ★ 総論

総論 — ホルムズ再開期待がポジティブドミノをもたらした

トランプ大統領の「イラン交渉最終段階」宣言は、一見地政学イベントに見えるが、日本市場への波及経路は多層的だ。原油安→輸入コスト低減→企業収益改善、ホルムズ再開→サプライチェーン安定化→輸出安心感、という二本立ての正のフィードバックが日経平均+3.31%を生み出した。

§02 → 為替・経済

為替・経済 — 円高+株高、日本経済の正常化シグナル

通常、円高は輸出企業の株安要因だが、本日はUSD/JPY 157.9円への急落と日経平均急騰が同時に起きた。このパラドックスは「外的リスクの消滅（イラン和平）」と「内的力強さ（輸出+14.8%）」が重なった時にだけ生まれる。日本経済の正常化局面に入ったと読むべきサインだ。Warsh FRBの利下げ拒絶がドル安要因となり、BOJの利上げ加速が円高要因となる構造的な変化が始まっている。

§03 → AI・技術

AI・技術 — Karpathy参加とGemini Omniで「再帰的AI時代」が産業面でも意識され始めた

カルパシーのAnthropicへの移籍は単なる人材移動ではなく、「AIがAIをトレーニングする」再帰的自己改善フェーズへの産業界の覚醒を示す。Google Gemini Omniが「ワールドモデル」として現実世界の物理法則を内包し始めた事実と合わせて、AI業界が基盤モデルの質的転換点に差し掛かっていることが今週のI/O後の報道で確定した。

§04 → 産業・業界

産業・業界 — Google $750Mがコンサル業界にGoogleFirstシフトを強制

Google Cloud $750Mパートナーファンドは数字以上に構造的な変化をもたらす。$7.05のサービス収益倍率という経済的優位により、Accenture・Deloitte・KPMGがAzure/AWSからGoogle Cloudに軸足を移すプレッシャーがかかっている。NTTデータのAIVistaや富士通のTakane戦略が国内市場で独自路線を維持できるかどうか、Google Cloudの「エンタープライズ民主化」に対して日本のSIer大手がどう対抗するかが今後の焦点となる。

§05 → 明日へ

明日へ — 雇用統計とBOJインタビューが来週の方向を決める

本日の米雇用統計次第で、Warsh FRBの利下げ判断と円相場の方向が決まる。同時にBOJインタビューがあればヘッジファンドの円ショートスクイーズが一気に加速するリスクがある。来週は「円高・株高」か「円安・株調整」かの分岐点として、市場参加者全員が固唾を飲んで本日の結果を待っている。
