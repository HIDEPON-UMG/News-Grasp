ゴールドマン、ドル円見通しを上方修正 1年後165円を想定

FACT
【事実・概要】
ゴールドマン・サックスはUSDJPY見通しを引き上げ、3カ月162円・6カ月163円・12カ月165円を新目標に据えた。従来の160円・158円・155円から一段の円安方向へ修正した。
CONTEXT
【背景・要点】
背景には米高金利の長期化、米景気後退リスクの低さ、日銀の緩やかな利上げ、日本の財政懸念がある。介入があっても基調反転までは見込みにくいという見立てだ。
OUTLOOK
【影響・展望】
財務省の円買い介入警戒は強まるが、米成長の失速か日銀の引き締め加速がなければ流れは変わりにくい。ドル円の上値目線が再び市場の中心シナリオになりやすい。
