ウォーシュFRB新議長の初FOMC(6/17)前、タカ派シフト観測高まる CPI3.8%で利上げ圧力

FACT
【事実】
ウォーシュ議長は5/22に正式就任し、6月17日に初回FOMCを主宰する。CPI3.8%（2023年5月来の高水準）を前に、利下げ路線からタカ派への転換を市場は意識し始めた。
CONTEXT
【背景】
CME FedWatchでは6月据え置き確率が99%を維持している一方、年内の利上げ観測が浮上。4月非農業部門雇用者数115,000人増も雇用の底堅さを示した。
OUTLOOK
【展望】
日米金利差（約2.9%ポイント）は円売りを誘引し、ドル円は159〜160円台で推移。FOMCの結果が年後半の為替方向感を決める最大の分岐点となる。

30日の円買い介入、5兆円規模か 市場推計 介入効果の持続性が焦点

FACT
【事実】
4月30日の円買い介入は市場推計で約5兆円規模。ドル円を160円台から155円台に一時押し返したが、その後は再び159円台へと戻る値動きとなった。
CONTEXT
【背景】
財務省・日銀はコメントを避けているが、過去最大規模の単日介入との見方が支配的。介入効果の持続力の短命化が今回も確認された形。
OUTLOOK
【展望】
ヘッジファンドの円売りポジションは介入前水準を超え再拡大。金利差が変わらない限り「介入はガス抜きに過ぎない」との評価が市場では定着しつつある。

ドル円160円台再接近 日銀はいつ再び介入するのか？ キャリートレードの持続性を検証

FACT
【事実】
ドル円は4月介入後も160円台に再接近。日銀政策金利は0.75%、米FRBは3.5〜3.75%で金利差は約2.9ポイント——円売りキャリートレードの恒常的な引力が働く。
CONTEXT
【背景】
日銀は6月利上げの可能性を残しつつも、9名中3名が反対票を投じた4月会合の結果から分裂した政策委員会が浮かぶ。利上げ決断の遅延が次の介入トリガーを早める構図。
OUTLOOK
【展望】
市場推計では160円突破で第2の介入が発動とみる向きが多い。次の注目点は6月17日FOMCと植田総裁の講演で政策ミックスの乖離がさらに広がるか否か。

2026年末ドル円146円予測 MUFG、日米金利差縮小で円高転換シナリオ

FACT
【事実】
MUFGは2026年末のドル円を146円前後に予測。FRBの年2回利下げ（計0.5%）と日銀の追加利上げ1回が金利差縮小の主因として想定されている。
CONTEXT
【背景】
円高転換の鍵は日米の政策乖離の縮小。現在の2.9%ポイントの金利差が2ポイント以下に下がれば、キャリートレード解消の連鎖が起きやすい環境になる。
OUTLOOK
【展望】
ただしFRBのタカ派転換（ウォーシュ体制での利上げ観測）が加われば、予測は大きくずれる。現在は双方向リスクが均衡しており、予測精度は通常より低い。
