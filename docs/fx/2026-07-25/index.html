ドル円、163円台後半で高止まり　来週の日米中銀会合が焦点

FACT
【事実・概要】
ドル円はニューヨーク市場終盤に163.81円で推移した。前日には163.98円まで上昇し、1986年11月以来のドル高・円安水準を更新した。
CONTEXT
【背景・要点】
中東情勢を背景に原油高と米インフレ懸念が再燃し、FRBの利上げ観測が持ち直した。日銀は30〜31日の会合で利上げを見送る可能性が高く、日米金利差が円の重しになっている。
OUTLOOK
【影響・展望】
片山財務相は過度な為替変動に対し断固たる措置を取る姿勢を改めて示した。163円台後半の定着、原油価格、28〜29日のFOMCが次の確認点になる。

日銀、7月会合は1％据え置きへ　円安・原油高の物価リスクを警戒

FACT
【事実・概要】
日銀は30〜31日の金融政策決定会合で、政策金利を1％に据え置く見通しだ。6月に半年ぶりの利上げを決めた後、その影響を見極める。
CONTEXT
【背景・要点】
展望リポートでは経済見通しを小幅に引き上げる一方、円安、原油などの代替調達コスト、AI需要による物価上振れリスクを示すとみられる。
OUTLOOK
【影響・展望】
据え置きは利上げ路線の終了ではなく、基調物価が2％程度で定着するかを見極めるための間合いだ。円安と原油高が次回の利上げ時期をどこまで前倒しするかに注目したい。

ウォーシュFRB議長、7月FOMCで問われる「沈黙」の限界

FACT
【事実・概要】
FRBのウォーシュ議長は金利見通しを明言せず、28〜29日のFOMCでは政策金利を3.50〜3.75％に据え置く見方が優勢だ。
CONTEXT
【背景・要点】
原油価格の再上昇や米関税による物価上昇圧力に加え、FRB内ではインフレ抑制へ踏み込むべきだとの声が強まっている。
OUTLOOK
【影響・展望】
