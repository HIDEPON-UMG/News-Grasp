米国債バイバック拡大、円安予想に介入警戒の冷や水

FACT
【事実・概要】
米財務省が10年以上の米国債買い戻し上限を少なくとも2倍に拡充すると発表。米国債バイバックで米長期金利が急低下し、ドル指数は1%下落した。
CONTEXT
【背景・要点】
債券需給の改善期待が金利を押し下げる一方、円安が続く市場には日本の為替介入への警戒が広がった。金利差だけでは読めない政策要因が加わった形だ。
OUTLOOK
【影響・展望】
円相場は米金利とドル指数の反応に加え、日本当局の発言・行動を見極める展開。158〜160円台での介入警戒と金利の持続性が次の焦点になる。

協調介入後も円安回帰、投機売り減少でも実需の円売り残る

FACT
【事実・概要】
日米協調介入後、ドル円は一時155円台まで下落したものの158〜159円台へ回帰。IMMの円ネットショートは2週間で約125億ドルから33億ドルへ減った。

【影響・展望】
