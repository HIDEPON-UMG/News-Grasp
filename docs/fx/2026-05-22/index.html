USD/JPY 157.9円台へ急落 — イラン和平期待とホルムズ再開でドル安・原油安の連鎖

FACT
【事実・概要】
トランプ大統領が「イランとの核交渉は最終段階にある」と表明。ホルムズ海峡再開期待でドル売り・原油売りが同時進行し、USD/JPYは昨晩の159円台から157.9円台へ急落した。
CONTEXT
【背景・要点】
4月の日本輸出が前年比+14.8%と市場予想を大幅に上回り、中国・米国・ASEAN・EU向けが全方位好調。円の実力回復シナリオに数字面の裏付けが加わった。
OUTLOOK
【影響・展望】
ホルムズ封鎖が続けば原油輸入9割を依存する日本経済への打撃は不可避だったが、和平合意が実現すれば輸入コスト低減→円高支持という三段論法が一気に織り込まれた形。
