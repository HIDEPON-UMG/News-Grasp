日銀、円安と原油高で利上げペースを再検討

FACT
【事実・概要】
日銀は円安と原油の代替調達コスト上昇を受け、物価の上振れリスクを警戒している。6月に政策金利を1％へ引き上げた後も、追加利上げの時期は情勢次第としている。
CONTEXT
【背景・要点】
中東情勢による原油高に加え、AI需要による価格圧力も重なる。為替変動が物価へ波及しやすくなり、基調物価を2％程度で安定させる判断が難しくなっている。
OUTLOOK
【影響・展望】
市場の利上げ想定は半年に1回程度だが、円安が続けば前倒し観測が強まり得る。CPIへの転嫁と次回会合の利上げ判断が焦点になる。

円安防衛より国債利回り抑制へ　政策の優先順位転換に警戒

FACT
