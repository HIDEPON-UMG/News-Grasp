米6月雇用統計、5.7万人増と急減速 FRB年内利上げ観測が後退

FACT
【事実・概要】
米6月雇用統計は5.7万人増と予想11.3万人増を大きく下回った。ドル指数は101割れを試し、利上げの織り込みが後退した。
CONTEXT
【背景・要点】
失業率は4.2%へ低下したが、労働参加率低下が主因で強い雇用とは言いにくい。4・5月分の7.4万人下方修正も、米景気の減速サインを強めた。
OUTLOOK
【影響・展望】
FOMC議事要旨がタカ派でも、年内利上げの再点火には追加の物価上振れ材料が要る。ドル円は米金利の戻りが弱ければ上値追いより押し目探りになりやすい。

FACT
【事実・概要】
日本の長期金利は新発10年債で一時2.810%まで上昇し、USDJPYは162円台後半から161円台へ荒く往復した。
CONTEXT
【背景・要点】

OUTLOOK
【影響・展望】
日銀が動きにくいままなら、円安で食品減税効果が削られる構図が強まりやすい。金利3%接近と介入警戒を両にらみで追う必要がある。
