§01
¥ FOREIGN EXCHANGE / 為替

162円台後半、言葉が相場を動かす

FACT 事実・概要

USDJPYは162円後半へ上昇し、24年7月介入前に似た局面としてロイターが「暗黒月曜」再来リスクを報じた。

CONTEXT 背景・要点

背景には円売りポジションの偏りと政府・日銀の介入警戒があり、CFTC統計でも巻き戻し圧力の蓄積が意識されている。

OUTLOOK 影響・展望

介入が入れば株安を伴う急反転もあり得るため、163円台接近時の当局メッセージと投機筋のショート解消が次の焦点だ。

→ §01 為替 詳細を読む
§02
◆ ARTIFICIAL INTELLIGENCE / AI

資本の厚みが配布条件を変える

FACT 事実・概要

ソフトバンクグループがOpenAIへ100億ドル（1兆6273億円）の追加出資を実行し、300億ドル枠の第2弾を完了した。

CONTEXT 背景・要点

出資は4月の第1弾に続く大型資本投入で、同日にブリッジ融資も実行された。モデル競争の裏側で資金調達力が差を広げている。

OUTLOOK 影響・展望

OpenAIは計算資源と研究投資の余力を確保しやすくなり、AI基盤競争が性能だけでなく資本耐久戦になっていることが鮮明だ。

→ §02 AI 詳細を読む
§03
⌗ IT & CONSULTING / IT

導入前審査が入口になる

FACT 事実・概要

MetaはAI向け計算資源とモデル提供を外販するクラウド事業構想が伝わり、日本時間7月1日夜に株価が6%超上昇した。

CONTEXT 背景・要点

AIインフラ投資で積み上がる自前データセンターを収益化し、AWS・Azure・Google Cloudに対抗する新たな供給者を目指す構図だ。

OUTLOOK 影響・展望

企業ITでは生成AI基盤の調達先が増える可能性があり、価格競争とモデル選択肢の拡大がIT投資判断を左右する。

→ §03 IT 詳細を読む
§04
◎ MOBILITY / モビリティ

売り値より運用標準が前に出る

FACT 事実・概要

テスラコリアは「モデル3 プレミアムロングレンジRWD」を 5299万ウォンから5999万ウォンへ700万ウォン 引き上げ、他モデルも300万〜500万ウォン上げた。

CONTEXT 背景・要点

韓国政府は前日にテスラを含む27社への下半期補助金継続を公表した。会社側は 為替と原材料高 を理由に挙げたが、補助金を織り込んだ値上げではないか との見方が広がった。

OUTLOOK 影響・展望

テスラは1〜5月に 4万5020台 を売って韓国EV市場を先導している。補助金の恩恵が消費者価格に残るのか と、競合各社が追随するかが次の焦点だ。

→ §04 モビリティ 詳細を読む
§05
⬢ MANUFACTURING / 製造

量産の場所を組み替える

FACT 事実・概要

日印協力で2兆円規模の事業創出が見込まれ、120件の協力文書が首脳会談に合わせて交わされる見通しだ。半導体材料工場の設立やAI協業が柱になった。

CONTEXT 背景・要点

富士フイルムの半導体材料工場協力やスズキのバイオガス計画まで含み、単発の輸出ではなく現地生産と技術連携を束ねた。経済安保と供給網分散を同時に進める設計が鮮明だ。

OUTLOOK 影響・展望

10年で10兆円の対印投資目標の実装段階に入るかが次の焦点で、製造業は用地・人材・現地調達の具体化速度を見極めたい。インドを量産拠点として組み込む動きが広がる可能性がある。

→ §05 製造 詳細を読む
§06
■ ECONOMY / 経済

物価と金利の重さをどう吸うか

FACT 事実・概要

7月値上げは2566品目に広がり、円相場は1ドル=162円80銭台まで下落して家計負担が一段と増した。

CONTEXT 背景・要点

政府の利上げけん制と財源不透明な経済対策が円安圧力を強め、輸入肉や包装資材のコスト上昇が値上げ連鎖を押し上げている。

OUTLOOK 影響・展望

次の焦点は日銀の正常化判断と政府の物価対策で、円安の長期化なら秋以降の食品・日用品にも再値上げが波及しやすい。

→ §06 経済 詳細を読む
§07
▶ GAMING / ゲーム

売り方と守り方が収益を決める

FACT 事実・概要

PlayStationは2028年1月以降の新作をダウンロード版のみに切り替えると告知し、ディスク版の新規生産を止める方針を示した。

CONTEXT 背景・要点

物理媒体よりデジタル需要が上回ったと説明しており、PS-Store中心へ販路を寄せる事業再設計の色が濃い。従来の店頭前提モデルを畳む判断でもある。

OUTLOOK 影響・展望

小売や限定版の売り方には見直し圧力がかかる一方、Sonyは購入導線の一元化で収益管理を深める。中古流通や店頭特典の扱いが次の論点だ。

→ §07 ゲーム 詳細を読む
