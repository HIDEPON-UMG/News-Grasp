§01
¥ FOREIGN EXCHANGE / 為替

政策余地と円相場

FACT 事実・概要

政府は食料品の消費税を8%から1%へ下げる方針を決定。為替介入で得た円を5兆円規模の減税財源に回す案が浮上したが、会計上の制約が大きい。

CONTEXT 背景・要点

円買い介入では外貨資産を売って円を得るが、介入資金と国の歳入は別管理になる。為替差益をそのまま恒久財源にするのは難しい。

OUTLOOK 影響・展望

財源論が国債発行や税制の議論へ波及する可能性がある。市場では、財政拡張と円安圧力の組み合わせが次の焦点になる。

§02
◆ ARTIFICIAL INTELLIGENCE / AI

AI半導体の制御

FACT 事実・概要

Anthropicが5日、Claudeに最適化した独自半導体の開発方針を明らかにし、社内の設計チームで技術者の採用を始めた。

CONTEXT 背景・要点

外部半導体への依存を抑え、モデルとハードを共同設計することで、推論の運用コストと応答速度を改善する狙いがある。

OUTLOOK 影響・展望

AIモデル企業がチップ設計まで踏み込む流れが強まる。今後は性能だけでなく、調達・電力・推論単価を含む競争になる。

→ §02 AI 詳細を読む
§03
⌗ IT & CONSULTING / IT

Consulting — 認証漏えいの防衛

FACT 事実・概要

GitHubの認証情報が漏えいし、イノベーションに不正アクセス。最大約6万件の氏名・メールアドレスが流出した可能性があり、電話番号を含む対象もある。

CONTEXT 背景・要点

ソースコードやリポジトリ内ファイルに個人情報が記載されていた。認証キーとパスワードは無効化・再発行済みだが、影響範囲は精査中。

OUTLOOK 影響・展望

対象顧客への個別連絡と続報が焦点になる。企業は秘密情報をコードに残さず、認証情報の無効化と保管経路の点検を急ぐ必要がある。

→ §03 IT 詳細を読む
§04
◎ MOBILITY / モビリティ

自動運転の量産基盤

FACT 事実・概要

ティアフォーとAstemoが、Co-MLOpsを活用したE2E型自動運転AIの次世代開発プラットフォームで合意した。2030年頃の実用化を目指す。

CONTEXT 背景・要点

認知・判断・制御を一体化するAIを、量産品質へ継続改善できる基盤にする狙いだ。自動車部品大手とソフト企業の役割分担が焦点になる。

OUTLOOK 影響・展望

Astemoは2030年代前半の自家用車搭載を目標に掲げる。量産車で安全評価と更新サイクルをどう成立させるかを追いたい。

→ §04 モビリティ 詳細を読む
§05
⬢ MANUFACTURING / 製造

半導体部材の強化

FACT 事実・概要

TOTOが茅ケ崎工場に研究棟を計画し、半導体製造装置向けの静電チャックやAD部材を開発する。設備の内製知見を研究開発へつなぐ動きだ。

CONTEXT 背景・要点

半導体の設備投資が続くなか、装置部品は歩留まりや稼働率を左右する。研究拠点の整備は、衛生陶器から高機能セラミックへ広げた技術蓄積を成長分野へ移す布石になる。

OUTLOOK 影響・展望

研究棟の稼働時期や投資額、顧客装置への採用が次の確認点だ。半導体部品の開発から量産・品質保証までを茅ヶ崎でどこまで一貫化できるかが、事業化の焦点になる。

→ §05 製造 詳細を読む
§06
■ ECONOMY / 経済

AI投資と利益循環

FACT 事実・概要

S&P500構成企業の2026年4〜6月期決算は、1株利益が前年同期比5割増となる見通しで、5年ぶりの好決算となる。AI関連テックに加え、エネルギー企業が寄与した。

CONTEXT 背景・要点

利益のけん引役がテックだけに偏らず、原油高の恩恵を受けたエネルギーにも広がった。業種別の利益構成をみることで、相場の強さがAI期待だけかを判断できる。

OUTLOOK 影響・展望

企業業績は堅調でも、エネルギー価格や地政学の変動に左右される面がある。次の焦点は、AI投資と原油高の寄与が一時的か、利益成長として定着するかだ。

→ §06 経済 詳細を読む
§07
▶ GAMING / ゲーム

ゲーム企業のAI転換

FACT 事実・概要

DeNAは4〜6月期に営業利益が前年同期比46%減の74億円。ゲーム事業の不振を受け、南場智子社長は生成AIなど新規事業投資へ軸足を移す方針を示した。

CONTEXT 背景・要点

前年にヒットしたポケポケの反動でゲーム事業の売上収益は33%減。新規事業の収益化には時間がかかるため、既存ゲームの立て直しとの両立が判断材料になる。

OUTLOOK 影響・展望

DeNAは自社開発に加えスタートアップ投資も成長策に掲げる。生成AIを使うBtoBサービスが、ゲーム依存を薄める次の収益柱になれるかが焦点だ。

→ §07 ゲーム 詳細を読む
