§ 00 EDITORIAL SYNTHESIS / 総論

今日の総論

§01
¥ FOREIGN EXCHANGE / 為替

東京CPI・介入実績・イラン合意の三重奏

FACT 事実・概要

米・イラン両国が60日間停戦延長と核開発交渉開始で合意との報道を受け、ドル安が優勢となりドル円は159.21円台前半まで下落した。

CONTEXT 背景・要点

ホルムズ海峡リスク後退で原油先物も急落しインフレ懸念が和らぎ、ドル売り・円買いに拍車をかけた。

OUTLOOK 影響・展望

中東情勢の変化が為替の新たな変数として浮上し、断続的な報道が相場を揺さぶる構図が続く。

§02
◆ ARTIFICIAL INTELLIGENCE / AI

Anthropic1兆ドル、OpenAI上場申請、NVIDIA 816億ドル

FACT 事実・概要

AnthropicがシリーズHで650億ドルを調達し評価額9,650億ドル（1兆ドル目前）に到達。OpenAIを抜き世界最高値のプライベートAI企業となった。

CONTEXT 背景・要点

売上年換算470億ドルでAltimeter Capital・Sequoiaが主導。Claude Codeの企業向け展開がNetflix・Spotify・KPMGに広がりQ2で130%増を記録。

OUTLOOK 影響・展望

IPO前最終資金調達とみられ、1兆ドルバリュエーションへの歴史的な一里塚として市場に衝撃が走った。

→ §02 AI 詳細を読む
§03
⌗ IT & CONSULTING / IT

日本IT大手3社がそろい踏み、中東AI覇権戦争が開幕

FACT 事実・概要

AccentureとHUMAIN（サウジアラビアPIF傘下）が戦略的パートナーシップを締結。官民のAI実装を実験段階から本番運用に移行させる5分野で協業開始。

CONTEXT 背景・要点

Vision 2030加速とGCC地域全域への波及を視野に入れた大規模コンサル案件で、中東市場の主導権を巡るMBBとの競争が激化する。

OUTLOOK 影響・展望

新興AI経済圏でのコンサル覇権争いという新局面を開く案件で、中東発のAI投資規模がシリコンバレーに匹敵しはじめている。

→ §03 IT 詳細を読む
§04
◎ MOBILITY / モビリティ

Ojai・テキサス合法化・IEA 2300万台の三連打

FACT 事実・概要

Waymoが新型ロボタクシー「Ojai」をSF・LA・フェニックスの一部ユーザーに無料開放。Zeekr製ワゴン型車体に第6世代Driverを搭載しコスト削減を実現。

CONTEXT 背景・要点

現行Jaguar I-PACEより製造コストが大幅低減。週50万件の有償ライドを既達成しており、今夏サンディエゴ・ラスベガス・デンバーにも展開予定。

OUTLOOK 影響・展望

ロボタクシー商業化の正念場を迎えるWaymoが、スケーラブルな次世代車両で勝負に出た。国際展開（ロンドン・東京）も視野に入れている。

→ §04 モビリティ 詳細を読む
§06
■ ECONOMY / 経済

S&P最高値・Goldman 8000・日経5月売りの三叉路

FACT 事実・概要

5月28日のS&P500は0.58%高の7,563ptと最高値を更新。SnowflakeがQ2ガイダンス好調で36.5%急騰し、Microsoft・Palantirも3〜4%上昇。

CONTEXT 背景・要点

NVIDIA Vera Rubin発表後もAIデータセンター関連株が強含み継続し、NASDAQ 26,000台超えを定着させる相場環境が維持された。

OUTLOOK 影響・展望

AIマネーフローが一点集中から幅広いエコシステム株に拡散し始めた初期兆候として、市場関係者がターニングポイントと注目。

→ §06 経済 詳細を読む
§07
▶ GAMING / ゲーム

Forza 30万人・スクエニ10億円・SIE攻勢の夏商戦号砲

FACT 事実・概要

日本を舞台にしたForza Horizon 6が正式リリース。Steam最高同接302,645人を記録し前作比約3倍のユーザーを集め、シリーズ史上最大のローンチを達成。

CONTEXT 背景・要点

メタスコアも今年暫定トップを獲得。東京・大阪・京都の実写スキャンデータと日本固有の車文化が海外プレイヤーに高く評価された。

OUTLOOK 影響・展望

「日本が主役の欧米AAA作品」という稀有なポジションが全世界のゲーマーを引きつけ、ゲームツーリズム的な経済効果も生まれつつある。
