§01 総論

総論 — 同時多発のリセットが示す「転換の週」

Google I/O 前夜のこの日曜日、OpenAIの組織再編・Deloitteの職名廃止・BOJの利上げ先読みが同時に動いた。いずれも「昨日までの構造が今日終わる」という性格のニュースであり、週明けは前週と異なる地図で市場と産業が動き始める 可能性が高い。

§02 為替・経済

為替・経済 — 158円という「再警戒ライン」

USD/JPYが 158円台 で週を終え、BOJ利上げ確率は 77% に急騰した。介入効果の半減とドル高の持続が交錯するなか、160円超えが再現するか否かで財務省の再出動が問われる。ECBの6月利上げ不確実性も絡み、円・ユーロ・ポンドが同時に試される週が来る。

§03 AI・技術

AI・技術 — AnthropicとOpenAIで分岐する「AIの使い途」

Anthropicは 2億ドル のゲイツ財団提携でAIを「医療・農業・教育の公共財」として位置付け、一方OpenAIはIPO前夜に「スーパーアプリ」という商業モデルを選んだ。どちらが「AI民主化」の正解かは、2026年末には数字で答えが出る。Z.aiのGLM-4.7登場は、中国発OSS勢力が議論に加わることを示す。

§04 産業・業界

産業・業界 — コンサルと「知識労働のリセット」

Deloitteの 181,500人 職名廃止とBCGのAI収益 25% 開示は、コンサル業の「知識産業」定義が書き換わることを端的に示す。「アナリストがAIにできる仕事をするなら、そのタイトルを名乗る意味がない」 という問いは、コンサル以外の産業でも2026年内に突きつけられる。

§05 明日へ

明日へ — 週明けに見るべき3つのシグナル

①Google I/O キーノートでGemini Sparkが正式発表されるか（AIエージェント競争の天井が見える）、②USD/JPYが 160円 に接近した時点で財務省が動くか（円安の政策上限が明示される）、③Switch2の 5月累計販売台数 が700万台を超えるかどうか（ゲームハード普及の新基準が定まる）。いずれも来週号で答え合わせをしたい。
