公開 web 配信と OGP 対応

News-Grasp の各カテゴリ digest を独立した公開 HTML として発行し、Slack / Discord / X / Gmail / iOS Messages で OGP プレビューが安定して出る状態を作る。

implemented HIDEPON-UMG GitHub Pages Jinja2 2026-05-22 公開
FX AI IT-Consulting Economy Game Summary

概要

News-Grasp は毎朝 06:00 にカテゴリ別 (FX / AI / IT-Consulting / Economy / Game) ニュースダイジェストをメール配信しているが、公開 web ページが存在しないため、記事 URL を SNS / Slack に貼っても OGP プレビューが出ない。親アイデア News-Grasp-thumbnail-fix-2026-05-04.md でメール側の og:image は data URI inline 化で解決済みだが、web 経由の OGP プレビューには公開ページが要る。

前提

News-Grasp 本体リポを private → public に切り替える（mirror なし）。実行前に gitleaks で履歴の機密スキャンを行い、検出ゼロでなければ plan を中断して別アイデアに切り出す。

完了条件 (DoD)

  • 任意の記事 URL を Slack / Discord / X / Gmail / iOS Messages に貼ったとき、意図したサムネ + タイトル + 説明が表示される
  • 全記事ページの og:image / og:url / og:title / og:description が https:// 始まりの絶対 URL で出力される
  • Facebook / X / LinkedIn の OGP デバッガーでキャッシュをパージしても次回取得で画像が読まれる
  • メール本文の "VIEW IN BROWSER" リンクが自前 URL を指している

不可逆操作の注意

private → public 切替は GitHub UI 上は元に戻せるが、SNS インデックス・検索クローラのキャッシュは即時撤回できない。public 化前に safe-commit ゲートを通し、watchlist.md と .env が cached 対象から外れていることを必ず目視確認すること。

ホスティング

GitHub Pages

採用
  • web UI のみで設定完了、Actions 不要
  • push = 即配信（既存 Windows タスクスケジューラ運用と完全整合）
  • CNAME 1 行で独自ドメイン対応、Let's Encrypt 自動
  • soft limit 100GB/月（News-Grasp 規模なら余裕）
  • SNS クローラ実績豊富

Cloudflare Pages

将来選択肢
  • 無制限帯域 / リクエスト数
  • edge function / preview deploy が強力
  • dashboard で repo 連携・追加サービスアカウントの管理対象が増える
  • build 済 commit 運用なら差別化要素を活かしきれない
  • 本タスクでは GitHub Pages で十分という判断

def test_og_image_is_absolute_https(sample_digest):
    ctx = build_context(sample_digest)

def test_og_url_matches_canonical(sample_digest):
    ctx = build_context(sample_digest)
    assert ctx["og_url"] == ctx["canonical"]

def test_og_description_within_160_chars(sample_digest):
    ctx = build_context(sample_digest)
    assert len(ctx["og_description"]) <= 160
