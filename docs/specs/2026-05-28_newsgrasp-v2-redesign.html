Context

News-Grasp は A 群 (Mobility カテゴリ追加 / 未 commit) 完了後、Claude Design 納品物 (variant-b.jsx / category-b.jsx / category-mobile.jsx / desktop-extra.jsx / mobile-extra.jsx) を一次ソースに v2 編集者トーン強化 へ進む。prompts/index-template.html (Home) を 6 LENSES 化、prompts/category-template.html (現状 71 行のシンプルリスト型) を Magazine Spread にフル置換、Daily Overview (docs/{YYYY-MM-DD}/index.html) を Pattern C/D 化、メール縦尺を圧縮する。

DONE 定義

  1. Home に 6 LENSES grid が表示される (タグライン SIX LENSES ON TODAY)
  2. /{cat}/ 詳細が hero + 9 grid + past 1 週間で render される (Magazine Spread)
  3. Daily Overview が 6 カテゴリ俯瞰 (KV + TOP3 + Score histogram) で出る
  4. SITE_TAGLINE_EN = "SIX LENSES ON TODAY" が全箇所に反映
  5. Past カードが /News-Grasp/{cat}/{YYYY-MM-DD}/ リンクでラップ
  6. メール本文の全高が現状比 10-15% 短縮
  7. 本 HTML 仕様書が safe-commit gate 4' を pass
  8. A 群 + v2 を一括した単一 commit が作成される

Data Flow — digest から render まで

digest/{Cat}/YYYY-MM-DD-*.md から SSG (tools/generate_pages.py) を経由して、Home / Category / Detail / Overview / Email の 5 出力に分岐する。Past 1 週間セクションは build_category 内で同カテゴリの直近 7 日分を抽出。

Past 1 週間セクションの抽出ロジック

build_category 関数で同カテゴリの過去 7 日分を entries[:7] で抽出。テンプレ側で <a href="{{ base_url }}/{{ category_id }}/{{ p.date }}/" class="cat-past__card">...</a> でラップ。既存生成済の docs/{cat}/{YYYY-MM-DD}/index.html と URL 整合する (= リンク先 200 OK 前提)。

def build_category_pages(entries, docs_root):
    for cat_id, cat in CATEGORIES.items():
        if cat_id == "summary": continue
        cat_entries = [e for e in entries if e["category_id"] == cat_id]
        if not cat_entries: continue

        # v2 追加 ↓ Magazine Spread 用 context
        cat_entries.sort(key=lambda e: e["date"], reverse=True)
        hero_entry = cat_entries[0]                  # 最新 1 件 = Hero KV
        featured   = cat_entries[0]                  # TOP feature (同じか別判定可)
        grid_9     = cat_entries[:9]                 # 2 列 9 grid
        past_7     = cat_entries[1:8]                # Past 1 週間 (Hero を除く)

        ctx = {
            "site_title": SITE_TITLE, "base_url": BASE_URL,
            "category_id": cat_id, "category_label": cat["label"],
            "category_jp": cat["jp"], "accent": cat["accent"],
            "glyph": cat["glyph"], "canonical": f"{BASE_URL}/{cat_id}/",
            "entries": cat_entries,
            "hero_entry": hero_entry, "featured": featured,
            "grid_9": grid_9, "past_7": past_7,
        }
        out = Path(docs_root) / cat_id / "index.html"
        render_page(ctx, out, template_name="category-template.html")
