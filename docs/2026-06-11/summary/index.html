§01 総論

総論 — 引き締めとリニューアルが同時に動いた日

ECBの利上げ再開と任天堂のSwitch 2大型発表が同じ週に並んだ今日は、「金融環境の変化」と「消費・エンタメ需要の更新」が同時に起きた日として記録される。ECB・BOJ・Fedという3つの中央銀行が引き締め・据え置き・様子見の各フェーズにありながら、いずれも「2026年後半の分岐点」に立っている。ゲーム産業では28年ぶりのゼルダリメイクが世代を跨いだ消費の復活を示唆している。引き締めとリニューアルは相反しているようで、両者が重なる局面こそ新しい市場構造が生まれる。

§02 為替

為替 — ECB利上げは「終わりの始まり」か「材料出尽くし」か

ECBが25bp利上げで3.75%に到達した今日、EUR/USDは1.1540付近で「織り込み済み」の利食いリスクに直面している。USD/JPYは160円台を維持しBOJ 6月16日利上げ（0.75%→1.0%）前の攻防が続く。ラガルド総裁の記者会見で7月追加利上げへの言質があればユーロは1.16試しに、なければ1.14台への急落が警戒される。EUR/JPY 185円台を試す場面も視野に入り、週内に3つの中央銀行イベントが集中する稀な局面が続く。為替の真の方向は、ラガルドとBOJ植田が「どう終わるか」を示した後に初めて決まる。

FACT
【事実】
ECBは6月11日の理事会で25bp利上げ（3.50%→3.75%）を決定する見通し。ユーロ圏インフレが3.2%と目標2%を大幅に超過しており、3年ぶりの引き締め再開が確実視されている。
CONTEXT
【背景】
ラガルド総裁の記者会見では「データ依存」を強調しつつ7月追加利上げへの言質は避けると予測。EUR/USD の反応は「利上げ確定後の利食い売り」シナリオが警戒される。
OUTLOOK
【展望】
USD/JPY は160.33付近で推移。ECB利上げ後にユーロ高・ドル安の流れが生じれば一時的に円高方向の波及も起こりえる。

§04 IT

§07 経済

経済 — CPI4.2%とFedの沈黙が7月以降の焦点を決める

米5月CPI前年比+4.2%は3年ぶりの高水準で、市場が織り込んでいた「インフレ鈍化シナリオ」を修正させた。コアCPIは+3.4%で落ち着いているが、ガソリン急騰（中東情勢起因）が全体を押し上げており、エネルギー価格の動向が今後の方向を左右する。Fed 6月据え置きは確定済みで、次の焦点は7月・9月FOMC。ウォーシュ議長のタカ派発言と市場の利下げ期待剥落が続くなか、米国経済の「ソフトランディング」シナリオは静かに書き直されている。

FACT
【事実】
米BLS発表の5月CPI（消費者物価指数）は前年比+4.2%（4月+4.3%から小幅鈍化）。3年ぶりの高水準で、中東紛争に伴うガソリン価格急騰が主因。
CONTEXT
【背景】
コアCPI（食品・エネルギー除く）は+3.4%と落ち着いており、エネルギー価格が一時的に剥落すればインフレ鈍化トレンドは維持との見方が優勢。
OUTLOOK
【展望】
Fed は6月FOMCで据え置き確定済み。7月以降の利上げ再開シナリオは後退したが、高金利長期化シナリオは維持される。
