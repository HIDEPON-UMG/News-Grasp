§01
¥ FOREIGN EXCHANGE / 為替

ECB利上げは「終わりの始まり」か「材料出尽くし」か

FACT 事実・概要

ECBが25bp利上げで3.75%に到達した今日、EUR/USDは1.1540付近で「織り込み済み」の利食いリスクに直面している。

CONTEXT 背景・要点

【事実】：ECBは6月11日の理事会で25bp利上げ（3.50%→3.75%）を決定する見通し。ユーロ圏インフレが3.2%と目標2%を大幅に超過しており、3年ぶりの引き締め再開が確実視されている。

OUTLOOK 影響・展望

【背景】：ラガルド総裁の記者会見では「データ依存」を強調しつつ7月追加利上げへの言質は避けると予測。EUR/USD の反応は「利上げ確定後の利食い売り」シナリオが警戒される。

⌗ IT & CONSULTING / IT

エンタープライズAI支出$7,500の衝撃と欧州実装加速

FACT 事実・概要

「AI化企業」が従業員一人当たり月$7,500のAIサービスに支出しているというデータは、AI投資の規模感を可視化した。

CONTEXT 背景・要点

【事実】：調査によると「AI化が進んだ企業」は従業員一人あたり月平均$7,500をAIサービスに支出。これはソフトウェア全体への支出の2倍以上に相当する。

OUTLOOK 影響・展望

【背景】：支出の中心は LLM API（OpenAI/Anthropic/Google）、AIコーディングアシスタント（Claude Code/GitHub Copilot）、エージェント管理基盤の三つ。

BYDがFordを超え、Waymoがベンチマークを再定義

FACT 事実・概要

BYDのQ1世界販売でFordを上回ったことは、EV時代の市場序列の変化を象徴する。

CONTEXT 背景・要点

§06
■ ECONOMY / 経済

CPI4.2%とFedの沈黙が7月以降の焦点を決める

FACT 事実・概要

米5月CPI前年比+4.2%は3年ぶりの高水準で、市場が織り込んでいた「インフレ鈍化シナリオ」を修正させた。

CONTEXT 背景・要点

【事実】：米BLS発表の5月CPI（消費者物価指数）は前年比+4.2%（4月+4.3%から小幅鈍化）。3年ぶりの高水準で、中東紛争に伴うガソリン価格急騰が主因。

OUTLOOK 影響・展望

【背景】：コアCPI（食品・エネルギー除く）は+3.4%と落ち着いており、エネルギー価格が一時的に剥落すればインフレ鈍化トレンドは維持との見方が優勢。

→ §06 経済 詳細を読む
