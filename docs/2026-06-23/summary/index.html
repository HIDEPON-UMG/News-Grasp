§01 ★ 総論

総論 — 伸び方より支え方が先に見えた

円安、国産LLM、電池交換網、工場新設が一列に並ぶと、今日は成長率の話より、どの条件を先に固めたかが主役だと分かります。資本も制度も供給も、入口を広げる前に出口を作る流れがはっきりしました。速く広げる話と支える設計の差が、全カテゴリに出ています。

§02 ¥ 為替

為替 — 介入カードと利上げ観測が交錯

USD/JPYは161円90銭台で、片山財務相とベッセント財務長官の協議が市場の目線を集めました。介入の持久戦と米金利の再評価が同時進行し、BofAやドイツ銀の年内利上げ観測修正、ウォーシュFRBのタカ派観測がドル高を支えています。水準より材料の順番が効く朝です。

FACT
【事実・概要】
ドル円は一時161円90銭台まで円安が進行し、1986年以来の安値圏が日付をまたいで政策当局を追い込んだ。
CONTEXT
【背景・要点】
片山財務相とベッセント米財務長官のオンライン会談が入り、為替介入を含む対応の選択肢が市場の中心シナリオへ戻った。
OUTLOOK
【影響・展望】
4月末から5月にかけての介入総額は約11兆7000億円に達しており、FRBの利上げ観測が続く限り、次の一手は規模よりタイミングが問われる。
→ §02 為替 詳細を読む
§03 ◆ AI

AI — 作る人と支える部材と止めるルール

PFNのPLaMo 3.0 Primeは、日本語と256k文脈を武器に企業導入の入口へ進みました。対照的にAlphabetは人材流出で時価総額を落とし、MicronはAIメモリー供給で勝負。モデル性能より誰が作り、誰が支え、どこで止めるかが前に出て、ノルウェーの利用禁止も同じ線上にあります。

FACT
【事実・概要】
PLaMo 3.0 PrimeはReasoningとNon-reasoningを分けて提供し、APIとオンプレミスの両方で企業利用を取りにいく構えを鮮明にした。
CONTEXT
【背景・要点】
対応コンテキスト長は64kから256kへ拡張され、長文の業務文書処理やエージェント運用を前提にした実務投入がしやすくなった。
OUTLOOK
【影響・展望】
PFNは日本語ベンチマークとコスト効率を前面に出しており、OpenAIやAnthropicへの依存を減らしたい国内企業の比較軸を作りに来た。
→ §03 AI 詳細を読む
§04 ⌗ IT

IT — 国内化とMCPで摩擦を減らす

Alibaba Cloudの日本5拠点体制とウイングアーク1stのMCP連携が、AI接続と国内完結を進めました。メモリ逼迫でコストが上がる一方、ネットワンとシスコの認証基盤クラウド完結、ゴディバのシフト集約は、ITを便利さではなく運用負荷の平準化で評価する流れを強めています。

FACT
【事実・概要】
アリババクラウドは東京で国内5拠点目のデータセンターを開設し、数カ月で4拠点から5拠点へ増強する異例の速さを見せた。
CONTEXT
【背景・要点】
新拠点は計算・ストレージ・ネットワークを国内冗長化し、高可用性とBCPを前面に出して、日本企業の基幹系クラウド需要を取り込みにいく。
OUTLOOK
【影響・展望】
同時にModel StudioとQwen3_7-Plusを日本リージョンで提供し、インフラ確保とAI実装支援を同じ契約面で束ねる戦い方へ踏み込んだ。
→ §04 IT 詳細を読む
§05 ◎ モビリティ

モビリティ — 網を張る力と止まる条件

CATLの欧州電池交換網、T2の自動運転トラック商用化、Lean3の資金調達が並び、Mobilityは車両性能より運用網で語る段階に入りました。いっぽう岐阜の実証は補助要件見直しで見送り。大分の空飛ぶクルマ向け調査補助も含め、拡大の条件と停止の条件がはっきり分かれています。

FACT
【事実・概要】
CATLは英Octopus Energyと組み、2035年までに欧州で30超の交換拠点を敷く構想を打ち出した。
CONTEXT
【背景・要点】
狙いは車両本体と電池を切り離し、導入コストと充電停止時間を同時に下げて大型EV普及の壁を崩すことだ。
OUTLOOK
【影響・展望】
読者視点では電池交換が、乗用車の実験論ではなく物流幹線の採算を左右するインフラ投資テーマへ進んだ意味が大きい。
→ §05 モビリティ 詳細を読む
§06 ⬢ 製造

製造 — 立地と供給力の置き方が競争力

イグスの栃木さくら工場、JBICのサムテック増設融資、東邦アセチレンの中計、中国サプライチェーン博、茂原市の産業用地公募が同時に出ると、製造の論点は何を作るかからどこに置くかへ移ります。供給力は設備の場所で決まる、という朝でした。物流や電力の手当てまで含めて、配置の巧さがそのまま競争力になります。

FACT
【事実・概要】
イグスは栃木さくら工場を6月22日に稼働させ、分散していた4拠点を一本化して国内供給網を組み直す段階に入った。
CONTEXT
【背景・要点】
新工場では高層ラックと組み立てライン効率化を入れ、在庫保管能力を旧4拠点比で約70%増とすることで欠品リスクと拠点間輸送を同時に縮める。
OUTLOOK
【影響・展望】
約4.2万平方メートルの敷地に追加拡張余地も残しており、需要増を前提にした先回り投資として日本市場向けの供給弾力性を高める。
→ §06 製造 詳細を読む
§07 ■ 経済

経済 — 中央銀行と供給網地政学

グリーンスパン氏の死去は金融政策の功罪を振り返らせ、ECBは追加引き締めの過熱を抑える姿勢を示しました。中国の供給網博と日銀長崎支店の景気判断を並べると、金利と供給網が別々に効く局面だと分かります。ひとつの指標ではなく、複数の回路で読む日です。足元の温度は、政策コメントと現場感覚のズレに出ます。

FACT
【事実・概要】
グリーンスパン氏は18年半にわたりFRBを率い、低インフレ下で10年に及ぶ景気拡大を実現して「マエストロ」と呼ばれた。
CONTEXT
【背景・要点】
1987年のブラックマンデーや01年同時テロ後の利下げで市場を支え、米金融政策が危機時にどこまで踏み込むかの原型を作った。
OUTLOOK
【影響・展望】
一方で、長期の低金利と規制緩和が08年金融危機の土壌になったとの批判も根強く、市場安定と過剰リスク抑制の境界を改めて問い直す材料になる。
→ §07 経済 詳細を読む
§08 ▶ ゲーム

ゲーム — 流通とIP運用が主題

Valveの新型Steam Machine、開発者への権利買い取りメール、miHoYoの新作、NINTENDO 64の30周年、個人制作の復帰作が並び、今日は何を出すかよりどう長く回すかが中心でした。ハード、配信、IP再利用が一つの線でつながり、ゲーム面も運用設計のニュースになっています。

FACT
【事実・概要】
Steam Machineは512GBで1049ドル、2TBで1349ドルから販売が始まり、Steam Deckの次に据え置きPCをどう広げるかというValveの次の一手が見えた。
CONTEXT
【背景・要点】
AMD製セミカスタムCPU/GPUや16GB DDR5、8GB GDDR6 VRAMを備え、SteamOS前提でSteam Deckの6倍超性能を訴求する構成は、リビング向けPC市場の再挑戦として重い。
OUTLOOK
【影響・展望】
日本ではKOMODO経由の販売見込みにとどまり時期は未公表で、価格帯と供給量がどこまで日本市場に合うか、Steam Deck後の販路設計が次の焦点になる。
→ §08 ゲーム 詳細を読む
