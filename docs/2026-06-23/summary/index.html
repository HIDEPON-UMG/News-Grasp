§01
¥ FOREIGN EXCHANGE / 為替

介入カードと利上げ観測が交錯

FACT 事実・概要

ドル円は一時161円90銭台まで円安が進行し、1986年以来の安値圏が日付をまたいで政策当局を追い込んだ。

CONTEXT 背景・要点

片山財務相とベッセント米財務長官のオンライン会談が入り、為替介入を含む対応の選択肢が市場の中心シナリオへ戻った。

OUTLOOK 影響・展望

4月末から5月にかけての介入総額は約11兆7000億円に達しており、FRBの利上げ観測が続く限り、次の一手は規模よりタイミングが問われる。

→ §01 為替 詳細を読む
§02
◆ ARTIFICIAL INTELLIGENCE / AI

作る人と支える部材と止めるルール

FACT 事実・概要

PLaMo 3.0 PrimeはReasoningとNon-reasoningを分けて提供し、APIとオンプレミスの両方で企業利用を取りにいく構えを鮮明にした。

CONTEXT 背景・要点

対応コンテキスト長は64kから256kへ拡張され、長文の業務文書処理やエージェント運用を前提にした実務投入がしやすくなった。

OUTLOOK 影響・展望

PFNは日本語ベンチマークとコスト効率を前面に出しており、OpenAIやAnthropicへの依存を減らしたい国内企業の比較軸を作りに来た。

→ §02 AI 詳細を読む
§03
⌗ IT & CONSULTING / IT

国内化とMCPで摩擦を減らす

FACT 事実・概要

アリババクラウドは東京で国内5拠点目のデータセンターを開設し、数カ月で4拠点から5拠点へ増強する異例の速さを見せた。

CONTEXT 背景・要点

新拠点は計算・ストレージ・ネットワークを国内冗長化し、高可用性とBCPを前面に出して、日本企業の基幹系クラウド需要を取り込みにいく。

OUTLOOK 影響・展望

同時にModel StudioとQwen3_7-Plusを日本リージョンで提供し、インフラ確保とAI実装支援を同じ契約面で束ねる戦い方へ踏み込んだ。

→ §03 IT 詳細を読む
§04
◎ MOBILITY / モビリティ

網を張る力と止まる条件

FACT 事実・概要

CATLは英Octopus Energyと組み、2035年までに欧州で30超の交換拠点を敷く構想を打ち出した。

CONTEXT 背景・要点

狙いは車両本体と電池を切り離し、導入コストと充電停止時間を同時に下げて大型EV普及の壁を崩すことだ。

OUTLOOK 影響・展望

読者視点では電池交換が、乗用車の実験論ではなく物流幹線の採算を左右するインフラ投資テーマへ進んだ意味が大きい。

→ §04 モビリティ 詳細を読む
§05
⬢ MANUFACTURING / 製造

立地と供給力の置き方が競争力

FACT 事実・概要

イグスは栃木さくら工場を6月22日に稼働させ、分散していた4拠点を一本化して国内供給網を組み直す段階に入った。

CONTEXT 背景・要点

新工場では高層ラックと組み立てライン効率化を入れ、在庫保管能力を旧4拠点比で約70%増とすることで欠品リスクと拠点間輸送を同時に縮める。

OUTLOOK 影響・展望

約4.2万平方メートルの敷地に追加拡張余地も残しており、需要増を前提にした先回り投資として日本市場向けの供給弾力性を高める。

→ §05 製造 詳細を読む
§06
■ ECONOMY / 経済

中央銀行と供給網地政学

FACT 事実・概要

グリーンスパン氏は18年半にわたりFRBを率い、低インフレ下で10年に及ぶ景気拡大を実現して「マエストロ」と呼ばれた。

CONTEXT 背景・要点

1987年のブラックマンデーや01年同時テロ後の利下げで市場を支え、米金融政策が危機時にどこまで踏み込むかの原型を作った。

OUTLOOK 影響・展望

一方で、長期の低金利と規制緩和が08年金融危機の土壌になったとの批判も根強く、市場安定と過剰リスク抑制の境界を改めて問い直す材料になる。

→ §06 経済 詳細を読む
§07
▶ GAMING / ゲーム

流通とIP運用が主題

FACT 事実・概要

Steam Machineは512GBで1049ドル、2TBで1349ドルから販売が始まり、Steam Deckの次に据え置きPCをどう広げるかというValveの次の一手が見えた。

CONTEXT 背景・要点

AMD製セミカスタムCPU/GPUや16GB DDR5、8GB GDDR6 VRAMを備え、SteamOS前提でSteam Deckの6倍超性能を訴求する構成は、リビング向けPC市場の再挑戦として重い。

OUTLOOK 影響・展望

日本ではKOMODO経由の販売見込みにとどまり時期は未公表で、価格帯と供給量がどこまで日本市場に合うか、Steam Deck後の販路設計が次の焦点になる。

→ §07 ゲーム 詳細を読む
