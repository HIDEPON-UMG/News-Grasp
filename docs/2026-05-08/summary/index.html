為替・経済 — 今夜の雇用統計：「157円か155円か」が来週の相場基調を決める

USD/JPYは156円台で膠着しているが、今夜21:30の米4月雇用統計発表後に相場が一変するリスクがある。強い数字が出れば157円台を試し、政府の介入判断が問われる。弱い数字なら「年内利下げ復活」シナリオが再浮上し一時的な円高転換も。5月1日の5〜6兆円介入でヘッジファンドのショートは45%急減し、市場は次の方向感を待っている状態。来週承認見込みのFRBウォーシュ新議長の方針が固まれば、日米金利差の行方が少しずつ明確になる。

§03 → AI・技術

AI・技術 — Anthropicの包囲戦略と「独立性のコスト」

SpaceX・Google・Amazonという三者のコンピュートを同時に確保するAnthropicの戦略は、「誰か一社に依存しない」という独立性の追求に見える。しかし実態は、Google（投資400億ドル+チップ200Bドル）という特定の大口依存を別の大口で分散させているに過ぎない。Vera Rubin NVL72の展開が2026年後半に加速すれば、Claude系モデルの推論速度と量がさらに向上する見通し。IBM Context Studioも企業のAIエージェント展開を加速させており、コンサル業界のアセット化が業種横断で進む。

§04 → 産業・業界

産業・業界 — 任天堂・ソニー同日決算と「日本株6万円への問い」

任天堂Switch 2の1,900万台達成とソニーの営業益1.54兆円上方修正は、日本製造業×コンテンツの二大王者が揃って好業績を出すという日本株にとって理想的なシナリオだ。一方で米関税・円高・メモリコスト高という三重リスクを「27年3月期見通し」がどう折り込むかが株価の短期的な上下を決める。日経平均が6万円台を定着させるには、今日の決算後の来週の買い継続が不可欠。AI・半導体・ゲームの「日本版Magnificent 3」が揃い踏みする一日が今日だ。

§05 → 明日へ

明日へ — 週末前「静かな嵐」：雇用統計・決算・ウォーシュが同居する金曜日

今夜21:30の雇用統計、本日15:30の任天堂・ソニー決算、来週のウォーシュ新議長承認というイベントが全て「今週末から来週頭」に集中している。週末のポジション調整が起きやすい金曜日に、日本時間深夜の統計まで市場が一日中「待ちの構え」でいるという緊張状態が続く。短期ではボラティリティが高い局面だが、中長期ではAI・コンピュート・日本企業の好業績というトレンドは変わっていない。今日という一日は、その長期トレンドの上に短期的な嵐が重なる特別な金曜日だ。
