§02 為替

米4月雇用統計 本日21:30発表 — ドル円「157円試しか、再介入か」の正念場

米4月雇用統計が本日21:30に発表され、ドル円「157円試しか再介入か」の正念場を迎える。GW介入後の円ショートポジションが45%急減した後、過熱感が抜けた今夜は統計次第で大幅なポジション入れ替えが予想される。ウォーシュ新FRB議長の来週承認も控え、日米両引き締め局面という異例の環境が続く。

  • 4月非農業部門雇用者数は前月比+16万人前後が予想。3月の+17.8万人（市場予想の3倍超）に続く強さなら、FRBの利下げ観測が後退しドルが強含む展開が想定される。日本時間21:30発表直後にドル円が157円台を試す可能性がある。
  • 日本政府の為替介入警戒水準は市場推計で157〜160円。強めの雇用 → ドル高 → 介入圧力というフィードバックループが一夜で作動しうるため、リアルタイム攻防のリスクが最も高い夜となる。
  • 5月1日の円買い介入（5〜6兆円推計）後に投機的円売り残高が45%急減。過熱感が抜けた今夜は統計次第でポジション大幅入れ替えのリスクが高く、ボラティリティは4月GW期間並みに膨らむ可能性がある。

§03 AI

Anthropic×SpaceX Colossus協定 — 220,000 NVIDIA GPU・300MW確保、Claudeレート2倍に即時引き上げ

AnthropicがSpaceX Colossusの220,000 NVIDIA GPUを全量確保し、Claudeレート制限を即日2倍に引き上げ。同社は金融特化AIエージェント10種をGoldman・Visa・Citiに展開し、Googleとの200Bドルチップ長期契約も浮上。コンピュートとWall Streetの両面で包囲戦略が加速している。

  • AnthropicがSpaceXのメンフィス「Colossus 1」データセンター（NVIDIA GPU 22万基・300MW超）の計算資源を全量確保する協定を5/6に締結。Amazon AWS（5GW）に続くインフラの大型確保で、コンピュート3社分散戦略が形になった。
  • 即日効果としてClaude Pro/Max/Teamの5時間レート制限を2倍に拡大、Claude Opus系APIの上限も「大幅引き上げ」を実施。コンピュート不足起因のユーザー体験悪化を直接解消する措置。
  • 将来的には軌道上AIコンピュート（スペース開発）でのSpaceXとの連携も検討。IlonMusk vs Altman/Amodeiという業界の対立構図に複雑な新軸が加わる格好。

§04 IT

IBM Think 2026: Context Studio＋Process Studio — AIコンサルが「アセット基盤型」に本格移行

IBM Think 2026でContext Studio（即日）・Process Studio（近日）が発表され、アセット基盤型AIコンサルが本格始動。OpenAI×PwCはCFO業務を全エージェント化するJVを発表。人月モデルの終焉がコンサル・SI両業界で同時進行している。

  • IBM Think 2026（5/4〜7、ボストン）で「Enterprise Advantage」の大幅拡充を発表。Context Studio（即日提供）は企業の組織データ・業務プロセスを学習したAIエージェントを自律生成し、デジタル主権を保持しながらカスタマイズ可能。
  • Process Studio（近日提供予定）はAIが1,400件以上の標準作業手順書（SOP）を読み込み、エージェント対応ワークフローに自動変換。導入18ヶ月で運用コスト25%削減の実績例を公表。Providence健康システムでは採用プロセス管理が90%短縮。
  • コンサルタントの「知識移転」というコアコンピテンシーをAIが代替し始めており、人月モデルの崩壊が現実のものになりつつある。IBM CEOアービンド・クリシュナは「AIとエンタープライズの統合が実績フェーズに入った」と宣言。

§05 経済

任天堂FY2026通期決算本日発表 — Switch 2累計1,900万台・売上2.25兆円の着地に注目

任天堂・ソニーが本日15:30に通期決算を同時発表し、Switch 2累計1,900万台達成の可否が焦点となる。日経平均59,513円は「6万円ライン回復」への試み継続中。夜21:30の米4月雇用統計が株式・為替市場の週末の方向性を決める二大イベントが集中する一日。

  • 任天堂が本日15:30に2026年3月期通期決算を発表予定。直前のQ3時点でSwitch 2が累計1,737万台と当初目標1,500万台を大幅超過。通期1,900万台達成は過去最速ペースを確定させる数字になる。
  • 2026年3月期売上高見通しは2兆2,500億円（前期比93%増）、純利益は3,500億円前後が予想。マリカワールド（1,403万本）が牽引し、ソフト販売がハードウェア普及を補完する好サイクルが確立。
  • 最大の関心は「27年3月期見通し」の数字。米関税影響・メモリ価格高騰・欧米年末需要をどう織り込むかで株価の方向性が決まる。Bloomberg記事では「スイッチ2のジレンマ」として株価の上値が重い背景を指摘。
