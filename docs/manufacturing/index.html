SKハイニックス、清州に100兆ウォン投資 NAND新工場を新設へ

FACT
【事実・概要】
SKハイニックスは韓国・清州で100兆ウォンを投じ、NAND新工場と先端パッケージング拠点を段階的に整備する。2029年までの大型投資としてAI向けメモリー供給を増強する。
CONTEXT
【背景・要点】
計画はNAND工場に80兆ウォン、2027年終盤までのパッケージング工場に20兆ウォンを配分する。AIサーバー向けHBMの需要が急増するなか、後工程まで自前で押さえる投資判断になった。
OUTLOOK
【影響・展望】
メモリー増産競争が前工程だけでなく後工程投資にも広がる。韓国勢の能力積み増しが続けば、装置・材料・基板まで周辺サプライヤーの受注見通しも一段と強まりそうだ。

半導体装置販売、26年度26%増へ 1兆円上方修正

FACT

OUTLOOK
【影響・展望】
装置需要の上振れは材料・部材・保守まで裾野が広い。2027年にかけて国内装置各社の生産負荷が高止まりすれば、供給能力確保そのものが競争力になりそうだ。
