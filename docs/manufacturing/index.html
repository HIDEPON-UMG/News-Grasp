韓国半導体の投資上乗せ100兆円 サムスン、｢産業不毛の地｣に工場群

FACT
【事実・概要】
韓国半導体で投資上乗せが100兆円規模に達し、サムスン電子が工場群を整備する構図が報じられた。2026年純利益は前期比8倍の38兆円見通しとされる。
CONTEXT
【背景・要点】
中国勢のメモリー半導体が追い上げるなか、巨額投資は生産能力と競争優位を守るための国家・企業連携のシグナルだ。設備投資の規模が競争条件を左右する。
OUTLOOK
【影響・展望】
投資額の拡大だけでなく、工場の稼働時期と歩留まり、中国勢との価格・技術差を追う必要がある。メモリー供給網の再編が焦点になる。
