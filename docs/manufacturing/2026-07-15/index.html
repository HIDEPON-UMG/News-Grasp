経産省、タワーセミコンダクターの6000億円投資を支援　光通信用半導体を国内量産へ

FACT
【事実・概要】
タワーセミコンダクターは富山・新潟で総事業規模6000億円超の投資を進め、光通信用半導体の量産に入る計画を示した。
CONTEXT
【背景・要点】
経産省は最大1600億円を助成し、IOWNを見据える国内需要と、ひっ迫時の国内優先供給を条件に経済安保の枠組みへ取り込む。
OUTLOOK
【影響・展望】
光電融合の量産基盤が日本側にできれば、NTT系通信網やAIデータセンター向け部材の調達余地が広がり、国内サプライチェーン再編の起点になる。

CXMT、最大1.6兆円調達へ　中国DRAM自給の大型IPOが始動

FACT
【事実・概要】
CXMTは上海STAR市場で1株8.66元の公開価格を決め、最大666億元（約1.6兆円）を調達し得る大型IPOに踏み切った。
CONTEXT
【背景・要点】
中国政府はDRAMをAI時代のボトルネックとみており、HBMを含むメモリー自給を急ぐ中でCXMTを中核企業に据えている。
OUTLOOK
【影響・展望】
SamsungやSK-hynixが握る市場に中国勢の増産資金が流れ込めば、DRAMとHBMの価格・供給バランスに新たな圧力がかかる。
