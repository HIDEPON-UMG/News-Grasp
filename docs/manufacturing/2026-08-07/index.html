米、ポリシリコンに15％追加関税　日本などは上限特例

FACT
【事実・概要】
米政権が半導体・太陽光パネル材料のポリシリコンに15％の追加関税と最低輸入価格を課す布告に署名した。発動は12月4日で、日本などには上限特例を設ける。
CONTEXT
【背景・要点】
措置は中国のダンピング防止と米国内生産の拡大が狙いだ。承認された国内投資には関税免除も想定され、供給網の組み替えを促す政策になる。
OUTLOOK
【影響・展望】
12月の発動までに、対象品目の範囲と各国の実効税率を確認したい。米国での素材生産投資が実際に増えるかが次の焦点だ。
