ソニーとTSMC、次世代画像センサーを2029年に量産

FACT
【事実・概要】
ソニーの半導体グループ会社とTSMCが新たな合弁会社を設立し、2029年から次世代画像センサーを量産する予定を発表した。
CONTEXT
【背景・要点】
画像センサーは設計だけでなく量産拠点と製造能力が競争力を左右する。ソニーの技術とTSMCの生産基盤を組み合わせる判断だ。
OUTLOOK
【影響・展望】
焦点は熊本での設備整備と量産立ち上げの進捗、歩留まり、顧客向け供給時期になる。国内半導体投資の実装力も問われる。

キオクシアの成長が示す、日本半導体の再浮上に必要な専業化

FACT
【事実・概要】
キオクシアは2026年3月期に過去最高の売上高を記録した。東芝から独立し、半導体専業へ軸足を移した経営判断が成長を支えたと分析している。
CONTEXT
【背景・要点】
メモリー市場は好不況の波が大きいが、半導体全体は長期で成長してきた。専業化と投資継続が市況変動への対応力を左右する。

今後は北上工場を含む生産能力の拡張とAI向けメモリー需要を追う必要がある。日本半導体が再成長を続けられるかが焦点だ。

製造現場の暗黙知をAIへ、エムニがデータ化の要点を説く

FACT
【事実・概要】
エムニの下野祐太CEOは、製造業でAIを活用するには現場の暗黙知から取るべきデータを定めることが重要だと語った。80社以上との取引実績も示した。
CONTEXT
【背景・要点】
製造現場では経験や勘が工程に埋め込まれ、データ化の対象が曖昧なままではAI導入が止まりやすい。継続利用率8割は実装の定着を示す材料だ。
OUTLOOK
【影響・展望】
次に見るべきはどの工程の判断をデータ化し、品質・保全・技能継承へどう接続するかだ。製造業AIの成否は現場設計で分かれる。
