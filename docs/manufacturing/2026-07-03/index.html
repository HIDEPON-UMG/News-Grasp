SKハイニックス、清州に100兆ウォン投資 NAND新工場を新設へ

FACT
【事実・概要】
SKハイニックスは韓国・清州で100兆ウォンを投じ、NAND新工場と先端パッケージング拠点を段階的に整備する。2029年までの大型投資としてAI向けメモリー供給を増強する。
CONTEXT
【背景・要点】
計画はNAND工場に80兆ウォン、2027年終盤までのパッケージング工場に20兆ウォンを配分する。AIサーバー向けHBMの需要が急増するなか、後工程まで自前で押さえる投資判断になった。
OUTLOOK
【影響・展望】
メモリー増産競争が前工程だけでなく後工程投資にも広がる。韓国勢の能力積み増しが続けば、装置・材料・基板まで周辺サプライヤーの受注見通しも一段と強まりそうだ。

半導体装置販売、26年度26%増へ 1兆円上方修正

FACT
【事実・概要】
SEAJは日本製半導体製造装置の2026年度販売見通しを6兆5502億円へ引き上げた。1月予測から1兆498億円の上方修正で、前年度比26%増を見込む。
CONTEXT
【背景・要点】
AI向けサーバー需要の拡大でDRAM投資が想定以上に強く、先端ロジック向けの装置発注も上振れた。後工程だけでなく前工程の大型案件が半年で一段と積み上がった。
OUTLOOK
【影響・展望】
装置需要の上振れは材料・部材・保守まで裾野が広い。2027年にかけて国内装置各社の生産負荷が高止まりすれば、供給能力確保そのものが競争力になりそうだ。

FACT

住友化学、サムスン電機とガラスコア基板JVを設立へ

FACT
【事実・概要】
住友化学はサムスン電機と、AI向け先端半導体に使うガラスコア基板の合弁会社を設立する。2026年内の会社設立を計画し、韓国・平沢で供給体制を整える。

【背景・要点】

OUTLOOK
【影響・展望】

住友電工、光通信用半導体材料を3.1倍へ増産

FACT
【事実・概要】
住友電工は光通信用の半導体材料であるインジウムリン基板に180億円を投じる。2028年度までに24年度比3.1倍へ生産能力を引き上げる。
CONTEXT
【背景・要点】

OUTLOOK
【影響・展望】
光通信部材の増産が進むと、AIサーバー投資のボトルネックがメモリーだけでなく配線・光学部材まで拡張していることが鮮明になる。材料立ち上げの速度がデータセンター増設ペースを左右する局面に入った。
