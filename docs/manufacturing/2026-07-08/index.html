トヨタ、米テキサス工場に5800億円投資　タコマ生産をメキシコから一部移管

FACT
【事実・概要】
トヨタは約5800億円を投じてテキサス州サンアントニオ工場にタコマ新ラインを設け、メキシコ生産の一部を4年かけて移す。
CONTEXT
【背景・要点】
米国ではピックアップ需要が厚く、関税対応と北米供給網の再配置が重なった。最大100億ドル投資方針の延長線上にある判断だ。
OUTLOOK
【影響・展望】
完成車だけでなく部材・物流の配分も米南部へ寄れば、メキシコ拠点の役割が変わる。域内生産の採算が次の焦点になる。
