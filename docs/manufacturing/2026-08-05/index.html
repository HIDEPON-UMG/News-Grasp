熊本地震、自動車部品の供給懸念が遠方工場へ波及

FACT
【事実・概要】
熊本地震から1週間、半導体工場の復旧が進む一方、自動車部品工場では供給懸念が残る。ホンダ3工場は8月19日まで一部停止し、遠方工場への波及も続く。
CONTEXT
【背景・要点】
自動車は一部部品の滞りで完成車を作れない。部品供給網ではTSMCなどが通常生産へ戻る一方、再開後の品質確認が必要になる。
OUTLOOK
【影響・展望】
工場集積は効率を高める反面、災害時の集中リスクも増やす。生産集積の復旧に続き、物流と関連工場の平常化が次の焦点だ。

FACT

CONTEXT
