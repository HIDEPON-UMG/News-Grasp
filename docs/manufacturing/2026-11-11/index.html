Infineon processes first 300 mm SiC wafers into working power devices Infineon、300mm SiCウエハーを機能するパワーデバイスへ加工　世界初

FACT
【事実・概要】
：Infineonはオーストリア・フィラッハ工場で、300mmのSiCウエハーを機能するパワーデバイスに加工することに世界で初めて成功したと発表した。既存のシリコン用設備を使い、300mm化で1枚から約2.3倍のチップが取れる。大口径化がEV向けパワー半導体の量産効率を左右する。
CONTEXT
【背景・要点】
：同社はシリコン・SiC・GaNの3材料すべてで300mm技術を持つ形になり、フィラッハでは約11億ユーロのGaN量産投資も進む。一方で300mm SiCの量産時期は未定で、顧客と足並みをそろえる方針だ。技術の到達と量産の開始は別の関門である。
OUTLOOK
【影響・展望】
：焦点は車載SiCのコスト低下の速度と歩留まりの実績で、競合の追随が設備投資競争を再燃させる可能性がある。ミュンヘンのelectronicaで実物が公開される。

韓国のAPシステム、半導体装置の年間受注が初の1000億ウォン突破…RTPとレーザーの二本柱

FACT
【事実・概要】
：韓国のAPシステムは10日、半導体装置部門の年間新規受注が初めて1,000億ウォン（約120億円）を突破したと発表した。前年の部門売上652億ウォンの約1.5倍に当たる。メモリー増設の波が装置受注に届いた形だ。
CONTEXT
【背景・要点】
：牽引役は急速熱処理（RTP）装置で、DRAM工程への適用拡大が進んだ。第二の柱のレーザー装置はOLED量産で検証した技術を半導体工程へ移したものだ。異分野の量産実績を横展開する装置メーカーの型が表れた。
OUTLOOK
【影響・展望】
：受注残は2027年まで順次売上に反映される見込みで、先端パッケージ向けレーザー装置の商用化が次の上積み材料になる。国内メモリー投資の持続が前提条件だ。

ルネサスの新MPU、4軸モーター制御と産業イーサ、Linux処理を統合

FACT
【事実・概要】

CONTEXT

OUTLOOK

：11月10日からミュンヘンで開くelectronica 2026で実機デモが行われ、採用の広がりが試される。工場自動化の更新需要を国産MPUが取り込めるかが焦点だ。
