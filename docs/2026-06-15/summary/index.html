§01
FOREIGN EXCHANGE / 為替

利上げ観測より説明の一手が相場を動かす

FACT 事実・概要

日銀会合は31年ぶりの1%利上げ観測が前提となり、焦点は実施の有無より次の一手と総裁不在時の説明に移った。

CONTEXT 背景・要点

【事実】：日銀が1%利上げへ踏み込めば、為替市場の関心は実施可否よりも次回以降の道筋に移る。円高が続くかは追加引き締めの示唆次第だ。

OUTLOOK 影響・展望

【背景】：植田和男総裁の欠席で、会見メッセージを誰がどう伝えるかが価格形成の新しい変数になった。政策の中身が同じでも、説明の温度差はドル円の振れ幅を広げやすい。

§02
ARTIFICIAL INTELLIGENCE / AI

決済、詐欺対策、価格競争が一体化する

FACT 事実・概要

GoogleがGemini悪用の詐欺網を提訴し、VisaとOpenAIはエージェント決済で提携した。

CONTEXT 背景・要点

【事実】：GoogleがGeminiを悪用した詐欺網を提訴し、2週間で250万通という送信規模を示した。

OUTLOOK 影響・展望

【背景】：論点はモデル性能ではなく、生成AIを誰がどう監視し止めるかへ移っている。

→ §02 AI 詳細を読む
§03
IT & CONSULTING / IT

契約、権限、運用の三点で再構築が進む

FACT 事実・概要

SMBCグループは日本総研とNECを軸にAI時代のIT再構築へ動き、Keeper Securityは秘密情報のドリフト解消を狙う。

CONTEXT 背景・要点

【事実】：SMBCグループはAI活用を前提に、既存ITの延命ではなく再構築へ舵を切った。日本総研とNECを軸に据える点が、金融大手の実装フェーズ入りを示す。

OUTLOOK 影響・展望

【背景】：生成AI導入は個別ツール選定より、勘定系周辺や業務基盤をどうつなぎ直すかが勝負になる。金融ITの本丸が基盤統合に移るというメッセージが重い。

→ §03 IT 詳細を読む
§04
MOBILITY / モビリティ

自動運転はデモから再利用へ進む

FACT 事実・概要

欧州ではロボタクシーの越境運行が制度論点になり、GMはEV電池を1.5MW蓄電に再利用した。

CONTEXT 背景・要点

【事実】：欧州でロボタクシーの越境運行を認める方向が浮上し、実証の単位が都市ごとから広域路線へ広がり始めた。

OUTLOOK 影響・展望

【背景】：勝負どころは車両性能そのものより、国境をまたぐ許認可と責任分界をどう揃えるかに移っている。

→ §04 モビリティ 詳細を読む
§05
MANUFACTURING / 製造

設備投資は国際分業の速度勝負へ

FACT 事実・概要

Rapidusは英半導体センターと基本合意し、ASEは先端後工程の量産ラインを拡張した。

CONTEXT 背景・要点

【事実】：ラピダスが将来の半導体製造で英国側と連携する基本合意を結び、2ナノ量産へ向けた研究接続を外へ広げた。

OUTLOOK 影響・展望

【背景】：焦点は提携そのものより、量産立ち上げ前に工程知見をどこまで吸い込めるかにある。国産化だけでは歩留まり競争に勝てない。

→ §05 製造 詳細を読む

ECONOMY / 経済

安保と資源高が政策余地を削る

FACT 事実・概要

米イランの戦闘終結覚書、日英首脳の経済安保共同宣言、イタリア中銀のGDP見通し維持が同日に並んだ。

CONTEXT 背景・要点

【事実】：米イラン合意でホルムズ海峡の封鎖懸念が和らげば、原油と海上運賃の急騰シナリオは一旦後退する。

OUTLOOK 影響・展望

【背景】：ただし覚書段階にとどまるため、通航の安定が本当に戻るかは履行と地域情勢の確認待ちだ。

GAMING / ゲーム

価格と導線の設計が勝負を決める

FACT 事実・概要

Xbox新CEOは性能競争より価格を優先し、任天堂は『ポッピュコム』を会員向けに限定開放した。

CONTEXT 背景・要点

【事実】：Xbox の新CEOアーシャ・シャルマ氏は、次世代機に数千ドルを払える層は限られるとして、性能一辺倒の競争を見直す 必要性を示した。

OUTLOOK 影響・展望

【背景】：背景には、Game Pass 値上げの反省と部材高騰があり、ハードとサブスクをまとめて組み替える 発想がにじむ。
