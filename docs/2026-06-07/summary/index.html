§01
FOREIGN EXCHANGE / 為替

超過密週への備え

FACT 事実・概要

6/16のBOJ会合と6/17のFOMCが2日連続で来る「超過密週」が迫る。

CONTEXT 背景・要点

【事実】：日銀は6/16会合で25bp利上げ（0.75→1.0%）を78%超の確率で織り込み、FRBは据え置き濃厚——金利差縮小期待が円の支援材料になりつつある。

OUTLOOK 影響・展望

【背景】：USD/JPY 160円が介入トリガーとして市場が意識する節目で、大蔵省が「decisive action」を繰り返し警告。直近2ヶ月で11.7兆円介入済み。

→ §01 為替 詳細を読む
§02
ARTIFICIAL INTELLIGENCE / AI

IPO戦争と安全問題の同時進行

FACT 事実・概要

Anthropicの$965B評価は2ヶ月で3倍というフィンテックバブル超えのペース。

CONTEXT 背景・要点

【事実】：Anthropic・OpenAI・Microsoft AI・Google DeepMindの4CEO（アモデイ/アルトマン/スレイマン/ハサビス）が連名で米議会に書簡——「AIが生物兵器設計の技術的障壁を侵食している」と警鐘。

OUTLOOK 影響・展望

【背景】：合成DNAのオンライン注文・AI支援設計への強制スクリーニングを求め、Twist BioscienceやAnsa Biotechnologiesも署名——産業界横断の規制要求として異例。

→ §02 AI 詳細を読む
§04
MOBILITY / モビリティ

自動運転の地政学

FACT 事実・概要

Teslaの中国FSD解禁と日本FSD展開宣言は東アジア市場での自動運転版「第二幕」の開幕だ。

CONTEXT 背景・要点

【事実】：Teslaが中国でFSD（監視付き）提供開始——数年の規制交渉と現地ADAS競合との競争の末。サブスクリプション専用モデル（2月から一括購入廃止）で展開、10市場のひとつとして追加。

OUTLOOK 影響・展望

【背景】：先行する小鵬・Huawei ADS 3.0・BYDはすでに成熟した都市型NOA機能で城塞を構築中——中国独自の複雑交通環境への適応がTeslaの次の試練。

→ §04 モビリティ 詳細を読む
§07
GAMING / ゲーム

6月発表祭りの中核週

FACT 事実・概要

FF7 RevelationのSpring 2027発表と6/9 Nintendo Directの確定リークが重なり、2026年6月は史上最大の発表月になりつつある。

CONTEXT 背景・要点

【事実】：スクウェア・エニックスがSummer Game Fest 2026（6/5）でFFVII Rebirthの続編「FINAL FANTASY VII: Revelation」を発表。ジョブクラスシステム導入・飛空艇からのオープンワールドへのシームレス移行を初公開。

OUTLOOK 影響・展望

【背景】：PS5・Xbox Series X/S・PC・Nintendo Switch 2同時リリース（Spring 2027）、ヴィンセント・ヴァレンタインとシド・ハイウインドが操作可能キャラとして復活——ファン待望の完結編。
