PSN障害、デジタルゲームの起動可否を浮き彫りに

FACT
【事実・概要】
PlayStation Networkでアカウント管理、ストア、ゲームなど全サービスに障害が発生し、6時間以上続いた。『MARVEL Tōkon』のPS5向けベータにも影響した。
CONTEXT
【背景・要点】
オフライン対応でもデジタル版の一部はオンライン認証を要する。サービス障害が購入済みゲームへのアクセスに波及する構造が可視化された。
OUTLOOK
【影響・展望】
物理ディスク縮小とデジタル移行が進むなか、認証障害時のプレイ継続性と復旧説明がプラットフォームの信頼を左右する。
