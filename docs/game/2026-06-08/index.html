Resident Evil Code: Veronica リメイク発表 ── 2027年・PS5/Switch 2/PC同時発売

  • カプコン が Summer Game Fest 2026 で Resident Evil Code: Veronica のフルリメイクを発表。主人公は Claire Redfield で2027年 PS5・Xbox Series X|S・Switch 2・PC 全プラットフォーム同時発売。シリーズ全球累計690万本超の Requiem 成功を受けた次手。
  • バイオ7（2017）以来の原点回帰路線で、カプコンが 「シリーズ最高傑作の一つ」 と称する Code: Veronica を令和版で完全再構築。ゴシック調の洋館とネオアンブレラの脅威が現代グラフィックで蘇る。
  • Switch 2 への豪華サードパーティ参入が続く流れで、ハード魅力を底上げするキラータイトル として業界評価も高い。カプコンは今後もバイオシリーズのスイッチ2対応を積極推進する方針。

Summer Game Fest 2026 総括 ── FF7・RE:Veronica・Stellar Blade 2が同日発表の衝撃

  • スクウェア・エニックス の FFVII Revelation（三部作完結・Spring 2027）、カプコン の RE:Veronica リメイク（2027）、SIE の Stellar Blade: Blood Rain（新主人公 Evie・初期開発）が同日発表というまれな豪華ラインナップ。
