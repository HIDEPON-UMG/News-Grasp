任天堂FY2026通期決算 — Switch 2累計1,986万台・売上2.3兆円・5月25日に1万円値上げ

【事実】
任天堂FY2026通期（2026年3月期）は売上高2兆3,136億円（前期比+98.6%）・純利益4,240億円（+52.1%）と大幅改善。Switch 2が初年度で累計1,986万台を達成し、初代Switch発売直後の勢いを超えた。
【背景】
主要ソフト：マリカワールド14.7万本（バンドル含む）・ドンキーコング4.52万本・ポケモンLEGENDS 3.94万本。Switch 2ソフト合計4,871万本と旺盛なソフト付着率を記録。
【展望】
5月25日より日本語専用版を49,980→59,980円（+10,000円）に値上げ。部品コスト高騰が理由。FY2027は販売台数16.5万台予測・最終減益見通しに転じており、「量から質」への転換期に入った。
