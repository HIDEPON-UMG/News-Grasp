Switch 2値上げ前日に購入騒動——Bic Camera等が制限措置、転売抑制と旧価格駆け込みが交錯

  • 5月24日（日本時間）、Switch 2翌日の値上げ（¥49,980→¥59,980）を前に全国の量販店で在庫争奪が起きた。Bic Cameraは「Bic Cameraブランドのクレジットカード保有者限定」という販売制限を導入し、転売目的の大量購入を阻止しようとした。
  • 価格改定の公式理由はAI半導体需要急増によるメモリチップ高騰と米国関税・円安の三重苦。任天堂は5月8日の発表から17日間の「駆け込み期間」が予期せぬ特需を生み出したと後から評価することになった。
  • Switch 2発売（6月5日）から約1年が経過しようとする中、価格帯が任天堂史上最高値¥59,980となるSwitch 2は来期の出荷目標16.5M台（前期比▲3M台修正）の重石になる可能性がある一方、品薄プレミアム効果で需要の長期持続を示す逆説的な兆候でもある。
