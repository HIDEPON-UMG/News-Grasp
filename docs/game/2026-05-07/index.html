任天堂FY2026通期決算（5/8発表前夜） — Switch 2累計1,737万台、マリカワールド1,403万本

FACT
【事実・概要】
任天堂は5月8日に2026年3月期通期決算を発表予定。第3四半期（2月）時点でSwitch 2累計販売は1,737万台、マリオカート ワールドは1,403万本という驚異的な数字が判明。
CONTEXT
【背景・要点】
通期純利益は26%増の3,500億円、売上高は93%増の2.25兆円と任天堂の歴史を塗り替える好業績が期待される。Switch 2の4ヵ月で1,000万台突破は歴代最速の普及ペース。
OUTLOOK
【影響・展望】
ポケモンZAのSwitch 2版も389万本を記録し、サードパーティ含めた複数のキラーコンテンツが揃い踏み。Nintendo Switch初代（6.8ヵ月で1,000万台）を大きく上回る勢いが続いている。

コナミG FY2026 Q2：2期連続過去最高業績 — デジタルエンタメ事業が全方位で好調

FACT
【事実・概要】
コナミグループの2026年3月期Q2は売上高2,248億円（前年比+22.1%）、純利益465億円（+27.7%）で2期連続の過去最高更新。株価は年初来高値圏で推移。
CONTEXT
【背景・要点】
デジタルエンタテインメント部門の主力コンテンツ（eFootball・遊戯王・プロ野球スピリッツ）が全方位で好調。モバイルとコンソールの複線展開が確立されたエコシステム設計が収益を安定化。
OUTLOOK
【影響・展望】
スポーツ・フィットネス事業との相乗効果も数字に現れており、純粋なゲーム企業からの脱却が市場評価を押し上げ。5月の通期決算でさらなる上方修正への期待も高まっている。

カプコン FY2026 Q2：増収増益で2,385万本販売 — IP活用で246タイトルが231カ国へ

FACT
【事実・概要】
