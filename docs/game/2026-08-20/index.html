エクソーラとアクセルバイト、ゲーム向けバックエンドと決済を統合

FACT
【事実・概要】
エクソーラとアクセルバイトが、ゲーム向けバックエンドと決済をまとめた統合ソリューションを発表。クローズドテストを開始し、早期アクセスを募る。
CONTEXT
【背景・要点】
プレイヤー管理やマッチメイキングを含む基盤と、決済・サブスクリプションを組み合わせる構想だ。LiveOpsの複数基盤を一体化し、導入負荷を下げる狙いがある。
OUTLOOK
【影響・展望】
