gamescom 2026開幕、日米欧の新作が集結

FACT
【事実・概要】
gamescom 2026がドイツ・ケルンで開幕。カプコン、スクウェア・エニックス、任天堂、HoYoverseなど日米欧の主要社が出展し、試遊や取材が始まった。
CONTEXT
【背景・要点】
gamescomは欧州最大級のゲーム見本市で、会場では発売前タイトルを直接体験できる。Opening Night Live後の展示が、次の新作トレンドを読む場になる。
OUTLOOK
【影響・展望】
会期は8月30日まで。各社の新映像や試遊情報が続くため、新作発表の反応と発売時期の具体化を追いたい。日本勢の存在感も焦点だ。

viviON GAMES始動、PCゲームをスマホへ橋渡し

FACT
【事実・概要】
viviON GAMESが8月26日に始動し、PCゲームをダウンロードせずスマートフォンで提供する。30タイトル以上をそろえ、『アクおど』などを扱う。
CONTEXT
【背景・要点】
スマホ向け移植を不要にし、タイトル単位で購入できる仕組みだ。PCを持たない層や時間制約のある人へ、作品との接点を増やす設計が狙いになる。
OUTLOOK
【影響・展望】
既存PC作品の販路を広げる一方、操作性や通信環境が継続利用を左右する。クリエイター側の参加拡大と、購入後の定着を見たい。
