CONTEXT
【背景・要点】
2027年2月施行のEUバッテリー規制で、携帯ゲーム機もユーザー交換式が販売条件になる。現行機から容量1%減・重量約14g増に抑えたのは、規制対応と互換維持を両立するためだ。
