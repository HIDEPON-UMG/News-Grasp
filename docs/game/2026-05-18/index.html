スクウェア・エニックスがSwitch2マルチ戦略を強化 — CEO「特にSwitch2に注力」と明言

インディ・ジョーンズSwitch2版が好調 — XboxのAAA移植でサードパーティ参入加速

  • インディ・ジョーンズ のSwitch2版（5月12日配信）が好調な滑り出し。XboxおよびPC専用だったタイトルがSwitch2に移植されることで、Microsoft の「コンテンツのプラットフォーム非依存化」戦略が加速している。

  • カプコンの「プラグマタ」200万本突破と合わせると、Switch2は発売から1ヶ月以内に 複数のAAA IPが同時ヒット するプラットフォームとして、業界の注目ポイントになっている。
