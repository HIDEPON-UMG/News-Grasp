Steam上半期売上が1.8兆円突破、旧作比率8割へ

FACT
【事実・概要】
Steamの2026年上半期売上は111億ドルに達し、約1.8兆円で過去最高となった。売上の約8割を旧作群が占め、新作偏重から構図が変わっている。
CONTEXT
【背景・要点】
調査では中国を含むアジアの利用拡大に加え、値引き・バンドル・再販運用の巧拙が収益差を広げた。旧作を長く売る配信型ストアの強みが鮮明だ。
OUTLOOK
【影響・展望】
大型新作だけでは棚を取りにくくなり、長期セール設計とライブ運営の比重がさらに上がる。パブリッシャーが旧作資産をどう回すかが次の競争軸になる。
