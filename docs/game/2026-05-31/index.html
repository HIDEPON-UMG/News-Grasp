Nintendo FY2026決算: Switch 2累計1,986万台・ソフト4,871万本 — Mario Kart World 1,470万本で首位

  • 任天堂がFY2026通期決算を発表。Switch 2累計ハード1,986万台・年間ソフト4,871万本で当初ガイダンスを上回る好スタートを確認。
