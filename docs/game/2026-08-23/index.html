『楽園追放』初のゲーム化、11月26日発売へ

FACT
【事実・概要】
『楽園追放 -The Stellar Angel-』が11月26日に発売決定。Nintendo Switch／Steam対応で、公式サイトの本オープンと予約受付が同日始まった。
CONTEXT
【背景・要点】
2014年の劇場アニメと11月公開予定の次回作をつなぐ完全新作。通常版6,380円、限定版11,880円など複数形態を用意する。
OUTLOOK
【影響・展望】
アニメ続編とゲームを同年に展開するメディアミックス案件。今後はダウンロード版の予約時期と、シリーズ横断の販促効果が焦点になる。

GGGP2026、64チームの頂点に「2024年のリターンマッチ」

FACT
【事実・概要】
GGGP2026が両国国技館で開催され、「2024年のリターンマッチ」が優勝。『機動戦士ガンダム エクストリームバーサス2 インフィニットブースト』で64チームが競った。
CONTEXT
【背景・要点】
バンダイナムコフィルムワークス主催、SANKYO特別協賛の大型大会。過去の因縁を含む対戦構図が、競技性と観戦価値を押し上げた。
OUTLOOK
【影響・展望】
IP単体の販売に加え、eスポーツ大会が継続的な接点を作る。次回大会のタイトル選定と配信規模がコミュニティ拡大を左右する。

無料Steamゲーム『No Results Found』、97％好評で人気化

FACT
【事実・概要】
No Results FoundがSteamで「圧倒的に好評」を獲得。架空の新興宗教と227人死亡事件を、ゲーム内PCの検索機能で調べる無料アドベンチャーだ。
CONTEXT
【背景・要点】
KRAFTONのJungle Game Lab第5期生が9週間で制作し、Steam公開後の評価収集とパッチ配信まで経験する育成設計から生まれた。
OUTLOOK
【影響・展望】
育成プログラムが作品公開まで担うことで、学習と市場検証を接続できる。無料作品群の評価差と継続支援が次の観測点になる。
