§01
¥ FOREIGN EXCHANGE / 為替

介入後の円安を止める金利差

FACT 事実・概要

日米協調介入後も円安圧力が残り、日銀9月利上げ予想は約8割、ドル円の戻りのめどは160円台半ばとされた。

CONTEXT 背景・要点

介入は一時的な需給を動かせても、日米金利差や海外資産投資の流れを変えなければ円高を定着させにくい。

OUTLOOK 影響・展望

9月の日銀判断、米金利の低下幅、160円を巡る当局姿勢を組み合わせ、政策期待が実際の相場へ移るかを追う。

→ §01 為替 詳細を読む
§02
◆ ARTIFICIAL INTELLIGENCE / AI

普及規模を証跡と業務へつなぐ

FACT 事実・概要

Geminiアプリの月間利用者が10億人を突破し、Claudeの生成テキストには機械可読の透かしを導入する方針が示された。

CONTEXT 背景・要点

配布面の強さで利用が広がるほど、生成物の来歴、教育現場の安全設計、現場KPIまでを接続する必要が増す。

OUTLOOK 影響・展望

検出だけを出所証明とせず、編集履歴・人の確認・業務効果を組み合わせたAI導入の評価軸を確認したい。

→ §02 AI 詳細を読む
§03
⌗ IT & CONSULTING / IT

Consulting — 例外運用を統制へ戻す

FACT 事実・概要

アスクル被害では委託先管理者アカウントのMFA未適用が論点となり、政府は機密情報向け民間クラウドの導入方針を示した。

CONTEXT 背景・要点

クラウド移行やAI導入は製品選定だけで完結せず、例外ID、責任分界、基礎データ、監査証跡を運用に埋め込む必要がある。

OUTLOOK 影響・展望

年内の調達条件、例外アカウント棚卸し、AI判断の人手評価、保全・購買データの定着度を実務の確認点にする。

→ §03 IT 詳細を読む
§04
◎ MOBILITY / モビリティ

政策と価格がEV競争を動かす

FACT 事実・概要

豪州で中国EVが伸び、中国の新車販売は23.6％減、名古屋ではNTT系3社が3台の自動運転配車実証を始める。

CONTEXT 背景・要点

政策支援、燃料価格、販売網、配車ソフト、資金調達が地域ごとのEV・自動運転の事業化条件を変えている。

OUTLOOK 影響・展望

優遇縮小後の価格、レベル2実証からレベル4への移行、ティアフォーの量産導入と黒字化の進捗を追う。

→ §04 モビリティ 詳細を読む
§05
⬢ MANUFACTURING / 製造

供給制約を資金で抑える

FACT 事実・概要

ソニーとTSMCが7470億円を投じる合弁計画を示し、半導体受注は約2倍、GMは最大45億ドル分の重要部品を確保する枠組みを設けた。

CONTEXT 背景・要点

AI需要で受動部品にも供給制約が広がる可能性があり、在庫を持つ費用と生産停止を避ける価値を同時に考える必要がある。

OUTLOOK 影響・展望

熊本の量産工程、部品の代替可否、知多工場の復旧と出荷影響、ロボット導入の投資対効果を確認する。

→ §05 製造 詳細を読む
§06
■ ECONOMY / 経済

暑さと地政学が需要を変える

FACT 事実・概要

ロシアGDPは1.3％増の一方、猛暑35.7度が消費と街づくりの分岐点となり、4〜6月期GDPは年率1.67％増と予測された。

CONTEXT 背景・要点

戦時の供給制約、物価、暑さ、自然関連リスク、技術流出が、企業と金融機関の資金配分や需要の前提を変えている。

OUTLOOK 影響・展望

8月17日のGDP速報、個人消費、冷却設備と屋内導線への投資、自然関連開示と輸出管理の実装を追いたい。

→ §06 経済 詳細を読む
§07
▶ GAMING / ゲーム

販売経路と所有を問い直す

FACT 事実・概要

Stop Killing GamesなどがPS Storeの販売集中を問題視する集団訴訟を支持し、PS Plusには8月13日・18日に大型作が追加される。

CONTEXT 背景・要点

デジタル価格、物理メディア縮小、所有と中古市場の選択肢が、プラットフォームの収益設計と利用者の納得感を左右する。

OUTLOOK 影響・展望

オランダ・英国の訴訟動向、PS Plusの継続率、新作の発売前配信、Switch移植の受容を次の観測点にする。

→ §07 ゲーム 詳細を読む
