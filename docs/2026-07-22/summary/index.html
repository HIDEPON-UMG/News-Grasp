§01
¥ FOREIGN EXCHANGE / 為替

原油高が政策観測を揺らす

FACT 事実・概要

ドル円は163.23円まで上昇し、ユーロドルも原油高が続けば1.13ドル台前半まで下落する可能性が示された。

CONTEXT 背景・要点

原油高はインフレを押し上げる一方で景気を圧迫し、FedやECBの政策期待を単純な方向へは運ばない。

OUTLOOK 影響・展望

28〜29日のFOMC、原油価格、財政規律と日銀の次の判断を、為替水準と合わせて確認する。

→ §01 為替 詳細を読む
§02
◆ ARTIFICIAL INTELLIGENCE / AI

性能より処理単価を測る

FACT 事実・概要

GoogleがGemini 3.6 Flashと3.5 Flash-Lite、AlibabaがQwen-Image-3.0を発表し、OpenAIのエージェント利用者1000万人との報道も出た。

CONTEXT 背景・要点

性能の絶対値から、用途別の処理量、待ち時間、利用規模、文字再現性へ評価軸が広がっている。

OUTLOOK 影響・展望

API利用の単価、実測レイテンシー、継続利用率、生成物の権利と再現性を次の判断材料にしたい。

→ §02 AI 詳細を読む
§03
⌗ IT & CONSULTING / IT

権限をつなぐ境界が焦点

FACT 事実・概要

StyleflowがAIエージェント連携と企業間連携を追加し、NRIは生成AIと業務SaaSの共存条件を整理した。

CONTEXT 背景・要点

権限管理、監査、誤検知対応、業務データの品質を、エージェントの操作経路へ組み込む必要がある。

OUTLOOK 影響・展望

AI Agent Dayの実装事例やWAF運用、地域交通データ分析から、導入後の責任者と再現性を確認する。

→ §03 IT 詳細を読む
§04
◎ MOBILITY / モビリティ

道路側の整備が自動化率を押す

FACT 事実・概要

Teslaはロボタクシーを2都市へ拡大し、T2は50億円を調達、WeRideはUAEで展開し、GMは通期見通しを引き上げた。

CONTEXT 背景・要点

自律配車、幹線物流、海外許認可、EV採算が、車両単体ではなく都市・資本・制度の組み合わせで進む。

OUTLOOK 影響・展望

安全性、稼働率、料金、拠点、停車帯、路側センサーの整備状況を、商用化の実績として追いたい。

→ §04 モビリティ 詳細を読む
§05
⬢ MANUFACTURING / 製造

値上げを吸収する工程

FACT 事実・概要

パナソニック環境エンジニアリングは薬液・排水・金属回収を一体化し、SkyDriveはインド企業と複合材部品を量産する。

CONTEXT 背景・要点

材料費、装置費、海外拡張費、環境対応費が製造原価に入り、AI需要の増産が周辺工程にも負担を広げる。

OUTLOOK 影響・展望

2027年契約、量産時の品質、資源回収の量産適用、2028年商用運航の認証進捗を確認する。

→ §05 製造 詳細を読む
§06
■ ECONOMY / 経済

成長投資と金利のせめぎ合い

FACT 事実・概要

日本政府は責任ある積極財政を掲げ、ドイツの投資家心理は予想超に改善し、RBNZはインフレを2%へ戻すため利上げした。

CONTEXT 背景・要点

景気の強さは企業利益を支えるが、金利上昇を通じて株価や設備投資の評価を圧迫する。

OUTLOOK 影響・展望

予算執行、物価、NZドル、企業利益、投資家心理が、成長戦略の実体経済への波及を測る材料になる。

→ §06 経済 詳細を読む
