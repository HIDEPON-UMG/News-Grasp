§01
¥ FOREIGN EXCHANGE / 為替

利上げ条件が円安圧力を延命

FACT 事実・概要

浅田委員の慎重発言、骨太原案への金利上昇反応、ドル円161円台後半の高止まり、ウォン安連鎖が同時に出た。

CONTEXT 背景・要点

日銀の追加利上げには内生的な需要と賃金の確認が要るという線引きが、円高反転のハードルを上げている。

OUTLOOK 影響・展望

FOMC議事要旨と日銀発言を受けて、介入警戒より円安圧力の持続条件が重視されるかを見たい。

→ §01 為替 詳細を読む
§02
◆ ARTIFICIAL INTELLIGENCE / AI

配信面より原価と統制が主戦場

FACT 事実・概要

MicrosoftのOffice系AI内製化、Anthropicの内部表現可視化、Metaの画像生成AI公開、Claude Code追跡説明が並んだ。

CONTEXT 背景・要点

利用面を押さえた企業ほど、トークン原価、監査可能性、配信面の広さを一体で設計できる局面に入っている。

OUTLOOK 影響・展望

次は、内製AIと安全可視化が企業導入率や価格交渉力へどこまで効くかが焦点になる。

→ §02 AI 詳細を読む
§03
⌗ IT & CONSULTING / IT

AI導入が機能比較から運用設計へ

FACT 事実・概要

Oracleの国内SaaS支援、情シス調査、SUBARU・フジテックの組織再設計、今治市DX、ERP連携強化が同日に出た。

CONTEXT 背景・要点

PoCを超えるには、データ統制、部門運営、費用回収、運用責任を同時に示す必要があり、単体機能だけでは採用が進みにくい。

OUTLOOK 影響・展望

実装件数や自治体横展開が伸びるかどうかで、運用設計を握るSIとSaaSの優位が見えやすくなる。

→ §03 IT 詳細を読む
§04
◎ MOBILITY / モビリティ

自動運転は例外審査から制度本則へ

FACT 事実・概要

米FMVSS見直し案、武蔵野市の実証、ロンドンのロボタクシー事前登録、MGの欧州向けEV披露が並んだ。

CONTEXT 背景・要点

AVは目新しい実証より、認可ルート、インフラ協調、通常運賃での運営を固められるかが勝負になっている。

OUTLOOK 影響・展望

規則の適用範囲と自治体案件の採算が見えれば、自動運転の投入順が一段具体化しそうだ。

→ §04 モビリティ 詳細を読む
§05
⬢ MANUFACTURING / 製造

工場移管と供給ソフト見直しが同時進行

FACT 事実・概要

トヨタの北米移管、シノプシスの工場ソフト停止、FUSO BUS新会社、血液製剤新工場、クリーンパイプ逼迫が同日に並んだ。

CONTEXT 背景・要点

量産能力だけでなく、工場配置、運用ソフト、部材供給のどこで詰まるかを先回りして直す投資が増えている。

OUTLOOK 影響・展望

北米移管の採算、ファブ運用負荷、新工場立ち上がりが次の数字として問われる。

→ §05 製造 詳細を読む
§06
■ ECONOMY / 経済

政策文言と物価期待が配分を揺らす

FACT 事実・概要

1年先インフレ期待3.7%、骨太原案の修正検討、NY連銀総裁の見通し、NY株反落、アジア株の業種ローテーションが出た。

CONTEXT 背景・要点

景況感改善と物価警戒が同居し、Fedと日本政府の言葉選びが金利、株式、業種配分へ直結する局面になっている。

OUTLOOK 影響・展望

次のCPIとPCE、骨太決定版、決算発表で、政策メッセージが本当に資金配分を変えるかを見たい。

→ §06 経済 詳細を読む
