§01
¥ FOREIGN EXCHANGE / 為替

ドル円159円台で膠着・介入ラインと利上げ観測が「均衡なき均衡」を形成

FACT 事実・概要

ドル円は5/22 NYクローズで159.18円と2週連続上昇で週を終えたが、東京都区部コアCPI 1.4%（4年ぶり低水準）を受けて9月利上げ観測に若干の陰りが生じた。

CONTEXT 背景・要点

日銀・植田総裁が「下振れなければ利上げ可能」と明言したことで市場はスワップでのプライシングを維持。9月25bps利上げ確率は依然57%水準で、週明けは雇用統計とBOJシグナル次第の構図が続く。

OUTLOOK 影響・展望

介入ライン160円は依然有効。財務省は5月初旬の5兆円介入効果が半減した後も「対話を重視する」姿勢で、週明けの雇用統計待ちの構図が持続する。

§02
◆ ARTIFICIAL INTELLIGENCE / AI

$4兆IPOウェーブ・AIの「産業化」が資本市場に問いかけるもの

FACT 事実・概要

SpaceXが5/20にS-1提出（評価額$1.75兆）、OpenAIが5/22にS-1提出（9月上場目標・評価額$8,520億）、Anthropicが10月を目標とする3社のIPO競争が同時進行している。

CONTEXT 背景・要点

アナリストは「3社合計$4兆」という史上最大規模のIPOウェーブが投資家のリスク選好を飽和させ、Magnificent-7 への資金フローを分散させる可能性を指摘する。

OUTLOOK 影響・展望

SpaceXのS-1開示でAnthropicへの月額$12.5億のクラウドコンピュート契約が判明。AI同士の相互依存という新たな産業構造が可視化された。

→ §02 AI 詳細を読む
§03
⌗ IT & CONSULTING / IT

Google $750Mがコンサル二極化を加速・エージェント実装の「早者勝ち」

FACT 事実・概要

DeloitteがGoogle Cloud専任のAgentic Transformation Practiceを設立。同社内の10万名以上にGemini Enterpriseをロールアウトし、クライアント向けのGenAIエージェント実装を専門部隊が担う体制が整った。

CONTEXT 背景・要点

Google Cloudの750億円規模パートナーファンド（$750M）の最大受益者として、DeloitteはFDE（Forward Deployed Engineer）の共同派遣を受け、顧客案件の技術深度を確保できる仕組みを確立している。

OUTLOOK 影響・展望

Deloitteが公表した内部調査では「74%の企業がAIに期待するが、実績は20%止まり」という「死の谷」の実態があり、今回の専任体制はその解消が主目的。

§07
▶ GAMING / ゲーム

Star Fox確定・Miyamoto示唆でSwitch 2夏コンテンツが完成形へ

FACT 事実・概要

任天堂がStar Fox新作の6月25日発売を再確認。1997年のStar Fox 64のステージ構成をそのままに、グラフィックスをSwitch 2向けに大幅パワーアップ。新規シネマシーン（ジェームズ・マクラウドのエピソード）も収録。

CONTEXT 背景・要点

最大8人対戦のオンラインモード・シェアプレイ対応・マウスコントロール対応が発表。ダウンロード版5,480円・パッケージ版6,480円と価格設定もFF7 Rebirth 6/3発売を意識したトップバリューを実現。

OUTLOOK 影響・展望

週明けの6月にはFF VII Rebirth (6/3)・Star Fox (6/25) の2本が続く。Switch 2版Splatoon Raiders (7/23)も公式確認済みで、任天堂の秋へのブリッジ戦略が鮮明に。

→ §07 ゲーム 詳細を読む
