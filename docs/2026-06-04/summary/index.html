§01
FOREIGN EXCHANGE / 為替

160円前後で「二重試練」に備える攻防

FACT 事実・概要

USD/JPY は160円台に乗せた後、財務省・日銀の介入警戒で上値が重い。

CONTEXT 背景・要点

【事実】：USD/JPY は160円台に乗せたが、財務省の直接介入警戒から上値は重く、過去21か月ぶり高値の160.73円に再び接近しつつある

OUTLOOK 影響・展望

【背景】：6月16日のBOJ（スワップ市場66%利上げ織り込み）と6月17日のFOMC（ウォーシュタカ派初会合）が相場を挟む「バイナリー」な政策週 介入か利上げかの二択が迫る

§02
ARTIFICIAL INTELLIGENCE / AI

「OpenAI依存脱却」が技術競争の新テーマに浮上

FACT 事実・概要

Microsoft がMAI-Code-1-Flashを投入し、OpenAI製モデルへの依存度削減に乗り出した。

CONTEXT 背景・要点

【事実】：Microsoft はMAI-Code-1-Flashを発表。テキスト記述からアプリケーションのソースコードを生成する同社初の自社開発コーディングモデルで、Buildカンファレンスで公開

OUTLOOK 影響・展望

【背景】：OpenAIへのコスト依存と競合リスクを軽減する戦略的自立化の一手。MicrosoftはAzure経由でOpenAIモデルを再販しながら並行して自社モデルを育成する二重構造を採用

→ §02 AI 詳細を読む
§03
IT & CONSULTING / IT

DeployCoが「コンサルの解体業者」として上陸

FACT 事実・概要

OpenAI DeployCoがコンサル市場に直接参入し、Accenture・McKinseyが長年独占してきた企業AI実装領域を狙っている。

CONTEXT 背景・要点

【事実】：OpenAI は5月11日、$10B評価のDeployCo（出資$4B、TPG主導）を設立。Accenture やMcKinseyが長年独占してきた企業向けAI実装の$375B市場を直接ターゲット

OUTLOOK 影響・展望

【背景】：AI咨询会社Tomoroを買収し150名のForward Deployed Engineer（FDE）を即日投入。クライアント企業内部に入り込んでワークフローをゼロから再構築するモデルはコンサルの知識販売型と根本的に異なる

§04
MOBILITY / モビリティ

Waymoが「量」でTeslaを圧倒、中国が第三極に浮上

FACT 事実・概要

Waymo 週50万ライド・10都市に対し、Tesla はオースティン全域拡大でもフリートは39台。

CONTEXT 背景・要点

【事実】：Tesla は6月3日、無人Robotaxiのジオフェンスをオースティン全域に拡大。マスク の公式確認後、オースティンメトロ全エリアでアプリ予約が可能に — ただし稼働車両は推定わずか39台

OUTLOOK 影響・展望

【背景】：ダラスとヒューストンは4月のローンチから車両数がゼロ成長（3台と6台のまま）。マスクは「FSD v15のリライト完了後（2026年末〜2027年初）に本格増車」と述べ、5都市への拡大も延期

§05
MANUFACTURING / 製造

BYDの垂直統合完成、日本の統合交渉は足踏み

FACT 事実・概要

BYDが中国初の4nm車載ADASチップ量産を開始し、EVから電池・パワー半導体・ADASまでの完全垂直統合が実現しつつある。

CONTEXT 背景・要点

【事実】：BYD は自社初の4nm車載ADASチップ「玄機A3（Xuanji A3）」の量産を開始。BYD Semiconductor製の同チップはBYDにとって567枚目の自動車グレードチップで、中国初の4nm品

OUTLOOK 影響・展望

【背景】：80 TOPS（毎秒80兆回演算）の処理性能を持ち、NVIDIA DRIVEやHorizon Roboticsに対抗。BYD-TSMC・MediaTek協業の4nm次世代コックピットチップとは別ライン
