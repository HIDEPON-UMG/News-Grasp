為替 — 160円前後で「二重試練」に備える攻防

  • 【事実】：USD/JPY は160円台に乗せたが、財務省の直接介入警戒から上値は重く、過去21か月ぶり高値の160.73円に再び接近しつつある
  • 【背景】：6月16日のBOJ（スワップ市場66%利上げ織り込み）と6月17日のFOMC（ウォーシュタカ派初会合）が相場を挟む「バイナリー」な政策週 介入か利上げかの二択が迫る
  • 【展望】：介入の発動ラインは直近の160.00〜160.73円レンジ上端とみられており、5月末以降の¥11.73兆円介入効果が既に薄れていることが短期勢の攻勢材料に

§04 IT

IT — DeployCoが「コンサルの解体業者」として上陸

OpenAI DeployCoがコンサル市場に直接参入し、Accenture・McKinseyが長年独占してきた企業AI実装領域を狙っている。Accentureはガートナー首位評価で防衛壁を示したが、FDE型「現場に入り込む実装業者」モデルは従来の知識販売型コンサルと根本的に異なる価値提案で、業界の収益構造そのものへの挑戦だ。

  • 【事実】：OpenAI は5月11日、$10B評価のDeployCo（出資$4B、TPG主導）を設立。Accenture やMcKinseyが長年独占してきた企業向けAI実装の$375B市場を直接ターゲット
  • 【背景】：AI咨询会社Tomoroを買収し150名のForward Deployed Engineer（FDE）を即日投入。クライアント企業内部に入り込んでワークフローをゼロから再構築するモデルはコンサルの知識販売型と根本的に異なる
  • 【展望】：「独占を崩す楔」：BCG・McKinseyが戦略・オペモデル担当、Accenture・Capgeminiがシステム統合担当という旧来の分業体制に、OpenAIがシステム実装の直接受注という楔を打ち込んだ形

§05 モビリティ

モビリティ — Waymoが「量」でTeslaを圧倒、中国が第三極に浮上

Waymo 週50万ライド・10都市に対し、Tesla はオースティン全域拡大でもフリートは39台。自動運転の覇権争いは「AIモデルの精度」から「何台走らせられるか」という製造・規制・資本の戦いに移行した。デトロイトニュースが警告する中国AV勢の急追も加わり、米国2強＋中国10社超という多極化構図が明確に。

  • 【事実】：Tesla は6月3日、無人Robotaxiのジオフェンスをオースティン全域に拡大。マスク の公式確認後、オースティンメトロ全エリアでアプリ予約が可能に — ただし稼働車両は推定わずか39台
  • 【背景】：ダラスとヒューストンは4月のローンチから車両数がゼロ成長（3台と6台のまま）。マスクは「FSD v15のリライト完了後（2026年末〜2027年初）に本格増車」と述べ、5都市への拡大も延期
  • 【展望】：「版図は広げたが兵士がいない」：オースティン全域カバーは戦略的訴求力があるが、Waymoが同10都市で週50万ライドを提供しているのと並べると拡大速度の差は歴然

§06 製造

製造 — BYDの垂直統合完成、日本の統合交渉は足踏み

BYDが中国初の4nm車載ADASチップ量産を開始し、EVから電池・パワー半導体・ADASまでの完全垂直統合が実現しつつある。対照的に日本のローム/東芝/三菱電機統合は「想定より時間必要」と難航。サプライチェーンの主権をめぐる日中の「速度の差」が、中長期の競争力を左右する。

  • 【事実】：BYD は自社初の4nm車載ADASチップ「玄機A3（Xuanji A3）」の量産を開始。BYD Semiconductor製の同チップはBYDにとって567枚目の自動車グレードチップで、中国初の4nm品
  • 【背景】：80 TOPS（毎秒80兆回演算）の処理性能を持ち、NVIDIA DRIVEやHorizon Roboticsに対抗。BYD-TSMC・MediaTek協業の4nm次世代コックピットチップとは別ライン
  • 【展望】：垂直統合の最終章：EV本体→電池（FinDreams）→パワー半導体→ADASチップ、とサプライチェーン全体を内製化。「中国EVメーカー」から「車載半導体メーカー」へのパラダイムシフトが完成しつつある
