総論 — 公開ルールと供給線を先に見る

FX、AI、Mobility、Manufacturing、Gameが同じ朝に並び、商品や機能の見栄えより公開ルールと供給線の握り方が前に出ました。市場は完成品より先に、流れを決める側を見ています。IT でも SaaS の名前より、人の作業をどう置き換えるかが論点になりました。

§02 為替

為替 — 161円台後半、介入より金利差が先

ドル円は161円台後半で推移し、161.96円の節目を意識した介入警戒が続きました。いっぽうで、日銀総裁は経済・物価・金融情勢に応じて利上げを続ける姿勢を示し、口先介入より金利差の縮まり方が相場の説明軸になっています。早期利上げを求める会合内の意見も、その読みを補強しました。

FACT
【事実】
ドル円はNY終盤に161.78円まで上げ、161.96円を超えれば1986年以来の円安水準に入るため、介入警戒が相場の上値を抑えている。
CONTEXT
【背景】
FRBの年内利上げ観測がドル買いを支え、ユーロにもドル高が波及した一方で、日本当局の口先介入は流れを変え切れていない。
OUTLOOK
【展望】
日銀会合で早期利上げ論が複数確認されたものの、日米金利差の圧力がなお優勢で、165円シナリオへの警戒が残った。

§03 AI

AI — チップと防衛導入で実装へ

OpenAIはJalapeño推論チップをBroadcomとGW級展開へ進め、SoftBankは重要インフラ向けのAI防衛を無償展開しました。国内では富士通のPHOTONが推論性能を押し上げ、DeepMindとNVIDIAのDiffusionGemma、Anthropicの日本アンバサダー募集まで含めて、推論基盤と防御へ重心が移っています。モデル性能だけでなく実装面を見る日です。

FACT
【事実】
JalapeñoはLLM推論専用にゼロから設計され、GPU依存の供給制約をOpenAIが自前シリコンで崩しにいく意思を鮮明にした。
CONTEXT
【背景】
BroadcomとCelesticaを組み合わせた量産経路を約9カ月でテープアウトまで進めた点は、モデル会社の垂直統合を一段押し上げる。
OUTLOOK
【展望】
26年末までにギガワット級データセンター展開を始める計画はChatGPTやCodexの原価低下と供給安定化に直結し、推論単価競争の主戦場をさらに下流へ移す。

§04 IT

IT — SaaSは残り、作業の置き換えが進む

SaaS不要論が出ても、日経はソフトそのものより人の作業が置き換わると整理しました。電通はAIペルソナをSaaS化し、日本IBMとINPEXはクラウド前提の基幹刷新を進めています。売り物の名称より現場の往復を何回減らせるかが論点で、常時監視型の運用外部化もその延長です。

FACT
【事実】
AIエージェントの普及で「SaaSの死」が語られる一方、記事は企業現場では業務ソフトとの併用が主流だと整理した。
CONTEXT
【背景】
代替の中心はソフトそのものではなく、入力・確認・転記といった人の作業であり、SaaS側にはAIを組み込む再設計余地が残る。
OUTLOOK
【展望】
業務ソフト株への見方が修正されれば、AI時代の投資判断は「置き換え」より「併用して何を減らすか」へ移りやすい。

§05 モビリティ

モビリティ — 規則と補助金が市場を広げる

国連は自動運転の初の包括規則を採択し、Waymoは2億2000万マイルの安全実績を更新しました。東京都はEV補助を130万円へ引き上げ、日産とヴァレオは欧州V2Gを商用化へ進めています。認証・補助・充電の回路が市場を広げ、ダラスの赤信号無視は安全説明責任の重さも示しました。

FACT
【事実】
WP29は自動運転の初の包括規則を採択し、メーカーに安全管理体制と走行データ記録装置を義務づけた。
CONTEXT
【背景】
焦点は性能評価だけでなく、事故や異常時に当局が検証できるデータを残す責任が国際ルール化された点にある。
OUTLOOK
【展望】
読者が次に見るべきは制度整備が各国でどこまで前倒しされ、量産計画や認証コストにどう波及するかだ。

§06 製造

製造 — 工程表と材料制約で再配置

政府は17分野で370兆円超の工程表を示し、ASEは26年に15工場計画、中国のタングステン禁輸は半導体ガスの急所を浮かび上がらせました。日産の国内5拠点の早期退職や三菱電機のSiC拡大も含め、材料と工程の結び方が競争力を左右しています。量より配置が問われる朝です。

FACT
【事実】
政府の官民投資ロードマップはAI・半導体・造船など戦略17分野に2040年度まで370兆円超を積み上げ、量産能力の土台を政策で先に固める方針を示した。
CONTEXT
【背景】
骨太方針と日本成長戦略に盛り込む前提で打ち出したため、半導体投資は単年度補助金ではなく15年単位の設備計画として扱われ、材料・装置各社の投資回収シナリオを描きやすくする。
OUTLOOK
【展望】
高市政権が責任ある積極財政の目玉に据えたことで、採択・立地・人材確保を巡る競争が前倒しされる公算が大きく、次は配分ルールと実行速度が焦点になる。

§07 経済

経済 — 政策メッセージと決算前の警戒

米財務長官はFRBのフォワードガイダンス縮小を支持し、ベセント氏もインフレ重視を後押ししました。いっぽうでS&P500と日経平均はマイクロン決算前の半導体警戒で下落し、政策の青写真と株式の先回りが別の速度で動いています。高市政権の370兆円投資方針は、中期の成長期待を下支えしました。

FACT
【事実】
ベセント米財務長官は、ウォーシュ議長によるフォワードガイダンス縮小を「市場の杖を外す判断」と評価した。
CONTEXT
【背景】
四半期ごとの金利見通しであるドットプロットにも否定的で、政策運営は事前約束よりその時点のデータで決めるべきだとの姿勢を鮮明にした。
OUTLOOK
【展望】
AIの生産性向上とイラン情勢の沈静化を踏まえ、高成長とインフレ鈍化の両立がFRBの次の説明軸になるかが焦点だ。

§08 ゲーム

ゲーム — 課金回路とマルチプラットフォーム

PS5の販売減速でもソニーのゲーム利益は2ケタ増で、PSN課金が収益を支えました。SteamのAI開示ゲームはレビューが鈍化し、SteamOSやSwitch 2向け展開は広がっています。課金回路と配信面が勝敗を決め、Star Fox とツクヨミの動きもマルチプラットフォーム化の線上にあります。

FACT
【事実】
PS5の出荷は今期に前期比600万台超減の見通しでも、G&NS営業利益は4632億円まで伸びたと整理され、台数依存からの転換が見えた。
CONTEXT
【背景】
利益の主役がPSNの定額課金とドル建て収益へ移り、逆ざや気味のハードが鈍っても全体収益を守れる構造が強まった。
OUTLOOK
【展望】
次の焦点はPS6期でもこの継続収益モデルが維持できるかで、ソニーは日本の存在感低下を補う海外課金基盤の厚みを問われる。
