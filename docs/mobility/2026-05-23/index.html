Waymo、ロンドンで実走テスト開始──東京に続く海外2拠点目、$160億で世界20都市超へ

  • Waymoはロンドンの約100平方マイルで自動運転Jaguar I-Pace 約100台による実走テストを開始し、東京に続く海外2拠点目として2026年内の商用ローンチを英政府の認可待ちで狙う。
  • 年初に調達した$160億（バリュエーション$1260億）を原資に世界20都市超へ拡大する構えで、週100万トリップ（現状の週50万から倍増）を年内目標に据えている。
  • 国内11都市で固めた優位をそのまま国境の外へ持ち出せるかが次の試金石であり、英Wayve・Uberとの現地競争を制せれば「米国発プラットフォームの世界標準化」という構図が一段と鮮明になる。

全固体電池レース最終盤、米中勢が日本を猛追──日産は23層プロトタイプで充放電目標をクリア
