中国、EV・低燃費車の税優遇を2027年廃止へ

FACT
【事実・概要】
中国財政省は2027年から 省エネ車と一部EV商用車の車船税優遇 をやめ、2012年から続いた税支援を見直す 方針を示した。
CONTEXT
【背景・要点】
現行制度では低燃費内燃車は半減、ハイブリッドや一部の燃料電池商用車は免税だった。普及段階から選別段階へ政策軸が移る ことが要点だ。
OUTLOOK
【影響・展望】
中国でのEV需要は購入補助だけでなく保有税条件でも揺れるため、メーカー各社の価格戦略 と 地方普及策の再設計 が次の焦点になる。
