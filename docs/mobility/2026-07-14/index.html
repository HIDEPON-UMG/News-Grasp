日独でEV販売急伸、補助金頼みの持続性に課題

FACT
【事実・概要】
日本の6月EV販売は1万2225台で前年同月の2.8倍、ドイツも8万4057台で78.2%増となり、日独で同時に需要が跳ねた。
CONTEXT
【背景・要点】

OUTLOOK
【影響・展望】
