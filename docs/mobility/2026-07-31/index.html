ロボトラック、52億円調達。国産L4トラックの実装を加速

FACT
【事実・概要】
ロボトラックがシリーズAのファーストクローズで約52億円を調達。5月には厚木南IC〜豊田JCTの約260kmをセーフティドライバーの介入なしで走破した。
CONTEXT
【背景・要点】
政府は2030年度に自動運転トラック1000台の導入を目標に掲げる。資金は車両増備、冗長化、安全性評価、E2E AIなどに充てる。
OUTLOOK
【影響・展望】
高速道路だけでなく一般道・物流施設内まで一体化した国産L4を目指す。安全認証と物流現場への接続が次の焦点だ。

上期の国内EV販売、トヨタが2位に浮上。BYDは9位へ後退

FACT
【事実・概要】
2026年上期の国内EV販売でトヨタ自動車が2位に浮上。補助金が1月に増額されたトヨタやTeslaが伸びる一方、BYDは前年同期比3割減で9位に下がった。
CONTEXT
【背景・要点】
BYDなどは4月の補助金減額の影響を受けた。EVの競争力は車両性能だけでなく、購入時の実質価格と制度設計に左右される。
OUTLOOK
【影響・展望】
メーカー順位の変化は補助金の需給効果を映す。下期の新型車投入と補助制度変更が販売構成をどう変えるかを追いたい。

オモビオ、単眼カメラでE2E自動運転を実験。センサー簡素化で低コスト化

FACT
【事実・概要】
オモビオが東京都内の高速道路でE2E自動運転の実験車を走行させた。前方認識のセンサーを単眼カメラ1台に絞り、AIに認識と判断を担わせる。
CONTEXT
【背景・要点】
中国で学習した走行データを基に、日本で強化学習を実施した。複数センサー方式に比べ、構成を簡素化できる点がコスト低減の余地になる。
OUTLOOK
【影響・展望】
単眼化は量産車への搭載コストを左右する一方、悪天候や安全性評価が課題になる。日本の道路環境での再現性と検証範囲に注目したい。

BYD軽EV、実質199.5万円。日本勢の値上げ依存に新たな競争圧力

FACT
【事実・概要】
BYDの軽EV「RACCO」は、国の補助金適用後で199万5000円。200万円を切る価格で、日本の軽自動車市場に投入された。
CONTEXT
【背景・要点】
国内メーカーは販売台数の減少を補うため、車両価格を引き上げてきた。RACCOはその値上げで成り立つ収益構造を、価格と航続距離の両面から問い直す。
OUTLOOK
【影響・展望】
