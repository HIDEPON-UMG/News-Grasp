FACT
【事実・概要】
Waymoがカリフォルニア州で18郡を対象に有料の完全自動運転配車を展開する承認を取得した。サンディエゴとサクラメントが新たな進出先になる。
CONTEXT

CPUCの承認で運転手なしの運賃収受に残っていた規制上の壁が下がった。Ohaiなど量産しやすい車両への切り替えも拡大の前提になる。
OUTLOOK

テラチャージ、EV急速充電器を2030年までに5倍へ

FACT
【事実・概要】
テラチャージは急速充電設備を2030年3月までに5000口へ拡大する。2026年3月末比で5倍とし、投資額は200億〜300億円を見込む。
CONTEXT
【背景・要点】
EVの普及が緩やかでも、急速充電は立地が使い勝手を決める。先行整備で好立地を押さえ、充電網の規模を競争力に変える狙いだ。
OUTLOOK
【影響・展望】
全国の急速充電器は2025年3月末で約1万2000口にとどまる。投資回収、稼働率、設置場所の重複が拡大計画の実効性を測る。
