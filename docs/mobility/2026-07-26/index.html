ニュージャージー州、自動運転法案がTeslaの方式を直撃

FACT
【事実・概要】
ニュージャージー州で、自動運転車に複数センサーや安全運転手を求める法案を審議している。S1677は、カメラ中心のTeslaに直接効く内容だ。
CONTEXT
【背景・要点】
法案は成立前だが、LiDARとレーダーを併用するWaymoは要件に近い。対してTeslaはカメラとAIを軸にし、Cybercabの無人設計も制度適合性を問われる。
OUTLOOK
【影響・展望】
安全要件を巡る議論が、企業の技術思想から州法の競争条件へ移った。Teslaの反対運動と、S1677の委員会審議・採決時期が次の確認点になる。

Tesla、CybercabにStarlink V5を直接統合へ

FACT
【事実・概要】
Teslaは自動運転タクシーCybercabへ、SpaceXのStarlink V5アンテナを直接組み込む方針を示した。通信速度は375Mbps超とされる。
CONTEXT

OUTLOOK

車両を常時接続された運行端末へ広げる設計は、Teslaのロボタクシー事業の基盤に直結する。実車搭載時期と運用コストが次に見る論点となる。

ホンダ「Super-ONE」、受注1.1万台超の小型BEV

FACT
【事実・概要】
ホンダの小型BEVSuper-ONEは、6月上旬時点で受注1.1万台超に達した。N-ONE e:を基盤に、軽規格を超える車体へ仕立てている。
CONTEXT
【背景・要点】
専用シャシーと仮想7段変速に加え、BOOST時は70kWを発揮する。補助金だけでなく、1090kgの軽さと走りの個性が支持を集めている。
OUTLOOK
【影響・展望】
EVの普及には価格や航続距離だけでなく、運転体験も効く。Super-ONEの受注が、小型BEVの差別化と補助金依存をどう示すかが焦点だ。

フィアット初の小型三輪EV「トリス」登場、2027年から欧州販売へ

FACT
【事実・概要】
Fiatが小型三輪EVTris DolceVitaを発表した。伝説的なPiaggio Apeの電動化を意識し、2027年から欧州販売を予定する。
CONTEXT
【背景・要点】
まずアフリカ・中東向けに開発された車両で、乗用車とは異なる近距離輸送の選択肢になる。小型・三輪・電動を組み合わせた市場設計が特徴だ。
OUTLOOK
【影響・展望】
三輪EVは、配送や短距離移動の電動化を低コストで進める可能性がある。Fiatの欧州展開で、安全基準・価格・用途適合がどこまで広がるかを見たい。
