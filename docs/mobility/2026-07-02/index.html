テスラ韓国法人、補助金継続決定の翌日に主力EVを値上げ

FACT

テスラコリアは「モデル3 プレミアムロングレンジRWD」を 5299万ウォンから5999万ウォンへ700万ウォン 引き上げ、他モデルも300万〜500万ウォン上げた。

FACT

CONTEXT
【背景・要点】

OUTLOOK
【影響・展望】
英国とEUのEV・PHV貿易は 164億ポンド規模 とされる。電池調達と生産拠点の再配置 が進むのか、交渉で再延期や例外措置が出るのかが次の分岐点になる。

FACT

豊田通商など11社、自動運転トラックの国交省事業に採択

FACT
【事実・概要】
豊田通商を代表とする11社コンソーシアムが、国交省の 2026年度「自動運転トラック実装支援事業」 に採択された。ロボトラックと先進モビリティが実証運行を担う。
CONTEXT
【背景・要点】

OUTLOOK
【影響・展望】

NTTモビリティ、自動運転安全管理委員会を新設

FACT
【事実・概要】

CONTEXT
