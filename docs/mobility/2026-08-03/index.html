BYD軽EV「ラッコ」受注700台超、発売直後の需要を確認

FACT
【事実・概要】
BYDの軽EV「ラッコ」の受注が700台を超えた。7月販売は125台だったが、発売から4日間の登録で大半は試乗車とされる。
CONTEXT
【背景・要点】
販売台数だけでは初動を測りにくいなか、受注が販売店登録を上回る。日本専用の軽規格に合わせた価格・商品設計が需要を試す。
OUTLOOK
【影響・展望】
今後は受注の納車転換と販売網の拡大が焦点になる。国内勢が軽EVの品ぞろえと補助金依存をどう見直すかにも波及する。

FACT
