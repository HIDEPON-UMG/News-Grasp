KDDI、堺市の自動運転タクシー実装に参画

FACT
【事実・概要】
KDDIとKDDIスマートモビリティが堺市の自動運転タクシー実装コンソーシアムに参画する。通信・遠隔監視とGPU基盤を提供し、2028年のレベル4商用化を支える。
CONTEXT
【背景・要点】
車両と監視センターを常時接続し、地域固有の走行データをAIに学習させる構えだ。ドライバー不足への対応を、通信・計算基盤まで含む運行設計として進める。
OUTLOOK
【影響・展望】
実証の走行範囲、遠隔監視の安全運用、AI基盤の学習成果が次の確認点になる。堺市の取り組みが、自治体と通信事業者の標準的な連携モデルへ育つかを追う。

GO、EVタクシー230基超を電力需給調整に活用

FACT
【事実・概要】

日産車体子会社、中古トラックをEVへ改造

FACT
【事実・概要】
日産車体の100%子会社オートワークス京都が、中古トラックをEVへ改造する。新車の4分の1程度の実質価格を狙い、日産アトラスから始める。
CONTEXT
【背景・要点】

OUTLOOK

FACT
