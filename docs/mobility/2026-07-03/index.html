テスラの中国製EV販売、6月24.4％増 欧州回復で8カ月連続プラス

FACT
【事実・概要】
テスラの6月の中国製EV販売は 8万9091台 と前年同月比24.4％増え、欧州向け輸出を含めて8カ月連続の増加 になった。
CONTEXT
【背景・要点】
対象は上海工場のモデル3とモデルYで、4〜6月の中国国内販売と輸出の合計も 32.8％増。欧州で燃料高を受けたEV需要回復 が追い風になっている。
OUTLOOK
【影響・展望】
BYDは4〜6月に 55万7090台 のBEVを販売しており、テスラが中国生産と欧州回復でどこまで差を縮めるか が次の焦点だ。
