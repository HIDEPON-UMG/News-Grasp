Waymo Breaks Up With Uber (Sort Of) Waymo、Uberとの独占契約を2028年1月に終了へ（条件付き）

FACT
【事実・概要】
：WaymoはオースティンとアトランタでのUberとの独占提携を2028年1月に終え、自社アプリから直接呼べる形へ移す方針を示した。契約自体は2028年5月まで続く。配車の入り口を自社に戻す動きだ。
CONTEXT
【背景・要点】
：両市以外では既に自社アプリが主経路で、独占は例外的な形だった。あわせて同社は悪天候時に運行を一時停止・縮小する冬季計画も示した。拡大と安全マージンの両立が運営の前提になっている。
OUTLOOK
【影響・展望】
：プラットフォーム依存の解消は顧客接点とデータを運行業者側に戻す。配車大手との力関係が自動運転の普及速度を左右する局面だ。

The Daily Brief: NHTSA Opens Waymo School Bus Recall Query NHTSA、Waymoのスクールバス関連リコールに調査開始　対象2,895台

FACT
【事実・概要】
：米NHTSAは6日、Waymoのスクールバス関連リコールについて調査クエリRQ26006を開き、2,895台が対象になった。停車中のバスを追い越す事案がソフトウェア修正後も報告されたことが発端だ。直したはずの不具合の検証が目的になる。
CONTEXT
【背景・要点】
：同社は2025年12月にリコール25E084を届け出て、対象車両へのOTA更新を完了したとしていた。報告された事案の多くはその後に起きている。修正の実効性を当局が確かめる段階に入った。
OUTLOOK
【影響・展望】
：焦点は調査結果が追加のリコールや運行条件につながるかで、安全実績の説明が新規都市の許認可にも波及する。透明な開示が拡大の通行証になる。
