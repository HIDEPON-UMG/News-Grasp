Waymoロボタクシーが洪水路に再進入、5都市で運行停止──全3,791台のパッチが2週間で失敗

FACT
記者／事実・概要
Waymoはアトランタで自社ロボタクシーが冠水した道路に進入し約1時間立ち往生したことを受け、Atlanta・Austin・Dallas・Houston・San Antonioの5都市で運行を停止したと5月22日に報じられた。
CONTEXT
解説者／背景・要点
4月20日の制限速度40mph区間での冠水進入を受け全3,791台にOTAパッチを配布したが、2週間も経たずに別の車両が再び冠水路へ進入し、応急修正では根治できないことが露呈した。
OUTLOOK
予測者／影響・展望
「水たまりを検知しても減速だけで停止しない」という設計上の穴は、社会的信頼が最重要な自動運転にとって最も危険なクラスの欠陥であり、規制当局の本格介入と展開ロードマップ後退のリスクが一気に高まった。
