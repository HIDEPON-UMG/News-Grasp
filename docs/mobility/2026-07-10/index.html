テスラ、日本のEVにGrok搭載 OTAで音声検索強化

FACT
【事実・概要】
テスラは日本向けEVに対話型AI「Grok」の配信を始め、運転中の音声検索とナビ操作をOTAで順次有効化する。
CONTEXT
【背景・要点】
ハード刷新よりもソフト更新で体験を上積みできる点が強みで、EVを「走る端末」に近づける競争が日本市場でも前面に出てきた。
OUTLOOK
【影響・展望】
車載AIが定着すれば検索・案内・車内操作の主導権が移り、完成車の差別化軸は航続距離だけでなく更新速度とAI品質へ広がる。

BYD、軽EV「ラッコ」を7月28日発売 日本向け専用車で軽市場参入

FACT
【事実・概要】
BYDは日本専用の軽EV「RACCO」を7月28日に発売し、広瀬アリスさん起用の新CMで投入を本格告知した。
CONTEXT
【背景・要点】
人気のスーパートールワゴンにスライドドアと最大320km航続を組み合わせ、日本の軽規格へ正面から合わせ込んだ初の中国勢量販車になる。
OUTLOOK
【影響・展望】
軽EV市場に価格・装備競争が持ち込まれれば、日産やホンダ系の国内勢は商品改良と販売戦略の再設計を迫られ、日本のEV普及ペースにも影響する。

日産「サクラ」累計販売10万台 国内EVの3割占める

FACT
【事実・概要】
日産は軽EV「サクラ」の国内累計販売が10万台に達したと発表し、日本の量販EVで存在感を改めて示した。
CONTEXT
【背景・要点】
発売から約4年で国内累計EV販売の約3割を占めたことは、高価な大型EVよりも軽規格・価格・使い勝手が普及の主戦場である現実を映す。
OUTLOOK
【影響・展望】
BYDラッコの参入で軽EV競争が深まれば、航続距離や給電機能だけでなく価格と補助金後の実負担が比較軸となり、日本市場の勝ち筋がより鮮明になる。
