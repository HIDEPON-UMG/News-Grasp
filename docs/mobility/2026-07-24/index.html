欧州新車販売、電動車と中国ブランドが成長をけん引

FACT
【事実・概要】
欧州新車販売は6月に前年同月比13%増となった。BEVは51%増、PHEVは22.7%増で、電動車が市場全体を押し上げた。
CONTEXT
【背景・要点】
ガソリン車とディーゼル車の不振を、電動車と中国ブランドの販売拡大が補った。BYDなどの攻勢は、欧州メーカーの価格・商品競争を強める。
OUTLOOK
【影響・展望】
欧州では電動化の需要が一段と鮮明になった。今後は中国ブランドの現地生産・販売網と、既存メーカーの採算改善が焦点になる。

吉利、フォード工場でEV生産へ　欧州現地化を加速

FACT
【事実・概要】
吉利汽車とフォードが欧州で提携し、スペイン工場でEV・SUV 2車種を生産する。2028年の出荷開始を見込む。
CONTEXT
【背景・要点】
フォードの低稼働工場を活用し、中国メーカーが欧州の現地調達ルールに対応する。バレンシア工場の稼働率は2025年で26%だった。
OUTLOOK
【影響・展望】
吉利にとって欧州初の生産拠点となる。中国車の現地化と欧州メーカーの設備再利用が、競争地図を変える可能性がある。

T2とPFN、自動運転トラックのレアシーン認識を改善

FACT
【事実・概要】
T2とPreferred Networksが、自動運転トラックのレアシーン合成に関する研究成果を発表する。歩行者や落下物の認識精度向上を検証した。
CONTEXT

OUTLOOK
【影響・展望】
T2は2027年度以降のレベル4幹線輸送を目指す。レアケースを学習した認識モデルが実運行の安全説明に耐えるかを見たい。
