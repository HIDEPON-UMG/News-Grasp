FACT
【事実・概要】
トヨタが米国製初の3列EV「ハイランダー」の生産開始を延期し、2026年後半発売計画の見直しを認めた。
CONTEXT
【背景・要点】
米国でHV版ハイランダー系が上半期10万台超売れ、EV税額控除廃止とCAFE罰金ゼロ化で急ぐ理由が薄れた。
OUTLOOK
【影響・展望】
EV移行の速度は政策と採算で再調整局面に入り、ヒョンデ・起亜・テスラが先行する市場でトヨタの再提示時期が焦点になる。
