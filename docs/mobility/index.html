テスラ韓国法人、補助金継続決定の翌日に主力EVを値上げ

FACT
【事実・概要】
テスラコリアは「モデル3 プレミアムロングレンジRWD」を 5299万ウォンから5999万ウォンへ700万ウォン 引き上げ、他モデルも300万〜500万ウォン上げた。
CONTEXT
【背景・要点】
韓国政府は前日にテスラを含む27社への下半期補助金継続を公表した。会社側は 為替と原材料高 を理由に挙げたが、補助金を織り込んだ値上げではないか との見方が広がった。
OUTLOOK
【影響・展望】
テスラは1〜5月に 4万5020台 を売って韓国EV市場を先導している。補助金の恩恵が消費者価格に残るのか と、競合各社が追随するかが次の焦点だ。

英EV業界、EU原産地規則なら14億ポンドの関税負担

FACT
【事実・概要】
英国自動車工業会SMMTは、EUとの原産地規則で解決策が出なければ 14億ポンド の関税負担が生じると試算した。対象はEVとPHVの7割に及ぶ。
CONTEXT
【背景・要点】
規則の厳格化は2023年に一度延期されたが、2027年1月 から再び発効予定だ。欧州委員会の Made in EU 案も重なり、英国組み立て車の販売余地 に不透明感が増している。
OUTLOOK
【影響・展望】
英国とEUのEV・PHV貿易は 164億ポンド規模 とされる。電池調達と生産拠点の再配置 が進むのか、交渉で再延期や例外措置が出るのかが次の分岐点になる。

スズキ、インド・アーメダバードで次世代自動運転交通を調査

FACT
【事実・概要】
スズキはThoth、Glydwaysと覚書を結び、インド西部アーメダバードのターミナル駅周辺で 次世代モビリティ導入の調査 を始める。小型EVの自動運転公共交通 が前提だ。
CONTEXT
【背景・要点】
対象は高速鉄道接続を見込むSabarmati Multimodal Hub周辺で、Glydwaysの PRT（専用レーン型の小型電動車両） を検討する。渋滞緩和と低コスト導入 を両立しやすいのが売りになる。
OUTLOOK
【影響・展望】
スズキは車両販売だけでなくインフラ型モビリティへ踏み込む構えを強めた。高速鉄道の結節点と地域交通をどう一体設計するか が、インドでの都市交通モデルの試金石になる。
04 2026-07-02 · ロボトラック 86

豊田通商など11社、自動運転トラックの国交省事業に採択

FACT
【事実・概要】
豊田通商を代表とする11社コンソーシアムが、国交省の 2026年度「自動運転トラック実装支援事業」 に採択された。ロボトラックと先進モビリティが実証運行を担う。
CONTEXT
【背景・要点】
参画企業には大塚倉庫、佐川急便、福山通運、日野自動車などが並び、昨年度より参加物流会社が増えた。関東〜関西の物流拠点間でセミトレーラー実証 を進め、積載効率と運用条件を詰める。
OUTLOOK
【影響・展望】
自動運転トラックは単独実証から共同運用モデルの検証段階へ進んだ。荷主と物流会社が同じ前提で導入条件を固められるか が、2027年以降の幹線輸送商用化を左右する。

NTTモビリティ、自動運転安全管理委員会を新設

FACT
【事実・概要】
NTTモビリティは7月1日、自動運転安全管理委員会 を設立した。外部有識者を含む3つのワーキンググループ で、安全ルールと運用体制を整える。
CONTEXT
【背景・要点】
委員会はグループ共通の安全管理フロー、事故対応マニュアル、事故事例分析、演習計画を扱う。法務・技術・調査 を分けて検討する構成は、実証から運用へ移る前提作り といえる。
OUTLOOK
【影響・展望】
NTTグループは2027年度までの自動運転社会実装を視野に置く。個別実証で蓄えた知見を全国標準へ変換できるか が、通信主導の自動運転運用モデルの評価軸になる。
