MK、バナジウムイオン蓄電池でEVタクシー充電を実証

FACT
【事実・概要】
MKはバナジウムイオン電池の蓄電システムを導入し、EVタクシーの急速充電に使う実証を始めた。電力ピークを抑え、電気基本料金を20〜25%削減できるかを確かめる。
CONTEXT
【背景・要点】

OUTLOOK
【影響・展望】
実証は1年間で、結果を踏まえて本格導入を判断する。EV台数が増えた拠点での総コストと保守性が、タクシー・物流事業者の採用判断を左右する。
