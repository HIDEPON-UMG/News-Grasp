FACT
【事実・概要】
日本の6月EV販売は1万2225台で前年同月の2.8倍、ドイツも8万4057台で78.2%増となり、日独で同時に需要が跳ねた。
CONTEXT
【背景・要点】
国のCEV補助上限は130万円に引き上げられ、自治体補助やガソリン高も追い風になった一方、需要の自走力はまだ見極め段階にある。
OUTLOOK
【影響・展望】
トヨタのbZ4Xや日産リーフなど国内勢の新車投入は追い風だが、補助金縮小後の販売持続性が見えない限り、普及ペースの本格加速は読み切れない。
