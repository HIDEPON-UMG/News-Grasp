BYD、日本専用の軽EVで日本市場の巻き返しへ

FACT
【事実・概要】
BYDが日本専用の軽EV「RACCO（ラッコ）」を7月28日に発売する。背高ワゴンとスライドドアを採用し、価格と補助金が初動を左右する。
CONTEXT
【背景・要点】
BYDは2023年の日本参入後、2025年の乗用車販売が3,742台にとどまった。国の補助金は現行一律15万円で、日本車との実質価格差が残る。
OUTLOOK
【影響・展望】
補助金を含めて200万円以下なら日本勢も警戒すべきとの見方がある。受注目標1万台に向け、販売網と電池の信頼性が次の評価軸になる。

能登の道路復旧、遠隔・自動運転重機で安全性を検証

FACT
【事実・概要】
