トヨタ、次世代EVを見直し 後継車へ技術転用し投入時期は再設定へ

  • トヨタは次世代EVの計画をいったん止め、後継車種へ技術を転用する方向へ舵を切った。投入時期を決め打ちしない点も含め、慎重姿勢が鮮明だ。
  • 焦点は販売台数の上積みより、どの技術をどの車種で先に回収するかへ移った。EV専用車を増やすより、採算の立つ投入順を組み直す判断と読める。
  • 日本勢のEV戦略は遅れだけで測れなくなった。後継車種に要素技術を先回しで載せるなら、次に見るべきは電池調達と価格設定がどこまで変わるかだ。
