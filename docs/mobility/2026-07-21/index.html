ロボタクシー指数、BaiduとWaymoが首位争い　日本勢は圏外

FACT
【事実・概要】
Baiduが自動運転タクシー指数で1位、累計乗車回数2200万回と10都市での無人商用運行が示された。Waymoは僅差の2位だった。
CONTEXT
【背景・要点】
指数は技術、規模、収益、提携、安全性などをAIで評価し、12時間ごとに更新する。順位は固定の市場シェアではなく、評価軸と時点を確認して読む必要がある。
OUTLOOK
【影響・展望】
中国勢の運用規模と米国勢の都市展開が競う構図が続く。日本勢はランキング対象外で、商用運行の実績づくりが次の焦点になる。

XPeng、ロボタクシーを8カ月で量産テストへ　チップから車両まで内製

FACT
【事実・概要】
XPengが計画発表から8カ月でロボタクシーの量産1号車と社内テストをつないだ。Turing AIチップ4基とVLA 2.0を載せ、2026年7月10日に試験を始めた。
CONTEXT
【背景・要点】
チップ、AI、車両を自社で束ね、LiDARやHDマップに頼らない純視覚方式を選んだ。自社で車隊を運行せず技術を供給するイネーブラー型も特徴だ。
OUTLOOK
【影響・展望】
開発・量産の速さは中国勢の強みとして浮上するが、WaymoやBaiduの運用実績との差は残る。量産速度と安全運用の成熟度を分けて見る必要がある。

VW傘下Moia、ハンブルクで自動運転シャトルを試験運行

FACT
【事実・概要】
Moiaがハンブルクで電動ミニバンID. Buzzを使う自動運転シャトルを開始する。初期5台から最大10台へ広げ、安全監視員を車内に置く。

OUTLOOK
【影響・展望】
VWは車両販売だけでなくMaaS運行へ踏み込む。hvv switchとの連携と、監視員なしへ移る条件が欧州展開の見極めどころになる。
