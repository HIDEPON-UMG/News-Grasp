BYD、日本専用の軽EV「RACCO」を発売

FACT
【事実・概要】
BYDが日本の軽規格に準拠した専用EV「RACCO」を発売した。価格は214万5000円からで、航続距離は210〜320km。
CONTEXT
【背景・要点】
海外メーカー初の軽EVとして、長期保証とOTA更新を組み合わせる。価格だけでなく購入後の安心まで軽市場の競争軸に持ち込んだ。
OUTLOOK
【影響・展望】
年間1万台の販売目標を掲げる。実際の受注と販売網の広がり、日本勢の補助金込み価格との差が次の焦点になる。

豊田通商、都市型小型EV「Lean3」を法人向けに販売

FACT
【事実・概要】
豊田通商が、都市型小型EV「Lean3」の法人向け販売代理店となる契約をリーンモビリティと結んだ。販売に加えリースも扱う。
CONTEXT
【背景・要点】
小回りの利く車体を生かし、狭い路地の配送や都市部の営業・巡回を主な用途に想定する。法人の導入形態を広げる契約だ。
OUTLOOK
【影響・展望】
車両価格だけでなく、リース、保守、充電を含む運用設計が重要になる。ラストワンマイルの採算と稼働率を見たい。
