§01 ★ 総論

総論 — AI資本と産業の分岐が同時進行した一日

今日のマーケットは「AI時代の資本主義の形成」と「旧来産業の現実的調整」が同時進行している。Anthropicの評価額9650億ドルIPO申請、NVIDIAの年間52兆円売上予測という数字が、もはやデジタル産業の規模を超えて「国家経済に匹敵する企業」の輪郭を描き始めている。一方でトヨタはEV車種を廃止し、現実路線への回帰を選択した。加速と減速が同日に報じられたことが今日の通底テーマだ。

§02 ¥ 為替

為替 — 159円台の膠着とWarsh初FOMCへの視線

ドル円は159.27円前後で膠着。Warsh初FOMC（6/17）を前に、タカ派シフト期待からドルが底堅く推移している。政府・日銀が160円防衛ラインを維持しており、投機的な上昇は介入警戒で抑制される。MUFG予測の159〜162円レンジが今週の実態を正確に映しており、急変動なき静かな円安が続くシナリオが最有力だ。

FACT
【事実・概要】
ドル円 は 159.27円前後で推移。6月1日高値は159.70円を記録し、Warsh初FOMC直前の緊張感の中で方向感を欠く展開
CONTEXT
【背景・要点】
6月17日のWarsh新FRB議長による初回FOMC会合を前に、タカ派シフト期待からドルが底堅く推移。7月利上げ観測が新たな相場の重しに
OUTLOOK
【影響・展望】
政府・日銀が160円防衛ラインを堅持しており、投機的な上昇は介入警戒で抑制。USD/JPY は狭いレンジ内で方向感を探る展開が続く

§03 ◆ AI

AI — Anthropic、OpenAI、SpaceX──3兆ドル上場ラッシュの幕開け

Anthropicが機密S-1をSECに提出。2025年末から半年でARRを5倍に伸ばした企業が1兆ドル規模での上場を目指す。Claude Mythosは欧州ENISA限定評価中で、サイバーセキュリティ分野での軍民両用能力が問題になっている。SpaceX・OpenAI・Anthropicが3社同時に1兆ドル上場を狙う「AI IPO元年」が到来した。この週はシリコンバレーの歴史に刻まれるかもしれない。

FACT
【事実・概要】
Anthropic が6月1日にSECへ機密S-1書類を提出しIPO申請。評価額 9650億ドル（約140兆円）でOpenAI（8520億ドル）を抜き史上最高値のAI企業に
CONTEXT
【背景・要点】
ARR $47B（前年末$10B比約5倍）の爆発的成長が上場の後押し。Series H 650億ドル調達完了直後の申請で時価総額1兆ドルデビューを狙う
OUTLOOK
【影響・展望】
2026年はAI上場ラッシュの年：SpaceX・OpenAI・Anthropicが3社同時に1兆ドル規模の上場を目指す前例なき状況に

§04 ⌗ IT

IT — アクセンチュアのAI受注最高と日本SIerのコンサル転換競争

AccentureのAI関連受注が$22.1Bで過去最高。NTTデータの生成AIエージェント（150秒）が7月提供予定。日本のSIerがコンサル転換を急ぐ一方で、富士通の3000人リストラが示すように「転換に失敗したSIer」の行方も問われ始めている。NTTドコモ×アクセンチュアのWallet基盤は日本発グローバル展開の試金石だ。

FACT
【事実・概要】
Accenture がQ2 FY2026決算を発表（3月19日）。売上高 $18.04B（+8%） と堅調。AI関連受注 $22.1B でbookings過去最高を更新
CONTEXT
【背景・要点】
AI関連で四半期booking $100M超の顧客が記録的な41社に達成。生成AIを活用した大型案件が急増しており、コンサル業界のAI化が加速
OUTLOOK
【影響・展望】
「規模の生成AI」時代に入った：大手顧客がPoC（概念実証）から本番展開へ移行し、Managed Services（$9.2B）が成長を牽引
→ §04 IT 詳細を読む
§05 ◎ モビリティ

モビリティ — Waymoが10都市制覇、トヨタが撤退した同じ日

Waymoがテキサス4都市に一斉展開し商業拠点を10都市に拡大。対してトヨタはLexus EVを含む重要車種を廃止した。同日に「Waymoがスケール」し「トヨタが撤退」した構図は象徴的だ。2026年のモビリティ産業を二分する出来事が重なった。トヨタは全固体電池の量産化（住友金属鉱山との協業）という長期賭けを続けており、2027〜2028年に照準を合わせている。

FACT
【事実・概要】
トヨタ が計画していた重要EV車種（Lexus EV複数モデル）を廃止。EV需要減速と中国BYDのコスト圧力が意思決定の背景
CONTEXT
【背景・要点】
トヨタはEV販売目標を100万台（当初150万台から大幅下方修正）に縮小。HEV・PHEVとの並走戦略に軸足を移す
OUTLOOK
【影響・展望】
世界最大の自動車メーカーの戦略転換が市場に与えるシグナルは大きく、純EV一辺倒の波が引く可能性を示唆している
→ §05 モビリティ 詳細を読む
§06 ■ 経済

経済 — S&P500最高値更新の「狭い土台」とCPI3.8%のジレンマ

S&P500が7600台最高値を更新したが、上昇はNVIDIAを中心とした2セクターのみ。CPI3.8%という粘着性の高いインフレが「7月利上げ」の観測を呼んでいる。Warsh初FOMC後の市場反応が最大の注目点で、野村証は「利下げ転換」シナリオを維持しているが、ヤーデニ研究所は「利上げ不可避」と真っ向対立する。均衡なき議論が続く。

FACT
【事実・概要】
S&P500 が 7,599.96Pで最高値更新（6/2）。NVIDIA新型半導体発表で情報技術セクターが+2.48%上昇し指数を牽引
CONTEXT
【背景・要点】
11セクター中2セクターが上昇（IT・エネルギー）、9セクターが下落。原油高によるインフレ懸念が広範なセクターの重しに
OUTLOOK
【影響・展望】
狭い土台の強さ：AI半導体という一点に集中した上昇が続いており、ハイテク以外への波及が見えない構造的懸念も浮上
