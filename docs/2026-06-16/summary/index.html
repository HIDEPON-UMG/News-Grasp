§01 ★ 総論

総論 — 条件を握る側が相場も事業も動かす

日銀会合、OpenAIのスーパーアプリ化、Rapidusやホンダの供給網再設計が同じ日に並び、性能や台数の競争だけでは足りない局面が見えた。AIも為替も、結局は配布・回収・説明の設計で勝負が決まる。今日の共通項は、勝ち筋を作る前提条件を誰が持つかに尽きる。

§02 ¥ 為替

為替 — 利上げの有無より、その後の対話が試される

日銀は1%利上げ観測でも、ドル円は160円台前半で重い。市場が見ているのは決定そのものではなく、会見で追加正常化の道筋を示せるかだ。原油高の一服で地政学プレミアムが薄れても、円安の説明軸は金利差と政策信認へ戻る。相場は数字よりメッセージに反応している。

FACT
【事実・概要】
円相場は米イラン合意で地政学プレミアムが薄れても160円台前半にとどまり、日銀の利上げだけでは円買いが続かないという見方が前面に出た。
CONTEXT
【背景・要点】
市場が身構えるのは決定そのものより、会見で追加利上げの道筋を示せるかだ。説明が慎重なら「利上げ後の円売り」が再燃しやすい。
OUTLOOK
【影響・展望】
原油高懸念が和らいでも円が戻らないなら、焦点は金利差と政策信認へ移る。日銀が次の一手を曖昧にすれば、円安圧力は残りやすい。

§03 ◆ AI

AI — 安全性と収益化が同時に問われる

OpenAIは42州規模の調査とChatGPTのスーパーアプリ化を同時に抱え、Anthropicは高額プランの上限表示で集団訴訟に直面した。GoogleはGemini Liveを画像編集へ広げ、PerplexityはIPO日程を維持する。性能競争だけでは差がつかず、誰が責任を負い、どう課金し、どこまで生活導線へ入るかが争点になった。

FACT
【事実・概要】
OpenAIはChatGPTが子どもや弱者に与える影響を巡り、米42州の司法長官連合による調査を受けた。
CONTEXT
【背景・要点】
問われているのは性能より、依存やメンタル悪化をどう抑え、説明責任をどう果たすかという運用設計だ。
OUTLOOK
【影響・展望】
読者にとっては生成AI導入の比較軸が、機能差だけでなく規制耐性と安全ガバナンスへ寄ったと見るべき局面だ。
→ §03 AI 詳細を読む
§04 ⌗ IT

IT — AI投資の裏で、基盤・契約・権限が再定義される

MicrosoftのAzure鈍化と株主訴訟、AI一極集中によるメモリー7倍・電力制約、Anthropic輸出規制論、そして「SaaSの死」論が重なった。AIを入れるかではなく、基盤・契約・権限をどう組み替えるかが主語になっている。社内AI基盤の議論も、クラウド依存の見直しとして読んだ方が早い。

FACT
【事実・概要】
Microsoftが株主訴訟を受け、Azure鈍化を抱えたままAI投資を積み増す構図に市場の視線が集まった。クラウド覇権より、投資回収の説明責任が問われる局面に入っている。
CONTEXT
【背景・要点】
企業ITの現場では、成長率の高さよりもGPU投資と契約単価をどう回収するかが重要になる。ハイパースケーラー各社の値付けや案件優先順位にも波及しやすい。
OUTLOOK
【影響・展望】
読者が見るべきは、クラウド投資の前提がIRと需給の両面で揺れ始めた点だ。AI基盤の供給力と収益説明の整合性が、導入判断そのものになりつつある。
→ §04 IT 詳細を読む
§05 ◎ モビリティ

モビリティ — EVは販売より後処理と責任分担が焦点

ホンダEV中止の余波で部品19社が補償請求へ進み、EV廃電池の回収義務化も論点化した。世界のEV登録は5月に3%増だったが、中国では価格競争が収益を削る。T2の料金所実証は、派手な完全自動化より止まる場所をどう消すかに踏み込んだ。採算と後処理が普及の条件になった。

FACT
【事実・概要】
ホンダのEV計画中止が部品19社の補償請求に発展し、完成車の戦略変更コストが系列外まで波及した。
CONTEXT
【背景・要点】
争点は試作費ではなく、全量受注を前提に積んだ生産・投資計画を誰が負担するかに移っている。
OUTLOOK
【影響・展望】
読者視点ではサプライチェーン契約が開発中止リスクをどう織り込むかが次の焦点だ。
→ §05 モビリティ 詳細を読む
§06 ⬢ 製造

製造 — 量産前の周辺能力をどこまで厚くできるか

ラピダスはイタリア設計機関と提携し、トクヤマは台湾で高純度IPAを増産、JX金属は光通信材料を10倍へ引き上げた。国内では日産が湘南工場の役割を見直し、平田機工が熊本で新工場を本格稼働。工場を建てるだけでは足りず、工程と地域を先に強くする順序設計が競争力になっている。

FACT
【事実・概要】
ラピダスがイタリアの半導体回路設計法人とMOUを結び、量産前に不足しやすい設計側の知見を外部から取り込む布石を打った。
CONTEXT
【背景・要点】
焦点は工場建設そのものではなく、2ナノ量産へ必要な設計支援と検証体制をどこまで早く整えられるかにある。
OUTLOOK
【影響・展望】
先端半導体では、製造ラインの競争力が国際的な設計エコシステムの厚みで決まる。ラピダスの提携先拡大はその現実を映す。
→ §06 製造 詳細を読む
§07 ■ 経済

経済 — 景気の底堅さと供給制約の残り方を読む

IMFは世界経済の減速回避を指摘したが、米イラン合意後も物流正常化には時間がかかる。日本では4-6月GDP見通しが上方修正された一方、財政赤字は続く。長期金利の低下は安心感を生んだが、日銀会合と米指標が重なれば解釈はすぐ揺れる。景気の強さより供給制約と政策余地を追う日だ。

FACT
【事実・概要】
IMFは世界経済に減速の兆しは見えないとしつつ、中東情勢が再び物価と物流を揺らすリスクには高警戒を崩していない。景気の底堅さと地政学リスクが同居する局面だ。
CONTEXT
【背景・要点】
市場にとって重要なのは、成長鈍化の心配が薄れた一方でエネルギーと輸送の供給障害がインフレ再燃の火種として残る点だ。利下げ期待だけで相場を組み立てにくい。
OUTLOOK
【影響・展望】
読者が次に見るべきは世界経済の強さそのものより、原油・運賃・期待インフレがどこで落ち着くかだ。景気の主役は需要ではなく供給制約へ戻りつつある。
→ §07 経済 詳細を読む
§08 ▶ ゲーム

ゲーム — 発見導線と広告在庫の設計が勝負を決める

Steam Nextフェスは無料デモで夏商戦前の発見競争を加速し、EAは広告事業を立ち上げた。『めっちゃカメレオン』の急伸は配信映えの強さを示し、個人開発の77本販売は発見難の厳しさを映す。『シティーズ：スカイライン リマスター』も含め、売れるかどうかは露出の設計次第で、価格と導線が主役になった。

FACT
【事実・概要】
Steam で作品を出した開発者が、3年かけた新作の販売本数は77本 だったと明かし、注目獲得と購入転換の間に深い溝 がある現実を示した。
CONTEXT
【背景・要点】
作品品質だけでなく ストア露出 とウィッシュリスト転換が 初動の生死を分ける ため、個人開発の収益設計はますます厳しい。
OUTLOOK
【影響・展望】
ヒット作の急伸と同じ日にこの報告が目立ったことで、インディー市場 は 勝者総取りの傾向 と発見導線の偏りを同時に映している。
