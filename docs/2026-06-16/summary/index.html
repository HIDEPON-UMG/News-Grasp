§01
FOREIGN EXCHANGE / 為替

利上げの有無より、その後の対話が試される

FACT 事実・概要

日銀は1%利上げ観測でも、ドル円は160円台前半で重い。

CONTEXT 背景・要点

【事実】：円相場は米イラン合意で地政学プレミアムが薄れても160円台前半にとどまり、日銀の利上げだけでは円買いが続かないという見方が前面に出た。

OUTLOOK 影響・展望

【背景】：市場が身構えるのは決定そのものより、会見で追加利上げの道筋を示せるかだ。説明が慎重なら「利上げ後の円売り」が再燃しやすい。

§02
ARTIFICIAL INTELLIGENCE / AI

安全性と収益化が同時に問われる

FACT 事実・概要

OpenAIは42州規模の調査とChatGPTのスーパーアプリ化を同時に抱え、Anthropicは高額プランの上限表示で集団訴訟に直面した。

CONTEXT 背景・要点

【事実】：OpenAIはChatGPTが子どもや弱者に与える影響を巡り、米42州の司法長官連合による調査を受けた。

OUTLOOK 影響・展望

【背景】：問われているのは性能より、依存やメンタル悪化をどう抑え、説明責任をどう果たすかという運用設計だ。

→ §02 AI 詳細を読む
§03
IT & CONSULTING / IT

AI投資の裏で、基盤・契約・権限が再定義される

FACT 事実・概要

MicrosoftのAzure鈍化と株主訴訟、AI一極集中によるメモリー7倍・電力制約、Anthropic輸出規制論、そして「SaaSの死」論が重なった。

CONTEXT 背景・要点

【事実】：Microsoftが株主訴訟を受け、Azure鈍化を抱えたままAI投資を積み増す構図に市場の視線が集まった。クラウド覇権より、投資回収の説明責任が問われる局面に入っている。

OUTLOOK 影響・展望

【背景】：企業ITの現場では、成長率の高さよりもGPU投資と契約単価をどう回収するかが重要になる。ハイパースケーラー各社の値付けや案件優先順位にも波及しやすい。

→ §03 IT 詳細を読む
§04
MOBILITY / モビリティ

EVは販売より後処理と責任分担が焦点

FACT 事実・概要

ホンダEV中止の余波で部品19社が補償請求へ進み、EV廃電池の回収義務化も論点化した。

CONTEXT 背景・要点

【事実】：ホンダのEV計画中止が部品19社の補償請求に発展し、完成車の戦略変更コストが系列外まで波及した。

OUTLOOK 影響・展望

【背景】：争点は試作費ではなく、全量受注を前提に積んだ生産・投資計画を誰が負担するかに移っている。

§05
MANUFACTURING / 製造

量産前の周辺能力をどこまで厚くできるか

FACT 事実・概要

ラピダスはイタリア設計機関と提携し、トクヤマは台湾で高純度IPAを増産、JX金属は光通信材料を10倍へ引き上げた。

CONTEXT 背景・要点

【事実】：ラピダスがイタリアの半導体回路設計法人とMOUを結び、量産前に不足しやすい設計側の知見を外部から取り込む布石を打った。

OUTLOOK 影響・展望

【背景】：焦点は工場建設そのものではなく、2ナノ量産へ必要な設計支援と検証体制をどこまで早く整えられるかにある。

→ §05 製造 詳細を読む
§06
ECONOMY / 経済

景気の底堅さと供給制約の残り方を読む

FACT 事実・概要

IMFは世界経済の減速回避を指摘したが、米イラン合意後も物流正常化には時間がかかる。

CONTEXT 背景・要点

【事実】：IMFは世界経済に減速の兆しは見えないとしつつ、中東情勢が再び物価と物流を揺らすリスクには高警戒を崩していない。景気の底堅さと地政学リスクが同居する局面だ。

OUTLOOK 影響・展望

【背景】：市場にとって重要なのは、成長鈍化の心配が薄れた一方でエネルギーと輸送の供給障害がインフレ再燃の火種として残る点だ。利下げ期待だけで相場を組み立てにくい。

→ §06 経済 詳細を読む
§07
GAMING / ゲーム

発見導線と広告在庫の設計が勝負を決める

FACT 事実・概要

Steam Nextフェスは無料デモで夏商戦前の発見競争を加速し、EAは広告事業を立ち上げた。

CONTEXT 背景・要点

【事実】：Steam で作品を出した開発者が、3年かけた新作の販売本数は77本 だったと明かし、注目獲得と購入転換の間に深い溝 がある現実を示した。

OUTLOOK 影響・展望

【背景】：作品品質だけでなく ストア露出 とウィッシュリスト転換が 初動の生死を分ける ため、個人開発の収益設計はますます厳しい。

→ §07 ゲーム 詳細を読む
