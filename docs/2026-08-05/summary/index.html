§01
¥ FOREIGN EXCHANGE / 為替

介入規模が円安構造を試す

FACT 事実・概要

政府・日銀の円買い介入は7月30日・31日と8月3日の3日間に及び、市場推計で12兆〜13兆円規模に達した。

CONTEXT 背景・要点

2024年の過去最大規模を上回る可能性があり、単発介入ではなく、行きすぎた円安を生んだ需給と投資家行動の変化が問われる。

OUTLOOK 影響・展望

介入の継続性だけでなく、USDJPYの円売り圧力が弱まるか、日米金利差と円安構造が変わるかを見極めたい。

→ §01 為替 詳細を読む
§02
◆ ARTIFICIAL INTELLIGENCE / AI

AI競争を統制に戻す

FACT 事実・概要

OpenAIはAppleの提訴に反論する声明を公開し、両社のメールと元社員のiMessageを示した。公開日は8月5日。

CONTEXT 背景・要点

AppleはOpenAIに移った元幹部らの機密情報アクセスを問題視。OpenAIは、退職後のアクセス管理や連絡経緯に事実誤認があると反論した。

OUTLOOK 影響・展望

AI人材の移籍をめぐる争いは、機密情報管理と競争の境界を問う。今後は仮差し止め請求への司法判断が焦点になる。

→ §02 AI 詳細を読む
§03
⌗ IT & CONSULTING / IT

Consulting — クラウド成長と認証防衛

FACT 事実・概要

企業向けクラウド支出は2026年第2四半期に1434億ドルへ拡大し、前年同期比43%増となった。

CONTEXT 背景・要点

生成AI専用クラウドは前年比165%増。AWSが28%で首位を保つ一方、ネオクラウド9社が上位40社に入った。

OUTLOOK 影響・展望

AI計算資源の需要がハイパースケーラーと新興勢の双方を押し上げる。設備投資とGPU供給の競争が次の焦点になる。

→ §03 IT 詳細を読む
§04
◎ MOBILITY / モビリティ

EVと自動運転を実装へ

FACT 事実・概要

KDDIとKDDIスマートモビリティが堺市の自動運転タクシー実装コンソーシアムに参画する。通信・遠隔監視とGPU基盤を提供し、2028年のレベル4商用化を支える。

CONTEXT 背景・要点

車両と監視センターを常時接続し、地域固有の走行データをAIに学習させる構えだ。ドライバー不足への対応を、通信・計算基盤まで含む運行設計として進める。

OUTLOOK 影響・展望

実証の走行範囲、遠隔監視の安全運用、AI基盤の学習成果が次の確認点になる。堺市の取り組みが、自治体と通信事業者の標準的な連携モデルへ育つかを追う。

→ §04 モビリティ 詳細を読む
§05
⬢ MANUFACTURING / 製造

半導体と部材の供給再設計

FACT 事実・概要

熊本地震から1週間、半導体工場の復旧が進む一方、自動車部品工場では供給懸念が残る。ホンダ3工場は8月19日まで一部停止し、遠方工場への波及も続く。

CONTEXT 背景・要点

自動車は一部部品の滞りで完成車を作れない。部品供給網ではTSMCなどが通常生産へ戻る一方、再開後の品質確認が必要になる。

OUTLOOK 影響・展望

工場集積は効率を高める反面、災害時の集中リスクも増やす。生産集積の復旧に続き、物流と関連工場の平常化が次の焦点だ。

→ §05 製造 詳細を読む
§06
■ ECONOMY / 経済

AI投資の赤字を測る

FACT 事実・概要

スペースXの2026年4〜6月期は売上高が前年同期比92%増の78億1400万ドル。一方、最終損益は5億4100万ドルの赤字だった。

CONTEXT 背景・要点

AIとロケット部門の赤字を、通信サービスの収入で補う構図が続く。前年同期の赤字10億ドルからは縮小したが、投資負担はなお大きい。

OUTLOOK 影響・展望

売上成長だけでなく、AI投資を将来の収益へ変えられるかが評価軸になる。Starlinkの現金創出力と設備投資の回収を追う。

→ §06 経済 詳細を読む
