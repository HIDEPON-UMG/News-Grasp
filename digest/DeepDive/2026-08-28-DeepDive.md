## 注目点

```decision
{
  "issue":"2028〜2029年の供給時間差に対し、AI基盤の調達をGPU中心からどこまで広げるか",
  "options":[
    "GPUを先行確保し、HBM・ストレージは既存供給網の増産に委ねる",
    "GPU・HBM・NAND・先端パッケージを一体契約し、納期を束ねる",
    "需要を段階導入し、供給能力の確定分だけ計算資源を増やす"
  ],
  "deadline":"2026年11月末までにFY2027 Q3決算と次年度調達計画を反映する",
  "decider":["クラウド事業者の設備投資責任者","AI基盤を大口調達する企業のCIO・CFO","半導体・メモリーメーカーの投資委員会"]
}
```

[[最も堅い選択は、GPU・HBM・NAND・先端パッケージの納期を一体で管理することだ。]] **一体契約は価格交渉の自由度を下げるが、どれか一つの遅れでGPUが遊休化する危険を減らせる。** __米国の新規HBM量産が2029年後半となる以上、単価の最小化より稼働開始日の確度を優先すべきだ。__

[[段階導入は過剰投資を抑えられる一方、需要が上振れしたときに供給枠を取り戻しにくい。]] **各社は次の決算で売上成長だけでなく、メモリー契約量、実装能力、工場の量産開始時期を同じ表で確認する必要がある。** __見るべき指標はGPU発注額から、供給網全体の「利用可能になる日」へ変わる。__

## 要約

[[AI供給網の次の制約は、GPUからHBM・NAND・製造装置へ広がっている。]] **SK hynixの米国量産は2029年後半で、キオクシアも既存棟を使いながら新工場の時期を見極める。** __GPUだけを先行確保せず、メモリーと実装能力まで納期を束ねることが、供給時間差を越える鍵になる。__
