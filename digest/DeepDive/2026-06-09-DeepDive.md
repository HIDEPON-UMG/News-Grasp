__今日のリスクは、政策イベントが市場の短期評価を支配していることだ。__ GDP下方修正は景気の鈍さを示す一方、為替市場ではBOJ利上げ観測が残る。これは投資家にとって分かりやすい「弱い経済だから金融緩和」ではない。円安・物価・成長鈍化が同時に存在し、__どの変数を政策が優先するかが見えにくい__。そのため日経平均はAI期待を持ちながらも、地政学や金利イベントで売られやすい。

__一方で、供給網側のニュースは中期の下支えである。__ Denso が ROHM 買収案から距離を置きながら SiC 協業を維持すること、ROHM・東芝・三菱電機のパワー半導体連携、Toyota / TSMC / Denso の熊本投資は、車載・AI・EV の物理基盤を国内に厚くする動きだ。AIモデルや企業導入のニュースが増えても、電力、半導体、車載制御がなければ実装は続かない。**供給網投資は、市場が短期で荒れる日にこそ中期の評価軸になる。**

__問題は、その下支えが市場の短期不安を相殺できるほど速く数字に出るかだ。__ Fujitsu と Anthropic、NTT DATA と Google Cloud の動きは企業AIの受け皿を広げるが、収益・生産性・利益率に反映されるには時間がかかる。ロボタクシーでも、Tesla のFSD物語より Waymo の台数と運用実績が説得力を持ち始めている。**2026年の投資家は、発表ではなく「何台動いたか」「何社導入したか」「どれだけ利益率が上がったか」を見る。**

__読み筋は、短期は政策、中期は供給網である。__ 今日のGDP下方修正と日経平均下落だけを見れば、日本市場は弱い。しかし同じ日に、企業AIの導入基盤、車載半導体の国内供給、熊本ファブ、ロボタクシー運用台数の比較が出ている。これは、日本市場の評価軸が「マクロで買うか売るか」だけでなく、__AIと半導体をどこまで国内産業の実装力へ変えられるか__へ広がっていることを示す。

__私見では__、BOJ前夜の市場で最も危ないのは、AI期待が短期の政策不安をすべて吸収できると見なすことだ。AI・半導体投資は確かに中期の支えになるが、利益率や生産性に出るまでは時間差がある。**来週見るべきは、円相場の反応だけでなく、AI・半導体関連株が政策イベント後にどれだけ崩れず残るか**である。残れば、日本市場は「政策不安を供給網期待で吸収できる」段階に入る。崩れれば、AIプレミアムはまだ脆い。

## 要約

6月9日の日本市場は、__GDP下方修正、BOJ利上げ観測、USD/JPY 160円接近、日経平均のリスクオフ__が重なった。一方で、[[Fujitsu]] / [[NTT DATA]] の企業AI、[[Denso]] / [[ROHM]] / [[Toyota]] / [[TSMC]] の半導体供給網、[[Tesla]] / [[Waymo]] のロボタクシー台数差が、実装力を問う中期テーマとして並んだ。__短期は政策イベントが支配し、中期はAI・半導体供給網が支える__という二重構造が今日の本質である。来週の焦点は、BOJ後に円相場だけでなく、AI・半導体関連株がどれだけ持ちこたえるかだ。
