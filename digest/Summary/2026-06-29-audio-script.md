# ニュース グラスプ #20260629 音声朗読原稿

6月29日の朝のニュースをお伝えします。ニュース グラスプ、6月29日号です。今日は、AI の計算資源、IT の受け皿、モビリティの地図と制度、製造の投資と技能者、経済の規制対応が同じ朝に並びました。私はこの並びを、派手な新機能より、前提条件をどこまで厚くできるかが勝負になる朝として受け止めています。数字や見出しの強さより、計算資源、人材、データ、制度、調達先を先に整えた側が、あとから実装を進めやすい。今日はその差がかなりはっきり出ました。FX も 162 円台と月末フローが重なっていて、ひとつの材料だけでは読めません。だからこそ、きょうは「何が新しいか」より「何を先に用意したか」を聞く朝です。私はその見方のほうが、今日のニュースにはしっくりくると思っています。言い換えると、きょうの焦点は成果物そのものではなく、その成果物を支える土台の厚さです。そこが見えると、同じ記事でも読み方がかなり変わってきます。

まず為替です。日銀の正常化論が一段進み、植田体制の利上げペースが 27 年夏までの物価対応とつながってきました。USDJPY は 162 円台をうかがい、月末・四半期末フローと米雇用統計が次の揺れを作ります。韓国ウォンの介入観測や外貨差益課税も重なって、為替は水準だけで追うと少し足りません。私はここを、政策、資金の流れ、税務の三つが同時に相場を押す朝として聞いています。どれか一つではなく、三つが同時に動くと、数字以上に市場の呼吸が変わります。節目そのものより、節目の理由がどこにあるかを見たほうが、今朝は整理しやすいです。相場が先に反応して、あとから説明が追いかける場面では、言葉の順番まで見ると少し落ち着きます。

AIは、計算資源と防衛が主戦場に入った感じが強いです。Google が Meta 向け Gemini 利用を絞り、Anthropic の蒸留告発はモデル防衛を前に押し上げました。OpenAI の Codex は非エンジニア利用が 189 倍まで伸びていて、AI は答える道具から、長い業務を預かる道具へかなり移っています。富士通の PHOTON や Google の Study Notebooks も、性能と教育接点を広げる動きです。私はここを聞いていて、AI でもう「どのモデルが賢いか」だけでは足りず、「どの会社が計算資源と守り方と配り方を握るか」に話が移ったと感じました。便利さより先に、止め方と定着先が問われる朝です。使う側から見ると、速さよりも、どこで止めるか、どこで広げるかの方が先に知りたい条件になっています。

IT は、人手不足を切り出して埋める話が前に出ました。アストンは障害者雇用を IT 運用 BPO へつなぎ、法定雇用率の引き上げを商機に変えようとしています。メディアフュージョンは DX 実務向けの情報基盤を公開し、何を読ませ、何を標準化するかを前面に出しました。私はこの章を、機能追加の話ではなく、現場のしんどさを運用と導線でほどく話として聞いています。採用の課題も、DX の課題も、結局は業務の切り出しと情報整理の設計に戻ってきます。現場が回る形を先に作れるかどうかで、支援の価値が変わる朝です。外から見ると地味ですが、こういう整備がないと、あとで全部が詰まります。

モビリティは、地図と制度を先に整える空気がはっきりしました。交通空白を 2029 年までに解消する政策が前に出て、newmo の走行データ収集、May Mobility と CaoCao の提携、スズキのマレーシア EV 初投入が並びました。私はここを、車両の派手さより、地図、制度、販売網を先に整える地味な仕事が勝つ朝として受け止めています。実証のかっこよさだけではなく、商用に移す前提があるかどうかで、見え方がかなり変わります。道路データを積むことも、販売網を広げることも、どちらもすぐには目立たないけれど、あとから効いてくる準備です。きょうのモビリティは、その準備の差がよく見えました。運行の前段でどこまで地味な段取りを積めるかが、今日の静かな分岐です。

製造は、部材、施工、人材、安全を積む話でした。京セラの 6500 億円投資、鹿島の技能者 7500 人超、日揮HD の材料転換、IBM の 0.7nm 試作、フジキンの安全弁量産が同居しています。どれも表に出る機能ではなく、裏で支える工程の話です。私は、AI や半導体の需要を支えるのは、最終製品だけではなく、その手前にある部材、工場、施工、そして安全部材だとあらためて感じました。投資額が大きいだけでは足りなくて、実行の厚みがあるかどうかが最後に効きます。工場を建てる人、材料を切り替える人、止めるときの安全を担保する人まで含めて、今日の製造は厚みの勝負でした。供給網が詰まらないように先回りする姿勢が、結果として競争力になります。

経済は、体感と適応力で読むのがわかりやすい日です。高市内閣の支持率上昇と食品消費税案への賛否、人権デューデリジェンスの遅れ、今週の小売決算、トリドールのインバウンド需要が並びました。私はここを、景気を指数だけで追うより、家計の実感と企業の適応力を見るほうが今朝はしっくりくると感じています。規制対応も、消費の底堅さも、結局はどこまで調達先を見える化できるか、どこまで需要を受け止められるかに戻ります。小売や外食の話が多い日ですが、見えているのは単なる販売ではなく、需要を受け止める器の大きさです。そこが強い会社ほど、少し静かでも安定して見えます。数字の強さより、暮らしにどう返るかのほうが、朝の実感には近いです。
