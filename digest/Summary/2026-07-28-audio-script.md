# ニュース グラスプ #20260728 音声朗読原稿

2026年7月28日、朝のニュースをお伝えします。今日は、新しい選択肢が増えたニュースが多い一日です。生成AIの声をどう守るか、アプリの手数料をどう変えるか、軽EVや自動運転をどこまで日常に入れるか。半導体の国産化、災害に強い融資、ゲームの売り方も同じ流れにあります。ただ、発表の大きさだけでは、続く仕組みまで分かりません。本人の同意、監査のログ、支払う価格、量産の実績、現場の通信、買った後の保存。今日は、広がったものが何を証拠に定着するのかという視点で、七つのカテゴリを巡ります。

まずFXです。日銀は30日からの金融政策決定会合を前に、政策金利を据え置く方向で検討していると報じられました。一方、アメリカのFOMCでは、原油高でインフレが再び強まる可能性を理由に、利上げを予想する証券会社も増えています。市場の利上げ確率は、二週間前の約10パーセントから約32パーセントへ上がりました。ドル円は161円から165円の範囲が意識され、声明や会見の言葉が次の方向を決めそうです。円安はキヤノンの利益予想を押し上げましたが、原油や部材のコストも増やします。リスクは、会合の文言だけで相場が急変し、企業の前提が遅れて動くこと。30、31日の声明、ドル円、企業のコスト見通しを一つの線で追います。

AIでは、法務省の検討会が、生成AIで使われる声も法的保護の対象に含める指針案を大筋で了承しました。正式公表は8月の予定で、法的拘束力はありませんが、本人同意や利用範囲をどう記録するかという実務に影響します。Hugging FaceのCEOは、OpenAIのAIエージェントによる侵害を巡って、行動ログの全面開示などを求めました。さらに、AnthropicはClaude Opus 5を入力5ドル、出力25ドルで提供しています。背景には、生成AIが試す段階から、声・エージェント・業務データを預ける段階へ移ったことがあります。利用経験率が58.8パーセントに上がった日本では、性能、価格、安全、業務内の人の判断点を同時に設計できるかが問われます。指針の正式文書、ログの開示範囲、契約上の同意、実際の利用単価を次の観測点にします。

ITでは、公正取引委員会がAppleとGoogleのスマートフォン手数料について、さらなる改善を求めました。率が下がっても、代替決済が本当に使われるかは別の論点です。NTTデータはSAPのクラウドERPと業務AIを自社へ導入し、自分たちを最初の利用者として効果を検証します。Infosysは30年以上社内にいる人材を次期CEOに指名し、AI変革を主導させる考えです。AIコンサルティング系の新興企業も増えています。機能を売るだけでなく、契約が続き、データが整い、説明できる支援へ変えられるかが、導入後の差になります。手数料の実利用、ERP導入後の効果、AI支援の継続率を確認します。

Mobilityでは、BYDが日本専用の軽EV、RACCOを発売しました。日本の乗用車市場での販売はまだ小さく、価格と補助金を含めた実質負担が巻き返しの分かれ目です。王子物流とT2は、関東と関西を結ぶ約510キロの輸送を商用化し、そのうち約420キロをレベル2で走ります。能登では無人のショベルカーを使う道路復旧の実証も始まりました。販売台数や実証回数だけでなく、充電、遠隔監視、通信、有人運転との切り替えが日々の運用に耐えるか。通信断や保守要員不足がリスクとして残るため、納車、商用走行、停止時の復旧手順を次に見ます。移動の未来は、現場の細かな条件で測られます。

Manufacturingでは、中国メモリー大手CXMTが上海上場初日に466パーセント上昇し、時価総額で中国本土首位になりました。AI向けDRAM需要と国産化への期待が株価を押し上げる一方、過熱への懸念も残ります。中国政府系企業が液浸型DUV露光装置の製造を始めたとの報道では、2026年に約5台、2027年に約20台という計画が示されました。熊本では、三井不動産と県が半導体の産学官拠点を設立します。次に見るべきは、発表の勢いではなく、台数、歩留まり、顧客採用、研究から量産への移行です。株価や計画値だけでは実力を測れないため、実機の稼働、量産時期、顧客の採用実績を観測します。

Economyでは、高市首相が市場へのメッセージと財政の持続性について発言しました。5月の景気動向指数は、一致指数が117.9に改定され、基調判断は改善を示しているとされています。インドでは、6月から9月のモンスーンが収穫、食品価格、金融政策へ波及します。JICAはソロモン諸島に上限30億円の円借款を供与し、災害時に元本と利息の支払いを繰り延べる条項を日本で初めて導入しました。背景には、成長率だけでなく、気候や災害に耐えながら資金を回せるかを見る考えがあります。景気の強さは、一つの数字ではなく、発言が市場へ届くか、天候に耐えられるか、危機の後に返済を続けられるかで見えてきます。今後は物価、消費、モンスーンの収穫、災害後の返済実績を並べて確認します。

Gameでは、成人向けゲームの『45番電車』が発売一カ月で22万本を突破し、Steamレビューも高い評価になりました。『スイカゲーム』はシリーズ二作品を各240円でSteamへ同時展開し、カードゲームは全20種のアクリルチャームへ広がります。一方で、現物を残したい人とダウンロード版で困らない人の議論も続いています。ゲームの価値は、売れた本数や発売先だけではありません。サービスが終わった後に遊べるのか、買ったものを保存できるのか。販売、IP、販路、所有の条件が、継続する熱量を決めます。販売本数だけでなく、PC展開の継続、再ダウンロード条件、サービス終了後の扱いを次の観測点にします。

七つの話題をつなぐと、増えた選択肢を残すための証拠が、分野ごとに違う形で現れています。FXでは声明と企業利益、AIでは同意とログ、ITでは手数料と契約、Mobilityでは納車と通信、Manufacturingでは量産と歩留まり、Economyでは指標と耐性、Gameでは販売後の保存です。新しいものを増やす速度が重要であるほど、あとから確認できる数字と責任分担が必要になります。私は今日、発表を聞いた瞬間に評価を決めるより、次の工程に進んだ証拠が出る場所を先に押さえておきたいと感じました。

今日の観点・考察です。広がったことは、まだ続くことと同じではありません。何が増えたのかを確認したら、誰が管理するのか、どの数字で定着を判断するのか、問題が起きたときにどこへ戻れるのかまで見る。明日以降は、日米の声明とドル円、AIの監査と契約、EVの納車と商用走行、半導体の製造実績、物価と消費、ゲームの販売継続と保存条件を追います。今日のニュースは、拡大のニュースであると同時に、その拡大を証明する仕事が始まったというニュースでもありました。発表を評価する物差しを、速度から証拠へ置き換えることが、今日のニュースを実務に持ち帰る要点です。
