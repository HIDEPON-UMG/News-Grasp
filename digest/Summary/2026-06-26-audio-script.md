# ニュース グラスプ #20260626 音声朗読原稿

6月26日の朝のニュースをお伝えします。ニュース グラスプです。今日は、AIが画面操作まで取り込み、会計SaaSが業務実行基盤へ寄り、ホンダがEVの配分を組み直し、追浜工場が防衛生産の候補になり、米景気はなお堅調という並びでした。私はこの朝を、技術の見栄えより、どこで運用し、どこで回収するかが先に見えた日として受け止めています。まずは全体を一つの流れとして聞くと、あとで各カテゴリを追いやすくなります。今日は「試す」から「回す」へ寄った変化が、いくつもの記事に重なっていました。しかも、AI は操作そのものをモデルに取り込み、IT は人が触るソフトから業務を動かす仕組みに寄り、製造は工場の使い道を組み替え、経済は景気の底堅さを確認する流れでした。見出しは別々でも、聞き方をそろえると一本の線でつながります。今日のニュースは、単発の新機能というより、導入後に誰が責任を持つかを先に考えたほうが筋が通る材料が多いです。

為替からいきます。ドル円は161円台後半で踏みとどまり、PCEの後に7月利上げ観測が少し後退しました。ただ、日銀の段階利上げ観測と介入警戒が消えたわけではなく、私はここを値段の上下というより、金利差の説明がどちらへ傾くかで聞くほうが整理しやすいと思っています。7月利上げ確率が約30%まで下がった一方で、ユーロドルは原油安とECB観測の後退を織り込んでいて、相場は次の指標待ちです。為替は、節目そのものより、節目を支える理由がどう変わるかを見ると流れが追いやすいです。

AIでは、Gemini 3.5 Flash に Computer Use が標準で入ったのが大きいですね。画面操作を別モデルに切り出さずに済むので、長い手順を任せる設計がかなり組みやすくなりました。OpenAI の Codex が社内で主力AIになった話も同じ並びで、AIは質問に答える道具というより、仕事を長く預ける相手に寄ってきています。Anthropic の蒸留攻撃告発は、モデル競争が安全保障の話に近づいていることを示しましたし、公取委の生成AI素材問題も、権利の有無だけでは足りず、どう審査したかが問われる段階を示しています。一方で、NEC の cotomi が秘匿計算下でも実用圏に近づいたのは、守りながら使う道が見えてきたという意味で大きいです。攻めの機能と守りの説明を同時に設計する必要があるので、私はこの分野を、性能競争よりも、どこまで説明して守れるかの競争として受け止めました。

ITは、freee の動きがとても分かりやすいです。会計SaaSが、画面を触る場所から業務を動かす場所へ寄っています。KPMG の顧客理解AIエージェント支援や Fortinet のSOC統合も、結局は往復をどこまで減らせるかの話でした。freee は MCP と 382 本のAPI を出しながら、介護現場の経費精算を月30分から2分へ縮めた事例も示していて、PoC ではなく運用KPIの世界に入った感じがはっきりあります。Amazon の大型投資は派手ですが、聞きどころは金額より、実務の接続点がどれだけ増えるかです。細かな自動化より、現場が戻るための逃げ道を残しつつ速度を上げられるかが勝負です。私はこの分野では、機能の数より、人が介入できる設計のほうが重くなったと感じています。

モビリティは、ホンダのEV見直し損失が象徴的でした。勢いよくEVへ寄せるのではなく、ハイブリッドを軸に再配分し直す局面です。そこにロボタクシーの欧州展開、ブレーキペダル義務の見直し、V2Gの商用化、中国の充電網の急拡大が重なり、車そのものより制度と充電回路が市場を決める空気が強まりました。中国の充電網は2249万基まで広がり、自宅充電の裾野も厚くなっています。私はここを聞きながら、完成車の話より、走らせ続ける仕組みのほうが主役に移ったと受け止めています。

製造は、追浜工場の転用協議が一番インパクトでした。自動車工場がドローン量産拠点へ向かうなら、国内の遊休設備は別用途に再配置されます。IBM のサブ1nm、TSMC の値上げ、トーヤクの新工場、日機装の太陽光稼働も並び、工場は単に増やす場所ではなく、材料、電力、用途を組み替える場所になっています。IBM は 0.7nm で 3D 積層の性能5割向上を狙い、TSMC は 3nm から 7nm まで 5〜10% 値上げを通知しました。新設だけでなく、既存設備の転用速度も競争力になります。私はこの並びに、量産の論点が作る話から、何をどこで回すかの話へ移った感じを受けました。

経済は、IMF の米景気堅調評価とGDP上方修正、NY株続伸が同じ方向を向いていました。利下げ期待が後退しても株が崩れないのは、景気の底堅さが先に見えているからでしょう。日本では高市首相が総債務対GDP比低下を財政目標の中核に据えましたが、ここでも大事なのは数字そのものより、どの物差しで信認を守るかです。GDP は年率2.1%増でも個人消費は 0.5% 増に鈍っていて、企業投資と家計消費の温度差が見えます。日本オラクルの最高益も、企業IT投資がなお強いことを裏づけました。私はこの章を、景気そのものより、市場が納得する枠組みをどう置くかの話として聞きました。

今日の観点・考察です。AI は性能より運用、IT は機能より業務実行、モビリティは車両より制度と充電、製造は設備より転用と電力、FX は水準より金利差、経済は景気そのものより信認の物差しでした。つまり今日は、各分野で何を作るかより、誰が回し、どこで回収するかが先に見えた日です。今日はまだ入口の確認でしたが、明日はその入口が本当に数字へつながるかを見れば、朝のニュースの筋が一段はっきりします。回転を始めた仕組みは、最初は小さく見えても、定着すると次の判断をかなり楽にしてくれます。そこで回り始めたものだけが、次の見出しで大きく見えてきます。その差は見逃せません。
