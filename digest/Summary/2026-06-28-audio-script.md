# ニュース グラスプ #20260628 音声朗読原稿

6月28日の朝のニュースをお伝えします。ニュース グラスプです。きょうは、AI と IT が「どこまで任せるか」に寄り、FX は 162 円台の節目、モビリティはルールと商用化、ゲームは運営と販路が並んだ日でした。私はこの並びを、性能や台数の話より、回収の線を先に引いた会社が静かに強く見える朝として受け止めています。見出しは違っても、実際にはどれも、作ったあとに誰が回し、どこで戻すかを先に決める話でした。耳で追うと、今日は「作る」より「任せる」が先に来ています。AI も IT も、答えを返すだけでなく、長い業務を預ける相手として見られ始めていますし、モビリティもゲームも、出口まで含めた設計がなければ回り切りません。そういう意味で、きょうは見た目の派手さより、回収の段取りが静かに効く朝です。だから、今日は数字の並び以上に、境界線の引き方を聞く日でもあります。そこが見えると、ニュースの並び方がかなり素直に読めます。

最初に為替です。ドル円は161円台後半を保ち、政府の骨太方針に金融政策が明記される見通しや、来週の米雇用統計が、162円台を試すかどうかの分岐になっています。個人の円安期待はまだ強いのですが、AUDJPY や NZDJPY では先に重さが出ていて、私はここに、円安一色では説明し切れない空気を感じました。相場の水準だけを追うより、どの言葉が次の値動きを作るのかを聞くほうが、今朝は整理しやすいです。政策メッセージと指標待ちが同時にあると、数字より先に参加者の身構え方が変わりますし、そこが変わると、同じ 1 円の動きでも見え方がかなり違ってきます。輸出入の採算を気にする人にとっては、節目そのものより、節目を支える理由がどう変わるかのほうが大事です。市場が見ているのは、円の強弱より、誰が説明の主語になるかです。説明の重心がどこに移るかで、次の一手の出し方も変わります。

AIに移ると、空気はさらに分かりやすくなります。OpenAI の Codex は非エンジニア利用が 189 倍まで伸び、Google は Computer Use を標準統合、Anthropic は米国内限定で再開と、どの会社も「どのモデルが賢いか」ではなく、「どこまで任せるか」を競っています。これは、AI が相談相手から業務の委任先へ移ってきたということです。私はここを聞きながら、便利さそのものより、止め方と配り方を先に決めた側が強いと感じました。モデルの見栄えが同じでも、運用の線を引けるかで使い勝手はかなり変わりますし、現場では「使えるか」より「途中で戻せるか」が安心材料になります。人が一つひとつ確認する時代から、確認の手順を先に作る時代へ寄ってきた、そんな印象です。任せる量が増えるほど、管理表のほうも厚くなる朝です。設定を詰める手間は増えますが、そのぶん、次に何を見ればいいかがはっきりしてきます。

ITは、その委任を実際に回すための土台が前に出ました。AMD の CIO は AI 導入後の複雑性を本丸に置き、infonerv は在庫戦略から実行までを担うエージェントを出し、freee は会計 API を受発注に接続しました。ここで大事なのは、単に便利な機能を増やすことではありません。監査、権限、例外処理まで含めて、現場が戻れる設計になっているかです。私はこの章を、ソフトを足す話ではなく、業務を薄くつなぐ話として聞いています。導入が進むほど、見えない運用の厚みが評価される感じがかなり強いです。案件の会話でも、何を入れるかより、誰が止めて誰が継続判断するかのほうが先に出てきます。実装が進むほど、説明責任のほうが目立つようになるのが今の IT です。画面の新しさが話題でも、現場は結局、障害時の戻し方で安心します。そこまで含めて設計できるかで、案件の重さが変わります。つまり、IT は「動くか」だけでなく、「止めるか」「戻せるか」まで評価される段階です。ここが固まると、導入の速度も落ち着いてきます。

モビリティは、走る車そのものより、通すルールと広げ方が主役でした。自動運転レベル4の国際ルールが決まり、May Mobility と CaoCao は 10 万台計画を掲げ、Tesla は FSD の移行条件を変え、Leapmotor は累計 150 万台を超えました。私はここを見て、ロボタクシーも EV も、性能だけで押し切る局面ではもうないと受け止めました。どの地域で、どの規則で、どの運行網から広げるか。順番を間違えると、いい技術でも商売に乗りにくくなります。技術の話に見えて、実際には運行と収益の設計の話です。車両が増えるほど、現場の運行責任、充電の段取り、利用者への説明が重くなるので、今日の材料はその準備の差もよく見せています。個社の競争より、地域ごとに広げる順番の違いが見えやすい朝です。そこを先に押さえた会社が、あとで回しやすくなります。ルールが先に立つと、売り方より通し方が見えてきます。現場の体感としては、車の話より、広げるための手順書の話に近いです。

ゲームは、続けて売るための仕掛けが並びました。GBVSR は Switch 2 と同時展開で入口を広げ、NIKKE は夏イベントで話題を持続させ、Garbage Growth は Steam 初動で小さくても効く経路を見せ、鈴木一也さんの新企画はベテランの現役感を見せています。私はこの章を聞いて、発売日そのものより、その後にどう語られ、どう運ばれるかのほうが重いと感じました。IP は一度出して終わりではなく、継続導線があるかで寿命が変わります。今日は、派手さの裏で運営の作り込みが見える朝でした。新作の発表が多い日ほど、実は継続の線をどこに置くかで差がつきますし、その線が太い作品ほど、次の話題もつながりやすくなります。短期の初速より、話題が途切れない導線づくりのほうが地力になります。小さく見える手当てが、あとで効いてきます。見逃しやすいですが、ここがかなり大事です。聞き終わるころには、単発のヒットより、熱をつなぐ仕掛けのほうが印象に残るはずです。

最後に、今日の観点・考察です。6月28日は、任せる範囲と回収の線を先に引けるかが分岐でした。AI は委任の範囲、IT は接続の厚み、モビリティはルールと運行網、ゲームは販路とイベント、FX は節目と政策メッセージです。明日は、この線が本当に持つのか、それとも少し緩むのかを見れば、流れはかなり追いやすくなります。ニュース グラスプでした。今日の整理はここで区切ります。ここまでお聞きいただき、ここまでお聞きいただき、ありがとうございました。朝の見出しは増えても、回す順番が見えていれば、判断はむしろ落ち着いてきます。それを聞けば、明日の見出しも少し落ち着いて追えます。私は明日も、数字の先にある境界線を意識して追っていきます。

補足すると、今日の材料は新しい機能の多さより、どの条件を先に満たすかを見た方が整理しやすい一日でした。
